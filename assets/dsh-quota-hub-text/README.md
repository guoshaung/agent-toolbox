# Toolbox 额度中枢文本适配

DSH 标准会话会发送大量工具定义和前导内容，额度中枢的优先通道可能拒绝。此插件仅在本机 `127.0.0.1:18879` 接收 DSH 请求：识别并剔除已验证的 DSH 前导结构，保留最近的用户与助手纯文本消息，再转发到 `DSH_HOME/toolbox-quota-hub-text.json` 配置的额度中枢地址。远端的 `auto` 负责通道优先级与故障切换。

此路由是**连续纯文本对话**：保留最近最多 20 条文本消息与约 12,000 字符上下文；不传工具定义、图片、文件或系统前导，不适合需要工具调用的任务。每次请求的输出上限为 4096 token。请求正文、回答和密钥不写日志。接口仅在 DSH 运行期间监听本机环回地址，仍由远端网关校验 Bearer 密钥。
