# Avatar library sources

These thumbnails are extracted, without modification, from the embedded previews
of seven VRoid Studio beta sample models. Each original VRM declares `CC0` in
`extensions.VRM.meta.licenseName` and permits use by everyone. The catalog pins
the source commit and SHA-256 of every original file.

- Models and original previews: [VRM samples, pinned revision](https://github.com/madjin/vrm-samples/tree/e16eb187100149a315ad92c3c9968f1d5baa6c7d/vroid/beta)
- Creator: pixiv / VRoid Studio beta sample models
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- [Official Sendagaya Shino source and license](https://vroid.pixiv.help/hc/en-us/articles/360013482714-Sendagaya-Shino)
- [Official Sendagaya Shibu and Darkness source and license](https://vroid.pixiv.help/hc/en-us/articles/360012381793-%CE%B2-Ver-AvatarSample-1)
- [Official Sakurada Fumiriya source and license](https://vroid.pixiv.help/hc/en-us/articles/360014788554-Sakurada-Fumiriya)

Full model data is downloaded on demand into the user's `avatar-models` folder,
verified against the catalog, and reused offline. Existing imported VRM files
are kept in place. The newer stable AvatarSample A/B/C models are not included.
