# 语音输入工具

对着说话，识别出的文字自动粘贴到你指定的应用里（比如终端）。

## 第一次用：填 Key

1. 把 `resources/voice_config.example.json` 复制一份改名为 `voice_config.json`
2. 填进去两处（都在火山引擎控制台拿）：
   - `asr.api_key` —— 语音识别
   - `tts.api_key` + `tts.speaker` —— 语音合成，只用识别的话可以不填
3. `injector.app_name` 填你想把文字粘到哪个应用，比如 `"iTerm2"`、`"Terminal"`。留 `null` 就粘到当前最前面的窗口。

> 随工具箱分发的这份**不含任何 Key**，是空的示例。Key 属于你自己，别提交到任何仓库。

## 启动

在「容器」里点这个文件夹上的 ▶ 就行。第一次会用 `uv` 自动建虚拟环境装依赖，要几十秒。

手动启动的话：

```bash
uv run main.py
```

## macOS 需要的权限

粘贴用的是「辅助功能」权限：系统设置 → 隐私与安全性 → 辅助功能，把运行它的那个终端（或工具箱）勾上。不给权限的话识别正常但粘不进去。
