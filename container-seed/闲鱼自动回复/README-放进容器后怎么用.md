# 闲鱼自动回复

闲鱼多账号自动回复 / AI 回复 / 虚拟商品自动发货，本机运行。
基于开源项目 [zhinianboke/xianyu-auto-reply](https://github.com/zhinianboke/xianyu-auto-reply)（AGPL-3.0）。工具箱只带启动脚本，不带它的代码：第一次运行时按 `run.py` 里固定的版本拉取。

> 只支持 macOS。需要本机有 `git`、`uv`、Node.js 18+（和本机同架构，nvm 装的也能自动找到）。

## 启动

在「容器」里点这个文件夹上的 ▶。

第一次会自动装好所有东西，要 5～10 分钟（都走国内镜像）：上游代码、Python 依赖、MySQL 8.0、Redis、浏览器内核、前端。之后再点 ▶ 十几秒就起来，浏览器自动打开 http://127.0.0.1:9000 。

手动启动：

```bash
python3 run.py
```

只安装不启动：`python3 run.py --setup-only`。

## 第一次用

1. 后台登录：`admin` / `admin123`（这是这个系统自己的账号，不是闲鱼的），**登录后马上改密码**。
2. 账号管理 → 添加账号 → **扫码登录**，用手机闲鱼「扫一扫」。没有短信验证码登录。
3. AI 回复：选 OpenAI 兼容接口，例如 DeepSeek：地址 `https://api.deepseek.com`，模型 `deepseek-chat`，填你自己的 Key。
4. 按商品配关键词回复、自动发货内容。

## 数据和安全

- 所有东西都在这个文件夹里：数据库 `.runtime/mysql-data`、Redis `.runtime/redis-data`、日志 `.runtime/logs/`。
- 数据库 / Redis / JWT 密码第一次运行时随机生成，存在 `.runtime/xianyu.env`（仅本人可读）。**不要把 `.runtime/` 发给别人或提交到任何仓库**，里面有你闲鱼账号的登录凭证。
- 所有服务只监听 `127.0.0.1`，别人访问不到。端口：前端 9000、后端 8089/8090/8091、MySQL 3307、Redis 6380，不会和本机已有的 MySQL(3306) / Redis(6379) 冲突。
- 上游默认会拉作者服务器的广告、公告，并开启商品自动采集，这里都关掉了。

## 要一直在线

Mac 睡眠就会掉线。插电时可以在终端运行 `caffeinate -s` 防止睡眠。

## 风险提示

这类工具通过模拟闲鱼网页版收发消息，平台可能判定为非人工操作并限制账号；登录凭证过期后需要重新扫码。只卖你有权销售的东西。
