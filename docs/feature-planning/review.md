# 新增功能设计核对记录

本记录核对的是 200 项功能设计的结构、计数与范围，不代表实现通过或真实客户端可用。基线源码为 `0d945d8`，版本 `0.43.5`，现有入口 38 个。

## 结构与数量

三份设计源 JSON 经严格 UTF-8 读取和解析，学习 60 项、工具 100 项、娱乐 40 项，共 20 个模块，每个模块 10 项。编号连续：L001 至 L060、T001 至 T100、E001 至 E040。全部 200 个编号、功能名唯一；名称、输入、输出、验收条件没有完全相同的字符串。

每项包含问题、输入、输出、最小交付范围、验收条件、硬依赖、执行方式、优先级、规模、建议执行位置和与现有功能的区别。合并目录另记录状态、候选批次、联网需求和平台目标。5 个候选批次各 40 项，均为学习 12、工具 20、娱乐 8。

自动检查结果保存在 [validation.json](validation.json)，可通过 `python docs/feature-planning/build_catalog.py` 重新生成总目录和详细规格。自动检查无法证明语义没有重复，因此另做了下述交叉审查。

## 交叉审查与修正

| 条目 | 审查发现 | 最终设计处理 |
|---|---|---|
| T001、T067、L027 | 三者若只校验 JSON Schema，会重复计数 | T001 检查生产数据；T067 比较接口契约版本的破坏性变更；L027 采用预测反例、揭示误判和修正规则的学习闭环 |
| T013、T014、T098 | 静态校验与复制的简单组合不足以成为另一项新能力 | T098 改为基础与增量版本链、删除重放、链断裂检测和历史状态恢复演练 |
| L054、T090 | 学习排程与工时容量容易混在一起 | L054 按前置与日预算生成顺序；T090 只检查用户已指定日期的负荷，不自动排程 |
| L058、L059 | 单次验收与长期证据追踪边界不清 | L058 冻结一次作业的量规、哈希与检查报告；L059 追踪跨版本、有效期与不同证据 ID，不把附件存在自动判为能力 |
| T031、T040、E016、E018 | 图片加工、遮盖和创作可共享底层但不能重复计数 | 分别限定为批量交付规格、截图指示及遮盖、表情包配字、四格叙事；不都扩成通用图片编辑器 |
| T044、T045、E014 | 音频处理与采样创作需要区分 | 分别限定为响度统一、确认静音后裁剪、按键触发切片并录制表演；E014 明确格式解码范围 |
| T022 | 文字提取不到敏感词不足以定义永久遮盖 | 先遮盖位图，再创建全新纯图像 PDF，不沿用隐藏文字、对象、附件、批注或旧元数据；明确搜索能力损失 |
| T063 | 代理路径不能直接观测代理端目标 DNS | 区分本机代理地址解析、TCP、CONNECT、目标 TLS 和首字节；代理侧目标 DNS 标未知 |
| T031、T042 | 体积上限的输入、MVP 和验收未对齐 | 限定尝试次数，成功产物必须实测达标，无法达标时返回失败，不降低规格后默称成功 |
| T025、T011 | 输出或验收与范围描述不一致 | T025 明列尺寸、字体、加密和附件；T011 明确是有预演与撤销的原地改名，不称副本处理 |
| L024、L011、L029 | 验收需要明确的模型与前提 | 补齐性质关系、流水线转发/延迟规则和已知好坏二分边界，避免无法重复的验收 |
| L033、L047、L053、L055 | AI 可选用途没有进入 MVP | 明确候选材料、对应片段、错误标签和变化维度建议，确认后才进入结果 |
| L055、L060 | 证据覆盖、个人分差可能被误称为迁移或因果证明 | 仅报告证据绑定覆盖与匹配材料的描述性分差，不自动证明掌握、迁移或因果效果 |
| T079 | 权限状态可查询程度依平台不同 | 不启动采集；公开接口无法确定时报告未知，不猜测拒绝 |

现有番茄钟界面已移除，声音克隆只是预告，Voicebox 是外部应用启动壳。设计中的边界描述已修正这些旧说明。娱乐玩法也对照了现有内置与网页游戏入口，避免再次列入 2048、数独、俄罗斯方块、现有棋类和流光记忆等。

## 可用性与实施边界

本地计算与是否需要网络分别记录，网络诊断并不因在本机执行而变成离线能力。AI 可选条目保留手工或本地路径。PDF 写入、办公文档、图像编码和部分结构数据处理库尚待选型；FFmpeg、OCR 和相关模型需要额外运行环境。图像、音乐、题库和游戏关卡优先使用项目原创或许可证明确的内容，完成前不能仅靠占位素材验收。

学习模拟器应明确教学模型的简化条件，不冒称真实硬件测量。统计类功能首版限定为所列公式和输入检查；产品实现时还需核对退化情况、样本条件和数值稳定性。

这次只新增设计文档、结构化目录及生成检查脚本。没有修改应用运行代码，没有安装依赖、启动应用或宣称 200 项已实现。后续逐项开发仍需完成库选型、接口定义、真实 UI 和产物验证。
