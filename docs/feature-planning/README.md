# 新增 200 个实用功能设计

本设计为 agent-toolbox 增加 200 个可独立验收的功能，分为学习 60 项、工具 100 项、娱乐 40 项，严格对应 6∶10∶4。它是开发提案，所有条目的状态均为待开发，不代表已有实现或运行验证。

基线为 2026 年 10 月 2 日读取的 `main` 提交 `0d945d8`，源码版本 `0.43.5`，现有 38 个注册入口。新增数量不包含现有能力。首要桌面平台为 Windows x64，同时保留 macOS ARM64 的适配路径；专属系统能力需显式标注。

## 功能计数规则

一个功能必须完成一个明确用户任务，有可描述的输入、可使用的输出和可独立验证的验收条件。同一任务的导入格式、导出格式、配色、模板和设置项合并计数；同一练习换学科、同一游戏换皮肤不增加数量。公共组件、文件选择、进度条和依赖检测是实现基础，不占 200 项。

现有能力的扩展可以计数，但必须说明用户新获得的能力。例如，本地批量数据清洗可以与已有在线网站入口区分；把已有网页入口改名不能计数。复杂能力按其最小可交付范围验收，尚未完成的后续扩展不提前计数。

## 可用性定义

本地处理能力应在断网和未配置 API Key 时完成核心任务；主动网络诊断则明确访问用户指定目标，网络断开时如实报告可观测失败。执行方式与联网需求分开记录，不能把本地运行等同于全部可离线。AI 可选能力必须提供可用的本地或手工路径。AI 必需功能应在执行前显示当前供应商、发送内容与调用状态。依赖外部软件、模型或系统权限的功能，应明确给出缺失项和用户可选择的准备方式，不能展示一个按钮就算完成。

文件写入采用预览后另存副本，确需修改原文件时提供明确范围与回滚记录。批处理应逐项报告结果，可取消，并保留已成功的产物。系统诊断默认只读。娱乐功能应能暂停、重置、退出，不使用强制通知、无限签到或故意增加难以退出的机制。

## 优先级与规模

- P0：高频使用、效果直观、依赖少，优先验证完整闭环。
- P1：有清晰价值，但需要较完整的数据模型、文件工作流或复用基础。
- P2：涉及较重运行时、硬件、平台适配或复杂模型，先验证可行性。
- S：单一局部流程，主要是本地算法或界面交互。
- M：跨步骤状态、批处理、较复杂编辑器或主进程服务。
- L：复杂解析、运行时集成、模型或平台差异明显。

规模是相对工作量判断，不是交付时间承诺。发布批次是按比例和依赖初步排序的候选开发范围，实际进入批次前仍需逐项明确接口、可行性和实现测试。

## 与现有项目的衔接

沿用原生 JavaScript/CSS、工具生命周期和现有 IPC 白名单。复用 AI、文件选择、配置、文献、媒体和系统能力。工具内部按功能模块组织，优先挂到现有工具；需要新增入口时只增加少量工作台，不把 200 项全部塞进侧栏。

大文件、PDF、音视频和批处理在 Worker 或受控后台进程执行，界面只处理交互与进度。执行位置不等于安全隔离：外部进程仍受用户账户权限约束。新能力的 IPC 应校验参数和目标路径，默认接收用户显式选择的文件或目录。

继续使用 `config.json` 保存小设置；新增项目记录、复习数据、作业结果和导出文件应分目录保存，并采用带版本的数据格式。大型数据不整批写入全局配置，也不在启动时把 200 个面板全部常驻创建。

## 技术依据与实施边界

项目已有文件对话框与主进程服务，可以复用 Electron 的原生多文件选择和保存能力，具体接口参见 [Electron dialog 官方文档](https://www.electronjs.org/docs/latest/api/dialog)。实现时需按当前 Electron 33 的可用接口核对，而非假定最新版接口全部存在。

项目使用 PDF.js；它适合 PDF 解析与显示，写入、合并和页面编辑仍需单独选择处理库，参见 [PDF.js 官方说明](https://mozilla.github.io/pdf.js/)。不能把现有阅读器视为已提供 PDF 修改能力。

音视频转换设计可使用独立 FFmpeg 服务；媒体输入输出和转换参数的依据见 [FFmpeg 官方文档](https://ffmpeg.org/ffmpeg.html)。FFmpeg 二进制、打包许可、编解码器和平台可用性必须另行核对，当前设计不假定应用已内置。

生成的功能名和价值判断是本次产品设计提案。API 可用性、依赖版本、性能上限和系统适配必须在各功能开发前验证。现有目录中的番茄钟旧说明、声音克隆预告和外部应用启动壳不作为已经完成的新功能。

文字配色功能首版只检查 WCAG 2.2 的文本对比度，不把一个颜色检查结果称为全应用无障碍合规。普通文本与大文本阈值分别为 4.5∶1 和 3∶1，计算结果不得先四舍五入再判断，依据见 [W3C 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。

设备权限诊断只使用平台可提供的公开状态；未知或不支持时显示未知，不为了检测而开启采集。Electron 媒体权限接口存在平台差异，实施前应核对当前版本，参见 [Electron systemPreferences 文档](https://www.electronjs.org/docs/latest/api/system-preferences)。
