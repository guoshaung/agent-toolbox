# 桌宠：四行快速解释

桌宠服务于代码阅读训练，不是聊天入口。默认关闭，也不会扫描或追踪整个项目。

## 使用

1. 在左侧打开「桌宠」，配置皮肤、大小、透明度、贴边与置顶行为，再打开总开关。
2. 阅读代码时先理解整体框架。只有某个函数、语法或调用确实卡住时，复制那一小段并点击桌宠。
3. 可补充语言名和一行「我卡在哪里」，然后点「解释当前层」。知识卡顶部按自然阅读顺序固定返回四行：这一行在做什么、关键写法、为什么要这样写、你现在只要记住。
4. 点「查看语法拆解与例子 ↓」可在同一张卡内查看语法拆解、真正的知识点、八行以内的最小例子和当前调用关系。补充区默认折叠并独立滚动，不会撑大桌宠窗口。
5. 标题栏的 `A−` / `A+` 可在紧凑、标准、舒适三级字号间切换，选择会自动保存在本机。
6. 桌宠不会自动追踪调用链。只有点击「向上一层追溯」才会发起第二次请求；若剪贴板已有新复制的调用处或定义，会优先使用它。没有上层上下文时，模型必须说明信息不足，不能猜项目细节。

## AI 配置与密钥

桌宠使用「设置 → AI 接口」里的 OpenAI-compatible Base URL 和模型名。先安全保存 API Key，再点「查询模型」；若端点不支持 `/models`，可手工填写模型名。

API Key 通过 Electron `safeStorage` 加密后存放，只在主进程中解密，请求时不会传入页面上下文，也不会在 UI 回显。旧版明文配置会在系统安全存储可用时自动迁移并删除。不要把真实 Key 写进源码、文档或问题截图。

## 皮肤

内置「蓝白学习助手」是项目原创 SVG，透明背景，适合屏幕边缘小尺寸显示。也可以导入本地 PNG、WebP 或 GIF（最大 8MB）。请只使用你有权使用的素材；应用不会联网下载第三方角色。

## 验证

```bash
npm run check
npm start
```

手工检查：桌宠默认不出现；打开总开关后在屏幕边缘出现；拖动后贴边；点击后展开知识卡；关闭主窗口后的行为遵循平台惯例（Windows/Linux 退出应用，macOS 仍可常驻并从 Dock 重新打开主窗）。

若开发运行被 `SIGTERM` 中止，先确认终端是否由开发运行器主动收尾，再检查是否已有 Electron 实例或调试端口占用。可用干净终端直接执行 `npm start` 复现；应用级错误会出现在该终端或 DevTools，而正常的运行器关闭通常只有信号退出、没有 renderer/main 异常堆栈。
