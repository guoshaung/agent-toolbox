# Goal：文档 → 有动效的 PPT → 配音讲解

> 起点：视频栏目已经能「B 站视频 / 本地视频 → 字幕 → AI 报告 → 飞书文档」。
> 终点：同一份报告一键变成每个元素会滑入 / 滑出的 PPT，每页带字幕和朗读，最终用我自己的克隆声音。

## 先把话说清楚：几个判断

- **现成的 pptx skill 不够用。** 它（以及工具箱里科研栏目的「PPT演示」）走 pptxgenjs，只会放静态元素；
  PowerPoint 的动画是 `p:timing` 那段 XML，pptxgenjs 根本不生成。要动效只能自己写这段 XML 注入进去。
- **不是生图。** 页面里的东西是标题、要点、图标、流程框、数据卡、截图——都是「组件拼装」，
  用矢量组件库 + 科研素材站的免费图 + 代码画的图（SVG）就够，不需要文生图模型。
- **动效在两个地方都要有：** 工具箱里自己的播放器（HTML/CSS 动画，所见即所得，能配音）和导出的 .pptx
  （PowerPoint / Keynote / WPS 打开也有动画）。播放器是主战场，pptx 是交付物。
- **配音分两步：** 初版用 Voicebox 默认音色（工具箱已经接了 `voicebox:tts`）；声音克隆要训练算力，放最后。

## 里程碑

### M1 · 文档 → 动效 PPT（先做这个）
1. **大纲**：AI 把报告 Markdown 拆成 8–15 页，每页给 `title / bullets / visual`（visual = 一段结构化描述：
   流程 3 步、对比两列、关键数字 3 个、一张截图…）。
2. **组件库**：`deck/components.js` —— 标题块、要点列、流程链、对比栏、数字卡、图文卡、引用块、代码块。
   每个组件是 DOM + 一份「动画脚本」：进场（左滑 / 上浮 / 淡入 / 缩放）、强调、退场；哪些元素静止由 AI 按内容定。
3. **播放器**：`deck/player.js` —— 16:9 舞台、按空格 / 点击逐步触发动画、进度条、演讲者备注。
4. **导出 .pptx 带动画**：pptxgenjs 出静态版 → 解压 → 给每页 `slideN.xml` 注入 `<p:timing>`
   （fly-in / fade / wipe 对应 PowerPoint 预设 id）→ 重新打包。用 PowerPoint 和 Keynote 各开一次验证。
5. 入口：视频栏目报告卡上加「转成动效 PPT」；科研「PPT演示」也能吃同一份 deck。

验收：拿一份真实的 B 站视频报告，一键出 12 页左右的动效 PPT，播放器里逐元素动、导出的 pptx 在 Keynote 里动画能播。

### M2 · 素材
- 优先级：内置矢量组件 → 科研素材站（已接在科研栏目里，免费）→ 代码画 SVG（示意图编辑器已有）→ 截图。
- 加一个「素材槽」：每页 visual 需要图时，先在本地素材库找，没有再开素材站搜索，都没有就 AI 画 SVG。

### M3 · 字幕 + 默认音色朗读
- 每页 `narration` 字段（AI 从备注生成，口语化，30–60 字/页）。
- Voicebox 默认音色逐页合成 wav，播放器按页播放并显示字幕；导出 pptx 时把音频嵌进每页（`p:audio`）自动播放。
- 可选：导出成 mp4（播放器录屏）。

### M4 · 克隆我的声音
- Voicebox 支持音色训练但要算力，不做实时；做成后台任务：录 2–3 分钟样本 → 排队训练 → 训好后 M3 的音色下拉里多一个「我的声音」。

## 不做的
- 不上文生图模型；不做 3D；不做 PPT 模板市场。

### M1 实测（2026-09-20）
拿「低空无人机通信与感知2025」那份 5039 字的飞书报告跑通：
AI 排版 12 页约 3 分钟（结果会缓存，再开是秒），导出 12 页 / 10 页带动画 / 48 个点击步骤。
每页 XML 合法、cTn id 不重复、动画指向的形状都存在。

### 做的过程中踩到的
- pptxgenjs 不生成 p:timing，动画只能自己拼 XML 再塞回 zip
- AI 给的 step 会撞车（两栏对比标 step 1，下一块标 step 2，于是第二栏和下一块同时冒出来），
  改成按块顺序自动重排，每一步只发生一件事
- 一次吐 14 页 JSON 要两三分钟，超时先给到 6 分钟，并把结果按报告内容哈希缓存
