# iPad 与电脑同步绘图

入口：**更多轮盘 → 绘图同步 → 同步绘图**，也可在命令面板搜索「同步绘图」并固定到侧栏。「绘图同步」是轮盘第一圈的独立分类，同组还提供设备传图。

## 连接

1. 电脑点击「打开绘图本并启用 iPad 同步」。首次连接会展开配对面板；以后可点工具栏「连接 iPad」查看二维码。
2. 原生 iPad 应用：打开「Toolbox 绘图本」→ 左上角「配对」→ 扫描二维码，或粘贴电脑复制的完整地址。首次允许本地网络权限，核对四位设备编号；右上角显示「已同步 · 待同步 0」表示连接成功。
3. 网页模式：使用系统相机扫描并在 Safari 打开。可在 Safari 分享菜单选择「添加到主屏幕」。系统相机打开网页不会自动给原生绘图本配对。

配对面板默认收起；远端窗口连接后自动收起，画布使用剩余空间。需要连接其他设备时仍可手动展开。工具栏统计的是远端同步窗口，不能等同于独立设备数；本机画布连接不计入。断开后不会强行展开二维码。

复用 `localsend.json` 的持久 ID、四位编号与设备名，不重新生成设备身份。编号用于辨认设备；二维码额外包含仅绘图服务使用的随机凭据。首次仍需二维码或电脑地址：Safari 不能单凭编号发现局域网内的电脑。多网卡时可在配对面板选择地址并复制。

支持 Safari 网页绘图，以及独立的 [PencilKit 原生 iPad 应用](../mobile/ipad/README.md)。原生版最低 iPadOS 16，未上架 App Store；构建的未签名 IPA 需要使用自己的 Apple ID 或开发证书签名后安装。电脑需保持 Toolbox 和绘图连接运行；没有云中继，跨网络需要两台设备能通过 VPN 等方式互相访问。服务使用局域网 HTTP，应在可信网络使用；未自动配置公网端口、开机项或防火墙规则。

## 绘图功能

- 多页绘图本；空白、点阵、方格、横线四种纸张。
- 钢笔读取 Pointer Events 压力值；高亮笔；整条笔迹橡皮擦。
- 套索以对象中心圈选，拖动选中对象；图片可单击选中并缩放。
- 仅 Pencil 模式防止手指画线；移动工具、双指缩放、鼠标滚轮平移及缩放。
- 撤销、重做；电脑 `Ctrl/⌘+V` 粘贴图片，也可拖入或从相册选择。
- 双向同步笔迹、图片、对象位置和纸张。书写时发送临时预览，抬笔后保存完整压感笔迹。
- 导入 PDF 为分页图片底稿，可继续手写批注。单次不超过 20 MB / 30 页；PDF 文字、链接和原始矢量不会保留为可编辑对象。
- 导出当前纸张 PNG；绘图本 JSON 备份包含全部页、对象、图片和待同步操作。首版尚无 JSON 备份导入界面，请同时保留电脑数据目录。

网页增强：笔迹采用可调压感曲线和平滑轮廓；预览通过 requestAnimationFrame 合并绘制，已完成的整页笔迹缓存在独立画布，不因每个笔移动事件重复绘制。预测点仅用于瞬时预览，不进入保存与同步。旧笔迹保留原有渲染方式。

触屏默认仅 Pencil 绘图；Pencil 接管时取消未完成的手指操作，落笔与抬笔后 650 ms 内拒绝掌触导航，宽接触及第三指阻断缩放。两指正常接触用于平移和缩放；可显式关闭「仅 Pencil」允许手指绘制。pointercancel、丢失捕获和焦点离开不会将未确认的临时笔迹保存为完成笔迹。笔刷参数在落笔时锁定，避免一次书写中颜色或粗细突变。

原生版用 `PKCanvasView` / `PKToolPicker` 处理笔输入和掌触，保留 PencilKit 原始笔迹并附跨端点数据。跨端移动笔迹后清除原生原位置数据，避免返回 iPad 时跳回旧位置。2026-10-24 已在 iPad 真机验证 Pencil 笔迹回传、电脑笔迹及图片下发；延迟量化、长期使用和完整掌触场景仍需独立验收。

## 保存与同步

电脑数据独立保存在 `userData/drawing-sync/`：

- `notebook.json`：纸张、矢量笔迹、图片引用、顺序与操作去重记录。
- `assets/`：解码并规范化后的 PNG，按内容哈希命名。
- `pairing.json`：绘图专用连接凭据，请勿公开。

首次修改先落盘，再通知客户端成功。浏览器使用 IndexedDB 保存待提交笔迹；网页已经打开的情况下，即使连接暂时中断也可继续书写，连接恢复后补传。**断线时不支持导入新图片/PDF，也不保证能离线重新打开网页。** 重要内容应同时保留电脑目录备份。

各设备独立新增笔迹不会互相覆盖；同时编辑同一个对象时按服务器收到的最后操作生效。撤销基于当前浏览器的操作历史，可能改回另一个设备刚调整的同一个对象；复杂协同编辑的冲突提示与按对象版本撤销尚未实现。

上限：100 页、12,000 个对象、48 MB 绘图本状态、256 MB 图片库、100,000 条操作编号。图片单次上传不超过 8 MB，服务端缩至最长边 2400 像素。首版保存一个共享绘图本；多本管理与历史版本属于后续功能。

「停止连接」关闭网络访问并保留绘图本。「重新配对」轮换绘图凭据，旧链接失效；不会更改 LocalSend 身份、原有手机配对、字体、API Key 或其他偏好。

## 验证与范围

自动化服务测试覆盖身份复用、鉴权、来源限制、图片解码、持久化失败、操作去重、重连与 SSE。隔离 Electron 双窗口联调覆盖并发笔迹、压力数据、图片、撤销/重做、离线补传、多页、PDF 底稿和桌面 iframe 嵌入；使用临时数据，不修改实际用户配置。

原生 0.2.1 修复了 SSE 接收后没有反应的问题。排查、签名、直接 USB 安装与真机验证步骤见 [iPad 联调记录](IPAD-INTEGRATION-NOTES.md)。

这是独立实现的手写同步工作流。Goodnotes 的手写识别、搜索、自动形状整理、多笔记本管理与 PDF 矢量导出尚未实现。没有复用 Goodnotes 二进制、资源或私有服务。

参考：[Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)、[压力值](https://developer.mozilla.org/en-US/docs/Web/API/PointerEvent/pressure)、[Apple 的 iPad 网页应用说明](https://support.apple.com/en-bw/guide/ipad/ipad8f1f7a29/ipados)。
