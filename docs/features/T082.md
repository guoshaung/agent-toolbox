# T082 日期工作日计算

## 功能内容

按用户明确选择的每周工作日与手填假日，计算起止日期之间的工作日数量，或从开始日期向前/向后推算指定工作日数。区间可以分别选择是否计入开始日、结束日；明细逐日显示星期、是否工作日和排除原因，可导出完整JSON副本。

## 为什么需要

估算一个截止日期或可用工作时间时，直接相减自然日会忽略周末、休假及不同工作周。工具将全部假日输入和计入端点规则放在结果旁边，方便团队确认采用的同一口径，而不假设各地节假日相同。

## 实现方式

模型严格解析YYYY-MM-DD并回查日期，范围1900–2100；使用UTC日期整数按86400000毫秒递增，避免本机夏令时造成23或25小时的“天”。这只是日历日期运算，不把输入解释成某地时刻。

工作周是0–6的明确集合，至少一天；假日用Set去重。排除条件为“不是选定工作星期”或“自定义假日”，两个条件同时满足只排除一次，完整保留两个原因。假日统计和非工作星期统计允许重叠，不应相加当作总排除数。

推算从开始日的下一/上一自然日开始计数，不把开始日算作第1工作日；正数向未来，负数向过去，0直接返回开始日期，即使当天是休假。结果保留经过的全部日期，日期越界拒绝输出。UI最多展示每页50天，所有日期包含在JSON中；文本安全渲染，不改变输入文件和系统日历。

## 如何使用

1. 功能工作台搜索T082或“日期工作日计算”。
2. 选择区间数量或推算日期模式，填写开始日期及结束日期/工作日数。
3. 勾选每周实际工作的星期，输入自定义假日，每行一个完整日期。
4. 区间模式核对两端是否计入；推算模式明确排除开始日。
5. 点击“按当前规则计算”，核对数量、推算结果及逐日排除原因。
6. 导出日期计算JSON并选择新的文件名；已有文件不会被覆盖。输入改变立即使旧结果失效。

## 使用后产出

完整JSON含格式及功能编号、模式、工作周/唯一假日、日期运算口径、端点选择或推算方向/时长、结果日期、自然日与工作日数、总排除数、两类排除统计、每一天的星期和原因。不保存到全局配置，不自动创建任务或日历事件。

## 具体例子

点击“载入周三休假示例”：2026-06-01周一至06-05周五，两端计入、工作周一至五，假日06-03周三。输出5个计入日期、4个工作日、1个排除日，周三原因为“自定义假日”。取消两端计入后，只有周二、三、四共3自然日，其中2工作日。

推算模式从06-01增加4工作日，同一假日和工作周下依次计入06-02、06-04、06-05、06-08，得到06-08周一。06-06和06-07按非工作星期排除；开始日06-01不计数。周五增加1工作日得到下周一，反向从周一减1工作日回到周五。

## 验证与限制

六项测试覆盖计划四工作日样例、端点包含/同日、假日去重及重叠原因、正反/零推算、仅周日工作的特殊规则、闰日/跨年/夏令时日历、非法日期、日期/区间/假日/时长上限。宿主与真实写入由集成记录补充。

区间最多3660自然日，推算时长−1000至1000整数工作日、最多遍历12000自然日，假日最多500个。使用用户提供的固定周规则，不联网更新法定节假日，不推断调休工作日，不含小时、地区法规、日期事件或跨会话恢复。某个休息星期的调休上班不能单独覆盖；需用户调整规则或分段计算。
