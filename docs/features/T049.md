# T049 音频信号质量检测

## 1. 功能内容

选择本地 WAV，逐样本只读计算声道峰值、RMS能量、dBFS、直流均值、全零/低能量状态和接近满幅的连续候选区间。提供实际帧编号与对应秒数、位深/采样率/时长，以及可选期望采样率不匹配检查。先显示完整结果，预览后保存JSON或Markdown报告新副本。

当前支持little-endian RIFF/WAVE内的PCM 8/16/24/32位或IEEE float32，1–8声道、1k–192kHz。最多16MiB、200万帧、300秒、128个RIFF块、10000段候选区间；超限整份拒绝。不是所有音频格式解码器，不支持MP3/AAC、压缩WAV、WAVEFORMATEXTENSIBLE、RF64/RIFX或多data块。

## 2. 为什么需要这个功能

录音交付前需要确定一个声道是否完全没有信号、哪些片段频繁贴近数字满幅，以及采样率是否符合项目要求。工具给出可定位的事实和阈值，让用户回到编辑器核查；不会凭听觉猜测质量，也不会自动修改原录音。

接近满幅可能是正常瞬态，不能据此证明削波；全零声道也可能是有意留空。报告称“满幅候选”，用户需要结合录音用途和波形判断。

## 3. 实现方式

model.mjs使用DataView直接读取RIFF块和交错音频帧，不建立WebAudio播放上下文、不启动扬声器。核验RIFF声明长度、块边界/奇数填充、唯一fmt/data、格式字节数、声道块对齐、byteRate与完整帧数，拒绝截断、重复或含NaN/Infinity的音频。未知元数据块只跳过，不导出其正文。PCM8按无符号128中点，其他PCM按相应有符号满量程分母，float保留超过±1的有限值并单独计数。

声道RMS=sqrt(sum(x²)/N)、均值=sum(x)/N、峰值=max(abs(x))；dBFS=20log10(幅度)。零幅度的dBFS为null并明确表示−∞，不是遗漏。allZero按每个样本精确零判定，lowEnergy按用户RMS阈值，不混用两者。abs(x)>=满幅阈值的连续帧合并成半开区间[startFrame,endFrameExclusive)，只导出至少指定连续样本数的候选；阈值样本数仍包含被连续长度过滤掉的短段。

每8192帧让出事件循环、检查取消并反馈进度。取消/隐藏/离开不会发布部分报告；回来不会自动检测。规则或来源改变废弃旧结果与预览。文件选择保留本次File引用，显式检测才读取，来源没有写操作、没有自动草稿或音频内容导出。

使用[Microsoft WAVEFORMATEX](https://learn.microsoft.com/en-us/windows/win32/api/mmreg/ns-mmreg-waveformatex)和[Microsoft RIFF说明](https://learn.microsoft.com/en-us/windows/win32/xaudio2/resource-interchange-file-format--riff-)核对块、PCM/float格式和对齐关系。本实现采用明确限定的WAV域，不依赖平台可变的音频解码支持。

完整报告先在textarea显示，再调用生产preload saveText，能力必须saveTextSupportsCopyOnly===true，payload为copyOnly:true，生产writer用wx防止覆盖任何已有文件。仅ok===true显示成功，取消/异常/拒绝保留预览。

## 4. 如何使用

1. 在新增功能工作台打开T049，选择支持的WAV文件，或点“载入空声道与满幅示例”。选择后不会自动播放。
2. 设满幅绝对幅度阈值0.5–1、候选最少连续样本1–1024、低能量RMS阈值0–0.1。可选填期望采样率；留空时不判断是否符合项目采样率。
3. 点“只读检测完整音频”，查看全部声道指标和clipCandidates。区间同时给精确帧数和按采样率转换的秒数，便于在编辑器定位。
4. 调整阈值后重新检测，旧报告不会继续可导出。长音频可点取消，结果不会是半份。
5. 预览完整JSON/Markdown，核对后保存报告新副本，选择新文件名。原WAV不会被修复或覆盖。

## 5. 使用后产出与具体例子

产出T049-quality-report.json或.md，含format、rules、summary与全部channels，每声道含峰值/RMS/dBFS/均值、全零/低能量、阈值样本数/比例、超过±1计数和全部候选区间。没有原音频样本、metadata原文或文件系统路径。

内置示例为16位双声道8kHz、8000帧、1秒：声道1全零；声道2在帧2000–2399取32767，其余为0。默认阈值0.999、连续1样本，输出allZeroChannels=[1]、声道2 thresholdSamples=400、一个区间startFrame=2000/endFrameExclusive=2400/startSeconds=0.25/endSeconds=0.30，峰值32767/32768，区间400样本。声道1 rms=0、rmsDbFS=null（−∞）。它是接近满幅候选，不声称已有可听失真。

独立计算例：float单声道样本[-1,0,1,0]，峰值1、RMS=sqrt(0.5)、均值0、峰值0dBFS、RMS约−3.0103dBFS；候选为[0,1)与[2,3)。将最少连续样本设2，两段不导出，但thresholdSamples仍为2。
