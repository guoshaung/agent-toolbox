# T077 开机启动项只读审计

## 1. 功能内容

在功能工作台打开 T077，读取当前 Windows 的 HKCU/HKLM Software\Microsoft\Windows\CurrentVersion\Run、RunOnce，分别保留 Registry32 / Registry64 来源；另枚举当前用户和公共 Startup 文件夹的顶层项。每项提供名称、来源、注册表值/文件类型、可靠解析的本地目标、存在/失效/未知、原因码和人工核对建议。不同注册表视图可能指向同一底层项，仍保留来源，不自动去重。

支持导入本地启动项描述 JSON。导入来源明确标为 user-imported-descriptors-not-live-config，不能当作当前注册表配置。启动目录中的快捷方式、脚本、目录、链接和复杂启动命令保留未知。每项启用状态和启动成功为 unknown / not_measured。

## 2. 为什么需要

目标移走或卸载后，启动配置可能留下旧条目；保留来源和未知证据的清单便于人工排查。存在性不能归因登录缓慢、证明项目启用、判断恶意性或程序完整性。本功能不禁用、删键、移文件、执行启动命令、结束启动程序、修改防火墙或安装依赖。

## 3. 实现方式与明确范围

自己的 host.cjs 通过生产 features.callHost / cancelHost 执行固定只读查询。系统安装路径限定 C:\Windows；固定 System32\WindowsPowerShell\v1.0\powershell.exe 使用 -NoProfile -NonInteractive -EncodedCommand、shell:false、隐藏子进程和只含四个系统定位变量的环境。模块自动加载关闭，只导入系统绝对路径 Utility 模块；用户输入不拼入脚本。注册表使用 OpenSubKey(path,false)，值用 DoNotExpandEnvironmentNames 读取，所有句柄 finally.Dispose()；没有写入 API。

脚本只查固定键、Startup 顶层元数据和 DriveInfo 类型。目录拒绝 UNC、祖先/自身重解析点，不解析快捷方式或遍历子目录。只确认 DriveType.Fixed 磁盘上的可靠绝对 exe，拒绝映射网络盘、UNC、设备路径、ADS、遍历、保留名或不明确路径。文件检查从盘根逐级 lstat，祖先/目标链接不跟随；仅 ENOENT 标失效，权限等异常保持未知。读取前后仍有路径变化竞态，不提供原子检查或执行保证。

接受带引号的绝对 exe 路径后跟参数，或不含空白的绝对 exe 路径后跟参数。无引号含空格路径、相对命令、脚本、rundll32/cmd/PowerShell/wscript 等启动器保留未知。仅展开 SYSTEMROOT/WINDIR/PROGRAMFILES/PROGRAMFILES(X86)/LOCALAPPDATA/APPDATA/USERPROFILE，展开后仍需本地固定盘与路径校验。原命令和参数仅在宿主/编辑输入当前内存，不放入结果、DOM 结果、配置或导出；名称及目标路径仍有隐私。编辑区保留原文可主动显露，CSS 遮盖不是 DOM 权限隔离或加密。

最多总计200项，单名称256字符、命令4096字符、路径1024字符/32段。stdout+stderr 共256KiB；某来源超过200项则该来源 unknown，其他来源保留；可读来源合计超过200项整份拒绝，不截断冒称完整。查询预算15秒，超时/取消只终止自己的固定查询子进程；文件系统调用不能硬终止，可能继续等待，返回后检查取消和期限，不提交迟到的存在性。每 sender 单任务、最多32 sender、128 jobID、全宿主四个尚未 close 的查询进程。首次 await 前登记任务，提前取消记录意图；隐藏、暂停、销毁取消并使晚结果失效，切回不自动重跑。

输入 strict JSON，64KiB UTF-8，8层/1500节点，拒绝重复字段、未知字段、错误版本、非法来源、重复 source+name、非法 Unicode/控制字符。桥的64KiB payload 限制仍适用，转义后超限也拒绝。完整报告上限2MiB。无网络/AI/账户/第三方安装包；实际平台依赖 Windows / 固定系统 PowerShell，其他平台/能力缺失未知或拒绝。

官方依据：[Run / RunOnce](https://learn.microsoft.com/windows/win32/setupapi/run-and-runonce-registry-keys)、[OpenSubKey 只读重载](https://learn.microsoft.com/en-us/dotnet/api/microsoft.win32.registrykey.opensubkey?view=net-9.0)、[RegistryValueOptions](https://learn.microsoft.com/en-us/dotnet/api/microsoft.win32.registryvalueoptions?view=net-9.0)。RunOnce 是系统的一次性启动机制；本工具读取不触发它。键和目录清单不等于完整平台启动机制。

## 4. 如何使用

1. 打开 T077，点击“读取当前 Windows 启动项”，读取本机元数据，无额外执行许可勾选。创建界面或填样例不会查系统。
2. 查看全部来源状态和逐项结果。unknown 不证明安全、失效或无启动项；没有失效也不意味已定位登录慢原因。
3. 可展开导入区，选本地 JSON，或显露后编辑，点击“检查快照中的本地目标”。导入先校验不自动检查；目标检查前固定查询本机磁盘类型，不回写源文件。
4. 预览完整 JSON/MD，再保存新副本。依赖 saveTextSupportsCopyOnly，只有 ok===true 成功。取消、false、undefined、异常保留预览；已有文件不覆盖。
5. 清除输入与报告释放内存引用。切换具体功能销毁面板，未保存内容不保留。遮盖的编辑区原文仍在当前内存/DOM 属性，报告的名称与路径分享前核对。

## 5. 使用后的产出

T077-startup-report version 1：来源、时间/实际耗时、平台、非原子声明、确认的固定盘根、容量、全部来源状态/数量、每项存在性/原因/建议及汇总。JSON 和包含同份完整数据的 MD 都创建新副本，不含启动命令、参数、输入正文或注册表全文。权限失败/取消保留未知。

未覆盖服务、计划任务、驱动、Winlogon、UWP、组策略等，不读取 StartupApproved，因此不报告启用状态。缺失目标不意味着条目一定会被运行。没有修复按钮，人工修改需在系统对应界面独立完成。
