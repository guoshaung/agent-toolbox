# E036 慢慢涂色

## 1. 功能内容

十二张原创闭合矢量线稿，共96个唯一编号区域：茶杯与书、山间日出、小屋花园、海上小船、城市街角、星空帐篷、荷塘小景、果篮午后、蝴蝶花园、猫咪窗台、几何花园、音乐时光。每幅图的主题、布局和路径不同，不是同一图换色。所有可涂区域是单独闭合path，固定描边；一次点击仅修改目标区域。

提供12色可见调色板、系统颜色选择器、六位HEX自定义颜色、区域选择控件、单区域清除、最近100步撤销、每幅图独立进度、自动继续上次全部作品、JSON存档和当前完整SVG/PNG副本。没有计分、标准答案、计时、动画、摄像头或网络请求。

## 2. 为什么需要

无需自己画图，也不用猜正确数字答案，只需选喜欢的颜色并点区域。作品独立保留，切换主题不会清掉已涂内容；键盘/控件也可完成区域操作。自动存档让重开后接着涂，JSON新副本作为独立备份；完整矢量/图片便于保存或分享。

## 3. 实现方式与边界

`model.mjs` 内置十二张自制程序路径，每图7–9个区域，区域编号含主题前缀且全局唯一。所有区域path以Z闭合，使用SVG原生独立填色，不做像素洪水填充；固定轮廓和叠置关系由源线稿决定。例如猫爪覆盖身体底部，但点击身体不会同时改变猫爪色表。标题/页脚是固定中文程序文本；区域颜色只接受 `#RRGGBB`，输入小写规范成大写。没有导入用户SVG、脚本、资源网址或网络字体。

状态 `schema:1` 只保存当前图、当前颜色、十二张图的区域颜色表和撤销记录。未涂区域缺省为白色；主动选择白色也保存为已涂，进度为色表条目数/本图区域总数，清除会删除条目。颜色数不是分数，100%没有正确性含义。同色重复点击不产生撤销步骤；真正改变颜色或清除才入历史。历史为全部主题合计最近100步，超过100时明确滚动移除最早步骤；撤销切换到受影响主题并恢复原色/未涂状态，其他区域保持。

状态、JSON草稿和文件≤64KiB UTF-8，逐文件严格UTF-8解码；精确根字段、schema1、十二张颜色表、已知图/区域、规范颜色、最近100步容量和可逆撤销链全部校验。撤销链从当前色表反向核对每一步after值，拒绝不一致记录；未知区域、未知字段、重复JSON键、损坏JSON/UTF-8、未来schema和超限输入均拒绝，不截断颜色或偷偷继承未知版本。线稿路径、渲染结果、DOM、PNG不写配置。

自动保存使用生产 `ctx.config` 的同步get/异步set门面，仅写 `featureLab.E036.archive`；该数据使用同一64KiB schema输入校验。保存调度有界：最多一份正在写入的完整快照和一份最新待存快照，快速操作合并中间待写请求；完整最新快照仍含所有区域和最近100操作。写入失败明确提示，内存作品不丢；可重试或另存JSON。旧自动档若损坏或未知版本，保留它，暂停自动覆盖；用户可手动另存当前作品，或勾选确认后明确允许替换旧档。缺ctx.config时说明手动保存/恢复方式，不声称重开已自动保留。

生产Config经preload IPC写主进程Store，现有Store负责临时文件+rename。本模块不更改公共配置实现，不保证应用被强杀/断电前未确认的快照已落盘；关闭前应看到“已自动保存”。已提交的有界自动存档可在离开/销毁后完成，界面回调不再访问新模块。

图形无RAF和定时器，只在输入变化时重画。景观使用click委托，点击背景无区域时忽略；不捕获Pointer、不实现绘画拖刷，也不安装全局鼠标监听。生命周期销毁移除UI、景观click、document可见性监听，撤销Blob URL；离开/隐藏/销毁使尚未提交的异步读取/PNG结果失效。

SVG完整输出800×600，PNG是同幅安全SVG经本地Blob→原生Image→Canvas编码，包含中文标题、全部区域和自由配色页脚，限10MiB。规范Base64和SHA-256交生产二进制桥重验；依赖公共二进制基础 `c0c93aa`（PR #14）。JSON/SVG用 `saveText({content,extension,defaultName,copyOnly:true})`，PNG用 `saveBinary({copyOnly:true,defaultName,base64,sha256})`；检查对应SupportsCopyOnly===true，老接口缺失时禁用。只有ok===true显示成功，取消/错误/partialPath明确区分，已有目标独占创建失败，绝不调用覆盖图片接口。

PNG生成捕获一份有效输入快照。生成期间继续上色、改颜色、换图或恢复会增加代次，使旧结果在原生写入前失效；可主动取消本地生成。进入原生另存后锁输入，需在对话框取消；不能宣称终止浏览器底层解码或已经提交的原生请求。SVG/JSON生成同步完成后立即进入原生另存。

## 4. 如何使用

1. 打开“慢慢涂色”，有有效自动档时直接恢复上次十二图作品与撤销记录；无档时从茶杯与书开始。
2. 在“线稿主题”选图，点击可见色块，或用“颜色选择器”；自定义输入例如 `#abcdef` 后点“使用自定义颜色”，规范成 `#ABCDEF`。只接受完整六位HEX，不接受CSS名字/三位简写/透明色。
3. 点击一个闭合区域上色。也可在“选择区域”选标签再点“给选中区域上色”，适用于键盘操作；“清除选中区域颜色”恢复未涂白色且可撤销。
4. “撤销最近上色（最多100步）”恢复前色，必要时自动切到对应主题。切换图保留所有作品。每图进度说明主动白色计为已涂。
5. 观察“自动保存状态”；失败时点重试或另存JSON。切换功能/关闭应用前确认已自动保存。无效旧档不会自动覆盖，替换需明确勾选并确认。
6. 用“保存全部作品JSON副本”备份全部图与记录；导入文件或粘贴JSON先校验，再点“恢复草稿（替换全部作品）”。“全部作品放入草稿”仅供检查/复制，尚未另存。当前SVG/PNG另存完整作品，须选择新文件名。

## 5. 产出与可复现例子

选择“茶杯与书”，选择 `#B7CDB6`，点击木桌（图底部横条）：只改变 `tea-r01`，进度1/7，杯身/书页仍白。撤销后木桌回到未涂白色、进度0/7。再上色，切到小屋花园用 `#D5A797` 点屋顶：只改变 `house-r01`，进度1/9。切回茶杯木桌绿色仍在；等待“已自动保存”后重开，两个主题的颜色继续保留。

白色例：给白色未涂木桌主动选 `#FFFFFF`，外观仍白但进度1/7，因为用户做了选择。清除后进度0/7；同色重复点击不增加历史。跨图撤销作用于所有图的最近操作，不仅当前图；界面会切到对应作品提示。

输出 `slow-color-all-archive-copy.json` 是可验证schema1输入；当前图片为 `slow-color-tea-copy.png`、`slow-color-house-copy.png` 等800×600 PNG，SVG同主题同完整画幅。当前作品导出不会修改其他主题色表。普通自动档在应用自身配置中更新，独立手动副本拒绝覆盖既有目标。
