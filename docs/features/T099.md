# T099 账号注销材料清单

## 1. 功能内容

离线整理用户手填的账号、数据导出、解绑事项和其他准备材料。每项有标题、可选外链文本、备注、人工完成声明和UTC确认时间。支持1–20账号、每账号1–50项、全部最多200项；预览后导出JSON/Markdown新副本，JSON可恢复清单。

## 2. 为什么需要

注销账号前常忘记导出相册、保留账单或解绑第三方登录。把准备项按账号整理后，可以看见待办和人工完成记录，避免只记得最终注销按钮而遗漏自己需要保留的材料。这里由用户提供实际事项，工具不连接服务、不自动注销或发送邮件，完成标记也不等于验证平台状态。

## 3. 实现方式

纯模型验证账号/事项唯一编号、五类有界文本（名称、标题、外链、备注、时间）、类别枚举、布尔完成标记及真实ISO UTC时间。按账号和类别汇总总项数、人工完成和待处理。原输入独立快照保留；恢复仅读inputs、忽略旧汇总并重算。外链只接受完整http/https且不带用户名口令，以文本显示；复制按钮仅调用显式剪贴板接口，没有自动打开。

界面编辑即废弃旧预览并禁用导出。改变事项标题/类别/外链会撤销该项完成声明；账号名称改变会撤销该账号全部声明，避免把旧账号记录套到新账号。备注只增加说明，不撤销声明。勾选“我已人工完成”记录本机UTC时间，取消勾选清空时间。没有自动获取或判断真实账号状态。

数据留在当前面板内存；切换前导出JSON。导入限64KiB UTF-8和版本1，格式失败原清单保留。导出使用copyOnly:true，接口能力严格检查、ok===true才报成功；现存文件不覆盖，取消/失败保留当前清单。

## 4. 使用方式与具体例子

在工作台打开T099，点击“载入两导出一解绑示例”：演示账号含“导出相册副本”“导出账单记录”两项数据导出，以及“解绑第三方登录”一项解绑，准确显示3项、人工完成0、待处理3。

你在服务自己的页面完成相册导出并检查本地副本后，回到清单勾选第一项“我已人工完成”，再点击“生成准备清单”：显示人工完成1、待处理2，UTC时间随JSON保存。这是用户声明；工具不会验证相册文件或服务状态。

若把第一项标题改成“导出原始照片”，该项完成声明及时间立即撤销，重新生成后回到0/3，提醒重新核对新增要求。可以添加账号和事项，逐项填标题、类别、可选外链及备注。点击“复制外链 I1”仅复制例子URL文本，不访问网站。

预览核对后导出JSON或Markdown，选不存在的新文件名。恢复时粘贴本工具JSON，点击“恢复手填清单”，人工记录恢复、统计重算；恢复的声明不构成实际账号状态的验证。

## 5. 使用后产出

界面产出按账号分类的材料清单、每类项数、人工完成数和待处理数。JSON包含feature/schemaVersion、完整inputs、归一化账号和事项、人工确认时间及“未验证平台操作”说明、重新计算的统计。Markdown包含各账号事项表、类别、人工状态、UTC时间、外链文本和备注。导出的账号标识来自你填写的材料，应自行选择适当保管位置。

## 6. 验证与限制

模型测试覆盖两导出一解绑准确3项、人工完成和真实时间校验、撤销确认、跨账号汇总、重复编号/错误类别/布尔/空清单拒绝、http/https外链及脚本网址拒绝、账号项数/UTF-8/版本边界、忽略旧统计、快照独立及完整Markdown。主代理另记录实际Electron事件与落盘验收。

它只整理用户提供项，未提供特定服务的注销教程或自动材料识别。外链可显式复制；没有登录、联网访问、邮件发送、实际注销或结果验证。人工声明和本机时间均依赖用户输入及设备时钟。单行有界文本，JSON恢复限64KiB UTF-8；面板关闭后未导出内容不会恢复。
