# E017 翻页动画

## 1. 功能与必要性

将自己画的像素小图做成循环动画。编辑器固定128×128，支持逐帧铅笔/橡皮、前一帧洋葱皮、复制、插入空白、前后排序、单帧时长及连续预览；不用上传、登录或动画平台。产物是一个离线可打开的HTML播放器，完整JSON用于之后继续编辑，当前帧透明PNG用于静态分享。没有AI、联网、音频或设备授权。

这是逐帧动画，与E011单幅像素画区分在帧序列、独立时长、洋葱皮和离线循环播放器。复制及排序移动整个帧的像素与时长，稳定帧ID帮助核对恢复；帧不是按数组索引混用素材。

## 2. 实现方式与明确边界

`model.mjs`保存schema1的输入状态：片名、当前帧ID、下一个ID、笔刷设置、洋葱皮设置及全部帧。每帧包含ID、整数时长和65536字节原始RGBA；JSON采用规范Base64，每帧87384字符。透明像素全部RGBA为0，绘制像素alpha255，导入半透明或隐藏RGB拒绝。完整JSON经大小、重复键、整数词法、精确键集合、版本、唯一ID、像素长度及规范编码校验。JSON解析片段源于本团队E016实现，但本ID没有跨功能运行时依赖。

1–48帧，每帧20–10000ms，笔宽1–12像素方形笔，片名1–80码点。48帧原始工程和包含全部帧的HTML均小于8MiB公共文本写入上限；超过限额整体拒绝，不截断。最大原始帧像素内存约3MiB，撤销保存当前帧最近20笔（约1.25MiB）；切帧/结构编辑清空撤销。撤销历史属于会话，不写入工程。原始像素是规范源，不把HTML截图或压缩PNG当恢复源。大工程不自动写config；窗口重载/模块销毁后需要手动导入此前另存JSON。

鼠标坐标依画布实际矩形映射到0–127格，整数Bresenham连线，笔刷边沿裁在画布内。Pointer Capture跟踪一笔；同指针文档级move/up为出画布的事件兜底。越界、Escape、pointercancel、捕获丢失或离开撤回整笔，不留下部分轨迹；其他指针取消事件不影响当前笔。完成一筆作为一个撤销事务。方向键移动光标，Shift跨8格，空格绘制一笔，重复键不重复提交。光标坐标显示在统计文本。

前一帧25%叠加只在编辑画布上，原始像素、动画预览及PNG不含洋葱皮。预览以单调时钟累计运行时间，暂停不增加；取周期位置再按左闭右开的每帧区间选择。默认停播，编辑重新从周期0开始。系统减少动效默认禁止连续预览，手动关闭仍需点播放。页面隐藏、切走、销毁取消RAF；返回不自启。连续动画没有后台计时器。

离线HTML内嵌全部原始帧及一个固定播放器，片名转义后通过textContent呈现，JSON中的HTML分隔字符转为Unicode转义。CSP只允许固定脚本SHA256，没有外链或用户代码。含播放、暂停、从头停播、上一帧、下一帧及减少动效控制。系统调度/显示刷新会使实际换帧晚于数学边界，不宣称物理显示毫秒精确或视频编码输出。

## 3. 使用步骤

1. 在“逐帧绘制”画布拖动绘制。可改颜色、笔宽或工具；也可用方向键与空格。画到边界外整笔撤回；需要撤回已提交笔画点击“撤销当前帧最近整笔”。
2. 设置当前帧毫秒数，点击“复制当前帧”后修改下一帧。洋葱皮展示前一帧参照，不会烧进作品。
3. 帧按钮选择帧，“向前/向后排序”移动整个当前帧。删除必须勾选确认且至少保留一帧；新建必须勾选清空全部动画。
4. 点击“播放/继续动画”循环，暂停保留周期进度；“从头停播”回第一帧。减少动效只允许手动选帧。连续播放时编辑锁定，先暂停再修改。
5. 先另存完整JSON，再另存离线HTML或当前帧PNG。重载后选择完整工程JSON，核对帧数/周期/片名，勾选替换确认并应用；恢复后停播。读取可取消，取消/离开后的迟到文件结果不替换工程。

## 4. 产出与保存保护

- `翻页动画-完整工程.json`：完整源像素、所有帧ID/顺序/时长、选择和编辑设置；无仅首帧/截断恢复。
- `翻页动画-离线.html`：单文件离线播放器，包含全部源帧；无工具箱preload仍可使用。
- `翻页动画-当前帧.png`：当前选中帧原尺寸128×128、透明背景、无插值及洋葱皮；不是精灵表或整段动画视频。

三种导出均`copyOnly:true`，需要公共能力标记，成功只接受`ok===true`。PNG计算SHA256并使用`files.saveBinary`生产接口；JSON/HTML用`files.saveText`。现有目标被WX拒绝，源工程文件不会覆盖。取消/失败/partialPath分别提示，没有成功回执不称保存成功。原生保存未返回时锁定编辑；离开后迟到回执不恢复旧提示。销毁释放监听、抓取、临时画布和模块源引用。已经保存的文件由用户管理。

## 5. 可复现例子

新建默认第一帧100ms，笔宽设12、红色`#e4583f`。从(40,60)横画到(64,60)，再从(40,72)画到(64,72)，形成x35–70、y55–78的实心红矩形。复制帧，时长300ms，橡皮擦相同两条线，蓝色`#285fac`在(64,40)→(88,40)、(64,52)→(88,52)绘制，形成x59–94、y35–58的蓝矩形。

工程有ID1/100ms红图、ID2/300ms蓝图：周期位置[0,100)红，[100,400)蓝，400回红。导出HTML点击播放应以此顺序循环；把当前第二帧向前排序后变为ID2/300ms蓝、ID1/100ms红：[0,300)蓝，[300,400)红，400回蓝。首帧红像素保持不变，当前帧PNG只有蓝块，洋葱皮红块不导出。另存JSON、重载、FileAPI导入并确认后所有帧像素与时长原样恢复。

另一个最小模型例：第一帧在y10的x10–13绘制红色，复制后擦掉x10–11，在y20的x20–23绘制蓝色。独立测试逐一判断全128²像素，而非调用生产绘制函数生成预期。
