# T086 单位约束计算台

## 功能内容

输入带单位算式及目标单位，先按长度、质量、时间三种基本量纲检查，再计算结果。相容量可以相加减，乘除与整数幂改变量纲；目标单位也必须相容。输出转换值、SI值、量纲向量和完整中间步骤。

## 为什么需要

混用米和厘米、小时和秒时，普通计算器容易直接把数字相加或遗漏换算。这里将单位作为计算的一部分，明确指出1米加1秒无法相加，帮助在实际算式中定位单位错误。它不计算测量不确定度或替代实验仪器校准。

## 实现方式

采用本模块维护的有限单位表和递归下降解析器，不引入通用执行器或额外单位库。仅解析数值、已有单位、四则、整数幂和括号；不使用eval、Function、脚本、变量或网络。每个量为SI值和[m,kg,s]整数指数向量；加减要求向量相同，乘除相加减指数，幂乘指数。最后将SI值除以相容目标的换算因子。

支持m/cm/mm/km、s/ms/min/h、kg/g/mg、L/mL、m2/m3，以及Hz、N、J、W、Pa和scalar及列出的中文别名。单位大小写敏感。分钟60秒、小时3600秒、升10^-3立方米等定义参考[NIST官方SI单位指南](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-5-units-outside-si)，SI前缀和派生量参考[NIST SI前缀指南](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-4-two-classes-si-units-and-si-prefixes)。运行只用本地已写定表。

数值紧接单位组成数量，因此100m/10s=(100m)/(10s)。幂紧贴单位时只作用于该单位：2m^2=2平方米；(2m)^2=4平方米。普通运算按幂、正负号、乘除、加减优先级，括号可改变次序；不支持连续幂，须用括号明确。目标单位只接受单位乘除与整数幂，1/scalar表示无量纲；留空则用SI组合。

算式最多1200字符、256标记、括号16层、目标120字符、幂指数±6、量纲指数±12；输入非零数字绝对值1e-12至1e12，中间结果非零绝对值1e-30至1e30，非有限、除零、零的非正幂、超限整式拒绝，不截断。计算用JavaScript双精度浮点，显示约12有效数字，报告保留原始数值，不声称任意精度。

## 如何使用

1. 打开T086，在“带单位算式”输入例如`1米 + 100厘米`，目标为`米`。
2. 点击“检查量纲并计算”，查看转换值、SI值和各步量纲。
3. 可用速度、派生单位和不相容示例快速了解规则；以`*`、`/`、`^`和括号组织新算式。
4. 改算式或目标会清空旧结果，需要重新计算，避免导出过期数值。
5. 预览后导出JSON或Markdown新副本；选择已有路径会被安全副本写入器拒绝覆盖。

## 使用后的产出

界面显示转换值/目标单位、完整SI值及组合单位、量纲向量和中间步骤。JSON版本1包含原式、目标、SI值、转换因子、输出值、量纲及全部运算记录（操作、左右量或底数/指数、结果），以及浮点精度声明。Markdown为可读结果和步骤，不隐藏错误或用不相容量继续算。

小配置仅保存版本1的算式与目标草稿，恢复后重新计算，不保存旧派生结果。两种导出要求saveTextSupportsCopyOnly===true、copyOnly=true，缺能力提示更新，失败/取消仍保留当前结果。所有内容本机计算，不连接外部服务，不对源文件做改写。

## 具体例子与验证

`1米 + 100厘米`转换到米得到2米，两加数SI长度分别1、1，向量[1,0,0]。`1米 + 1秒`直接拒绝，说明m与s量纲不一致，导出按钮不可用。

`100m / 10s`转换到km/h得到36，SI值10m/s，向量[1,0,-1]。`2 kg * (3 m / 1 s)^2`转换到J得到18，向量[2,1,-2]；该算式只是质量乘速度平方，并没有额外乘入动能公式中的1/2。`1L+500mL`转换到m3得到0.0015。
