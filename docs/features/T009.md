# T009 问卷结果汇总

## 1. 功能与交付内容

从CSV或JSON对象数组读取问卷答卷，用户明确配置字段、题名、单选/多选/数值题型及修剪规则；多选另外配置字面分隔符。按题输出有效样本数、缺答数、非法值数、类型明确的频数和有效分母比例。数值题附范围和近似均值，多选附重复选择去重/空项统计。

支持一对用户明确选择的单选题交叉统计，输出完整有效成对分母、排除状态组合和观测交叉频数。页面提供文件/粘贴输入、真实逐题配置、分页统计及完整失败来源详情，保存完整JSON或CSV报告副本。全部本地运行，不做总体推断、显著性检验、问卷评分模型或自动题目含义推断。

## 2. 为什么需要及已有能力关系

问卷导出中，多选答案常放在一个单元格，重复选项、空答卷和非法评分容易使用不一致的分母，导致比例错误。四份答卷中一份缺答，单选有效比例分母应为三；多选合计超过100%可以是正常现象；交叉统计也不能直接使用总答卷数。

现有webtools以网页入口为主。本功能提供离线本地原生汇总、配置预览、缺答/非法值溯源和副本保存，与数据对账、字段字典分开完成问卷任务。catalog的待选表格依赖由本功能内的严格解析器满足，没有新增npm依赖或运行时依赖其他feature。

## 3. 实现方式及数据保护

`meta.json`沿用工具/文本与结构化数据分组。`index.js`用现有h()创建界面，create同步返回activate/deactivate/destroy。`parser.mjs`独立复制T008严格解析器（来源提交`66785178`），不import未合并功能；`model.mjs`校验配置、解析答案状态、累计频数、计算交叉及生成报告。

解析器保留源文件名称、记录序号和起始物理行，CSV支持严格引号、双引号转义、BOM及字段内换行；标题必须唯一非空，列数必须匹配，不猜测错列。JSON顶层须为对象记录数组，拒绝重复属性、非对象记录、不安全整数、非有限值及Number转换改变十进制含义的值。不自动展开嵌套字段。

配置校验每个字段最多一道题，题ID不重复，最多20题；交叉须为两道不同的已配置单选题。按记录计算valid/missing/invalid状态，原始输入不改写。每题保留全部缺答/非法值的原值存在状态及来源。单选保留选项实际类型；多选使用字面split、逐项修剪和Set去重；数值解析仅接受明确十进制/科学记数法。

多选先按原始字符串拆分，再修剪各项，避免整体trim吞掉边界换行/空格分隔符。统计空项与重复选择，不把重复选择当多份答卷。交叉直接对同一答卷两题状态配对，仅valid/valid进入频数，其余状态组合完整计数。使用稀疏观测组合表，未观测组合为0，不铺开巨大笛卡尔矩阵。

读取采用可取消FileReader和fatal UTF-8解码；编码/大小错误不替换当前输入。独立保存文件原始文本，避免textarea展示时的CRLF规范化影响统计选项；编辑后采用文本框值。解析、按题扫描、交叉扫描及导出定期让出事件循环并检查AbortSignal。取消/切走/销毁中止当前任务，不开放半成品导出。数据改变废弃旧题目配置及报告，配置改变废弃旧报告；切换到另一功能会丢失未保存输入/配置，不写全局配置。

导出必须检查`window.toolbox.files.saveTextSupportsCopyOnly===true`，再调用`files.saveText({content,extension,defaultName,copyOnly:true})`；老写入接口禁用。基础排他写入拒绝已有目标，包括原文件。先核对页面预览，再在原生对话框核对新路径/文件名。保存对话框已打开时由系统取消按钮关闭，面板取消负责生成阶段。

## 4. 使用步骤与统计口径

1. 导入UTF-8 CSV/JSON文件或粘贴数据，选择明确格式，点击“解析问卷数据”。
2. 选择字段与题型，点击“添加此字段为题目”。在题卡中编辑字段、题型、题名及“修剪首尾空白”选项；不需要的字段不配置。
3. 多选题选择分号、逗号、竖线、LF换行或自定义1～10个UTF-16单位的字面分隔符。该分隔符不是正则，例如`[x]`只匹配字面文本`[x]`。
4. 如需交叉，至少添加两道单选题，勾选交叉并明确左右题。点击“按配置汇总问卷”。
5. 核对各题有效分母、缺答/非法值、来源及交叉排除口径，再保存JSON或CSV副本。

| 项目 | 明确口径 |
|---|---|
| 总样本 | 每条JSON对象记录或CSV数据行一份答卷；CSV标题和末尾换行不计，实际空物理行计入 |
| 缺答 | 字段不存在、null、按该题修剪规则处理后空字符串；多选去空项后无选项也缺答 |
| 非法值 | 题型不支持的结构，或非法数值；独立计数，不混入缺答。每题总数=有效+缺答+非法 |
| 单选 | 接受字符串、JSON数字或布尔，保留类型；数字1、字符串"1"不同。对象/数组非法。比例分母为本题有效答卷 |
| 多选 | 仅分隔文本字符串；不猜测JSON数组含义。同答卷同选项最多计1次；有效答卷至少有1个非空选项；每个选项比例以有效答卷为分母，因此合计可超过100% |
| 空白规则 | 默认每题启用修剪，用户可关闭。关闭后单选纯空白是有效字符串，数值纯空白为非法；多选按各项原样区分`A`和` A ` |
| 数值 | JSON数字或严格数字字符串；支持符号、小数和科学记数，例如`+.5`、`01.20`、`1e2`；不支持千位分隔、百分号、十六进制、NaN、Infinity；空值缺答，其他错误非法 |
| 数值精度 | 拒绝不安全整数、非有限值或最短Number十进制表示改变输入含义；1.2300等于1.23，-0等于0，0.1允许十进制往返；不承诺二进制浮点精确。均值标记为Number近似 |
| CSV类型 | 原输入每格是字符串；只有用户配置为数值题时才明确按数值规则解析。CSV文本`null`是普通单选项或非法数值，不猜为缺答 |
| 交叉 | 仅两题均有效的答卷进入频数，比例分母为有效成对数；状态组合计数含valid/missing/invalid，合计等于总答卷；未出现组合为0 |
| 零分母 | 不生成虚构比例；rate为null/无频数，显示有效分母0，数值min/max/mean为null |

默认题名来自字段名，可人工编辑；长字段名保留原字段身份，只截取题名初值到200字符。JSON合法空字段名以“（空字段名）”提示，原字段键仍为空字符串。标题/选项大小写敏感，不自动合并别名、改缺答编码或归类“其他”。

## 5. 产出与可执行验收例子

点击“载入四份答卷示例及配置”会载入以下CSV及明确配置：choice/group为单选，interests为分号多选，score为数值；交叉选择choice×group。

```csv
choice,group,interests,score
A,X,A;B;A,10
B,X,B,20
A,Y,A;B,not-number
,Y,,
```

点击“按配置汇总问卷”应得到：

- choice：总4、有效3、缺答1、非法0、比例分母3；A=2（66.6667%），B=1（33.3333%）。缺答来自survey.csv记录4/物理行5。
- interests：有效3、缺答1，首次答卷重复A去重1次；A=2（66.6667%），B=3（100%），选项次数合计5、百分比合计166.6667%，分母仍是3份答卷。
- score：有效2、缺答1、非法1；范围10～20、近似均值15；10/20频数各1，分母2。not-number单独列非法，来源记录3/物理行4。
- choice×group：总4、有效成对3、排除1、比例分母3；A/X、B/X、A/Y各1（33.3333%）。缺答/valid组合为1，不把group有效4误当交叉分母。

修改Q3分隔符为竖线会立即废弃旧报告，重新统计时`A;B;A`变成一个字面选项，不自动猜回分号。另一例：多选原文`\nA\nA\n`、分隔LF、启用修剪，A只计1次、重复选择1、边界空项2。

页面每页5题，每题频数每页25项，交叉每页25个观测组合。每题缺答/非法来源预览前20条，完整题目详情及导出保留全部失败记录，未截断统计结果。

JSON报告含feature=T009、version=1、来源、sampleCount、basis、每题完整config/频数/有效缺答非法/数值摘要/来源issues和cross。CSV使用统一六列kind/id_json/detail_json/count/denominator/rate_json，记录类型包括metadata、question、frequency、answer-missing、answer-invalid、cross-summary、cross-cell。metadata保留口径，question保留配置及摘要，失败行保留全部来源/原值，交叉摘要保留排除状态组合。字符串/对象先JSON编码再CSV引号转义，读回这些列时先CSV再JSON解码，以保留类型、空值及避免公式解释。两种格式均为完整报告，超出输出上限会失败，不写部分结果。
