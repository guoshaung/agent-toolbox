# E009 独粒棋

## 1. 功能与必要性

在本地通过正交跳吃减少棋子，尝试只留一枚。提供标准33孔十字棋盘（中心空、32子）及10个不同的原创小布局，初始3至12子。显示剩余棋子、当前有效跳数、包含撤销的完整操作数、主动用时和11关首次完成进度；合法起点/落点提示、撤销、确认重开和完整续玩让用户可以逐步尝试，而不必重新摆盘。

没有网络、AI、计分排名、广告或自动代走。提示只说明当前可合法跳吃，不保证下一步还能解；本功能不主张最优解、最少连续跳组数或唯一解。最多10000次操作足够普通反复尝试，达到上限会明确停下，允许另存、导入或确认重开，不截断旧记录。

## 2. 规则、关卡与可解证明

左上为坐标原点，横向A至G，纵向1至7。孔位是中间三列与中间三行的并集，共33孔；中心D4。一次跳跃只能横向或纵向跨两格：起点有子、中间相邻孔有子、落点空，移走起点和中子、落点放子，总数减1。剩1枚任意孔判胜；剩余大于1且没有合法跳跃判失败。失败可以撤销；胜利冻结本局、停止计时、每关只保留第一次完成记录。一次点击或一次正交跳跃是本功能的操作概念，不把一连串同子跳跃合并为“最短步”。规则核对了作者的[Jaap Scherphuis 独粒棋分析](https://www.jaapsch.net/puzzles/solitaire.htm)与[George Bell 英式独粒棋分析](https://www.gibell.net/pegsolitaire/English/index.html)。

P01–P10使用自编逆跳生成器从中心一子逐步增加棋子，固定种子98013，取不同3至12子布局。关卡静态数据和完整解例在 `levels.mjs`，无运行时生成器或自动求解按钮；路径和圆棋子均为程序绘制，无外部图像资产。P00前21跳采用上述Jaap公开分析的四臂清理序列，剩余10跳由独立Set棋盘深度搜索求出（该次搜索140次访问），因此不把标准局整条解称为原创。小布局为本项目生成，不宣称其他棋库从未出现同样布局。

独立验算器从**空落点**向外找相邻中子及两格外起子，以二维坐标字符串Set记录棋子；它没有调用生产 `legal/jump/token/replay`。每次独立跳跃同时校验孔位、正交距离、移除两子/新增一子、总数减1。每关解例终局均为D4一子；测试还逐步与生产棋盘及全部合法跳集合对照。

## 3. 实现与恢复边界

`meta.json`沿用娱乐/独立休闲游戏分类；`index.js`同步create与activate/deactivate/destroy契约。33个原生按钮组成棋盘，合法起子绿色边、选中子深色框、合法落点金色底；Canvas另行绘制完整820×820 PNG。没有RAF、拖放、摄像头/麦克风授权或用户代码执行。模块创建/恢复不启动计时，用户明确开始后才建立250ms显示刷新；隐藏/离开/销毁停止刷新并累计当前主动时间，返回保持暂停，重载也保持暂停。单调时钟按实际经过毫秒累计，暂停期间不补算；倒拨注入时钟夹至0增量，用时上限七天。撤销不倒退用时；每局重开用时归0。

小档自动存到 `featureLab.E009.progress`，每次选择、跳跃、撤销、暂停（含导出前暂停）、重开和正常离开保存。保存未完成时锁定操作；保存失败明确显示临时状态，可重试或另存。若离开时保存仍待返回，会在完成后再次保存冻结用时，避免把暂停后的时间漏掉。销毁尝试最后保存并清除DOM/监听/计时器/临时Canvas；进程崩溃、断电或强关窗口不能保证最后一次尚未完成的IPC保存，可使用已确认另存的JSON副本恢复。

schema1只保存源输入：当前关卡ID、完整操作字符串、选中棋子、整数毫秒用时，以及至多11条不同关卡首次完成记录。每跳为三字符（起点原始索引的两位小写base36 + 0上/1右/2下/3左），撤销为`u--`；原始索引为`7×行+列`，行列从0计。例D6→D4编码`120`。当前路径由日志推导，最多31跳；含撤销日志最多10000次、30000字符，64KiB UTF-8总源档限额，不按保留尾部悄悄裁掉。首次完成保存无撤销的完整有效解迹及准确毫秒，重开同关不会重记。

恢复逐条重放全部日志和全部完成解迹，重新生成棋盘、合法跳和胜负；不信任外部派生棋盘/胜负。拒绝未知版本/关卡/字段、重复JSON键、非安全整数词法、负数或超七天用时、非标准编码、无效跳、无效撤销、胜利后继续操作、非法选中、重复或未达胜利的完成记录；当前胜利必须有该关完成记录。文件先检查声明及实际≤64KiB、严格UTF-8；无效旧档不自动覆盖，需明确勾选清空或确认导入。文件导入预览只验证，应用需额外确认，替换的是当前局和全部首次进度。无缓存兼容或隐式迁移。

## 4. 使用与可复现例子

在功能工作台选择娱乐→独立休闲游戏→独粒棋。初始标准局暂停，先点击“开始 / 继续计时”。点击D6棋子，再点金色D4，D6及D5变空、D4有子，统计32→31；在操作表出现起点D6、落点D4、吃掉D5、剩31。选中子可以换选另一子；空落点非法时提示且棋盘/日志不变。方向键移动焦点，空格/Enter选择或落子；长按重复键不会连跳，Escape清除选择；暂停时棋盘不能操作。

最小完整胜利例：新局关卡选择“P01 双跳入门”，勾“确认放弃当前局”，点击“确认开启所选独粒棋关卡”，再开始计时。初始D2、E3、F3三子。鼠标点F3再D3，吃E3，剩2；焦点放D2，空格选择，向下两次到D4，空格落子，吃D3，只剩D4，显示胜利、当前2跳、日志2操作、已完成1/11。胜利不能撤销/继续；确认重开再完成同关，首次完成仍只有一条。未经勾选点击重开不会丢当前局。

未完成时点暂停或离开功能，之后重载会恢复选中棋子、全日志、棋盘、用时和11关进度，不自动继续。失败局可“撤销最近一次跳吃”退一跳后保持暂停，再开始。预览操作50行一页，上一页/下一页只改变显示；另存不会截掉分页之外的日志。达到10000操作时另存完整日志后再确认重开。

## 5. 产出与安全另存

JSON是完整续玩源档，包含当前全部日志、当前选中、准确毫秒和所有首次完成解例；可再通过“独粒棋续玩JSON”导入，预览核验后勾确认应用。Markdown包含全部操作（含撤销）、全部33孔在7×7坐标图的位置、11关完成情况、完整首次解迹和完整schema1源JSON代码块；显示秒数保留一位，代码块保留准确毫秒。PNG保存当前完整棋盘、坐标、关卡、数量、跳数、操作数、显示用时、胜负与规则提示；它不是完整历史备份，多关进度/所有操作应另存JSON或Markdown。

文本导出需 `saveTextSupportsCopyOnly===true`，PNG需 `saveBinarySupportsCopyOnly===true`；全部请求 `copyOnly:true`，PNG限制10MiB、规范Base64及SHA-256，成功只接受`ok===true`。缺能力时按钮禁用；取消不报成功，失败/清理异常明确提示。生产写入器独占wx创建，选回已有副本也不会覆盖。导出先暂停；解码/保存晚返回且模块已经离开时不更新旧UI。Canvas编码完成或离开销毁均释放像素和引用，不把PNG临时图写进配置。没有源文件改写、自动解压、联网或替用户删除旧副本。
