# T042 媒体交付体积预估

## 1. 功能内容

输入本地视频、目标字节数与明确输出尺寸，先查看源视频抽样，显示码率预算，再生成最多两次真实成片。每次报告实际字节、计划视频码率、实际总码率、实际尺寸、时长、音轨和完整解码核验；超限显示不合格，不静默降低分辨率。目标20MB明确指20,000,000字节，不是20MiB。

支持域：单个MP4、单条H.264/yuv420p 8bit视频、可选单条单/双声道AAC，≤64MiB/120秒、偶数尺寸≤1920×1080、≤60fps、零开始（±1毫秒）、SAR1:1。无章节/字幕/封面/旋转/HDR/外部引用，遇不支持整体拒绝。音频独立文件暂不支持。输出H.264 30fps与可选AAC96kbps/48kHz，用户明确等比例偶数尺寸，不放大。目标1–20,000,000字节，完整成片<20MiB。

## 2. 为什么需要

平台按实际文件大小限制交付，ABR估算不能保证大小；容器、音轨与短片首帧会产生差异。把预算和真实检查分开，能避免误称“达标”，并让用户检查画面和声音后决定是否保存。合格仅表示字节、尺寸、100毫秒时长容差、音轨与完整解码通过；不证明主观画质、无失真或平台接受。

## 3. 实现方式

`model.mjs`纯预算/验证，私有`host.cjs`通过生产固定Host执行可信已安装引擎，无跨功能import或新增生产依赖，无shell/网络/用户表达式。仅Windows本地固定盘普通文件，祖先lstat/realpath拒绝链接、UNC、设备和特殊路径。安装目录由原生选择绑定sender、固定ffmpeg.exe/ffprobe.exe basename，≤256MiB并保留身份；预览3次查询后确认才运行，只接受6.x及libx264/AAC。可选择其它可信目录，示例C:\ruanjian\ffmpeg\bin。缺引擎/版本/编码器明确拒绝；从[FFmpeg官方下载页](https://ffmpeg.org/download.html)选择Windows构建，本工具不安装。

原生选择MP4只读分块SHA（262KiB），确认后ffprobe/有限ISO-BMFF data-reference检查，禁止外部轨道。复制到自己的临时source-preview.mp4，不转码且SHA等于源；播放器只接受自身临时URL，renderer不能传任意路径。预览源的10%/50%/90%位置、加载实际尺寸时长并人工确认后才能计划。源副本是在工具操作意义上只读，未修改OS文件权限。复制系统调用不能逐字节取消，收到取消后等待有界复制/读操作返回并清理。

预算`reserve=max(65536,ceil(targetBytes×5%))`；`videoBps=floor(((targetBytes-reserve)×8000/durationMs-audioBps)/1000)×1000`，有音轨预留96000bps。视频范围64000–2000000bps；低于最低预算明确不可行，不改尺寸/删音轨。余量是估计，不冒称实际开销。软件libx264/veryfast/ABR，非two-pass，不设CRF/nal-hrd cbr，固定30fps/所选尺寸、file协议/map、去metadata/chapters/固定线程。[FFmpeg官方参数](https://ffmpeg.org/ffmpeg.html)、[libx264官方选项](https://ffmpeg.org/ffmpeg-all.html#libx264)、[FFprobe官方](https://ffmpeg.org/ffprobe.html)是实现格式依据。

运行前后源SHA/大小/身份核对并重新probe。源probe5秒、编码60秒、产物probe5秒、FFmpeg -xerror全视频和音轨解码到null30秒，总任务截止100秒；全解码不再编码。对实际输出SHA/字节与精确宽高、30fps、音轨、时长核验。第一份实际超限后，第二份预算为`min(原预算,floor(firstVideoBps×targetBytes/firstActualBytes×0.85/1000)×1000)`，保持尺寸与音轨，预览后单独确认；低于下限明确不可行。无自动重试/第三次编码。报告保留两次实际数据，只保留当前完整临时候选；首轮可先保存。取消/失败也消耗编码预算，同一源/同一约束重排字段不会重置，修改约束建立新任务，重选源明确重开。

首个await前预留任务/早取消意图；每sender一任务、16sender/4子进程，512调用/窗口、32早取消意图/60秒。观察child.close才释放槽，kill后5秒未关闭返回pending，不假称已终止。输出/日志≤128KiB，实际文件每100毫秒监控、-fs20MiB保护，源临时≤64MiB+当前候选<20MiB。达到硬容量终止的候选不当完整视频。候选15分钟空闲过期；源预览在清除/退出/sender销毁时清理。崩溃/断电可能残留临时文件。

## 4. 如何使用

1. 工作台打开T042，预览默认目录或原生选择可信已安装引擎，核对3条命令后确认查询。
2. 原生选择MP4，确认一次只读检查；源预览可完整播放。点击10%/50%/90%抽样，检查画面声音并勾选确认。默认静音，可手动取消静音。
3. 输入目标字节和等比例偶数宽高，默认保留源尺寸。预览完整预算、明确尺寸、固定参数和执行期限，确认本次完整编码。
4. 核对实际结果与全部报告。抽样按钮同步定位源与成片。如果实际超限，显示不合格；可预览并单独确认第二次更低码率计划。同任务最多两次，不能再次编码。预算不足禁止执行。
5. 核对实际成片、抽样画面、声音和报告，勾选确认，原生对话框选择全新目录名称。参数修改立即失效旧成片/保存资格。清除/切换/隐藏/销毁暂停两播放器、取消任务并清理临时内容；返回需重选源。不把源/视频/秘密写config。

## 5. 使用后产出

完整源信息、估算计划、逐次实际字节、实际尺寸/时长/音轨、计划视频码率、实测总码率、qualified/status和人工抽样时间。实测总码率包括音轨与容器，不能冒称视频流码率；没有虚构PSNR/SSIM。人工确认不证明每帧都已看过。

新目录包含qualified.mp4（实际合格）或unqualified.mp4（实际超限候选、明确非合格）及delivery-report.json，保留源SHA/字节、目标/估算余量、全部尝试、完整核验、固定argv摘要与copyOnly记录。最低预算不足时只有界面不可行计划，不生成假视频；暂未独立导出该不可行计划。未达标候选另存绝不表示达标。

本ID生产Host原生选择新目录，exclusive mkdir+COPYFILE_EXCL+报告wx，回读完整SHA/大小并确认源不变。公开bundle每文件2MiB限制不用于冒称能存20MB视频。已有目录/文件或选回源拒绝。正常失败按创建身份清理，失败返回partialPath人工核对；不是跨文件崩溃事务。只有ok===true显示成功，canceled/false/undefined/throw保留结果。报告包含选中文件名和实际目标路径，分享范围由用户判断；视频未做敏感信息清理。
