# E005 七巧板拼图

## 1. 功能内容

提供15张自制可解几何轮廓：G01折翼、G02梯台、G03双峰、G04曲桥、G05斜帆、G06展开、G07折尾、G08长角、G09尖顶、G10交错、G11山脊、G12云台、G13羽片、G14小径、G15回望。它们由标准七块板拼合，是独立轮廓而非同一图换色；名称描述抽象几何，不声称复刻传统名作。

鼠标/触屏拖动、45°旋转、镜像翻转、坐标编辑、键盘细调、重置、撤销与渐进提示均可用。平行四边形的镜像真实改变方向。七板覆盖目标≥99%且互相无正面积重叠才完成。灰色剪影不画内部分块；逐级提示才显示指定板位置。完成用时、首次完成及收藏本地保存，重载保持暂停。JSON续玩、Markdown记录、完整SVG/PNG作品另存新副本。无网络、设备权限、计分排名。

## 2. 为什么需要

通过空间拼合提供另一种休息活动，具有可验证目标，区别于科研图板的任意编辑。精细拖放不是唯一入口：键盘移动、独立旋转/翻转按钮和坐标字段可以完成同一操作。遇到困难可渐进提示和明确辅助摆入，作品记录保留是否使用提示，不混为未辅助完成。

## 3. 实现方式与边界

`model.mjs`管理几何、时钟、提示和源存档；`targets.mjs`保留原创七板目标分区；`index.js`提供SVG、PointerEvent捕获/CTM换算、控件和生产副本接口。用户输入仅位置及受限JSON，不可输入脚本/路径/SVG。

总面积32单位²，两大三角各8、中三角4、两小三角各2、正方形4、平行四边形4。大三角直角边4、小三角边2、方形边2、中三角直角边2√2；平行四边形邻边2和2√2、夹角45°。板局部原点不一定是外接框左上角。x右/y下，角度顺时针；镜像先反转局部x，再旋转平移。

凸多边形Sutherland–Hodgman裁剪计算每块板与七个互不重叠目标分区的交面积；另算板两两交面积。板间正交总面积≤1e-7单位²且覆盖≥0.99才结算。容差用于浮点，贴边允许；不以目标包围框、正确原点或PNG像素判胜，其他等价摆法也可通过。角度只接受0–315的45°倍数。正确角度/镜像、原点距指定解≤0.12单位时平移吸附，便于实际操作；吸附后仍算真实覆盖与重叠。

提示三层：板种与目标大致方位；虚线板边界；精确x/y、角度、镜像。第三层之后可明确点击辅助摆入；之前不会改板。任意提示将本局标为辅助，撤销摆板保留提示/辅助，用时不倒退，重开新局才重置。完成冻结移动，每图只保留首次完成用时/辅助/七板快照，后续重开不覆盖首次记录。收藏独立记录轮廓ID。

计时使用可注入单调时钟，主动开始到暂停的闭式差值取整毫秒。不计暂停/隐藏/离开/关闭时间。250ms刷新仅主动计时且active/visible时存在，暂停、完成、deactivate、destroy停止；返回不自启，无RAF或后台补算。累计最多七天。摆板、提示、收藏、暂停/离开等保存，正常destroy尝试保存；进程强杀可能丢最后一次保存后用时，不保证断电/崩溃。

x/y必须有限且绝对值≤2000单位，画布与导出扩展范围显示所有板，不静默夹紧；移得很远会缩小整体，可重置。撤销仅本次打开最近100次摆板，超过容量滚动旧记录，不跨重载。源schema1≤64KiB：一局七板/提示/用时、最多15条首次完成快照、15收藏；足够全15图记录，超限拒绝不截断。恢复核对字段、版本、重复键、轮廓、板数量、有限安全数值/角度和提示范围；重新计算全部完成快照，伪造won或未达标完成记录拒绝。位置为JS双精度，不声称无限小数精度。旧坏档需明确确认清空/替换，不能默默覆盖。

## 4. 使用方法与确定样例

进入娱乐→独立休闲游戏→七巧板拼图，选择G01，点“开始 / 继续计时”。拖动板并释放保存；选择平行四边形点“翻转所选板”观察斜边方向。通过板选择器填写x/y、角度与镜像，再“应用所选板位置”。聚焦板后方向键0.1单位、Shift+方向键0.01，R旋转45°，F镜像。暂停不能改板；选择/收藏/导出仍可用。

确定辅助完成：依次选择七块板，每块点三次“渐进提示下一层”。第2层可见虚线，第3层给精确位置；手填第三层值并应用，或明确“按已揭示提示摆入此板（辅助）”。第七板到位时显示覆盖100.000%、重叠面积0.00000000、完成及已用提示（辅助），首次完成增加一条。错误镜像/重叠/移出不通过。收藏，切G08/G15重复可见不同轮廓。

未完成时暂停，离开返回/重新加载保留七板、提示和用时且保持暂停。重置只清本局七板/用时，不删首次完成和收藏。独立计时例：运行120000ms→暂停10000ms→继续500ms，累计120500ms。另存JSON后切关，选择文件预览；勾确认替换再应用才能恢复整个源档。拒绝未知schema、无效完成记录、无效UTF-8及超过64KiB文件；离开令旧读取失效。

## 5. 产出与副本安全

- 配置 `featureLab.E005.progress`：七板、提示、主动用时、首次完成快照、收藏，不存撤销栈；重载推导覆盖/重叠。
- JSON：完整可恢复源档，所有已完成图与收藏。
- Markdown：当前七板坐标/角度/镜像/提示、覆盖/重叠/用时/辅助、完整15轮廓完成与收藏表、完成用时及规则。
- SVG和PNG：全部当前七板及灰色目标，标题/覆盖/用时/辅助和底部规则，不附未揭示答案。PNG固定1000×900，不是局部窗口截图。

导出主动暂停冻结作品，保持暂停。文本/SVG使用saveText(copyOnly:true)，PNG使用saveBinary(copyOnly:true)，规范Base64和SHA-256，≤10MiB。先检查capability，旧基础禁用。严格ok===true才报成功；取消不是保存，同名WX拒绝，partialPath要求人工核对。导出时锁交互，离开/销毁使旧回调失效；Canvas、Blob对象URL及Image引用结束后释放。不随重置删除已存文件。
