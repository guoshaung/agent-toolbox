# T092 结构数据匿名化

## 1. 功能内容

在本地处理 CSV 或扁平 JSON 记录数组，逐列选择四种策略：保留原值、删除字段、固定宽度数值分桶、带本次随机密钥的确定性伪名。先查看处理后的表格和完整文本，再通过宿主原生保存对话框创建 JSON 数据、CSV 数据或 JSON 处理报告的新副本。输入与输出均不上传；不调用 AI，不需要账号。

相同字段里类型和值都相同的输入在本次处理内得到同一伪名，便于保留重复用户的行间关联。不同字段隔离，JSON 数字 `1` 和字符串 `"1"` 也隔离。再次点击“生成新的处理结果”会生成新密钥，同一邮箱的伪名会改变。删除字段不保留原值映射，界面也不提供密钥和映射下载。

这是减少数据可识别性的辅助工具：保留列及字段名原样进入数据副本，使用者须逐列选择；剩余组合特征、外部信息和桶区间仍可能识别个人。功能名称沿用设计，不能据此保证全表匿名或无法重新识别。无需追溯的分享可只保留处理后副本；若工作需要追溯，请自行妥善保管原文件，分享包中不要附带它。本功能不生成可保存的反向映射。

## 2. 为什么需要

直接删除邮箱会让分析者无法识别同一用户的多行记录；直接保留邮箱又会把身份带进分享文件。每次新随机密钥的伪名保留一次分享所需的关联，而数值分桶降低精确年龄等数值的粒度。删除列适合完全不需要的备注，保留列适合用户确认可分享的指标。

完整预览让使用者在保存前核对实际字段和数据；副本保护保证选到已有目标时拒绝覆盖。失败审计只记录行号、列编号及错误原因，可以沟通数据质量问题而不把错误单元格的原值带进报告。

## 3. 实现方式

- `meta.json` 按工作台接口注册“工具 / 隐私与数据迁移”。`index.js` 默认导出同步 `create(root)` 与 `activate/deactivate/destroy` 生命周期，使用公共 `h()`，样式只匹配 `.feature-t092`。
- `model.mjs` 自包含 CSV 状态机及严格 JSON 扫描器，没有其他功能的运行时导入，也不需要待选的外部表格解析库。CSV 支持逗号、LF/CRLF、引号中换行、双引号转义和空字符串；表头须非空、无首尾空白、1–100 字符。按 Unicode NFKC 检查重复表头；不静默合并。每行列数必须与表头一致。
- JSON 只接受非空的扁平对象数组，值限字符串、普通十进制有限数字、布尔值和 `null`。逐记录检测重复键（包括转义后相同的键和 Unicode 兼容形式），不依赖 `JSON.parse` 覆盖重复键。记录必须具有与第一行完全相同的字段集合，允许键顺序不同。缺失、多余、嵌套、尾部多余内容或不支持的数字写法均明确失败，不补 `null`。`__proto__` 等作为普通数据字段安全构造。
- JSON 数字最多 15 位有效数字、6 位小数，不接受指数写法；避免无限大及超精度数字被悄悄舍入。数字语义下 `1.0` 与 `1` 相同，`-0` 按 `0` 处理。CSV 输入的所有值均为字符串。
- 每次伪名处理调用 WebCrypto `generateKey({ name: 'HMAC', hash: 'SHA-256', length: 256 }, false, ['sign'])` 生成随机、不可导出的密钥；对 `[字段名, 值类型, 值]` 的 JSON 编码签名，输出 `p_` 加完整 64 位十六进制摘要。仅本次缓存重复值签名；结束、失败或取消后清除缓存及密钥引用。没有把密钥、原值映射或输入文本写入配置或报告。摘要碰撞在密码学意义上极低，不能把它解读为数学上的绝对无碰撞或不可重新识别保证。
- 分桶将输入和桶宽严格转换为整数百分位：`lower = floor(value / width) × width`，再输出 `[lower, lower + width)`，零为固定边界、左闭右开、负数向下取整。值范围 `-1000000–1000000`；桶宽 `0.01–1000000`；最多两位小数，不接受首尾空白、指数、前导多余零、布尔值或空值。一次有任何不匹配单元格，整次不提供数据副本。桶的上边界可以超过输入值范围，例如最大值按最大桶宽产生 `[1000000.00, 2000000.00)`。
- 读取单个用户选择的文件使用 `File.arrayBuffer()` 与 `TextDecoder('utf-8', { fatal: true })`；不读取任意系统路径、不存文件名或原路径。拒绝错误 UTF-8、零字节或字节数不一致的文件。粘贴文本也检查 Unicode 代理字符和 UTF-8 字节限制。
- 限额：输入 1 MiB UTF-8、5000 条数据、100 列、单元格 65536 字符；本次最多 20000 个不同的字段/类型/值签名；JSON 和 CSV 每种结果最多 8 MiB。超限报错，无静默截断。失败审计最多展示/导出 100 项，同时保留完整不匹配数量。
- 每 50 行让出事件循环，签名等异步返回前后检查取消标记。输入/策略编辑和清除会丢弃旧结果；旧进度、文件读取和保存回调不能覆写新状态。正在取消的单个异步任务结束前阻止新处理，避免任务叠加。隐藏/暂停取消在途处理，恢复不自动重启；销毁移除可见性监听、清空源输入和结果引用。
- 保存要求 `window.toolbox.files.saveTextSupportsCopyOnly === true`，调用 `saveText({ content, extension, defaultName, copyOnly: true })`。只有返回 `ok === true` 才显示成功；`canceled === true` 提示取消；返回失败、`undefined` 或抛异常保留预览供重试。桥接错误不直接显示，防止其可能携带输入或路径。报告只用 `C001` 等原始列序号描述策略，不包含原字段名到伪名的映射。

## 4. 如何使用

1. 打开工具工作台的“结构数据匿名化”。选择 CSV 或 JSON，粘贴文本，或读取一个 UTF-8 文件。文件扩展名 `.csv/.json` 自动选对应格式，其他扩展名由用户确认格式。
2. 点击“解析字段”。每列显示原始列序号、字段名、默认“保留原值”策略。默认保留不会替你判断敏感字段，请明确选择：邮箱用“本次一致伪名”、年龄用“固定宽度分桶”、不需要的备注用“删除字段”。
3. 分桶列填写正桶宽，例如 `10`。点击“生成新的处理结果”。有错误时按界面行号与 `Cxxx` 找到自己的原数据修正，或预览无原值的失败报告；不能导出半成品数据。
4. 成功后查看前 20 行表格。点击“预览 JSON 数据副本”“预览 CSV 数据副本”或“预览处理报告”，检查完整只读文本。预览是保存的必要一步。
5. 点击“保存当前预览新副本”，在原生对话框确认目标路径。存在的目标不被覆盖；取消或失败保留当前结果。需要其他格式时重新选择对应预览再保存。
6. “取消处理”不保留部分结果；“清除源数据和结果”清空原输入、列策略、预览和报告。切换功能会销毁面板，未保存内容需要提前导出。关闭整个工作台会暂停；返回后已完成结果仍在本面板，取消的任务需要手动重新生成。

取消不能中断已发出的底层 WebCrypto 签名或 `File.arrayBuffer()`，但返回结果会被丢弃，取消结束前不启动第二个任务。已经弹出的原生保存对话框由用户取消或完成；切换/清除后的返回消息不会更新旧面板。JavaScript 清除引用不能承诺系统内存物理擦除。

## 5. 使用后产出

产出为新的 JSON/CSV 数据副本及单独 JSON 处理报告。数据副本只含保留、分桶、伪名三类列，删除列不出现。成功报告含行列数量、按 `Cxxx` 编号的列策略、桶宽和闭开边界说明、保留列数及本次关联说明。失败报告含 `state: failed`、完整不匹配数和最多 100 项无原值审计，`noDataExport: true` 明确没有数据副本。

JSON 保留选定列的标量类型；CSV 本身不携带 JSON 类型信息，JSON `null` 在 CSV 中写作字面 `null`，而不是变成空单元格；布尔值写作 `true/false`。CSV 的引号和换行正确转义，分桶区间中的逗号会被引号包裹。需要保留 JSON 类型语义时请导出 JSON。未处理列及字段名原样保留，仍须用户核对；这里没有全表匿名认证或跨次稳定 ID。

## 6. 具体可重现例子、测试与限制

点击“填入邮箱演示”会载入并解析：

```csv
email,age,note
ana@example.test,23,第一行
ana@example.test,29,同一用户
bo@example.test,-1,另一用户
```

将 `C001` 设为“本次一致伪名”，`C002` 设为“固定宽度分桶”、桶宽 `10`，`C003` 设为“删除字段”，生成后应有 3 行、2 列：前两行邮箱伪名相同，第三行不同；年龄分别是 `[20.00, 30.00)`、`[20.00, 30.00)`、`[-10.00, 0.00)`；没有 `note` 列。JSON、CSV 和处理报告均不含 `ana@example.test`、`bo@example.test` 及已删除备注。再次生成时，邮箱伪名应与上一轮不同，因此例子只断言关联性质，不承诺固定哈希值。

错误例：把第一行年龄改成 `oops-secret`、再次解析并设置同样策略。处理失败审计显示 `行 1 · C002 · bucketValue`，不会显示 `oops-secret`。只出现“预览处理报告”，无 JSON/CSV 数据导出按钮；失败报告不含原邮箱或错误单元格原值。边界例：`0.3`、桶宽 `0.1` 得 `[0.30, 0.40)`；`-10.01`、桶宽 `10` 得 `[-20.00, -10.00)`。
