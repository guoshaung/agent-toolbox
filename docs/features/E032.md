# E032 触碰水面

## 1. 功能内容

安静的本地水面视觉互动。点击落点或按住拖动给水面添加扰动，两处波纹相互叠加和传播，逐渐衰减。支持1至10级强度、三种配色、普通/¼速慢动作、冻结暂停、单次清空，以及完整800×560 PNG副本。没有分数、倒计时、声音、摄像头、网络或AI。

初始暂停，用户点击“开始水波”才运行。暂停禁用点击/拖动，也停止计算和绘画，因此没有输入修改时像素冻结；更改配色和清空是界面说明的显式单次画面修改，不能用它们验证“不变截图”。截图会自动暂停并直接读取当前画布，不补算、重绘或推进模拟。连续两次保存而不继续/修改时像素一致。

## 2. 为什么需要

通过鼠标触碰水面休息注意力，不做题、不计成绩，也无需授权摄像头或播放背景音。暂停把某一刻的涟漪保留，截图保存完整画面。离开后停止计算，让视觉休息不会在后台持续消耗资源；返回不会突然动画，需要用户明确继续。

## 3. 实现方式和资源限制

160×112二维heightfield，两个Float32Array分别表示当前和前一步高度。每一步采用邻居和的一半减去上一高度、乘0.985衰减，然后交换缓冲。边界固定零；落点只影响内部半径4网格点的有限高斯扰动，并向已有高度加值，未重置其他波纹。高度限制±50，运算结果有有限数检查，重复高强度输入不会生成无界幅度/NaN。此为有界视觉波动模型，没有真实水深/单位、物理预测或流体精度承诺；饱和限幅区域不承诺线性叠加。

固定步长1000/60ms，普通速1、慢动作¼速按累积时间决定固定步数，不改变稳定递推系数。每帧最多处理4步，单次真实时间差最多计100ms，达到4步丢弃剩余累积避免长帧补算。暂停清掉累积时间，继续第一帧只重绘当前状态、不补算离开时间。每次帧绘画从当前高度/局部梯度映射RGBA，再平滑放大到800×560；没有随机光影、计时装饰或假波纹图片。

create只准备Canvas和静止画面，不请求RAF；activate不自动开始。用户开始才requestAnimationFrame，pause、deactivate、document.hidden及destroy立即cancelAnimationFrame并清时间与拖动capture。document隐藏后恢复可见也保持暂停。Canvas使用Pointer capture，屏幕坐标按getBoundingClientRect换算有限网格；拖动相邻落点至少间隔2网格单位。没有setInterval或后备定时器驱动后台计算；导出中的一次异步让出执行权不属于模拟循环。destroy清监听、可视画布、离屏画布及模型缓冲；取消不承诺擦除操作系统内存。

PNG直接由同一Canvas.toBlob(image/png)生成，截图前不调用step或paint，不依赖窗口截图、滚动位置或可见区域。字节上限10MiB，规范Base64与SHA-256后调用saveBinary(copyOnly:true)，依赖公共基础c0c93aa/PR #14；缺能力禁用按钮，绝不转用旧覆盖型saveImage。主进程独占创建新副本，已有目标拒绝；仅ok===true显示成功，canceled单独报告，partialPath提示人工核对。PNG编码/摘要生成可请求取消并忽略晚到结果，不声称终止浏览器底层编码；原生另存打开时用对话框取消。

生命周期依据：[MDN requestAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/requestAnimationFrame)、[cancelAnimationFrame](https://developer.mozilla.org/en-US/docs/Web/API/Window/cancelAnimationFrame)、[Page Visibility API](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)。本功能还主动停止循环，不依赖浏览器隐藏页节流作为唯一机制。

## 4. 如何使用

1. 打开页面是静止水面。点击“开始水波”，在画布两处点击，或按住拖动。强度决定后续输入大小，不抹掉已有波纹。
2. 选择慢动作，波动继续以相同固定递推步长、¼模拟速度演进。切配色会立即单次修改整幅颜色。可调青蓝湖面、深海暮色或浅绿水面。
3. 点“暂停并冻结画面”。此时点击/拖动禁用，变更强度/速度不会改变像素；更改配色或“清空水波（单次修改）”明确改变当前图像，但不会启动动画。
4. 点“保存当前完整PNG副本（自动暂停）”，选择新文件名。第一次、第二次保存默认不同序号；若要检查冻结，期间不要开始、清空或改色。保存不会自动继续。
5. 离开/隐藏/暂停后返回，仍是暂停状态，点击“开始水波”才继续已有状态。切换到另一具体功能会destroy，波动不存档；PNG保存图像，不是可重开模拟工程。

## 5. 产出和具体可复现例子

屏幕提供实时叠加涟漪或冻结水面；输出固定800×560、带全部画布的PNG，默认water-ripple-copy-1.png、water-ripple-copy-2.png等。没有计分报告、联网记录或大型config写入。

窗口操作例：默认青蓝/强度4/普通速→开始→在画布像素约(300,260)与(380,290)点击→等待两个环扩展并交叠→暂停。连续保存两次PNG，两个图片像素应逐字节一致；暂停期间再点画布不添加波纹。离开工具后等待，再返回；页面显示开始按钮，没有自动动画。

确定性模型验收：160×112网格在(76,56)和(84,56)分别注入强度2。独立A、独立B、组合AB在前30步逐点满足AB≈A+B（绝对误差<0.0001，Float32舍入范围内）。同点(80,56)连续强度1输入，初始高度从4加为8，没有重置。单落点强度5初始峰20，1000个固定步后峰小于0.02；边界保持零。巨大帧差只推进4步、下一tick(0)不追补；四个普通固定间隔推进4步，¼速仅1步。

实际Electron暂停样例：第10个实际RAF回调时暂停，两张PNG各81578字节、800×560，PNG文件SHA-256都为93dca7ba67763899723219c681d8e7ff43cf6141b1e8a944622cefd8c9880bff；解码后的nativeImage bitmap SHA-256都为06b48fda6eb4cc8d6d8f81a0e196d87ad57fdca8b671575ab60356fcaf8327a4。暂停与两次截图期间RAF计数保持10；明确开始一次至11后deactivate，等待1.2秒保持11，activate后再等待1.2秒仍11。每次原生重跑时暂停前时间轨迹可有差别，因此样例文件hash是本次证据，验收要求是同一次暂停的两个副本一致，而非所有机器重跑相同hash。
