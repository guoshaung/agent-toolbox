# L056 试卷测量质量检查

## 1. 功能内容

离线读取用户提供的 0/1 作答矩阵，计算每题的答对人数、难度指标 p（答对比例）、上下组区分度 D，并列出全对、全错、D 恰为 0、D 为负的字面异常。至少 10 人且 10 题才估计指标；较小矩阵可以编辑和导出原始计数，但 p、D 及分组人数明确为 null／不可估，不把未知当作 0，不标异常题。

提供人工来源、原始 CSV 编辑、可操作的矩阵单元格、作答者／题目增删、分页、异常筛选、完整分组与排名，以及 JSON／Markdown 完整预览和新副本。所有题目和作答者都参与统计，显示分页和筛选不减少导出范围。

## 2. 为什么需要

一个题库的分数看起来精确，不代表题目能区分本次作答者，也不证明测量质量。把原始人数、整卷排序、分组和题目计数同时展示，可以发现全对题在这次数据里 D=0，或某题上组答对人数低于下组。工具让这些算式可复核，不自动建议删题或作考试决策。

本功能不产生信度、效度、个人能力、学习效果或医学结论。来源由用户填写，空字段显示未知；原 CSV 的 SHA-256 只用于字节核对，不认证人员身份、数据真实性或样本代表性。

## 3. 实现方式、公式及容量

`model.mjs` 严格校验 schemaVersion 1 草稿，并解析有限无引号逗号 CSV。首格必须为 `participant`，其余表头为唯一题名，后续每行首格为唯一作答者名。姓名和题名最多 40 Unicode 码点，修剪字段首尾空白后检查重复；禁止逗号、引号、制表符或字段内换行。允许 CRLF／CR 行分隔及一次末尾换行，不忽略空行。不支持 BOM、带引号 CSV、缺答、null、部分评分或缺失值；作答只能是字面 0 或 1，`1.0` 也拒绝。

固定计算口径：N 为作答人数，p=该题答对数/N，数值越高越容易。按包含当前题的整卷总分降序排序，同分按原输入行顺序。上下各取 k=floor(N×27%) 人，D=(上组答对数−下组答对数)/k；中间组不参与 D。报告保留全部排名、上下／中间组、人数和分数。上下边界同分时显示提示，任意行序可能改变 D，不自动排除同分者或变更分组方法。10 人时上下各 2，12 人时各 3，200 人时各 54。此分组与取整是工具固定教学口径，不声称对当前数据最优。

27% 极端组的历史讨论见 Kelley (1939), *The selection of upper and lower groups for the validation of test items*, [原论文 DOI](https://doi.org/10.1037/h0057123)；核对的是 [APA 提供的原文首页预览](https://www.researchgate.net/publication/232494422_The_selection_of_upper_and_lower_groups_for_the_validation_of_test_items)。本实现不检验该论文讨论的分布条件，也不借其结论认证本次题目效度。同分规则、取整、至少十人十题和异常标记是本功能明确制定的有限规则。

异常仅基于整数计数精确比较：全对、全错、上下答对数相同、上组答对数少于下组。没有经验阈值或难度等级。界面小数最多显示 6 位；报告保留 Number 值及计数分子／分母，不根据舍入后的显示值判断异常。

允许 1–200 人×1–100 题；最多 20,000 个作答值。来源名最多 160、来源位置最多 320 码点，原 CSV 最多 192 KiB，整个输入最多 256 KiB。超限整份拒绝，不截断数据假装完成。表格每页 10 人×10 题，结果每页 10 题。异步操作先冻结输入、分段让出并支持取消；SHA-256 基于报告保留的原 CSV UTF-8 字节。文字通过文本节点显示，Markdown 转义 HTML 并调整代码围栏，不执行输入代码，不联网、不调用 AI。

## 4. 使用步骤与恢复

1. 填写人工来源和出处，粘贴无引号 CSV；姓名及题名在 CSV 中编辑。格式或维度错误会显示原因，不猜缺答。
2. 也可直接点击矩阵单元格切换 0↔1，添加人或题时新作答初始化为 0，需用户核对。矩阵操作会把当前数据规范化为 LF CSV；原始报告需要保留时先导出。删除末人／末题或整体替换示例有明确确认。
3. 点击「统计题目指标」，查看全部题目、上下组和同分提示。样本不足明确不可估。
4. 翻页或切换「仅字面异常」只影响显示。展开全部分组及 JSON／Markdown 预览检查所有原始记录。
5. 导出完整 JSON 或 Markdown 新副本。只有生产桥具有 `saveTextSupportsCopyOnly===true` 才调用保存，始终传 `copyOnly:true`；仅 `ok===true` 宣告成功，取消及防覆盖失败不算成功。

只保存 schema1 原始 CSV 和人工来源，不保存派生统计。草稿以完整 JSON 的 UTF-8 大小检验，超过 64 KiB 时不写全局配置并提示导出完整报告；关闭只能恢复较早合法输入。保存队列合并待写输入并隔离旧回执；草稿中未完成的 CSV 语法可以保留，恢复后仍需校验才能统计。恢复拒绝错误版本及超容量，不自动运行。编辑、取消、隐藏、离开和销毁隔离迟到结果，来源修订也清旧报告。

## 5. 产出和可复现例子

默认十人十题示例：Q01 的十人全部为 1，总分从 P01 的 1 递增至 P10 的 10。点击统计后，上组 P10(10)、P09(9)，下组 P02(2)、P01(1)，上下各 2。Q01 正确数 10/10，所以 **p=1、D=(2−2)/2=0**，标记全对及区分度恰 0。Q10 仅 P10 答对，所以 **p=1/10=0.1、D=(1−0)/2=0.5**。

点击 P01/Q01 单元格把 1 改为 0 后旧报告消失，重新统计 Q01 为正确 9/10、p=0.9，D=(2−1)/2=0.5。删除末位作答者需确认；变成九人后保留原始计数，全部指标为 null／不可估，异常列表为空，不能据此产生考试结论。

同分独立例：十人各总分 1，前五人只 Q1 正确，后五人只 Q2 正确，其余八题全错。稳定按行序取组时 Q1 的 D=1；反转十人行序后 D=−1。两次结果都会提示边界同分。它展示分组口径对指标的影响，不说明这道题的真实区分能力发生变化。

JSON 包含完整输入及人工来源、原 CSV 哈希、解析后的全部作答、样本可估状态、排名与三个组、全部题目计数及分数分子／分母、字面异常和计算定义。Markdown 包含同样的完整安全 JSON。副本可能包含所有作答者标识和逐题记录，没有自动脱敏；过滤不会缩小导出内容。来源文件没有导入改写接口，输入采用粘贴或编辑。
