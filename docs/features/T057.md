# T057 项目依赖许可证清单

## 1. 功能内容

只读盘点用户选择的本地Node项目File集合。读取根package.json四类依赖声明、传统node_modules路径内每个安装位置的package.json、包根部标准许可/通知文件及明确单文件名的SEE LICENSE IN引用。输出包名/版本/许可声明、相对来源路径、文件字节数/SHA-256、未知或待核对项，完整预览JSON/Markdown后保存新副本。

每个安装位置独立一行，嵌套同名不同版本不合并。标准支持LICENSE/LICENCE/COPYING及.txt/.md（大小写不敏感）、NOTICE及.txt/.md单独归为通知。只查看实际所选范围，不声称磁盘全部依赖已盘点。

## 2. 为什么需要

交付前常需知道“哪些声明、哪些许可文本、来源在哪里、哪些还没找到”，便于逐项人工核对。缺许可文本与没有所选安装位置分别记录，不能用猜测填成MIT。记录固定来源摘要便于后续复查，避免重复安装或向外部服务上传项目。

声明与文件存在不代表法律适用或权限成立；本功能不作法律判断、不证明声明和文件正文一致、不推断可商用或组合兼容性。所有行reviewRequired=true。

## 3. 实现方式

格式字段参考[npm官方package.json说明](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/#license)。license字符串原样记录，未经SPDX语法/标识符验证；对象/空字段及旧licenses数组不解释并提示。UNLICENSED单独提示不推断授予权限。SEE LICENSE IN仅允许包根目录一个文件名；缺所选文件/目录或遍历引用明确提示。NOTICE不能成为许可文本证据。

独立模型验证所选路径，目录入口去掉根段，必须有根package.json。支持node_modules/name及node_modules/@scope/name与这些位置下同式嵌套安装。PNPM store、链接/workspace、PnP布局不解析，也不读取lockfile、不解析依赖图、不求版本范围满足；根四类声明分别保留，不模拟npm覆盖/解析。文件夹名和package.name不同时提示可能alias，不擅自更名或按名去重。未选中根声明的位置记selectedInstalled=false，不说“未安装”。

独立JSON词法解析拒绝普通/转义重复键、尾随文本、非对象根、非有限数字及孤立代理项；最多16层/5000节点/64KiB UTF8。其他package字段不执行/不复制到报告。源数字是Number，忽略字段的大整数不用于版本/许可判断；版本/包名/许可须有限文本。根四类声明合计≤500条，名称限传统ASCII名称（含@scope）。支持SEE声明自定义文件根部一段，不支持包内子目录引用。

所选≤1000文件/传统安装位置≤200，package≤64KiB、单许可/通知≤1MiB、实际读取总≤8MiB、完整JSON≤4MiB。以64KiB块File.slice读取，核对真实长度；fatal UTF8，不猜编码，解码可去除起始BOM，原字节SHA保留。任何纳入文件JSON/UTF8/读取/容量问题整份拒绝，无部分成功清单。未纳入的任意源码/README/binary不会读正文。许可全文只在当前读取内存用于非空判断，报告记录SHA/字节/路径，不输出正文，也不猜内容许可类型；存在文件可能不完整，待人工阅读。

状态declared_unverified表示支持的声明存在；text_only_unclassified表示无支持声明但有非空许可文件；unknown表示两者均无支持证据。空文件、未选许可、旧字段、版本/名称缺失等分别issues。即使declared_unverified也不意味有效许可或已验证，无文本仍需核对。

所有UI输出文本节点；Markdown使用动态代码围栏/HTML转义。异步每块读取/每个包及摘要之后检查票据，取消/隐藏/暂停/销毁废弃任务；无自动持久化、网络、安装、脚本/依赖执行。报告含声明的请求版本（可能为私库URL/本地路径），不自动脱敏，预览明确提醒检查分享范围。选择改变清空旧结果；正文读取并非实时监控源码改动。

完整导出预览后显式确认，生产saveTextSupportsCopyOnly===true接口、copyOnly:true，严格ok===true才成功；取消/失败保留预览。主进程wx拒绝覆盖已有目标。UI取消不能撤回已完成原生写入。

## 4. 如何使用

1. 在T057选择含package.json和已安装node_modules的项目根目录；必须浏览器实际列出所需文件。过大项目可先在独立副本准备明确范围，工具不会安装或补读未选依赖。
2. 点“预览项目读取范围”查看将盘点的传统安装清单路径，尚未读取正文。
3. 点“盘点完整所选许可证”，检查每行来源、声明、许可/NOTICE摘要及issues。每页50行，全部行留在报告。
4. 核对根声明未选项及未知项，按来源路径人工阅读真实许可。需要其他布局或完整法律复核时不能靠这个有限清单下结论。
5. 预览完整JSON/Markdown，核对私库地址及路径后保存新副本；离开没有自动保存。

## 5. 使用后产出

`T057-license-inventory.json`或`.md`新副本，含根清单摘要、四类全部声明、每个安装位置全部来源/许可字段/文件摘要/问题、完整范围及限制。没有依赖安装、执行、源码修改或法律适用结论；报告不含许可正文/其他package字段。不只导出当前表页。
