# L032 双人文献筛选校准

## 功能内容

两名评审按共同纳排规则各自导入或粘贴文献筛选CSV。A提交后移除原输入节点，只显示已提交；B独自输入，两份都提交后才揭晓。按ID对齐相同文献，展示原始一致率、Cohen kappa、交叉计数和逐篇冲突。

## 为什么需要

综述或资料整理中，两人可能对同一规则理解不同，单看各自纳入数量容易忽略逐篇冲突。本功能帮助核对规则执行的一致性，并保留每条判定供讨论。结果衡量两套标注的相合程度，不保证规则、文献质量或最终结论正确，不据此自动替任一评审改判。

## 实现方式

独立纯模型严格解析CSV，支持UTF-8 BOM、CRLF、带引号逗号、转义引号及多行标题，并保留记录起始物理行。表头固定id,title,decision。ID与标题去首尾空白，ID不可重复；判定限include/exclude或纳入/排除，两类统一为include/exclude。不混入未知或空判定。

两份ID集合和同ID标题必须全部一致，顺序可不同；不一致则列出缺失和标题问题，阻止计算部分配对指标。对齐后以全部N篇为分母，Po=同判篇数/N，Pe=sum(A各类数×B各类数)/N²，κ=(Po−Pe)/(1−Pe)，未加权。为避免接近1的减法误差，kappa按整数计数分子/分母计算。两位全部同一类别时Pe=1、kappa未定义，即使一致率100%也不写成1。公式参考[scikit-learn官方指标文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.cohen_kappa_score.html)；运行不需要该库或网络。

提交顺序为A输入→交接屏→B输入→揭晓。首份提交后锁定共同规则，A文本框清空并移除，B新建输入框不沿用其撤销栈；不在B页面写入A判定到隐藏DOM。用户共同操作本机，不提供账号权限隔离，评审独处需要参与者配合。完成后只读对照，需修订应重新开始全部筛选，避免把看到对方结果后的判定说成独立。

每份限制1MiB UTF-8、600000字符、1000文献、ID80字符、标题500字符，规则4000字符。导入严格UTF-8校验并成功解析后才替换当前输入；失败保留草稿。表格分页每页50，报告包含全部记录。本地内存存数据，切换功能前导出，不写大型全局配置，不执行CSV文字或访问所写路径。

## 如何使用

1. 打开L032，先共同填写实际的纳排规则。
2. 评审A独处，将CSV导入或粘贴，检查自己的结果，点击“提交评审A并隐藏输入”。
3. 将屏幕交给评审B。B点“评审B已独处，开始输入”，导入自己的独立CSV，再提交。
4. 检查条目匹配问题或完整一致率、kappa与逐篇判定。冲突通过文字及背景提示，不仅依赖颜色。
5. 导出JSON或Markdown新副本。想改变规则或判定，点“重新开始全部筛选”；这会清空当前两套数据和结果。

CSV例子如下，顺序可不同，但ID和同ID标题必须相同：

```csv
id,title,decision
P1,本地文献一,include
P2,本地文献二,include
P3,本地文献三,exclude
P4,本地文献四,exclude
```

## 使用后产出

揭晓界面有N、同判数、一致率、冲突数、期望一致率、kappa及未定义原因；2×2交叉计数；全部配对的ID、标题、两位判定、是否冲突和CSV物理行，分页展示。JSON版本1含共同规则、完整A/B记录、匹配审计、计数矩阵/边际数、指标、全部配对及冲突清单。未对齐时statistics=null，报告保留问题，不假造部分指标。

Markdown为可读逐篇对照和匹配问题，用户文字转义。通过saveText安全副本能力、copyOnly=true保存，不覆盖已有文件；取消/失败不会丢当前结果。没有报告导入，仅支持两份CSV独立输入；完整JSON用于保存审计，分享前自行确认文献与判定内容。

## 具体例子与验证

A载入四篇演示CSV，两篇纳入、两篇排除，提交后A判定不出现在B输入页面。B再载入同样四篇并提交：交叉矩阵[[2,0],[0,2]]，同判4/4、一致率100%、Pe=0.5、kappa=1、冲突0。

如果B把P3改纳入，则同判3/4、一致率75%、Pe=0.5、kappa=0.5，唯一冲突为P3。两份全部互反则kappa=-1；两份只有一篇且都纳入时一致率100%，kappa未定义。如果B遗漏P4，匹配审计列出缺B=P4，指标不计算。

8项Node专项测试通过，覆盖上述手算、边际计数、同类别未定义、ID/标题对齐、顺序独立、CSV引号/BOM/物理行、非法判定/重复ID、行数和UTF-8限额。不提供多人kappa、加权标签、在线协作、筛选AI建议或质量评分。

主代理在隔离隐藏Electron33.4.11窗口用生产preload、功能目录和实际写入器验收：A提交后其CSV节点被移除，无指标节点；B全部同判后100%/κ=1。重新开始，B将P3改纳入，显示75%/κ=0.5/冲突1。实际写入2603字节JSON并解析核对矩阵[[2,0],[1,1]]和唯一冲突P3。配置及保存目标为测试夹具，未操作原生文件对话框或完成打包、macOS、辅助技术验收。

含39功能的隔离集成分支按项目CI模式检查1106项：1096通过、10跳过、0失败。


主题适配补充：输入框、按钮或结果区域使用项目已定义的 `--bg-raised` 和 `--line`；在实际 Electron 中加载生产 base.css，检查三个功能的文本框计算颜色为当前主题背景 rgb(28,33,36)、文字 rgb(210,216,213)。不再依赖未定义的 surface/border 变量落到白底；此轮检查验证计算样式，没有操作系统保存对话框。
