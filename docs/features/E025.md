# E025 同屏抢答

## 功能内容

一台电脑支持 2–4 位玩家和一位主持人。内置 50 道原创轻松常识题，覆盖基础算术、欧氏几何、时间与公制单位、英语字母、太阳系知识；每题包含标准答案、解释、来源简述。主持人打开题目后单独点击“开抢”，第一个有效物理字母键或点击获得唯一答题权。玩家口头回答，主持人私下查看参考答案并判对错，不自动分析声音或文本。

答对固定 +2，答错固定 −1，未作答 0。允许答错续抢时，答错玩家本题失去抢答资格，主持人重新开放剩余玩家抢答；全部玩家答错则结束并显示答案和解释。关闭续抢时，第一次答错就结束本题。主持人也可提前结束本题，已判分保留，其他玩家 0 分。

## 为什么需要

个人知识问答不能给同屏多人一个明确且不可抢走的答题权。此功能适合朋友聚会、短时休息、家庭知识游戏；明确区分读题、开抢、锁定、判分和结算，减少抢答归属争议。点击备选按钮便于键盘冲突时继续活动。原生键盘事件只表示浏览器接收先后，无法证明多人实际按键的毫秒级物理顺序。

## 实现方式

`model.mjs` 是可注入单调时钟的纯状态机：ready → open → locked → closed；答错续抢经 retryReady 明确重新开抢。判分同时校验题号、抢答归属序号和状态，旧按钮、双击、多次判分无法重复改变积分。已错玩家集合按题重置；题目顺序固定且不重复。一局 1–50 题，每题最多四次判分，不设置自动截止时间，由主持人控制口头作答节奏。

UI 使用现有 `h()` 渲染文本和独立样式。只在主持人明确点击私密查看后把当前答案放进私密面板；作答前普通题目区不出现答案、解释或来源。关闭私密面板重新显示锁定归属及判分按钮。页面隐藏、窗口失焦或工作台切走均隐藏私密面板并暂停；恢复必须手动“继续”，锁定归属和已错集合保留。暂停时抢答、判分及下一题均无效。开抢到首键的接收延迟使用 `performance.now()`，排除暂停时间，只供报告参考。

键位从 A/S/D/F/Q/W/E/R/Z/X/C/V/J/K/L/M 的物理 `KeyboardEvent.code` 中选择，玩家键位唯一。拒绝 repeat、已按住未释放、组合键、输入法组合状态，以及事件目标或当前焦点在 input/textarea/select/contenteditable 的按键。没有后台计时器、联网、摄像头或麦克风依赖；destroy 解绑所有事件并清理草稿与本局内存。

内置来源：单位事实对应 [BIPM SI Brochure](https://www.bipm.org/en/publications/si-brochure/)，字母对应 [Unicode Basic Latin 字符表](https://www.unicode.org/charts/nameslist/n_0000.html)，太阳系对应 [NASA Solar System Facts](https://science.nasa.gov/solar-system/solar-system-facts/)。算术题解释给出可直接复算的式子，几何题注明欧氏平面条件或定义。题目为本项目重新编写，没有复制外部题库。主持人应先检查自己导入题目的明确性；结构校验不能验证自定义知识真假。

## 如何使用

1. 选择 2–4 人，名称各 1–20 字，规范化后不可重复；为每人选不同字母键。选择本局题数、是否允许答错续抢，点击“建立新局”。题目按题库顺序，从第一题开始。
2. 主持人读题，确认玩家准备好后点击“开抢”。玩家按自己的物理键或点击对应抢答按钮。首抢锁定后其他键不能夺取归属。
3. 玩家口头作答。主持人让其他玩家转身，点“主持人独处，查看答案”，阅读后点“隐藏答案，返回判定”，再选择答对或答错。这里采用本机信任约定，无法防止旁观偷看。
4. 若允许续抢且有剩余玩家，主持人点击“剩余玩家重新开抢”；结束本题后显示答案、解释和判定记录。点击“下一题”，最后一题点击“结算本局”。
5. 若需自定义题库，主持人独处时点击“编辑题库”，粘贴 JSON 并校验；成功后草稿立即清空，建立新局才使用新题库。放弃草稿或恢复内置题库均有明确按钮。编辑时停止玩家操作；隐藏后原赛局仍保持暂停，需手动继续。

导入仅接受以下完整结构，version 必须是数字 1；不接受额外字段。题库 1–50 题，草稿最多 65536 字符；题号 1–32 位字母、数字、_ 或 - 且唯一，题目去空白并规范化后不可重复。题目最多 240 字、答案 120 字、解释 400 字、来源简述 300 字，均为非空单行文本。可添加可信链接为来源简述，链接按文本显示。

```json
{"version":1,"questions":[{"id":"MY001","question":"三个袋子，每袋两个球，一共几个球？","answer":"6 个","explanation":"3 × 2 = 6。","source":"题目给定数量，基础乘法直接复算。"}]}
```

## 使用后产出

结束一局得到含并列名次的排行榜，以及每道题的题号、题面、答案、解释、来源、结束原因、每次首抢玩家、物理键、判定、加减分、接收延迟和题后累计分。最后点击“导出完整 JSON 副本”，使用 `files.saveTextSupportsCopyOnly === true` 及 `saveText({copyOnly:true})` 的安全副本接口。取消保存明确提示取消；缺少该能力会阻止导出并提示升级。导出不覆盖既有文件。

全局配置仅保存最近 10 局小成绩摘要，过滤大型题库、逐题答案和详细记录。保存失败不会阻止本局游玩或完整内存报告导出。私密 JSON 草稿有界且不持久化；导入题库、当前赛局和完整报告都保存在功能内存，切换具体功能、重建一局或关闭应用会丢失，需先导出。

## 具体可重现例子、验证与限制

选择两人：小明 A、小红 S；题数 2；允许答错续抢。点击“建立新局”。第一题“三盒铅笔，每盒四支，一共有多少支？”先点击“开抢”，按 A 再按 S，归属仍为小明。主持人私下看到答案“12 支”，隐藏后判小明答错，小明 −1。点击“剩余玩家重新开抢”，A 已禁用；按 S 后判小红答对，小红 +2。

点击“下一题”，题面为“十块饼干平均分给五个人，每人几块？”。先“开抢”，松开前轮按键后按 A，主持人私密查看“2 块”，隐藏后判答对。点击“结算本局”：小红 2 分第 1，小明 1 分第 2；JSON 第一题有小明错误、小红正确两条判定，第二题有小明正确一条判定。若第一题第二次也判错，则会出现“所有玩家答错”和解释 3 × 4 = 12。

验证命令：`node --test test/feature-E025.test.js`，覆盖 50 题数据与导入边界、首键唯一、错误排除与重新开抢、全部答错、关闭续抢、旧题号/归属序号、暂停恢复与接收延迟、排行榜、50 题上限、有限历史，以及真实 UI 处理函数的 keydown/keyup/点击、私密答案移除、焦点误触、repeat/组合键、隐藏/失焦、草稿限制、导入文本安全和副本导出取消。

组件测试使用轻量 DOM/IPC 适配器，属于渲染事件与模型验证；实际 Electron 多键输入、硬件键盘冲突、窗口隐藏及原生文件对话框需单独集成验证。按父任务要求不重复运行已知缺失其他模块依赖的全库检查；提交后检查自有模块与样式的 committed-import 路径。没有模拟证据声称实际原生文件保存成功。
