# E020 拼词写诗

## 1. 功能内容与必要性

根据 `entertainment.json` 的 E020，提供261个内置常用词块、按词性抽词、自定义词、词块替换、逐行拖排/键盘排序、换行、撤销、完整工程恢复、诗文本和诗卡PNG。用几个已有词开始，减少面对空白页的停顿；作品每一行和每个词都由用户选定。基础功能完全本地，无网络、账户、AI、设备授权或音频。

内置内容是为本项目人工整理的独立日常词汇，不摘录现有诗歌、歌词或名句；分类是创作提示的粗分组，不是自动语法分析。此实现未接入可选AI供应商，不将随机词块叫做AI创作，也不评价作品水平、含义或情绪。自加词原样由用户提供，应用不会自动查询来源或生成引用。

## 2. 实现方式与规则

`model.mjs` 定义可版本恢复的source工程、词库、按索引移动/换行/替换、纯文本顺序和完整字素排版；`index.js` 通过现有 `h()` 建立实际控件与Canvas，用户文字只以文本/Canvas绘制，不执行HTML。按词性抽词使用 `crypto.getRandomValues(Uint32Array)`，以 `floor(2^32/剩余词数)*剩余词数` 为拒绝阈值，避免直接取模偏差；每批从剩余池移除，1–30个词、批内不重复。分组不足时拒绝抽取，不偷偷少给；随机源连续拒绝最多128次后明确失败。没有承诺为每首诗选出最合适的词。

工程schema1完整包含标题、署名、紧接/单空格连接方式、字号/颜色、行ID、每词ID/文本/人工词性/内置或自定义来源、自己的词库、ID计数与当前选择。不保存Canvas、Blob或随机抽词临时池。内置词来源必须与本版本固定词库相符，自定义来源必须能在自己词库中找到；未知schema/字段、重复键/ID、孤立代理字符、控制字符、非法来源、非规范/不安全整数、非UTF8和超容量整体拒绝。

最多32逻辑行、300个在用词块、200个自己的词库条目；每词1–40码点（不trim，保留内部/两端空格，但全空白不算词），标题80码点、署名60码点，字号24–64整数。允许同词在诗里重复出现，各有独立ID；自己的词库相同文字只存一次。总工程UTF8最多64KiB，组合触发此限额时整次编辑拒绝，所有先前作品保留。删除词块不自动删除自己的词库，所以之后仍可复用；新建才清空库和作品，且能撤销。

编辑在克隆source上完整验证后提交；非法操作不污染当前作品。撤销保留整次操作，最多100条且最多8MiB工程字符串，超出时滚动移除最早历史，界面写明此范围。选择词/行不是编辑记录；拖动只在释放到有效目标后提交，整块共同撤销。拖出排列区、Esc、lostcapture、隐藏/离开取消本次拖动。没有RAF、计时器或后台自动创作，返回不会自动动作；销毁释放capture/事件/Canvas像素/临时引用。

诗卡固定宽1200、安全边距100、高度按完整文字扩展（最少600、最多8192）；使用Intl.Segmenter完整字素测量和换行，ZWJ emoji不拆开。标题/署名与各逻辑行按可验证基线排列，长逻辑行可软换行，但每个字素都保留。超过高度或PNG10MiB预算整体拒绝，不截断文字或悄悄减小字号；文本/JSON仍可保存完整作品。Canvas使用本机sans-serif，所以不同字体/OS可能改变排版与PNG像素。

## 3. 如何使用、拖排与恢复

在娱乐工作台进入“拼词写诗”。先点某行编号，再点击内置词或自己的词，将词加入本行末尾；按词性和抽取数量点击“按词性抽词”，再手工从本批词中选择。检索只影响内置词分页，不改变诗，也不会联网。自定义输入后点击“加入自定义词”；选中已有词后还可使用“替换所选词为自定义输入”，保持ID、位置与行不变。

点击词块选择，用主按钮拖到目标词之前，或一行空处/行头放至末尾；支持跨行。用左右移动按钮或聚焦词块后的方向键调整本行顺序，上下键或跨行按钮移动到相邻行末尾；Tab可达词块，Space选择。Enter或“所选词后换行”将所选词之后的余下词整体移到下一行；没有选词则从本行末新增。也可“本行末新增下一行”，现有词保持原行。空行保留为真实换行，只有空行能直接删除，至少留一行。Delete移除所选词、Esc取消拖排，边界移动拒绝不循环。

标题、署名、连接方式、字号和颜色在change/离开控件时应用并刷新完整文本/诗卡；非法输入回到旧值，不输出未应用的输入。默认词块紧接，适合中文；选择单空格连接后每相邻词间加一个空格，词内部原空格仍保留。完整诗文本区与导出TXT使用同一个明确source顺序和逻辑换行，不包含标题、署名或界面标签。

此功能**不自动写config**。关闭具体功能/窗口重载会丢弃未保存作品，继续上次需“另存完整工程JSON”。恢复时用真实文件控件选择1字节至64KiB UTF8工程，先核对“待恢复工程”的完整诗；勾选“确认替换当前作品”，再点“应用完整工程”，随后全部词序、空行、词库、样式和选择恢复。当前作品在应用前不改变，恢复可整次撤销。新建也要求明确勾选，不能无意清空。

## 4. 使用后产出与安全副本

“另存完整文本TXT”输出原始UTF8诗，保留所有词的确切文字、两端空格、逻辑换行与空行，不额外添加结尾换行。“另存完整工程JSON”输出完整schema1source，支持以后恢复。“另存完整诗卡PNG”输出整个绘制作品，包含完整标题、署名、正文与背景，无词块编辑按钮/选框/操作状态。PNG软换行是排版，不会写回TXT逻辑行。

文本/工程使用生产 `files.saveText({copyOnly:true,...})`，PNG完整字节先核对SHA-256再用 `files.saveBinary({copyOnly:true,...})`。必须具备 `SupportsCopyOnly===true`，成功仅认 `ok===true`；取消、错误、字符串“true”或partialPath均不报成功，后者提示人工核对。原生保存pending期间锁定编辑/新建/导入，hidden/离开/销毁token使旧异步结果失效，不复活旧模块。已有目标由WX独占写入拒绝，源工程及先前副本不改。10MiB二进制安全桥已在a80基线提供，没有改共享接口或安装依赖。

自己的文本和作品在本机内存/用户明确保存的文件中，未上传到AI或网站；未承诺安全擦除JS/OS内存、剪贴板或用户保存过的副本。默认界面不是引用他人诗词，用户写入的引用不自动变成应用的原创内容。

## 5. 具体可重现例子

标题填“春日拼词”，署名“小舟”。自定义添加“窗前”“一朵云☁️”“停了下来”，点击“所选词后换行”，再添加“我们”“把灯点亮”。保留默认紧接，排列和TXT应精确为：

```text
窗前一朵云☁️停了下来
我们把灯点亮
```

将第三词拖到第一词之前，会变成“停了下来窗前一朵云☁️”，撤销一次恢复原顺序；选第一词按右方向键，会变成“一朵云☁️窗前停了下来”，再撤销恢复。用自定义输入“灯下”替换第一个词会保留该词ID和位置，撤销回“窗前”。切成单空格连接，TXT为“窗前 一朵云☁️ 停了下来\n我们 把灯点亮”；该变化也可撤销。

保存TXT、工程和PNG后重载窗口，先看到一行空作品；选择原工程，勾选替换再应用，原作品完全恢复，重新输出三种副本应保持同文本/源参数/本机PNG像素。保存时若再次指定已有文件，会拒绝且原SHA不变。第二行再加40个“长”组成的一个词和五个“👩‍💻😀”组成的词，卡片自动扩展/软换行，TXT仍仅两行且全部字符保留。
