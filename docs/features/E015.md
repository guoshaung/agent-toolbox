# E015 万花筒绘画

## 1. 功能内容

按设计目录E015，提供2–12轴同步旋转笔刷、可选镜像、颜色/粗细/背景、整笔撤销、可重放源记录与完整PNG。画布是1000×1000连续坐标的自由线条，区别于E011逐格像素、填充和镜像格编辑。全程本地，无网络、生成图片模型、设备授权、计分或标准答案。

默认六轴、不开镜像：一笔每隔60°产生一份，共六份。开启镜像后，每轴增加一份先水平反射再旋转的笔迹，共2n个几何路径；与其他路径重合时视觉可能合并，不宣称一定看到2n个互不相交图形。每笔保存当时轴数、镜像、颜色和粗细，修改现行笔刷不改变旧画。背景为整个当前作品的全局设置。

## 2. 为什么需要与规则

一次简单笔触得到有规律的对称图案，容易随手创作；保存源点与参数后，重开能继续修改、整笔撤销并看到绘制过程。副本不依赖截图UI或当前窗口尺寸。

坐标原点左上、向右/向下增加，中心(500,500)。旋转第k份采用角度360k/n度，正角在屏幕上顺时针。镜像先将中心相对y变号（沿中心水平线反射），再旋转。旋转不拉伸，源每个点到中心的半径不变。线帽/连接为圆形，单点是半径粗细/2的圆点。笔刷粗细1–50逻辑像素，颜色#RRGGBB；笔迹/背景不透明。

鼠标/主触点按下到画布内松开构成一笔。整笔只有提交后加入作品，撤销删除最后一笔及全部旋转/镜像副本，不改背景/当前笔刷。最多100笔，所有现存笔都可逆序撤销；没有另存巨型画面快照栈。画布外松开、移出、捕获丢失、指针取消、窗口失焦、隐藏/离开取消未提交整笔。其他指针不会接管或取消主指针。

源点允许0–1000，旋转的角落笔迹可超出正方形，输出按画布裁切，不自动夹紧或扭曲几何。屏幕圆形辅助线提示留边，中心与焦点光标也只是预览，不进入PNG。半径≤475且粗细≤50的源点及连接线处于画布安全圆内，其全部副本可保留。

## 3. 实现方式与容量

纯model.mjs负责schema1严格校验、几何旋转/反射、共同撤销、时间位置、Canvas画笔。index.js用原有h()建立大画布/侧栏控件，Pointer capture通过实际getBoundingClientRect把CSS显示坐标换为1000坐标并取最近整数，不依赖窗口缩放假设。预览缓存已提交笔画，只重画当前笔与辅助线；导出另建Canvas，完整重画所有源记录。

schema1含brush{axes,mirror,width,color}、background、strokes；每笔同样保存轴/镜像/粗细/颜色，points为[x,y,笔内毫秒]。首点时间0，时间非递减且≤30000ms；源点整数0–1000。最多100笔、单笔512点/30秒、总4000点；超过任一上限整笔拒绝，不留部分、不截断。完整紧凑JSON≤128KiB；4000个包含时间的点与100笔参数最坏词法可超过64KiB，因此采用128KiB，让已声明的最大组合能整体保存。测试完整100笔/4000点往返，没有靠降低普通输入范围通过验收。

同位置移动事件合并；松开时必要的同位置终点时间保留笔内停留。每次接收点保存单调经过毫秒，时钟倒拨夹到上一值。重放按各笔内时间逐步显示已到时的源点/线段，笔间固定200ms，不保存两笔间发呆间隔；可选1/2/4倍。不声称连续模拟未采集的轨迹、真实压力或逐帧原视频。总时长有界，单点无时长至少用1ms。暂停不扣时，续播从当前进度；播放结束保留完整画面，点“返回完整画面”退出播放器继续绘画。播放位置/速度/光标为会话状态，不写源工程；返回/重载不自动重放。

创建不启动RAF；只有用户点击播放或继续才排RAF，暂停/隐藏/deactivate/blur/destroy取消。完整源记录与笔刷/背景每次有效提交/设置后用featureLab.E015.project自动保存，保存期间锁编辑；失败明确显示临时状态，可重试或另存。未提交笔画不保存。旧档无效不覆盖、不偷偷清空，用户可导入或勾确认新建。恢复严格拒绝未来schema、重复JSON键、未知/缺失字段、非整数/精度词法、坏颜色/点序/超限记录。配置中保存源点，不保存Canvas/Blob/派生副本。

## 4. 如何使用与具体例子

1. 保持六轴、镜像关闭、默认绿笔。在右侧大画布从大约(700,400)拖到(740,400)，再到(780,420)，在画布内松开；统计增加1笔，六个方向各出现同形笔迹。
2. 六轴例首点(700,400)的六个副本约为(700,400)、(686.603,623.205)、(486.603,723.205)、(300,600)、(313.397,376.795)、(513.397,276.795)。相邻角度60°，半径均√50000。点击“撤销最后整笔”，六份一起消失，统计回到0。
3. 勾“另加镜像”，把笔刷色填#e4583f后点应用，绘一条小折线/闭环；每轴增加反射笔迹。再选12轴、取消镜像、改金色与粗细9，可在中心附近画第二层花纹；已绘笔颜色/轴数不改。
4. 不使用鼠标也可：Tab聚焦画布，空格/Enter开始一笔，方向键移10逻辑像素，Shift+方向键移1，空格/Enter提交，Escape取消。长按确认键不重复提交。也可设置x/y光标后用开始/结束键盘笔画按钮；图内移动以方向键操作。
5. 点播放完整记录；可暂停，等十秒再继续，暂停时间不计入笔内播放时间。离开/隐藏会暂停，回来只显示当前进度，不自动播放。点返回完整画面才能继续编辑/导出。
6. 展开“容量、恢复与完整副本”，另存完整JSON与PNG。JSON导入预览后必须勾确认替换，再点应用；已有/无效工程新建也需勾确认清空。自动本地保存完成后，真实窗口重载继续原作品，所有源笔触完整恢复。JSON是独立备份/迁移入口。

## 5. 产出与安全副本

|产物|内容与用途|
|---|---|
|JSON|完整schema1、全部源点/笔内时间、各笔参数快照、当前笔刷/背景；可严格重载与重放|
|Markdown|完整每笔参数/点数/时长清单，嵌完整JSON代码块，记录重放口径|
|PNG|完整1000×1000不透明图案与当前背景，无辅助线/光标/UI，非屏幕局部截取|
|本地配置|完整源工程自动保存；不含当前未提交笔画或播放器进度|

导出始终copyOnly:true。文本先检查saveTextSupportsCopyOnly===true，PNG检查saveBinarySupportsCopyOnly===true；缺能力禁用并解释。PNG通过Canvas原生toBlob生成，≤10MiB，规范Base64/SHA-256交公共二进制新副本接口；完整JSON≤128KiB，Markdown有界且远低于公共文本8MiB。ok===true才成功，取消/错误/字符串“true”/partialPath不报成功，部分路径提示人工核对。已有目标wx拒绝，原文件字节不变。PNG准备中离开会丢弃旧结果并清离屏像素；已进入原生保存的请求锁到回执，不能以返回新模块状态来认旧回执成功。
