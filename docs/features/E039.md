# E039 感官观察

## 1. 功能内容

五步固定顺序的静态日常观察提示：周围颜色、表面与纹理、已有声音、轮廓形状、近远空间。每步建议36秒，总建议3分钟；用户主动确认或跳过才切换下一步，也可以随时结束。计时只是可选建议，到期既不确认、不推进步骤，也不结束观察。无摄像头、麦克风、录音录像、音频播放、必填文字或呼吸调整。

结束卡温和说明本次到这里即可，展示确认、跳过、未观察三个独立数量，以及五步完整选择表。未观察和跳过不计完成；“确认”只代表用户点击，不声称设备或程序核验了身体感官活动。全部跳过也可正常结束，不要求凑够观察数量。没有医疗效果、诊断、治疗、积分或连胜承诺。

## 2. 为什么需要

让用户有一个从屏幕信息转到周围具体事物的可自主选择流程，而不是要求录下自己、授权设备或写出感受。颜色不必命名，表面可以只看不摸，安静环境不必制造声音，形状不必判断好坏，空间不必移动身体或强迫转移视线。每步都有跳过选项，触摸只建议熟悉且安全的表面，不接触陌生、高温或锋利物体。

这是一组原创的非医疗日常提示，没有采用或命名诊疗程序，不使用传感器测量，也不分析用户的心理状态。文字卡已经能清楚表达提示，未额外加入SVG、音视频或外部素材，以免为理解简单观察而继续占用注意力。用户可以只读提示并选择，不启动计时也能完成五步流程。

## 3. 实现方式、时钟口径与边界

`model.mjs` 内置五个冻结提示，每个含唯一ID、标题、说明、替代/跳过提示和suggestedMs36000。当前实例只有固定五行选择及有限计时标量，没有增长的历史列表、感官正文输入或设备记录。状态 `unobserved/confirmed/skipped`分开；初始五行都是unobserved，当前序号另存，用户确认/跳过才改变一行并按固定顺序前进。序号校验可拒绝迟到的旧步骤操作，避免重复消费下一步。最后一步决策或主动结束设置phase=ended；之后不能继续计时/选择，未处理行仍是unobserved。

计时使用注入单调clock，生产默认 `performance.now()`，根据真实毫秒差值累计；200ms interval仅刷新界面，不按回调次数扣秒。精确总预算180000ms，暂停重新设置运行基准，暂停10秒不会补扣。倒拨时钟取已见最大值，非法或非有限时钟拒绝；极大前台时间差只消费最多180秒预算，不逐秒补tick。到期timerState=expired并停止interval，仍停在当前步骤、所有原选择不变。前台长时间阻塞时下一次采样可到期，但同样不自动确认。

每步36秒仅是建议，没有强制单步期限。当前步骤可以用掉更多或更少建议计时；UI的“本步建议计时累计”与报告 `steps[].timedMs`记录全局倒计时在该步骤期间实际运行的部分，所有行合计=session.timedMs，且 `timedMs + suggestedUnspentMs = 180000`。例如一直停在第一步直至3分钟到期，它累计180秒，其他行0秒，仍是五行未观察。到期后继续观察不再计时，因此timedMs不是用户总实际观察时长。提前确认、全跳过或主动结束也不会伪造用满180秒。

create/activate不自启动interval，只有主动开始/继续启动。隐藏和deactivate在事件到达时暂停、清interval；返回/activate不续播。destroy移除按钮和visibility监听、停止计时、释放当前session并清空DOM，销毁后重复生命周期操作安全。无RAF。设置和选择只在当前模块内，不调用config、localStorage或sessionStorage；销毁、重开或刷新不恢复，请主动另存。

保存前暂停，原生pending期间锁住选择、计时、重置和确认控件。仅 `ok===true`报保存成功，取消单独提示，失败/partialPath供人工核对；保存后不会自动继续。离开/隐藏/销毁使代次失效，旧保存回调不会改写新界面；已写出的副本不自动删除。重新开始会替换当前记录，已计时/有选择/已结束的记录必须先勾选确认，不静默丢失。无JSON导入、用户代码、设备权限或网络依赖。

## 4. 使用步骤

1. 打开娱乐工作台“感官观察”，先读第一步。可点击“开始 / 继续建议计时”，也可直接观察后确认或跳过，不需要输入文字。
2. “确认这一步已观察”把当前行记为confirmed；“跳过这一步（不算完成）”记为skipped。下一步严格按颜色→表面→声音→轮廓→空间推进。
3. 点击“暂停建议计时”停止倒计时，选择仍可操作。离开或隐藏也暂停，返回后需要主动继续。
4. 建议3分钟到期时，当前提示仍保留，选择按钮仍可用，未观察数量不会自动减少。可以慢慢继续五步，也可以跳过或点击“现在结束（其余保留未观察）”。
5. 最后一步确认/跳过自动显示结束卡；全部跳过也能结束。表格和三个数量清楚保留真实选择，不把“流程结束”写成所有观察完成。
6. 点击完整JSON或Markdown记录副本，选择新文件名。已有文件拒绝覆盖。需新副本公共能力 `saveTextSupportsCopyOnly===true`；缺能力时按钮禁用。要重新开始，先另存需要的记录，再勾选“确认替换当前观察记录”，点击重开；新实例建议计时未开始。

## 5. 输出与精确例子

`sensory-observation-record-copy.json`包含schema1、feature E039、当前session、建议总时长/已运行/未用/暂停/暂停次数、当前序号/流程状态/计时状态、三个选择数量及五行完整ID/提示/替代方式/建议/累计计时/选择，还有明确统计口径。`sensory-observation-record-copy.md`包含同样的五步表、全部说明与替代提示、计时及数量，方便阅读。两种都要求 `copyOnly:true`，不导出感官内容或设备数据。

例一：不启动计时，五步依次“确认、确认、跳过、确认、跳过”，预期结束卡为主动确认3/5、跳过2/5、未观察0/5；JSON状态 `[confirmed, confirmed, skipped, confirmed, skipped]`，timedMs=0、suggestedUnspentMs=180000。说明手动决定与计时彼此独立，不能把瞬间点击写成实际观察了三分钟。

例二：开始后停在第一步，不作任何选择。179999ms还剩1ms；180000ms建议到期，仍为第一步、0确认/0跳过/5未观察、phase=observing、timerState=expired，interval停止。这时确认第一步，再直接结束，结果1确认/0跳过/4未观察。倒计时不会替你确认后四步。

例三：先运行20秒，暂停10秒，剩余仍160秒。继续后在从开始起190秒到达预算180秒，暂停统计10000ms，仍不自动推进步骤。独立clock oracle验证这组期限，不等同于真人进行了三分钟感官活动。

例四：五步全跳过，结果0确认/5跳过/0未观察，可以结束；中途只确认第一步再结束，其余四步仍为未观察。所有结果都能导出完整五行，无截断或填充确认。
