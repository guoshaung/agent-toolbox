# T071 开发运行时发现报告

## 1. 功能内容

逐个选择最多4个可信 Python / Node 可执行文件，指定两种运行时各自最低稳定版本与32/64位筛选。文件选择和计划预览不执行程序；明确确认后只执行固定版本查询，完整列出用户选择来源、规范路径、自报版本/实现/进程位数/平台标签、是否满足条件，以及失败、取消和未运行项。JSON / Markdown先预览，再保存新副本。

不扫描PATH、不自动寻找磁盘文件、不安装或切换版本、不运行用户项目、包管理器或任意命令。两条Python路径分别查询，不按文件名或一次全局python结果填满报告。

## 2. 为什么需要

同一电脑可同时安装多套Python/Node；终端默认python与项目选择的解释器可能不同。分别观察明确路径的版本，再和项目要求比较，可定位“旧版本”或“进程位数不符”，并保留可复核的全部候选。报告描述本次所选安装，不能据此证明项目依赖齐全或能够启动；这些属于另一个验收步骤。

## 3. 实现方式

固定可信Host经公共features:hostCall调用。操作为choose/clear/plan/run；renderer不能提交可执行路径、脚本、额外参数、shell、环境变量或目录。choose每次系统文件选择一个普通本地文件；Windows限定.exe，拒绝cmd/bat/PowerShell、空文件、目录与最终文件符号链接；其它平台要求执行权限。父目录允许规范化实际路径，不声称所有父目录无链接。最多4候选，每窗口绑定随机候选ID和一次性计划ID，不能使用其它窗口的ID或未选择路径。最多32窗口，每窗口128已用任务ID，重放拒绝。

Python固定 `-I -B -S -c`：仅导入已安装标准库sys/sysconfig/json并输出版本三元组、releaselevel、implementation、sys.maxsize对应进程32/64位、sysconfig.get_platform及sys.executable。-I忽略PYTHON环境和用户site/工作目录，-S不加载site，-B禁止导入写pyc；Python3.4前不支持-I，本版本不回退执行其它参数。Node固定 `--eval`：只读process.version/arch/platform/execPath并输出同一有限JSON格式。Node未知架构不能冒充32/64位成功。版本查询代码完全显示于计划中。

spawn使用绝对规范可执行路径、shell:false、windowsHide:true、detached:false、cwd为该安装目录、stdin忽略；不经PATH查找。复制当前环境后删除大小写不敏感PYTHON*/NODE_*/ELECTRON_*启动变量，保持原进程环境和系统设置。其它环境和动态库/安装文件不做操作系统沙箱限制；因此必须由用户选择可信安装，文件名、正确JSON和隔离参数都不能认证恶意程序。程序自报不作数字签名/真实性证明，也不能阻止恶意文件自行联网、写入或派生进程；功能自身不发送网络请求或写用户安装。

每文件前后检查普通文件实际路径与dev/ino/size/mtime身份，变化或不可用不判通过；检查不是文件锁或恶意TOCTOU防护。自报executable须规范化字符串等于已选择路径（Windows忽略大小写），仅比对、不读取自报的其它文件。stdout最多16KiB、stderr最多8KiB，严格UTF-8与完整单JSON结构；原始stderr/异常/环境不进入报告。进程非零、输出超限、类型/字段/位数/路径不符均未知，不拿版本片段凑成功。

最低版本为无前导零的完整major.minor.patch，各0–999；逐数字比较，须稳定final且>=最低值，32/64位如有限制须匹配。预发布即使三元组较大也不满足稳定要求；失败/未运行的assessment为null。进程位数和平台标签分别保留；Python标签如win-amd64是安装报告，不将它推断成跨平台精确ISA或OS位数，Node标签如win32-x64记录编译进程架构。

每窗口串行，每项5秒进程等待期限、整批25秒协作期限；最多4次查询，不重试。文件API等待不能强制中止，计时器依赖事件循环，不主张硬实时25秒返回。取消请求当前本工具spawn所得child.kill(SIGKILL)，不按名字找进程、不停止用户已有程序、不递归结束进程树。立即取消可在程序启动前标记；完成前缀保留，未开始项not_run。报告区分terminationRequested/terminationObserved：请求kill返回不等于观察到退出，只有实际close释放槽；同一窗口尚有child未关闭则不能新查，所有窗口总计最多4个未关闭查询child，销毁窗口也不提前释放全局槽。

界面编辑条件清除旧计划/报告；运行期间锁定选择/条件，取消仍可用。隐藏/离开/销毁请求取消并使旧回调失效，不自动重查。离开时尚在选择文件的对话框不强制关闭，迟到选择不重建面板，返回后可清除候选再选。派生报告/路径/条件不存配置，仅工作台最近功能编号由基础工作台保存。报告各最多1MiB，全部候选完整输出，超限拒绝不截断。

官方依据：[Python3.13 CLI隔离、-B、-S](https://docs.python.org/3.13/using/cmdline.html)、[Node20.18.3 child_process spawn/kill](https://nodejs.org/download/release/v20.18.3/docs/api/child_process.html)、[Node process版本和架构](https://nodejs.org/download/release/v20.18.3/docs/api/process.html)。

## 4. 如何使用

1. 打开“工具 → 系统与本地环境 → 开发运行时发现报告”。选类型Python或Node，点“选择一个可信运行时文件”，逐个选择自己的安装，最多4个。
2. 输入完整最低稳定版本（如Python3.13.0、Node20.0.0），选择不限/32/64位。点击“预演完整固定查询”，核对每个规范路径、来源、完整固定参数、次数和期限；此时不执行版本查询。
3. 勾选“我确认所选可执行文件可信及上述固定参数”，点击“确认执行有限版本查询”。可取消；不要将not_run、失败或未知读成满足。
4. 查看各自版本、进程位数、平台标签及不满足项；修改条件需重新预演与确认。要更换候选，清除全部候选再选择。
5. 展开完整JSON或Markdown预览后保存新副本；分享前核对本地完整路径。已有文件拒绝覆盖。没有文本copyOnly能力则不调用保存；只有ok===true报成功，取消/false/undefined/异常保留预览。

## 5. 使用后产出与验证

`T071-runtime-report` v1包含已确认计划的全部候选/固定参数/筛选、任务ID、UTC本机时间、单调耗时、实际查询调用数量、全部逐项来源/路径/状态/观察值/不满足项，以及取消/超时原因。无原始stderr、环境和项目源码。JSON可逐字段核对，Markdown包括完整同一JSON；展示或筛选不删除不满足项。

定向21项 + 公共Host6项：27/27通过。验证数字版本比较/预发布/位数、严格自报格式、启动环境只复制不改原值、两条Python受控输出一条不满足、选择/预演零spawn、确认/跨窗口/额外路径/脚本/重放拒绝、4候选/重复/字段、普通文件变化前置阻止、非零/非法JSON/自报路径欺骗、只终止所属child且close前不放槽、输出预算及后续不运行、早取消零启动、六窗口并发最大4child、真实当前Node固定查询与实际process.version独立对照、完整报告。

五秒超时测试使用真实本工具测试spawn出的Node等待进程，约5秒请求终止并观察close，后续不启动；此测试seam将参数替换为测试等待代码，不冒称生产固定查询曾自然卡住。两Python不同版本在专项用受控child输出，真实生产路径查询另记原生证据。组件六项用真实h和DOM适配，覆盖确认、修改失效、全部候选、预览/copyOnly、严格保存响应、缺桥拒绝、隐藏/离开/销毁与迟到结果；不是操作系统鼠标/文件对话框证据。

原生生产Electron验收将完成后补记录；打包发行、跨OS、其它Python实现/旧版本及项目启动不在当前验证范围。

## 6. 具体使用例子

电脑有 `C:\Python313\python.exe`（Python3.13.7）和 `C:\ToolRuntime\python.exe`（Python3.12.14）。分别按Python类型选择它们，最低版本3.13.0、要求64位。计划列两次固定 `-I -B -S -c` 查询，确认后两个路径分别观察：3.13.7/64位满足；3.12.14/64位不满足，mismatches恰`below_minimum_version`。不删除旧版本、不修改PATH，也不把两个路径都填写成终端默认python版本。

另加Node22.20.0，Node最低20.0.0/64位，该行满足。如果第二Python无法执行或输出不合规范，则那行未知、assessment=null；不能宣称低版本或满足。查询过程中取消只影响本工具当前子进程，之后候选not_run，报告仍保留此前已完成行与取消原因。
