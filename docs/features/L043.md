# L043 语料搭配观察

## 1. 功能内容

L043在学习工作台的「语言与表达训练」中，从用户本地TXT或人工粘贴TXT构建KWIC（关键词左右窗口索引）、按侧/距离分别统计的邻词频次、完整原行及文件/行号出处。查询单个词元，不联网、不调用AI、不推荐某种用法一定正确。

用户可以真正选择1–8份本地TXT，检查文件名、字节数、原字节SHA-256和完整只读原文；也可在粘贴文本模式编辑小型练习语料。输入关键词、每侧窗口0–10词及显式大小写开关后主动构建。编辑输入会使旧报告失效；不会把部分扫描或前一次结果称为完成。

KWIC每页25个匹配，每个匹配都显示左右词、原词形、文件ID/名、原行号、行内词序号和UTF-16列。下方保留整条原行并高亮该处关键词。出处按原行记录：一行多句会完整显示，不自动切句、猜测说话人或补写引文。邻词表的每条计数同时指明「左/右」和「第几词」，避免把不同距离混成同一个搭配。

## 2. 为什么需要

词义或译文不能替代真实使用语境。用户可以带自己的阅读、写作材料，检查某词附近反复出现的词和原句位置，再自行判断上下文。保留来源和原行使统计能够复核；把频次按距离拆开，可区分紧邻词与较远词。

新增能力是用户语料的可追溯使用证据，不是已有术语解释、翻译或自动生成例句的复刻。相同句子被复制两次会贡献两次频次；工具不会将复制或重叠窗口视为两份独立语言学证据，也不会由高频自动推导适合所有场景的表达建议。

## 3. 实现方式

### 分词与查询口径

`model.mjs`先严格UTF-8解码并保留原字节SHA-256，再按CRLF/LF/CR拆分原行，保留空行和末尾空行。在每条原行内用JavaScript `/\S+/gu`取非空白词元：普通空格、制表符和Unicode空白是分隔符；标点仍属于词元，不去标点、词形还原、自动分中文词或做语言学分词。

关键词是单个完整词元的**字面匹配**，不是正则表达式。例如`look`不会匹配`look,`、`look.*`或`LOOK`（大小写敏感模式）。用户明确关闭大小写敏感时，查询与频次键使用`toLowerCase()`；KWIC仍保留原词形。这不是完整语言特定case-fold、Unicode规范化或词形等价。

每次匹配的窗口最多取同一原行内的N个左词和N个右词；窗口绝不跨行或文件。行首/行尾不足窗口不补词。KWIC把词元用单个空格连接展示，完整原行另存原空白/标点。模型记录UTF-16起止索引，用文本节点与`mark`高亮对应词，不执行或拼接用户HTML。

频次计算规则为：

```
对每个匹配：
  左第1词 = 左窗口最后一个词；左第2词 = 倒数第二个词；依次类推
  右第1词 = 右窗口第一个词；右第2词 = 第二个词；依次类推
  对(side, distance, normalizedToken)计数加1
```

词频键使用Map而不是把用户词作为对象属性；`__proto__`、`constructor`也是普通语料词。结果按左/右、距离升序、频次降序、词元确定性顺序排序。重复匹配与重叠窗口各自贡献，不自动去重。同文件名或相同hash的两份文件仍有不同F编号；不声称二者内容独立。

来源原字节不变。UTF-8 BOM只从索引正文移除，仍计入字节数/hash；列号为去BOM后JavaScript UTF-16代码单元的1起始位置，不是UTF-8字节位置或Unicode码点列。报告保留编码/BOM说明。

### 有界预算与整份失败

| 输入/输出 | 首版限制 |
| --- | --- |
| 本地TXT | 1–8份，每份≤512KiB，合计≤1MiB；严格UTF-8，拒绝GBK/UTF-16/非法UTF-8，不猜编码 |
| 粘贴 | UTF-8体积≤1MiB；空正文可以产生零匹配结果；来源名明确是人工输入，非磁盘文件证明 |
| 原行/词元 | 总≤20000行、100000词；每行≤2048 Unicode码点、每词≤80码点 |
| 查询 | 单个非空白关键词≤80码点；每侧窗口0–10；不接受指数数值/短语/用户正则 |
| 匹配 | 最多2000次；第2001次使整份查询失败，不保留截断报告 |
| 报告/导出 | 紧凑完整JSON≤4MiB；完整格式化JSON和Markdown各≤8MiB；任一不满足即整份查询失败 |
| 配置 | schemaVersion=1输入草稿，完整JSON UTF-8≤64KiB；检查版本/字段/字符/体积，不接受派生报告 |
| 展示 | KWIC每页25；邻词表明确显示首200项/全部项数；完整预览和导出含所有匹配、全部频次、全部原文 |

查询每2048个词/行工作项异步让出并检查取消，完整扫描后再检查报告与双格式导出预算。读取、UTF-8解码、WebCrypto hash和最终JSON序列化有上述有限字节上限；不能声称这些底层同步/原生步骤可逐字节强制Abort。取消/切走使票据失效，合作式查询停止，迟到结果不能替换来源或报告；当前任务释放后重新运行。文件导入整组校验完成后才替换来源，失败/取消保留先前完整来源集合。

`index.js`使用真实File/arrayBuffer读取本地文件，只缓存有界的解码文本与元数据，不写原文件。配置队列至多一个进行中和一个最新待保存输入；旧完成回调不能掩盖较新无效输入。草稿保存查询参数、粘贴来源名和粘贴正文；**导入TXT/名字/hash、索引、频次和派生报告不写配置**。大于64KiB的粘贴可在1MiB范围内查询，但明确提示未写配置，关闭只能恢复较早合法草稿，需先导出报告或自行保留文本。

过滤只匹配来源ID/名/原行文字，分页只限制显示。过滤输入重绘后恢复焦点与光标，可连续输入；不会因过滤清空完整结果。切走取消在途流程，销毁清理来源文本、报告和DOM；不创建音频、摄像头、网络连接或长期计时器。

## 4. 使用步骤与具体例子

1. 打开学习工作台→语言与表达训练→L043。
2. 选择「本地TXT文件」并选择自己的UTF-8文件；成功后核对完整文件名/hash和原文预览。或使用「粘贴/编辑TXT」，填写人工来源名与正文。
3. 输入单个关键词和每侧窗口，确认大小写规则。点击「构建KWIC与频次」。空白词元规则不适合未经分词的中文长句时，应先自行准备空白分词语料，工具不会自动补分词。
4. 查看KWIC、文件/行号和完整原行，核对左/右第几词的频次。需要时按出处文字过滤或翻页；导出不受这些显示选择影响。
5. 预览完整JSON/Markdown，注意报告含全部原文，选择不存在的新目标保存副本。重新打开时导入文件需重选，粘贴草稿仅在≤64KiB合法范围内恢复；结果重新计算。

### 验收例

点击「装入两行示例」，保持关键词`look`、每侧窗口2、大小写敏感，然后构建：

```text
take a look
take a look
```

恰好2个匹配，来源`P1 · 练习语料.txt`第1/2行，第3词、UTF-16列8；两条完整原行均可查看。左第1词`a`计数**2**，左第2词`take`计数2。没有右邻词。不是把`take`与`a`混为同一距离频次。

把关键词改为`look,`使旧结果失效；重新构建为零匹配，因为不会自动去标点。将窗口改0，重新查询`look`仍有2条出处，但邻词表为空，不能把「没有邻词」误称没有匹配。

### 多文件与大小写例

在临时目录运行以下Node脚本生成真实文件；只写入不存在的新文件，不改写用户原文件：

```js
const fs=require('node:fs');
fs.writeFileSync('evidence1.txt',Buffer.concat([
  Buffer.from([239,187,191]),
  Buffer.from('take a look\r\ntake a look\r\n','utf8')
]),{flag:'wx'});
fs.writeFileSync('evidence2.txt','LOOK around\nlook <script> &\n',{
  encoding:'utf8',flag:'wx'
});
```

只选第一个文件：`look`2次，左第1词`a`频次2；BOM被索引移除、来源hash含BOM，末尾空行仍计第3行。选择两文件：大小写敏感为3次；明确关闭大小写敏感为4次，其中KWIC仍显示原文`LOOK`。原行`<script>`只显示文字，不能执行。用过滤隐藏全部可见行后导出仍有全部4次。

## 5. 产出内容与保存

JSON顶层包含feature/schemaVersion/modelVersion、query、完整sources与原文/原行索引、totals、全部matches、全部neighborFrequencies和definitions。每个match保留来源ID、行号、词序号、UTF-16列/起止索引、完整左右窗口和原词形；sources的完整lines可恢复每条匹配的原行。保留全部语料正文使出处可复核，不只导出屏幕上的页。

Markdown包含查询/计数概述和安全围栏内完整JSON；用户`< > &`被转义、反引号围栏长度动态选择，不执行用户内容。超过双格式预算时整份报告拒绝，不提供假装完整的某一格式。

生产保存调用`files.saveText({content,extension,defaultName,copyOnly:true})`；要求`saveTextSupportsCopyOnly===true`且响应`ok===true`才确认成功。取消/失败保留当前报告。生产writer以`wx`拒绝已有目标；不能覆盖原TXT或已有报告。本工具不读取文件系统路径、执行用户代码或修改来源。报告包含全部正文、原文件名/hash或粘贴来源名，用户应在完整预览中判断是否适合分享。
