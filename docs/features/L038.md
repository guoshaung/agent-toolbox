# L038 固定效应汇总演练

## 1. 功能内容

输入1–20项用户研究的标签、effect、SE及效应单位/尺度，按固定共同效应逆方差模型复算相对与归一化权重、加权贡献、汇总effect/SE、各研究及汇总的±1.96SE正态近似95%区间。显示全部原始记录和中间项、完整JSON/Markdown预览以及森林图，支持JSON/Markdown/SVG安全新副本导出。

森林图的横线是各研究区间，方块中心是effect，方块面积与权重成比例，汇总钻石左右端点是汇总区间、中心是汇总effect。轴自动包含所有研究和汇总区间，最多20项都实际绘制，不裁剪区间或把筛选结果当完整导出。

## 2. 为什么需要

不只看到一个汇总数，还能逐项核对SE如何影响权重，以及相同或不同SE下加权结果如何形成。默认effect1/3、SE1/1产生50%/50%、汇总2；SE改为1/2时权重80%/20%，汇总约1.4。这些都是计算练习，不自动推荐模型、投稿或判断显著性。

共同效应假定、研究独立性与用户提供SE的正确性均未自动证实。图中正态近似区间不是覆盖保证，出现钻石不代表模型适用或论断可信。用户必须提供相同效应尺度；工具不自动转换比值/log、不估计SE或自动去重相关研究。

## 3. 公式、数值和实现

固定逆方差公式及汇总SE核对自[Cochrane官方RevMan算法文档](https://documentation.cochrane.org/revman-kb/files/210600101/210600103/1/1654774257333/Statistical_methods_in_revman.pdf)第6页式(7)/(8)，正态区间形式在第8页。共同效应假定与森林图语义参考[Cochrane Handbook第10章](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-10)10.2.1/10.3.1。本功能只实现指定教学模型，不实现该文档的其他方法。

```text
理论权重 wi = 1/SEi²
归一化 pi = wi / sum(w)
mean = sum(pi*effecti)
pooledSE = sqrt(1/sum(w))
研究区间 effecti ± 1.96SEi
汇总区间 mean ± 1.96pooledSE

实现缩放 m = min(SEi)
qi = (m/SEi)²，与wi成比例
pi = qi/sum(q)
pooledSE = m/sqrt(sum(q))
```

`model.mjs` 使用缩放后的相对逆方差，不直接求极小SE平方的倒数。权重和及加权贡献求和采用补偿求和。输出相对q、归一化p/%及贡献，不把q误称绝对1/SE²值。`index.js` 提供实际表格增删、例子、结果、图像与导出，`meta.json`由工作台发现，CSS使用实际项目主题变量。

- 1–20项研究，标签与单位最多40Unicode码点，effect/SE文本最多32码点。有限十进制/科学计数法（指数≤三位）；effect允许0或绝对值1e−150至1e9，SE严格正且1e−150至1e9。拒绝零/负SE、非有限、下溢为零、超范围、空标签/单位、控制符及孤立代理项。重复标签按行索引保留，不自动去重研究。
- 全部计算使用JS Number双精度，并非精确十进制。摘要/刻度8位有效数字，表与JSON保留实际Number及原输入。检查相对/归一化权重、非零加权贡献与汇总SE下溢、各中间项非有限；正区间半宽舍入成效应点时拒绝。轴需要五个不同Number刻度及不同的8位摘要标签，否则整份拒绝并提示调整单位/尺度，不假画一个零宽区间或相同刻度。
- SVG为代码生成的静态独立图片，宽1400、高`290+36×研究数`，默认362、20项1010像素。标签/单位/metadata严格XML转义，没有脚本、外部资源、textLength伸长或clipPath。标签图上最多14码点，完整名称在表格、title与metadata；主字号16，数字14，36像素行距防止碰撞。界面图片最小宽1100，可横向滚动，不压缩成长标签叠在区间上。
- 横轴取全部研究及汇总CI最小/最大，再各加5%范围留白。五个线性刻度；若零在范围内绘零参考线，否则注明零不在当前范围，不强行用零扩大。每个方块边长按`22*sqrt(p/max(p))`，面积比例符合权重；极小权重可能不可见，有文字说明和完整权重表。区间与钻石坐标均按实际计算值映射。
- schemaVersion=1，配置`features.L038.state`只保存unit和原研究标签/effect/SE，先验证整个JSON UTF-8体积≤64KiB，版本化草稿再验证，不保存汇总/图形/权重。恢复验证版本/体积/字段，结果须重算。每次编辑清空旧输出，切走保存、销毁释放图像DOM；异步保存/导出失败明确提示，销毁后不更新已释放界面。字段未完成可存草稿，不能当作有效汇总；超限整份拒绝，不截断，关闭只能恢复较早合法输入。

## 4. 使用步骤与可复现例子

1. 在功能工作台打开“固定效应汇总演练”，或点“载入50/50示例”。两项effect1/3，SE均1。点击“汇总并绘图”，相对q均1、sum(q)=2、权重50%/50%、贡献0.5/1.5、mean=2、pooledSE=1/√2约0.7071067812。各研究区间[-0.96,2.96]/[1.04,4.96]，汇总约[0.6140707089,3.385929291]。
2. 将研究2SE改为2，旧图失效，重新计算：q=1/0.25、sum(q)=1.25、权重80%/20%、mean约1.4、SE=√0.8约0.894427191、汇总区间约[-0.3530772944,3.153077294]。方块面积比4而非边长比4，第二研究区间变宽。
3. 删除第二研究，只保留effect−3、SE2，应得到100%权重、mean−3、SE2及原研究相同区间。单研究仅作为公式退化练习，不声称形成多研究证据。
4. 将SE填0应整份失败；effect1e9/SE1e−150会因区间半宽无法表示而拒绝。单研究effect1e9/SE1e−6虽可形成Number端点，但8位摘要刻度无法区分，也明确拒绝。合法极小例effect0/SE1e−150与effect1/SE1仍用稳定比例，较小权重正且数据完整保留。
5. 点击“添加研究”并编辑标签、effect/SE，最多20项；第21项不会被追加，提示上限。标签/原数字始终在表中；更改任何输入旧结果清空，需重算；示例会替换当前草稿，需要旧数据时先导出。
6. 查看完整预览，导出JSON/Markdown或SVG。重载/切走恢复输入草稿，汇总需重算。SVG是完整静态森林图，metadata包含全部研究原数字、权重、汇总及轴；需要导出时间和完整草稿封套时选JSON/Markdown。

## 5. 产出与副本保护

JSON含feature、schemaVersion、modelVersion、导出时间、原draft与完整result。结果保留每项index/完整label、原effect/SE字符串、实际Number、近似CI、相对与归一化权重、百分与贡献；还包含最小SE缩放基点、sum(q)、汇总effect/SE/CI、轴/刻度、公式及全部模型边界。Markdown给简短汇总后附完整记录，不省略20项；用户文本HTML转义并用动态长代码围栏包住。

SVG包含全部研究线/点、权重/区间数字、汇总钻石、网格/轴/参考及说明，完整result放入metadata，可还原精确JSON结果；所有原研究输入字符串保留。图上标签缩略只用于显示，完整title/metadata不截断。未生成成功结果时只可导出合法容量草稿JSON/Markdown，SVG按钮禁用。

检查`saveTextSupportsCopyOnly===true`后请求`copyOnly:true`，仅`ok===true`认定成功，取消/失败独立提示。生产写入器wx拒绝覆盖已有目标；超字段/整体容量的输入整份导出拒绝，不能假装保存了完整新报告。无AI、网络、计时器或图像识别。
