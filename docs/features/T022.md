# T022 · PDF 永久遮盖

## 1. 功能内容

选择本地 PDF，逐页在页面上拖动框选，或填入整数像素坐标添加遮盖框。每个框以不透明黑色覆写对应像素；随后将所有页面重新编码成 PNG，创建全新的纯图像 PDF。新文档没有原文字层，不复制源附件、批注对象、历史修订或元数据。生成后全部输出页必须成功预览，再勾选“已核对全部最终页与未遮盖内容”，才能另存 PDF。

支持一份 1 字节至 2 MiB、1–8 页的未加密 PDF，固定 144 DPI 白底渲染；每页边不超过 4096、像素不超过 4,194,304，所有页合计不超过 16,777,216 像素；最多 100 个页内整数像素框。完整 PNG 中间字节及最终 PDF 各不超过 10 MiB，审计报告不超过 1 MiB。任何超限或失败都整体拒绝，不保存部分页。

## 2. 为什么需要这个功能

在原 PDF 上叠加黑色形状可能只遮住外观，底下的文字仍可被复制、搜索或从文件对象中取出。分享包含手机号等信息的文件，需要让遮盖区域对应的原像素和原文字对象都不进入新文件。本功能通过新的页面位图重新构建文档，并提供区域和输出摘要记录，便于核对实际分享的是哪一份文件。

遮盖范围由用户明确指定，功能不会自动识别所有敏感内容。未被覆盖的视觉内容仍保留；用户必须逐页检查。输出失去文字搜索、矢量清晰度、可访问文字语义、链接和交互能力。

## 3. 实现方式

`index.js` 使用项目已有 PDF.js 4.10.38 的本地资源，把源页按可见裁切和旋转渲染到白底 Canvas；不提取正文，不执行源 PDF JavaScript，`isEvalSupported:false`。鼠标框选通过显示坐标换算到渲染像素，起点向下、终点向上取整，完整覆盖选区；数值输入提供无需拖动的操作方式。

`model.mjs` 对完整 RGBA 页面检查全部 alpha 为 255，再逐像素覆写黑色遮盖框，未覆盖像素不变。PNG 只由这个新位图编码。本功能私有的固定 pdf-lib 1.17.1 包运行于模块 Worker；它只接收 PNG、尺寸和页物理尺寸，不接收源 PDF 字节或对象。新建文档后逐页 `embedPng/drawImage`，删除生成库的空字体/图形状态/注释字典；不使用 `copyPages/embedPdf`。[上游 API](https://pdf-lib.js.org/docs/api/classes/pdfdocument)提供新建页面和嵌入 PNG 接口；原发行包完整性、字节 SHA 和六项原始许可证随私有 vendor 保存，不修改共享依赖。

源页的裁切与旋转落实为新页的位图方向，新页旋转为零，大小按可见页保存。页面白底保留，未复制的源对象没有恢复入口。PDF.js 的渲染兼容性和光栅分辨率仍限制可见内容质量，不保证所有特殊字体、交互表单或颜色配置与其它阅读器完全一致。

载入设 30 秒取消请求期限，PDF 构建 Worker 设 30 秒期限；取消会销毁加载任务、终止本次 Worker、废弃迟到编码/渲染回调。原生解码或文件读取结束前控件继续锁定。输入字节、像素和期限上限不等同于解压内存硬限或不可信文件安全沙箱。离开/隐藏清除原页位图、来源身份和输出，返回需重新选择；源 PDF 与大字节不写配置。

## 4. 如何使用

1. 在功能工作台打开 T022，选择待分享的 PDF，等待全部来源页完成渲染。
2. 选择页码，在页面上按住鼠标框选敏感区域；也可填写“遮盖X/Y/宽度/高度”并点击“添加当前页遮盖框”。坐标原点为渲染页左上，右下边界不包含。
3. 检查完整遮盖框清单。删除不需要的框，再检查其它页；添加或删除框会立即作废旧输出。
4. 点击“生成并预览全部纯图像PDF页”，检查所有最终页，确认遮盖区域和其它视觉内容符合需求。
5. 勾选已核对全部最终页，然后另存 PDF 到新文件。需要保留操作记录时，预览并另存完整 JSON 或 Markdown 遮盖审计。

源文件加载失败会保留之前成功载入的来源位图，旧输出已失效。保存开始后取消按钮禁用，不声称能撤回已提交的文件写入。关闭/切换前请保存所需产物；不自动保存或重放处理。

## 5. 使用后的产出与验证

产物为 `redacted-raster.pdf`，每页仅含新图像；来源报告 `redaction-audit.json/md` 记录来源文件名、字节数、SHA-256、页数、144 DPI、全部像素/物理尺寸、源裁切与旋转、每页遮盖位图 SHA、所有框的坐标与最终 PDF 摘要。报告不包含提取正文或原 PDF 字节，但来源文件名与摘要可能有识别意义，分享前须检查。

PDF 调用生产二进制新副本桥，报告调用生产文本新副本桥，全部 `copyOnly:true`、仅 `ok===true` 确认成功；缺少副本能力时禁用对应导出，已有目标拒绝覆盖，失败或取消保留完整预览。

17 项专项测试通过。独立逐坐标 RGBA oracle 检查重叠遮盖/原位图不变，透明输入拒绝；独立 PNG 块构建和 zlib 解压核对新 PDF 图像的完整 RGB，不复制 PNG 文本元数据。涵盖全部八页和一百框、严格几何/未知字段/原 PDF 误入构建拒绝、完整报告及二进制摘要、真实组件框选、最终预览确认门槛、全部失败/取消/undefined 保存回执、编码迟到、Worker 期限和离开清除。

真实隔离 Electron 33.4.11 / Node 20.18.3 使用生产工作台、catalog、预加载、PDF.js、模块 Worker 和文件写入器，10 组验收通过且无控制台错误。真实 FileAPI 加载两页，其中第二页源旋转 90°；实际 CDP 鼠标事件验证框选及删除，数值框覆盖手机号。生成的两页全部预览、完整审计 JSON/Markdown 回读一致、生产 WX 拒覆盖、加密拒绝、取消与离开清除、零网络/源 SHA 不变。原生保存对话框和配置目标为隔离夹具，未声称系统保存窗口人工交互或安装包验收。

独立 pypdf 6.10.0 验证源含手机号、隐藏文字、附件、旧作者/标题、JavaScript、旧注释；输出两页均无可提取文字、Font、Annots，根节点无 Names/Metadata、无附件、无 Info。独立解码输出嵌入图像核对全部 576,000 像素：25,200 个框内像素全部不透明黑色，其余全部与实际来源渲染位图完全一致。原 PDF SHA 不变。Poppler 独立渲染输出两页，完整图片均已实际查看：手机号区域纯黑，上方公开文字和第二页方向清晰。这是该夹具的完整对象/像素证据，不代表自动发现或遮盖了所有敏感信息。

## 6. 具体使用例子

一份 240×300 pt 的两页 PDF，第一页上方写 PUBLIC HELLO，下方有手机号 13800138000；文档还包含不可见文字 SECRET_HIDDEN_TEXT、敏感附件和旧注释。144 DPI 后第一页为 480×600 像素。选择第 1 页，填 X=60、Y=130、宽=360、高=70，添加框后生成。

最终第一页公开标题仍可读，手机号所在的 25,200 像素全部为黑色；第二页按原可见方向保留。输出不能搜索或提取手机号及隐藏文字，也不含旧附件、旧注释、旧标题/作者和脚本。检查两页、勾选确认后另存新 PDF，再另存审计记录。再次选择已有目标会失败且原目标 SHA 保持不变。若还有别处可见敏感信息，需显式添加对应框并重新生成、逐页核对。
