# L008 知识前置诊断图

## 1. 功能内容

L008 接收用户的前置依赖图、选定目标与各知识的**会/不会/未知**人工状态，沿目标全部前置寻找最早待处理前沿。前沿“不会”列首要修补，前沿“未知”列先核实，其上层仍待处理知识列延后。输出全部知识状态/相关性、最早阻挡项、所有目标→前沿路径及逆向回查顺序、完整箭头图和JSON/Markdown/SVG副本。实现 catalog 的“手工设置会/不会/未知；从目标沿依赖寻找未掌握根节点”，完全本地，无AI/网络/外部运行时要求。

默认K3=C→K2=B→K1=A，箭头表示**知识依赖前置**；A不会，B/C未知。点击“诊断人工前置图”：首要修补仅 **K1 A**，先核实0、B/C延后、路径C→B→A，回查A→B→C。符合catalog验收：B未知不会抢在更下层A前面。

真实界面可选择目标、增删知识/前置边、编辑名称/会不会未知/人工依据/出处、填写问题背景，查看全图和全知识表、选择高亮路径、查看全部路径/报告预览及保存输入归档。节点/边ID固定，不靠重名自动合并或位置锚来改引用。

## 2. 为什么需要

卡在目标知识时，单独标一个“不会”不能判断先处理哪项前置。把用户依赖声明和状态分开，能先找到其下层没有其他待处理前置的知识，而不是直接重复目标。多个分支可以同时列首修/核实，共享前置只列一个前沿节点，但保留每条到它的路径。

这与模板熟练标记/Leitner复习不同：本功能计算人工DAG的待处理偏序和路径，不进行出题、默写或能力测试；与讲解证据链/外部来源追溯也不同，节点是人工知识状态，前沿依状态变化重算。未知不是自动不会，缺出处不伪造证据。“会”也只是用户声明：若其图中仍有不会/未知前置，单列人工审阅提示，不自动判状态冲突或将会降级。所有依赖、状态、出处是否可靠由用户核实，没有学习效果分数或能力真实性认证。

## 3. 实现方式与规则

纯`model.mjs`严格验证人工图、计算可达/前沿/完整路径、生成报告和SVG；`index.js`实现生产feature接口、编辑表单、SVG DOM/表格、异步票据、配置队列/严格副本写盘；CSS使用项目实际主题变量。没有`eval`、用户代码、联网、AI或外部源扫描。

**方向和前沿。** 边from→to表示from需要to作为前置，方向由用户录入。全图必须DAG；未知端点、自环、重复同向边、任何位置的循环（包括本目标不可达部分）均拒绝。没有自动因果解释，也没有将未录入前置当成现实不存在。名称可重复，引用只认节点ID。

先得到目标及全部可达前置R，再取U={R内人工状态不是会的节点}；前沿F={u∈U，u的严格可达前置中没有其他U节点}。F内不会是修补、未知是核实，U\F延后并列其可达前沿阻挡者。“最早”是这个前置偏序，不是日期/难度/重要性排序。所谓未掌握根指待处理前沿，**可能是原图内部节点**：它更下层已手工会时，从该项补/核实，不要求原图出度为0。

不会因一个节点被填会而停止遍历其下层。相关会节点含待处理前置时只提示审阅、保持原声明。全R会时没有待处理前沿/路径，仅表示用户图中未见待处理项，不能报告“能力通过”。不可达节点/边仍保存、绘图灰色、完整列出，状态不影响本目标前沿，但全图结构仍必须合法。

每个前沿枚举**所有**目标→前沿的有向路径，节点和边ID完整保留；共享前沿去重、不同路径不丢。逆序回查只是路径说明，不是保证其他分支具备的自动学习计划。路径选择只高亮，不筛减JSON/Markdown或完整路径表。

**输入和容量。** schema1保存当前修订号、问题标题/背景/出处、全部知识名称/三态/依据/出处、边端点/依据/出处、目标和ID计数。知识K1–K9999、边P1–P9999递增，删除不复用；有目标/边引用的知识不能删除，先人工换目标/删除边，不隐式清图。合法编辑增加修订号、旧结果作废；它不是时间戳或不可变修改历史。名称/状态说明是整个当前字段，不是原文摘录，不虚构位置锚或历史版本。Unicode字符按码点限长，短图标签不切开emoji代理对；控件caret使用浏览器UTF-16，普通输入遵循浏览器换行规范化，不声称外部字节保真。

最多12节点/32边；知识名80、状态/前置依据600、问题标题80/背景1200、出处名160/位置320码点。非法控制字符/孤立代理项、错误schema/字段/ID计数、非三态（含布尔/null）拒绝。当前完整人工图JSON UTF8≤65536字节，任何操作超限整项拒绝、旧输入不变，不截断或写超预算配置。修订号≤10亿。空节点表或未选目标可归档，但执行不产生空“通过”诊断。

完整路径≤2048、枚举展开≤20000，防御预算超限整份失败不截断；当前12节点DAG本身也限制路径增长。JSON/Markdown/SVG各≤1MiB，超限整份拒绝，合法输入可归档。每4节点异步让出，取消/编辑/隐藏/离开/销毁使迟到结果失效。配置一在途/最新待写队列，旧回执不宣称最新已保存；只存输入，不存前沿/路径/绘图，恢复不自动执行。

不可恢复草稿（含未来schema/坏图/超预算）保留原配置，教学工作可以本地计算/归档，编辑和离开也暂停自动保存；只有“明确替换不可恢复旧草稿…”→明确确认后，才用当前工作替换它。纯离线诊断无需额外许可确认，确认仅用于删除/整体替换或旧草稿覆盖。

## 4. 使用步骤与可复现例子

1. 打开L008、点击诊断，默认首要修补1=K1 A、先核实0、延后2、完整路径1。图C→B→A，A不会红色，B/C未知为人工状态，上层标延后；完整表和逆序回查保留。
2. A改未知、B改不会、C改会，再诊断：首修0、先核实A、B延后；C保持用户会声明，但提示其有待处理前置。不会把A未知算不会，也不会停在C。
3. A改会后，B不会成为内部首修，路径C→B。B也改会而C会则无前沿；C再改不会，其全部前置会时，首修为C自身，路径只有C。没有自动将修补后节点改会，仍由用户更新状态/复算。
4. 还原教学例，新建K4并名D、状态未知，未连边时D本目标不可达。新增边知识端K3、前置端K4并填写人工依据：A首修、D先核实，完整两条路径。选第二条只高亮C→D，报告仍保留C→B→A与C→D。
5. 尝试A→C循环、已有C→B重复、D→D自环均整项拒绝，原图不变。目标改B，只诊断B→A，C/D不可达；目标选“尚未选择”执行失败，不能伪称无修补通过。
6. 改名称为中文/emoji、补状态依据/来源，空出处明确未知。删除A须先明确删B→A；当前目标节点需先换目标。删除需要确认，取消保留输入；新节点/边用未复用ID，不自动修改其他分支。
7. 预览全部人工图、前沿/延后、所有完整路径和JSON/Markdown，导出新副本或SVG。全部路径表可滚动、选择器完整，屏幕/高亮不截断报告。窗口重载只恢复当前图/来源/三态/目标/修订号，主动复算派生数据。
8. 64KiB或报告预算满时归档合法输入再明确另建；被拒候选未进入台账。不可恢复旧草稿只提示并暂停写配置，当前教学工作可归档；保留旧草稿可取消替换，只有明确替换确认才覆盖。删除/整体替换旧输入不承诺撤销恢复，要保留先导出。

分支手算：目标T→B、T→C、B→A、C→A，A不会，其余未知：前沿仅A，但两条完整路径T→B→A、T→C→A。若移除C→A且C未知，前沿为修补A＋核实C，两分支独立，不用一个未知挡掉另一条已知修补。

## 5. 产出与保存范围

界面有首修/核实名单、全图目标/三态/前沿/延后/不可达颜色和箭头、全部知识相关性与待处理前置表、全路径表/高亮、逆序回查、手工会但有待处理前置的审阅项、名称/出处待补及完整双格式预览。出处待补覆盖全图，不因结构运算成功而认证依赖来源。

完整JSON/Markdown保留modelVersion、schema、当前全部输入/修订号、每知识原状态/来源/可达前置/待处理前置/相关性/前沿、修补/核实/延后及最早阻挡ID、不可达项、会声明待审阅项、全部路径节点/边/回查顺序、数量与规则口径。没有能力/熟练度/学习效果评分。Markdown为全量JSON、安全HTML转义/动态围栏，不只复制当前选择。

SVG保存所有保留节点/边及所选路径高亮，名称短标签最多7码点，完整名称/依据/出处在SVG title和JSON/Markdown。跨层边绘弧线、层间箭头由知识向前置；稠密图可能有边交叉，应结合选路和完整文字表。SVG是图副本，不代替全路径/全文归档。

配置只存当前人工图，无派生/不可变旧修订历史，尚未提交的新边表单/高亮选择不持久化。无诊断时的输入归档明确不是结果。副本必须桥接支持copyOnly、调用copyOnly:true且ok===true；生产writer用wx新建，已有目标拒绝覆盖，取消/字符串ok/未知/失败不假成功。外部源不读/不改，输出会含用户人工记录；写盘开始不能撤回，离开/销毁不补显示迟到旧成功。
