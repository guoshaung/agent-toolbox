# L037 效应量计算练习

## 1. 功能内容

独立两组、用户声明等方差的教学复算，支持互斥的汇总模式（两组均值、样本SD、样本数）与原始模式（两组逐个数值）。显示A−B均值差、各组样本方差/SD、n−1权重、加权方差、合并方差的分子分母、合并SD及Cohen d。原始模式显示离差平方和与全部原始分词/实际Number，不把样本SD混作总体SD或标准误。

有可编辑表单、示例、明确不适用设定、结果与完整JSON/Markdown预览及副本导出。编辑或切换模式清空旧结果，输入草稿保留；未选模式的控件禁用，不参与计算。报告保留两种输入草稿，因此可能包含未选模式的原始记录。

## 2. 为什么需要

将均值差与用于标准化的合并SD分开展示，便于检查“差多少”和“分母来自哪里”，尤其是两组n不同的时候。计算中间项可人工复算，零分母与不适用条件不被包装成有效d。

本工具只复算选定模型。算出一个数不会自动证明独立性、等方差成立、统计显著或实际意义；不给效应大小等级、检验推荐、p值、置信区间或临床解释。输入中的设计与方差选项只是人工声明，不是自动验证结论。

## 3. 公式、实现与数值边界

本练习固定采用：

```text
Δmean = meanA - meanB
wA = nA - 1；wB = nB - 1
s²pool = (wA*s²A + wB*s²B) / (nA+nB-2)
spool = sqrt(s²pool)
d = Δmean / spool
```

合并SD按各组自由度加权，公式核对自[NIST Dataplot官方文档](https://www.itl.nist.gov/div898/software/dataplot/refman1/auxillar/t_test.htm)的等方差两独立样本说明；这里只使用其合并SD定义，不实现t检验。所选d为独立两组均值差/合并样本SD版本，不混用配对测量标准化定义，概念来源为[Lakens 2013方法论文](https://doi.org/10.3389/fpsyg.2013.00863)。本实现保留A−B方向，不取绝对值，也不实现Hedges修正。

`model.mjs` 校验选定数据源和模型设定、计算统计量及报告。原始数据先以首值为锚点，中心化后进行Welford更新，减少大偏移/小离差直接计算二次矩的抵消；样本方差为M2/(n−1)，不使用n。均值为锚点+中心化均值，仍可能Number舍入；摘要10位有效数字，表格/JSON保留实际Number和原输入。

- 模式summary只读取summary统计数字；模式raw只解析raw，忽略未选模式的数值语义，但保留原草稿。未选模式也遵守字符串类型/容量上限，不能作为无限额存储。输入结构固定两组，统计量不与另一模式混用。
- 分组声明为paired/unknown，或方差设定unequal/unknown，整份计算拒绝并明确本模型不适用，不自动推荐其他检验；默认声明independent/assumed也未被自动核实。
- 均值、SD、原始值是≤32字符的有限十进制或科学计数法（指数≤三位），允许0或绝对值1e−150至1e9，拒绝非零文本转为零、过小、非有限与超范围。汇总样本SD不得负，n为2–1000000整数（不接受小数/科学计数法n）；负均值及负原始值允许。
- 原始值用英文逗号或空白分隔，拒绝空逗号字段、代码、数组语法或NaN。每组至少2，两组合计最多1000点，原始文本每组最多18000个UTF-16代码单元。超过整份拒绝，不截断样本，不自动删除缺失值或过滤数据。
- 汇总SD平方、原始离差乘积、离差平方和、样本方差、合并分子/方差及d有有限性或下溢检查；非零离差乘积舍入/下溢为零、正M2变零方差等整份拒绝，不悄悄算零SD。Number不是精确十进制，静态精度提醒始终显示；没有承诺识别所有浮点舍入。
- 合并SD等于0时d未定义，不存Infinity/NaN，也不把0/0定义为d=0；非零SD且均值相同才得到d=0。结果数值范围可大于输入范围，例如A/B相差可达2e9，原始样本SD可大于1e9；均验证有限。
- `schemaVersion:1` 配置键`features.L037.state`只保存输入，包括未选模式，不回填统计量。先测完整JSON UTF-8体积≤64KiB，再校验字段类型/容量，版本化对象也再次检查；恢复校验版本与容量，需重新计算。超限输入/导出整份拒绝，保留界面文本供缩短或自行复制；关闭只能恢复较早合法草稿。切走保存、销毁清理，没有网络、AI、定时器或后台任务。

## 4. 使用步骤与可复现例子

1. 在功能工作台打开“效应量计算练习”，或点“载入10/8汇总示例”。summary模式A均值10/SD2/n20，B均值8/SD2/n20；人工声明独立与本练习等方差，点击“计算中间项”。应得到Δ=2、权重19/19、加权方差76/76、合并分子152/分母38、合并方差4/SD2、d=1。
2. 手算不等n：A均值10/SD2/n3，B均值4/SD4/n5，权重2/4，加权8/64，合并方差72/6=12，Δ=6，d=6/√12=√3约1.732050808；交换两组d变负，分母保持相同。
3. 点“载入原始数据示例”，原始A=`8,10,12`，B=`6,8,10`，均值10/8，两组M2均8，样本方差8/(3−1)=4、SD2，d仍1。改A=`7,9,11`，B=`1,3,5`，均值9/3、Δ6、d3。汇总控件禁用且不参与原始计算，切回summary仍保留两种输入。
4. summary中两组SD均改0，即使均值都8，结果仍d未定义。若SD非零且均值相同才得d0。选择配对/重复测量或方差不等，旧结果清空，计算显示不适用。
5. 原始A填`1e-150,1.000000000000001e-150`，B=`0,0`，离差乘积小到Number平方无法表达，整份拒绝并提示精度范围；输入`1,,2`会拒绝空逗号字段。每组500值（共1000）合法，第1001值使整份计算拒绝而非删去后继续。
6. 查看完整JSON/Markdown预览并导出。所有报告可能含原始记录，包括未选模式保留文本；本功能不自动脱敏。输入改变旧结果失效，恢复草稿后重算；载入示例会替换两种输入，需要旧数据时先导出。
