# T100 剪贴板内容分享净化

## 功能内容

用户显式粘贴 URL 或文本，选择追踪参数、不可见字符规则后生成预览，逐项查看删除内容与原文位置，再复制净化结果或导出新 TXT/JSON 文件。不读取系统剪贴板、不后台监听、不请求输入网址。

## 为什么需要

分享订单或文章链接时常夹带营销来源参数，复制文本可能含无法肉眼辨认的零宽字符。直接重新拼装链接也可能破坏订单号、转义值或重复参数。本功能允许保留业务信息、核对具体删除项；字符规则采用显式选项，默认保留会影响连字和表情的字符。

## 实现方式

纯模型验证完整 HTTP/HTTPS URL，按原始 `&` 片段拆分查询，只解码参数名用于精确白名单匹配，保留未删片段的大小写、百分号编码、顺序、重复键、空片段和 hash。不使用 URL 序列化重新拼接整个链接，避免正常化路径或重编码参数。默认删除 utm_source/medium/campaign/term/content/id/name，不删除 ref、order_id、token 等其他名称；gclid/dclid/fbclid/msclkid 需另行勾选。无法解码的参数名保留并提示。

文本按 Unicode 码点遍历，记录原文 UTF-16 偏移。默认删除 U+200B 和 U+FEFF；U+200C/U+200D 连字、U+2060、双向控制 U+202A–202E/U+2066–2069 都需明确勾选。无规则命中时结果原样保留。UI 使用安全文本节点、只读结果和最多50条变更预览，完整 JSON 保留所有明细；输入改变立即使旧结果失效。

## 如何使用

1. 功能工作台搜索 T100 或“分享净化”，选择 URL 或文本模式。
2. 粘贴要分享的完整内容，核对当前模式的规则。
3. 点击“生成净化预览”，比较原文、结果及删除列表。
4. 点击“复制净化结果”。宿主提供剪贴板写入接口时仅写入结果；普通浏览器会选中结果供 Ctrl/Cmd+C。
5. 需要保存时导出 TXT 或 JSON，选择新的目标文件；副本保护拒绝已有目标。

## 使用后产出

TXT 只包含净化后文本。JSON 包含功能与格式版本、模式、原文、结果、规则、逐参数或逐字符变更、编码提示。字符偏移从0开始且单位为UTF-16。JSON包含已删除内容及原文，不适合作为已脱敏内容直接分享。

## 具体例子

URL 示例 `https://example.com/order?utm_source=newsletter&order_id=42#detail` 得到 `https://example.com/order?order_id=42#detail`。删除列表仅包含第一个 utm_source 参数，order_id 和页面锚点保留。

文本示例“甲[U+200B]乙[U+FEFF]丙 👩[U+200D]💻”默认得到“甲乙丙 👩‍💻”，保留职业表情中的 U+200D。删除明细为原文偏移1的U+200B和偏移3的U+FEFF；如用户另外勾选连字规则，则连字也会删除且产生单独记录。

## 验证与限制

七项模型测试覆盖业务参数保留、原始编码与重复键、白名单开关、非法百分号名称、BOM/零宽、表情与UTF-16偏移、无变化、URL验证及10万字符边界。宿主交互、复制与真实文件验证另行补充。

最多100000个UTF-16字符，只处理明确 HTTP/HTTPS URL或文本，不下载网页、不更改文件、不保存草稿。白名单不是全部追踪参数目录；签名链接可能要求原始参数完整，需自行核对净化链接是否仍符合业务要求。本功能不检测个人信息或自动脱敏，不承诺删除所有标识符。可选连字与方向控制会改变语言或表情显示，应从预览中核对。
