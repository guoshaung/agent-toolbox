# T041 视频片段剪接台

## 1. 功能内容

在本机选一个 MP4，以原视频毫秒区间建立最多 8 段时间线。支持删段、上下重排和重复区间。先显示全部来源/成片区间、尺寸/帧率/音轨与固定重编码参数，明确确认后用已安装 FFmpeg 生成完整成片，再用 FFprobe 核对。播放完整实际 MP4、核对来源报告之后，创建新目录副本，不改源文件。

支持 Windows 本地固定盘普通文件；源≤64MiB、≤120秒，单个 H.264/yuv420p 视频（≤1920×1080、≤60fps、方形像素、无旋转/HDR/非零起始时间），可选唯一 AAC 单声道/双声道音轨（8–48kHz）。多音轨、字幕/数据流、封面、章节、外部轨道引用等整份拒绝。每段≥100ms，合计≤120秒。真实结果必须<20MiB，不截断后称成功。

## 2. 为什么需要

录屏有用片段常分散在多处。明确区间与来源映射，能让用户保留有效内容并重排，同时在保存前听看实际成片，发现边界、顺序和重编码质量问题。这是有限单源剪接，不是专业多轨编辑器。

## 3. 实现方式与依赖

`model.mjs` 校验有限媒体信息、建立时间线与数值生成的固定参数。`host.cjs` 通过生产 `features.callHost` 加载，用原生选择把可信引擎目录/源文件绑定到 sender 的不透明令牌；renderer 不提供系统源/目标路径或命令。执行前后核对源大小、身份与 SHA256，输出核对大小、SHA、实际 FFprobe 属性和时长差。

依赖用户自己可信的 FFmpeg/FFprobe **6.x** Windows 安装，要求 `libx264` 和 `aac` 编码器。本次验证版本6.1；其余主版本显式不支持。没有捆绑/下载外部引擎，不修改 PATH 或系统设置。可从 [FFmpeg 官方下载入口](https://ffmpeg.org/download.html) 获取适合 Windows 的发行版，解压到自己的可信本地目录，并在工具选择包含固定 `ffmpeg.exe` / `ffprobe.exe` 的目录。默认候选是 `C:\ruanjian\ffmpeg\bin`；它不是已安装的保证。缺文件/缺编码器/版本不支持明确拒绝。选择安装目录只查文件信息，用户另行确认才运行固定3次版本/编码器查询；可信程序来自用户选择，本工具不是可执行文件沙箱或数字签名验证器。

重编码固定 H.264/libx264、veryfast、CRF23、30fps、yuv420p、最大1000kbit/s，保持比例向下取偶数尺寸、不放大、最多1280×720；可选 AAC96kbit/s、48kHz，保留唯一源音轨的声道数；无音轨不补声音。`trim/atrim` 后 `setpts/asetpts` 重置时间戳、`concat` 拼接；见 [官方 trim/atrim](https://ffmpeg.org/ffmpeg-filters.html#trim)、[concat](https://ffmpeg.org/ffmpeg-filters.html#concat) 和 [FFprobe](https://ffmpeg.org/ffprobe.html)。毫秒是输入区间精度，不保证输出每毫秒都有帧；30fps帧边界与AAC编码产生量化，完整输出时长与计划相差超过100ms整份拒绝。

无 shell、无网络协议、无任意表达式、无隐式重试。强制 MOV/MP4 解复用，文件协议白名单，禁外部引用；额外有限ISO-BMFF数据引用检查，只接受自包含 url 条目。[官方 MOV 选项](https://ffmpeg.org/ffmpeg-formats.html#Options-5)说明外部轨道/绝对引用的边界。读取媒体不能证明它无恶意，依赖本机可信引擎实现。

单 sender 一个任务，最多4个实际子进程，源/结果各一个。每次版本/FFprobe5秒，重编码60秒，生成的3个过程最长70秒；这是子进程期限，不声称本地文件系统读取也可硬中止。每过程 stdout+stderr≤128KiB；编码输出轮询与固定 `-fs` 双重限20MiB，任何触顶/截断都拒绝。取消先预留 job/意图，终止自己的子进程，观察 close 后才释放槽；若无法确认关闭，返回 termination pending 并保留槽，不伪称已停止。离开工作台/隐藏/销毁清除源与临时成片，不自动恢复任务，不写全局配置。自己的临时MP4仅生成file URL，不能凭接口读取任意文件；空闲临时结果约15分钟清理，应用崩溃可能留下临时目录，需手工核对。

保存由本ID Host 的原生保存对话框确认全新目录名称；普通本地祖先目录拒链接/UNC。新目录独占 mkdir，视频 `COPYFILE_EXCL`，报告 `wx`，核对完整写出SHA；`ok===true`才成功。取消/失败保留现有预览，不覆盖既有目录/源；普通中途失败清理自己创建的目录，无法确认清理时返回 partialPath。不是跨文件/断电事务，不防对抗性同权限进程竞态。

## 4. 如何使用

1. 点击“预览默认引擎查询计划”或“选择可信引擎目录”，核对目录和三次固定查询，再点确认。
2. 原生选择单个 MP4，核对源名/大小/SHA与一次只读检查计划；点“确认一次只读媒体检查”。
3. 输入起点/终点整数毫秒，添加/移除/上下移动。终点不包含，不接受空输入。点“预览时间线与重编码计划”，查看全部来源映射及参数。
4. 点“确认生成实际剪接成片”。等完整转码/验证结束，播放完整实际视频（默认静音，可自行开声音），核对各段及实际时长。浏览器无法载入成片或时长不符时不能保存。
5. 阅读完整来源报告并勾选核对确认，点创建副本。在原生对话框预览新的目标名称，确认后只写全新目录。若选中既有源文件/目录，拒绝并保留预览。

编辑区间会废弃旧计划与结果。切换工具或窗口隐藏会清除本次内容，返回需重新选源；未导出内容不持久化。

## 5. 使用后产出

新目录含 `edited.mp4` 和完整 `edit-report.json`。报告逐段列出来源/成片起止毫秒，源/输出大小及SHA，期望/实际时长与差值，源/输出尺寸、编码、帧率、采样/声道，唯一音轨选择、固定执行 argv 摘要及源未变核对。报告不含媒体正文，但源名/目标目录可能是本机隐私，分享前自行决定范围。成片失去未选时间段；真实重编码有损，元数据/章节不从源继承。不是无损切片或通用项目工程格式。
