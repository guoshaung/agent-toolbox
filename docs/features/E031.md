# E031 桌面沙庭

## 1. 功能内容

在1000×700的本地小景观中画砂纹、摆放石头、局部抹平、撤销与重置，保存可重开的JSON布局和完整景观SVG/PNG副本。两种砂纹笔刷为5条细耙线、7条宽耙线，三种砂石配色，三种石头大小；石头可以拖动、数值定位、方向键移动和旋转。没有分数、倒计时、音频、网络或AI。

局部抹平保留底砂和石头，只移除圆形或圆头拖动轨迹覆盖到的此前砂纹部分。笔画未覆盖部分仍在，之后画的砂纹可以填回。抹平不是“删掉整条相交笔画”，不会假装局部效果；擦除操作及顺序和砂纹一起保存并在SVG/PNG重现。

## 2. 为什么需要

让人短暂从工作中抽离，通过耙砂和整理小景观放松注意力。布局由用户自己安排，不需要赢得游戏或赶上倒计时。版本布局可以重开继续整理，PNG可以保留整体景观；不依赖图库下载或图片生成服务。

## 3. 实现方式及边界

使用原生SVG viewBox、平行偏移path耙线、椭圆/高光矢量石头、砂点pattern和按时间顺序嵌套的mask。每次抹平将此前砂纹包入一个mask，白底保留、黑圆/黑色圆头轨迹移除；新笔画添加在这个层之外，所以不被旧抹平永久遮住。石头位于砂纹之外，只摆放、不擦除。选中轮廓仅用于编辑，不进入SVG或PNG副本。

所有笔画点是画布整数坐标X0–1000/Y0–700。石头中心限制X80–920/Y80–620，保证最大石头及阴影留在完整画布内；拖动和键盘到边界停止，数值输入超界明确拒绝。旋转为0–359整数角度，快捷旋转15度按360环绕。图片是静态二维景观，不模拟真实砂粒、碰撞或三维石头。

最多200笔（砂纹和抹平合计）、每笔1–200点、全部笔画合计5000点、30石头。为控制SVG重绘成本另设总点数上限；移动采样最小间隔3画布单位，超过每笔上限取消整笔，超限不静默截断。导入和JSON输出限256KiB、SVG限3MiB、PNG限10MiB。版本1布局严格校验字段集/枚举/整数范围/ID唯一/点数/字节上限，拒绝未知版本、重复JSON键、超过8层嵌套、无效UTF-8和不支持结构。JSON坐标及笔画顺序没有文本或可执行内容，输出SVG仅由固定模板、已验证数值及配色枚举生成，没有脚本、事件、外部图片或用户HTML。

单次手势只在抬起时提交一条笔画或一次石头移动。requestAnimationFrame合并预览，Pointer capture作用于SVG根；屏幕坐标经过getScreenCTM().inverse()换算，保留拖动抓取偏移。取消/失去capture/暂停/重绘/销毁释放capture与帧、取消未提交手势并清监听。每项修改保存一个不可变布局快照，最多20步撤销；没变化不占撤销项。重置和重开布局也各占一项，可撤销。切换具体功能销毁未保存布局，不自动写config或隐含保存。

PNG通过同一完整SVG（含全部mask、砂纹与石头）→本地Blob URL→浏览器Image解码→固定1000×700 Canvas→toBlob(image/png)，不是截图当前窗口。转换不依赖窗口可见部分或滚动位置。计算PNG原字节SHA-256与规范Base64后调用安全saveBinary(copyOnly:true)，不使用旧覆盖型saveImage。PNG依赖公共二进制副本基础c0c93aa（基础PR #14）；此分支按授权fast-forward到该基础，功能提交不手改公共文件。接口缺失时禁用对应导出。文本saveText和二进制saveBinary都只认ok===true，取消不报成功，partialPath明确提示人工核对。生成/读取可请求取消并忽略晚到结果；不能声称终止底层Image解码/File.arrayBuffer。原生另存已打开时在对话框取消，界面停止新的修改。

API依据：[MDN SVG getScreenCTM](https://developer.mozilla.org/en-US/docs/Web/API/SVGGraphicsElement/getScreenCTM)、[Pointer capture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture)、[Canvas toBlob](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toBlob)。

## 4. 如何使用

1. 保持“画砂纹”，选择细耙或宽耙，在画布拖动。左上角为(0,0)，右下角为(1000,700)，图形按画布比例显示。单击留下短耙纹，拖动形成一条多平行线笔画。
2. 选石头尺寸，点击“摆放一块石头”。新石头自动选中并切至选择/拖动模式。按住石头移动；也可在选中石头菜单选择ID，填X/Y/旋转角再“应用位置和角度”。不能输入空值、非整数或超界位置。
3. 聚焦画布时，选中石头后方向键移动1单位，Shift+方向键移动10单位，R旋转15度；控件也有旋转按钮。键盘移动后重新聚焦新画布，连续按键可以继续操作。移除选中石头可以撤销。
4. 切到“局部抹平”，选半径20/40/80，在原砂纹上单击或拖动。抹平只作用于此前纹理，保留石头；随后切回画砂纹可重新耙出纹路。切配色改变底砂/砂纹/石头的成套颜色。
5. “撤销上一项”最多恢复20次；“重置景观”要确认，重置后仍可撤销。保存JSON/SVG/PNG分别选择新文件名。用“重开沙庭JSON布局”选择先前JSON；校验成功后替换当前布局，旧布局仍可撤销。

## 5. 产出及具体例子

JSON版本1精确保留配色、按顺序的砂纹/抹平操作、每笔所有点/笔刷或半径、每石ID/位置/尺寸/旋转，不含撤销栈或临时选中轮廓。它用于继续整理。SVG是完整1000×700矢量景观，PNG是相同景观的1000×700像素副本；背景四个圆角外透明，不保存控件、选择框、状态文字或未提交手势。不存在“只保存可见窗口一角”的导出语义。

可重复窗口操作：默认暖砂/宽耙，拖第一条从画布约(150,200)经过(350,200)/(650,200)到(850,200)，第二条同样X路径而Y=300；点击摆石头三次，默认中心(300,400)/(500,400)/(700,400)。切局部抹平、半径40，在(500,200)单击。状态应为砂纹2笔、抹平1笔、石头3个；第一条中央局部断开，第二条完整，石头保留。保存JSON，重置，重开该JSON，恢复同样路径与三石位置；导出SVG/PNG保持同样局部断口。

实际验收还拖R3从(700,400)到(740,440)，位置控件为740/440；旋转一次变15度；Shift+右键变X750；用数值位置700/400和角0恢复后保存。对于严格布局示例，model使用两点砂纹[[150,200],[850,200]]、[[150,300],[850,300]]，以及抹平[[500,200]]/radius40。JSON精确重开后序列不变，后续新画[[490,200],[510,200]]能在旧擦除区再次显现。

实际PNG像素结果：背景(80,200)与擦除中心(500,200)均RGBA[230,216,181,255]；保留耙纹(250,200)/(250,300)均[178,155,112,255]；三石中心均[98,109,105,255]。导出PNG1000×700、27612字节，SHA-256为f3334d7453c2b0b54c768b044dc27069d840fb8bd5db63665015e54d22ec2937。实图已用view_image查看全景，确认两纹、三石、第一条局部抹平完整存在，不把隐藏窗口空白截图当验收。
