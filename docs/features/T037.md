# T037 精灵图集打包

## 1. 功能内容

选择1–48张PNG，设置单个图集宽高与双侧安全边距，确定性装箱。完整预览实际图集和每个已装入来源，坐标清单逐项列出来源身份、几何、装入坐标或未装入原因。核对后另存PNG图集与完整JSON新目录，不缩放、不旋转、不裁透明边，原来源RGBA逐字节复制。

支持未显式标色彩配置的8bit非交错静态PNG，灰度/RGB/8bit索引/灰度Alpha/RGBA含适用tRNS。每源≤2MiB、总≤20MiB、边≤4096、单图≤4194304/全部≤16777216像素；图集固定宽高16–1024，边距0–16整数。显式gAMA/cHRM/sRGB/iCCP的来源列未装入，避免不同配置共用单图集产生隐式颜色变换。

## 2. 为什么需要

小图片分别加载会增加请求数量，人工维护坐标易出错。图集与可追溯的来源坐标一起保存，可以按JSON在前端或游戏中绘制对应区域；安全间距避免相邻素材直接贴边。原图裁回像素一致、未装入项完整列出，让接入者能检查结果，而不是只得到一张看起来合理的大图。

## 3. 实现方式

自有`model.mjs`将来源按高度降序、宽度降序、原选择序号排序。使用guillotine-best-short-side-height-width-index-v1：从可容纳的空闲矩形中按短边残余、剩余面积、y/x和稳定序号选一个，分成互不重叠的两个空闲矩形。每张占用矩形宽高增加2×gap，实际图片坐标向内偏移gap；两来源矩形间至少2×gap，图集外边至少gap。无旋转、多图集、自动扩尺寸或重试最优搜索；启发式可能拒绝数学上存在其他装法的组合，明确未装入，不宣称最优。

固定独立module Worker使用功能私有PNG过滤器与平台DecompressionStream/CompressionStream（无需外部库），按原始RGBA贴到全零缓冲，生成RGBA8图集。完整重新解码，逐字节检查整个图集及每个来源裁回区域，记录PNG和RGBA SHA。Canvas仅显示真实ImageBitmap，未参与导出编码，半透明及透明像素隐藏RGB保留。来源元数据均不迁移；此功能不是隐私清理工具。

坏源、超出图集或显式色彩配置分别保留未装入原因；仍尝试后面的较小来源。不因名称相同覆盖，来源原序号是坐标ID。全部未装入时只提供完整清单，没有空白图集冒充成功。完整预算或预览失败没有可导出的部分结果。线程最长30秒、各实际图集/已装入来源预览5秒；取消终止线程、离开清除来源引用/画布/结果，不自动恢复。

生产`exportBundle`固定copyOnly、SHA核验、新目录独占与wx，单PNG/清单≤2MiB、整个包≤10MiB；超限整份拒绝。JSON可独立走生产文本副本桥；只认ok===true，取消保留预览，既有目录/文件/来源拒绝覆盖。等待打包SHA期间离开不发迟到写入IPC；已提交磁盘IPC不声称可撤销。不写配置、不联网、不运行系统命令。

## 4. 如何使用

1. 打开T037，选择完整PNG集合，核对全部来源名称和容量。
2. 设置图集宽、高和双侧安全边距，默认512×512/2px；明确点击“打包并预览完整精灵图集”。
3. 查看完整图集及每个已装入原图，核对x/y/宽/高。未装入清单会说明坏源、色彩配置或空间不足；自行扩大尺寸或减小边距后重新打包，旧结果即时失效。
4. 勾选核对图集、全部坐标与未装入项，在保存对话框选择全新目录名称，另存完整副本。也可单独保存坐标JSON。

选择来源或修改设置不会自动处理；离开后重新选源。没有“自动切掉透明边”隐式处理，使用坐标时宽高就是来源完整几何。

## 5. 使用后产出

新目录含`atlas.png`和`atlas-coordinates.json`；全部未装入时只有JSON。清单含算法版本、完整规则、装入/未装入数量、图集几何/字节/PNG与RGBA SHA；每项保留原序号/名称/字节/SHA/颜色类型/PNG块、来源RGBA SHA和x/y/宽/高及含边距的reserved矩形，失败明确reason。未使用像素全部RGBA0，不复制来源附加元数据。

消费例：按来源1的coordinates在图集中取`[x,y,x+width,y+height)`，可得到与该原PNG完整RGBA一致的矩形。间距只隔开素材，不做边缘颜色扩张，开启纹理滤波或mipmap时仍应按引擎规则处理采样，不能保证所有缩小纹理都无串色。
