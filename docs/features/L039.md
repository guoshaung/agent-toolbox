# L039 因果路径沙盘

## 1. 功能内容与需要解决的问题

学员手工建立一个2–8节点有向无环图（DAG），指定不同端点X/Y及条件变量集合C。工具完整枚举两端之间不重复节点的无向路径，沿原箭头判定每个内点是否为碰撞点，逐条给出开放/阻断、实际阻断内点、激活碰撞点的条件自身或后代，再给出图结构的d-separated/d-connected结论。

普通链或叉中条件化内点会阻断路径，而碰撞点或其后代被条件化可能开放原本阻断的路径。只看“已控制变量数”难理解这一区别。本功能把每个内点的理由展开，允许从同一图切换条件集验证；没有把条件化更多变量当作改善，也不自动推荐调整集。

所有图、箭头和条件集合均为用户声明。候选图是否正确、箭头是否具有真实因果含义及模型假定是否满足，没有被验证。本地完成，不访问网页、不执行回归/干预、不运行AI、不导入真实数据库，不自动从文献或数据推图。

## 2. 实现方式与规则依据

规则概念来源为Pearl的UCLA原始说明：[d-SEPARATION WITHOUT TEARS](https://bayes.cs.ucla.edu/BOOK-2K/d-sep.html)。以下为本工具的有限图实现，不是因果识别或统计推断产品：

- 枚举路径时忽略方向，但仍保留每条有向边的原箭头。内点必须在当前路径上相邻的两条边都指向自己，才是该路径的碰撞点；节点不是全局固定的“碰撞角色”。
- 碰撞点自身或任一可达后代在C中时，该内点开放；否则阻断。用DAG的有向可达集合找后代，不只检查直接子节点。
- 非碰撞内点在C中时阻断，否则开放。即使某碰撞点已激活，路径上另一个条件化非碰撞点仍会阻断整条路径。
- 全部内点开放才是开放路径。至少一条开放则d-connected；全部阻断则d-separated。无连接路径也是d-separated；直连路径没有内点，在禁止条件化端点的模型中开放。

`model.mjs`先验证**整个图**，包含不在选定X/Y组件中的节点：唯一ID、已知端点、唯一合法条件、无重复边/自环/双向边/有向循环。再枚举全部simple无向路径，最多8节点时最多`Σ(k=0..6) 6!/(6-k)! = 1957`条。超出理论预算会整份报错，不截断或假称完整。输入顺序决定路径显示次序，不改变开放判定。

SVG使用原箭头方向；紫色边表示选中路径，紫圈表示**选中路径**碰撞点，橙底为条件节点，蓝底为端点。环形排布，860×660，短标签最多8 Unicode码点并加省略号；完整名称在输入表、SVG title及metadata。高密度图的边会相交，应结合路径箭头文本和内点表阅读。界面图不携带完整metadata，避免重复嵌入大报告；导出的SVG包含完整结果及选中路径索引，未删路径。

## 3. 使用步骤与保存范围

1. 打开学习工作台中的L039，选择碰撞、链、叉或后代开放示例，或手动编辑节点ID和标签。添加/删除节点后自行同步边和X/Y，不会自动改写图。
2. 每行输入一条`A -> B`或`A → B`有向边；空文本表示无边。填写存在且不同的X/Y，条件集用逗号分隔ID，空值表示无条件变量。X/Y不得在条件集中。
3. 点击“完整核对路径”，查看路径总数、开放数、阻断数和图结构结论。编辑任一输入立刻清空旧结果，必须重新核对。
4. 从“选择路径”或清单“查看内点”定位具体路径，检查内点角色、自身条件化、激活它的条件变量和理由。清单每页25条，分页和路径选择不改变完整结果；1957条为79页。
5. 查看完整JSON/Markdown预览，再导出完整JSON、Markdown或路径图SVG新副本。SVG需要有效结果；合法容量输入草稿即使尚未核对也可导出JSON/Markdown，结果为null，不伪称完成。

输入限制：2–8节点；ID为字母起始的1–6位ASCII字母/数字/下划线/连字符；标签非空且≤40 Unicode码点；边文本≤2048码点；条件文本≤100码点。非法类型、未知/重复ID、未知边、重复条件及图结构错误均整份拒绝，无部分结论。非法控制字符和孤立代理码拒绝，用户文本经textContent/编码输出，不注入HTML/XML。

草稿`features.L039.state`为`schemaVersion:1`，只写节点、边、X/Y、条件输入；总JSON按TextEncoder测UTF-8体积，≤64KiB。结果、路径、分页和选择索引不回填全局配置。恢复校验版本、字段和总容量，只恢复输入，须重算。字段或总容量超限不写配置、不导出半份；提示当前整份输入未保存，关闭只能恢复较早已保存草稿。原始未知附加字段也参与容量校验，随后只保存约定输入字段。

切走立即尝试保存；销毁保存并清空DOM/结果，无定时器、网络和摄像头。异步保存失败明确提示；销毁后导出回调不回写界面。导出要求基础层`saveTextSupportsCopyOnly===true`，发`copyOnly:true`，只有响应`ok===true`才显示成功。生产writer以独占创建拒绝覆盖已有目标；取消或错误不会声称成功。

## 4. 产出与可复现具体例子

JSON保存原输入、模型版本、导出时间、完整DAG/后代集合、完整所有路径、逐内点判定理由、开放/阻断计数、d-separation结论及选择索引。Markdown带相同完整JSON（用户HTML字符编码、代码围栏安全），不是只有当前页摘要。SVG metadata保留完整结果，图上仅高亮选定路径。64KiB是**配置输入草稿限制**，不是完整派生报告限制；8节点完整图的JSON/Markdown可约3MiB，导出不会只留当前25行。

### 碰撞点与其后代

点击“碰撞示例”，边为`X -> Z`、`Y -> Z`，X/Y为端点，C为空。核对结果：仅`X → Z ← Y`一条路径，Z是碰撞点，未激活，开放0、阻断1、d-separated。将条件节点输入为`Z`后核对：Z由自身条件激活，开放1、d-connected。

点击“后代开放示例”：增加`Z -> W`，C=`W`。X/Y路径仍是`X → Z ← Y`，Z自身没有被条件化；因其后代W在条件集中，Z开放，路径开放1。导出SVG中X/Y箭头均指向Z，Z至W的箭头指向W；Z紫圈、W橙底。若W换成一个完全无关的孤立节点U，碰撞点仍阻断。

### 链、叉与多内点

链示例`X -> Z -> Y`，叉示例`Z -> X`和`Z -> Y`，无条件均开放；C=`Z`均阻断。另建`X -> Z`、`A -> Z`、`A -> Y`、`Z -> W`，C=`W,A`：路径`X → Z ← A → Y`中Z由W开放，但非碰撞点A被条件化，仍阻断。可据内点表避免“有一个开放碰撞点，所以整条开放”的误解。

### 完整8节点边界例

节点`N0`至`N7`，每一对`i<j`写边`Ni -> Nj`（28边），X=`N0`、Y=`N7`、C空。完整路径1957；其中按节点索引严格递增的路径无需碰撞点激活，有`2^6=64`条开放；其余1893条阻断。路径清单分页79页，选最后一条后导出，仍包含全部1957路径，最后索引1956；SVG同时包含8节点、28原箭头和1957路径metadata。图较密，清单/内点表是准确阅读路径的主要方式。

## 6. 限制与适用边界

本工具的d-separation是**给定人工DAG的结构结论**。图正确性、因果解释、对应分布是否满足图相关假定/忠实性等没有验证；开放路径不证明实际相关或因果效应，结构分离也不能直接作为未建模现实数据的结论。没有自动推荐调整集、识别干预效应、判断偏差方向/大小或验证研究设计。

仅DAG，不支持循环、双向边、潜变量混合图、selection diagram、多值干预或概率参数。允许用户在有限DAG中加入命名节点，但不自动判定其测量/潜在属性。端点不能条件化，避免把端点固定带来的退化情况当普通路径教学。显示顺序与环形坐标来自用户输入顺序，不代表时间顺序、因果效应大小或布局最佳；高密图边交叉不改变完整计算。

草稿不保存报告或选择状态；重载必须重新核对。导出保留全部人工名称、条件集合、后代/路径解释，应按实际需要选择保存位置。报告只记录输入模型和计算，并没有引用验证、网页抓取或自动作者证据核实能力。
