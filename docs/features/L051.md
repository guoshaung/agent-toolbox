# L051 信心校准分析

## 功能内容

导入既有学习任务的事先成功概率和核对后的正确/错误结果，计算二分类 Brier 分数、平均预测与实际成功比例、逐条平方误差，以及高信心失误与低估成功清单。至少五条才展示等宽可靠性分箱、每箱样本数和可悬停查看点值的图。工具不生成试题、不判定题目答案。

## 为什么需要

只看正确率难以知道事先把握是否合理。一道以90%把握答错的任务与以10%把握答错，在改进复习策略时信息不同。导入用户已经核对的结果可帮助定位值得回看的任务，并把预测概率与实际频次放在同一图表核对。

## 实现方式

纯模型严格验证每条 `probability` 为0–1有限数字、`outcome` 为数字0或1，拒绝缺失结果而不把未知当错误。二分类分数定义为 `mean((probability-outcome)^2)`，范围0–1；不使用多分类的双倍记法。定义核对自 [scikit-learn Brier 文档](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.brier_score_loss.html)。本功能自行以JavaScript实现，不调用或增加scikit-learn依赖。

可靠性图横轴是每箱平均预测概率，纵轴是同箱实际正确比例，采用2–10个等宽箱，默认5；区间左闭右开，最后一箱含1。空箱是null而不是0，图中不绘点。每条保留原始序号，便于回到任务。高信心失误规则为 `p >= threshold && y == 0`，默认阈值0.8；低估成功为 `p <= 1-threshold && y == 1`。

[scikit-learn 校准说明](https://scikit-learn.org/stable/modules/calibration.html)指出 Brier 同时反映校准与区分等因素，较低分数不能单独证明校准更好。本功能因此同时提供分箱和样本数，不输出“掌握等级”或自动心理诊断。少于五条仅核对分数和逐条误差；五条门槛是本产品展示规则，不代表统计充分性。

UI以安全文本节点和原生SVG构建，无HTML插值；JSON文件严格UTF-8解码，输入/分箱/阈值改变后旧结果立即失效。只保留页面内存，输入文件不会被修改。

## 如何使用

1. 功能工作台搜索 L051 或“信心校准分析”。
2. 粘贴JSON数组，或导入UTF-8 JSON文件；每项形如 `{"label":"任务A","probability":0.9,"outcome":0}`。label可选。
3. probability输入成功概率0–1，不输入90这样的百分数；outcome只能为数字0（错误）或1（正确）。
4. 选择分箱数和高信心阈值，点击“分析既有结果”。
5. 核对分数、可靠性图、空箱、样本数与高信心失误；逐条结果预览前50项。
6. 导出完整JSON副本，选择新的文件名。已有目标不会被覆盖。报告的records也可重新导入，不自动恢复上次阈值。

## 使用后产出

JSON含格式与功能版本、分数精确定义、记录数、Brier、平均预测/实际比例、分箱规则与统计、高信心阈值、是否有足够展示记录、全部逐条平方误差及原始序号、高信心失误和低估成功清单。UI显示六位小数，文件保留JavaScript数值精度。

## 具体例子

“载入两条验收示例”：概率1和0、实际均为1。两条平方误差分别0和1，Brier=(0+1)/2=0.5。记录不足5条所以没有可靠性图；第二条列为低估成功。

“载入五条分箱示例”：概率0.1、0.3、0.5、0.9、1，实际0、0、1、0、1。平方误差0.01、0.09、0.25、0.81、0，总分1.16/5=0.232。末箱有2条，平均预测0.95、实际0.5；0.6–0.8箱空，不画成正确率0。默认高信心失误只包含第四条任务D。

## 验证与限制

七项模型测试覆盖两个手算验收、分箱坐标/空箱、精确边界含1、最优与最差分数、阈值含边界、严格实际结果、BOM和报告再导入、不变更输入、概率/行数/字节/字段上限。宿主界面和IPC文件验证由集成记录补充。

最多10000条/2 MiB JSON，标签200字符；二分类、等权记录、等宽箱，不支持多分类、样本权重、自动答案判定、置信区间或统计显著性检验。重复任务仍是独立记录，不自动删重；输入任务选择和事后填写概率都会影响解释，工具不会认证这些记录是否为事前预测。
