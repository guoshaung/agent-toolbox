# T024 · PDF 文档视觉比对

## 1. 功能内容

明确选择两份本地 PDF 作为 A/B 版本，全部页按同样的 144 DPI 白底渲染。指定 A/B 页码配对，逐页计算像素差异，显示完整差异叠图与每个变更区域。差异像素以红色显示，其它像素使用两版平均颜色的浅色背景；报告保留源页码、裁切、旋转、尺寸、阈值和输出摘要。

每版 1 字节至 2 MiB、1–8 页；单页边≤4096、像素≤4,194,304，两版全部来源页合计≤16,777,216 像素。可明确配对 1–8 行，合计比较像素≤16,777,216。每页最多 5000 个原始四连通差异区域，超过整体拒绝，不隐藏后面区域。JSON 配对输入最多 8 KiB，完整 JSON/Markdown 报告各≤2 MiB。

## 2. 为什么需要这个功能

文件两版可能文字相同但签名框、图表或位置已移动，单纯文字比对不能定位布局变化。相同尺度的逐页视觉差异帮助找到要核对的区域；明确页配对也适合页码发生改变的版本，不将所有第 n 页自动当成对应页面。

它只检查用户指定配对的渲染像素。未配对页会单列，不当作一致；像素差异不能判断合同语义、真实性或法律效力，零像素差异也不证明文档文字/附件/其它对象相同。

## 3. 实现方式

`index.js` 使用项目已声明的 PDF.js 4.10.38 本地模块、Worker、字体和 CMap，将两版所有页渲染为不透明位图。固定相同 144 DPI、以可见裁切和旋转为基准；不同页面尺寸按左上对齐，缺少的区域填白，不暗中缩放或自动配准。源字节只读，渲染结束销毁 PDF 解析资源，不提取正文或执行源脚本，`isEvalSupported:false`。

`model.mjs` 检查完整 RGBA、来源几何、严格配对和设置。固定模块 Worker 只接收两页 RGBA 与阈值，计算 RGB 各通道绝对差的最大值，严格大于用户阈值才算原始差异。按四邻接建立连通区域，输出完整像素数量与包围框。小于“最少连通区域像素”的区域不标红，但原始差异、忽略像素和忽略区域数量完整保留，不能把过滤后无标记叫“文档一致”。每个区域按首次出现像素顺序编号。

默认阈值 8、最少像素 1，分别可设整数 0–255 和 1–5000。字体替代、抗锯齿、扫描噪点或颜色差异会影响结果；需要用户结合实际叠图调整阈值和配对。这是确定的像素规则，不是内容语义检测。

每对独立 Worker 20 秒期限；来源载入超过 30 秒请求取消并销毁加载资源。取消/离开会终止线程、废弃晚到编码/预览回调，清除部分输出；底层读取/编码结束前保持锁定。容量和期限不等同于解压内存硬限或文件安全沙箱。来源 PDF/位图/大报告不写配置，离开清除来源位图和配对，返回须重新选择，不自动运行。

## 4. 如何使用

1. 在工作台打开 T024，选择两份 PDF，核对界面列出的 A/B 文件名、摘要和全部来源页。
2. 查看默认配对。需要改页对应关系时编辑 JSON，例如 `[{"id":"C001","a":1,"b":2}]`；编号必须唯一，同一配对不能重复。
3. 设置 RGB 阈值和最少区域像素，点击“比较并预览全部页面配对”。
4. 检查所有实际 PNG 叠图及报告中的区域、原始/标记/忽略数量、尺寸变化和未配对页。改变配对或阈值会立即作废旧结果，需重新比较。
5. 单个配对可另存差异 PNG；多个配对可将全部叠图和完整 JSON/Markdown 报告另存为新目录。也可单独预览并另存完整报告。

解析、引用、区域或输出错误会拒绝整次比较，不能保存前面已成功配对的部分结果。载入新文件失败会保留之前成功来源，但旧输出已失效。保存请求开始后不能用取消按钮撤回已开始写入。

## 5. 使用后的产出与验证

叠图命名如 `C001-A1-B1.png`。完整目录包含全部 PNG 与 `visual-differences.json/md`，报告逐配对记录源 A/B 页引用、几何、差异数量、完整连通区域和叠图 SHA；另列没有配对的 A/B 页码。它不包含原 PDF 字节或提取正文，但叠图和来源文件名可能包含原件可见内容，分享前请核对。

单张 PNG 不超过 10 MiB；完整目录中每个文件≤2 MiB、总量≤10 MiB，包括两份完整报告。完整包超限时禁用整包导出，不挑掉某些成功页。所有导出使用生产 Binary/Bundle/Text 新副本桥、`copyOnly:true`，仅严格 `ok===true` 确认成功。已有目标拒绝覆盖；取消、失败、undefined 回执保留完整预览并明确不报告成功。缺少相应安全副本能力时禁用按钮。

## 6. 具体使用例子

两份 240×300 pt、各两页的文件第一页均写 PUBLIC CONTRACT，只有签名框从 PDF 坐标 x=40 移到 x=140；第二页都是 IDENTICAL PAGE。选择两版，保留 C001 的 A1/B1、C002 的 A2/B2，阈值 8、最少像素 1，点击比较。

第一页叠图出现两个红色框位置，报告原始/标记差异均为1280像素、两个区域；第二页原始差异0、区域为空。导出新目录含两张 PNG 和两份完整报告。若只保留 A1/B1，报告另列 A2、B2 未配对；不会把未比较的第二页判为一致。已有新目录再次被选择时拒绝覆盖，其原文件 SHA 保持不变。
