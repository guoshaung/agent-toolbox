# E033 四季窗景

## 1. 功能内容

完全离线的原创程序矢量窗景：春叶、夏云、秋叶、冬雪四季，以及白天、黄昏两个时段。完整画面包含窗外天空、太阳、云、远丘、树木、小径、窗框、窗台和室内盆栽。春秋有缓慢飘落叶片，夏季云缓慢位移，冬季有雪；没有声音、摄像头、网络图片或天气数据。

用户选择 1–5 整数分钟，默认 2 分钟，明确点击开始后才运行。暂停保留画面与累计播放时间。减少动效保留完整静态景观，并去掉所有飘落粒子、云移动和动画帧；此模式仍可明确开始静态休息计时。PNG 留影保存完整 1000×700 景观。

## 2. 为什么需要

为桌面提供短暂、可控且不依赖网络的视觉休息。季节和时段由用户直接选择，无需位置权限；限定时长避免不知不觉持续播放。减少动效让偏好静态画面的用户仍能使用完整景观和定时结束。作品由本模块代码绘制，不需要下载图片或安装素材依赖。

## 3. 实现方式与边界

`model.mjs` 生成固定 `viewBox="0 0 1000 700"` 的 SVG，仅接受枚举季节、枚举时段、有限非负累计时间和布尔动效参数。没有用户 SVG、脚本、资源引用或 SVG/CSS 自主动画。装饰粒子使用固定种子：春秋各 20 片叶，冬季 32 雪粒，夏季没有飘落粒子；不是公平随机数或天气模拟。单场景 SVG 限 128KiB，PNG 限 10MiB。

计时模型注入单调时钟，生产使用 `performance.now()`；累计播放到 `minutes×60000` 毫秒时含等号结束，累计值不超过目标。普通模式用 RAF 更新有限场景，同时仅有一个到期 timeout；提前唤醒会按剩余时间重新安排。减少动效没有 RAF，也没有逐秒绘画，只有一个结束 timeout。暂停、离开功能和页面隐藏停止两种调度；恢复界面不自动开始。浏览器调度可能晚于指定毫秒回调，模型在下一次观察时按截止时间结束，不能保证操作系统实时调度。

暂停期间不计时，继续后累加原有播放时长。更改季节、时段或动效暂停并保留累计时长；改时长或“重新计时”建立零秒新计时且保持暂停。到期后必须重新计时才能开始。首次 create/activate 不启动任何 RAF 或 timeout。切换具体功能时当前未保存计时随模块销毁，不恢复历史计时。

通过真实 `matchMedia('(prefers-reduced-motion: reduce)')` 查询系统偏好并监听变化；系统选择减少动效时强制启用且不能在页面取消。偏好变化暂停当前计时与动画，并废弃尚未提交到原生另存的旧图片生成结果。媒体查询的初始匹配与 change 事件依据 [MDN matchMedia](https://developer.mozilla.org/en-US/docs/Web/API/Window/matchMedia)，系统偏好语义依据 [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion)。

留影先暂停计时，把当前完整 SVG 通过本地 Blob URL 解码并绘制到 1000×700 Canvas，再编码 PNG。生成规范 Base64 和原字节 SHA-256 后，检查 `files.saveBinarySupportsCopyOnly===true` 并调用 `saveBinary({copyOnly:true,defaultName,base64,sha256})`；依赖安全二进制基础 `c0c93aa`（公共基础 PR #14）。主进程核验后独占创建新副本，已有文件不覆盖。只有 `ok===true` 才显示成功；取消、接口缺失、编码失败、写入失败和 `partialPath` 分别提示。原生对话框已经开始时，取消须在对话框操作；本地生成取消通过代次检查忽略后续结果，不声称能终止浏览器底层解码。

销毁移除 UI、document 和媒体查询监听，取消 RAF/timeout、撤销 Blob URL，并清空场景引用。离开或隐藏时尚未提交的编码结果不会调用保存。已经进入原生另存的请求由原生流程完成或取消。

## 4. 如何使用

1. 打开娱乐工作台中的“四季窗景”，初始为春叶、白天、2 分钟且暂停。
2. 用“窗景季节”“窗景时段”切换。选择“累计播放分钟”1–5 分钟；运行期间先暂停才能改时长。
3. 点击“开始所选休息”。普通模式播放轻缓叶片、云或雪；点击“暂停窗景与计时”保留累计时长。
4. 勾选“减少动效”后重新点击开始，景观静止且按所选累计时长结束。系统偏好已启用时该控件显示勾选并锁定。
5. 点击“保存完整窗景 PNG 副本（暂停）”，选择新文件名另存。保存后仍暂停；不会拍摄桌面或应用窗口。生成期间可取消本地生成，原生另存期间在对话框取消。
6. 到期显示自动暂停，点击“重新计时（保持暂停）”再明确开始下一次休息。

## 5. 使用产出与可重现例子

选择冬雪、黄昏、2 分钟，勾选减少动效并点击开始：画面包含暖色黄昏、积雪树枝、山丘、窗框和盆栽，不出现飘落雪粒，不运行 RAF。累计静态休息满 120000ms 后显示“本次2分钟已结束，自动暂停”。保存产生 `season-window-winter-dusk-copy.png`，完整 1000×700 PNG；同名已有目标应拒绝，不改原文件。

累计计时例：从单调时钟 0 开始播放，30000ms 暂停；暂停 60000ms 后在 90000ms 继续。179999ms 时累计 119999ms，未结束；180000ms 时累计 120000ms，结束。总经过 180 秒而有效播放 120 秒，暂停不算入。

暂停后的连续留影使用相同累计时间和固定种子，没有“截图时多推进一帧”。切换季节或时段是明确的画面修改，并保持暂停。减少动效下相同配置在累计时间 0 和 300000ms 输出相同 SVG；画面仍有静态附着树叶或积雪，不是空白背景。
