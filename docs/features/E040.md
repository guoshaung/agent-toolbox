# E040 时光胶囊

## 1. 功能内容

给未来的自己封存文字和一张本地 PNG/JPEG 图片，最多 8 个胶囊，每个有创建日、开启日和编号。封存列表仅展示日期、正文码点数、有无图片和到期状态；全文和图片不放在隐藏 DOM、标题或数据属性中。到期须点击“手动揭晓”，提前开启须勾选对应胶囊确认。重新遮挡、离开、页面隐藏和窗口重载都会撤去揭晓内容。

本功能提供本地展示遮挡；配置和备份都是明文，本机文件可读，系统日期可调整。不提供加密、授权隔离、可信时间锁、云服务、后台通知或摄像头访问。

## 2. 为什么需要

普通笔记立即展示内容，而胶囊保留一个由自己决定日期的小惊喜。文字与图片可组合，也可只保存一种；完整图片内嵌备份避免只记录原图路径，换机或移动源图片后失效。

被接受的图片保留原字节，不自动缩放、重编码或清除元数据。超限图必须由用户在其他工具主动准备较小副本，不声称保留未被接受的原始大图。

## 3. 实现方式与精确输入边界

`model.mjs` 实现日期、Unicode、严格 JSON、图片结构与摘要、完整档案校验；`index.js` 用现有 `h()` 的文本节点和受限 data 图片渲染，不执行用户 HTML 或加载外部 URL，不使用 RAF/定时器。初次恢复异步校验期间锁定修改；离开使旧任务失效，回来重新校验未完成的恢复，避免空档覆盖。取消只忽略异步结果，不承诺终止底层读取、SHA 或解码；ImageBitmap 在结束后关闭。

- 每胶囊正文最多 2000 Unicode 码点、8192 UTF-8 字节，保留空格/换行/Emoji及普通 `<script>` 字样。拒绝孤立代理码元、NUL 与非换行/制表控制字符。须有至少一个码点或一张图片。
- 日期使用本机本地 Gregorian `YYYY-MM-DD`，有效年份 1900–9999。开启日严格晚于创建日，间隔最多 36600 天；到期当天可手动开启。UTC 日期序号仅用于整日比较，不猜测开启小时或时区。
- 单图最多 262144 字节，编码宽高各 1–1024。扩展名/MIME 不作为真实性证据。PNG 检查签名、块边界、全部 CRC、IHDR 位深/颜色组合、IDAT/IEND 顺序与末尾；有限接受 IHDR/IDAT/IEND/PLTE/tRNS/sRGB/gAMA/cHRM/pHYs，拒绝 APNG、ICC、文本、EXIF及其他未支持块，不静默删块。JPEG 接受 8-bit 基线/渐进灰度或三分量图，检查 SOI、SOF0/SOF2、SOS、标记段、扫描转义/重启与 EOI；拒绝 CMYK、其他帧类型、截断及尾随字节。JPEG APP/EXIF原元数据仍保留。
- 结构与 SHA 校验后，生产界面必须使用 `createImageBitmap(...,{imageOrientation:'none'})` 实际解码并核对尺寸。结构解析不冒充完整熵解码，纯模型 decoder 可注入，原生解码单独验证。预览采用编码方向，不自动应用 EXIF 旋转；备份保持原始元数据。
- schema1 最多 8 胶囊，完整美化 JSON 的 UTF-8 总字节最多 2097152，包括 Base64/正文/字段。单图都合限仍可能触发总上限，明确拒绝不截断。备份严格 UTF-8、深度最多 8、数组读取上限 16，再按 schema 限制 8 胶囊；拒绝重复键（包括转义后重复）、未知/缺失字段、未来版本、小数/指数/不安全整数。图片规范 Base64、SHA-256、MIME、宽高、字节数必须全部匹配。

自动档保存于 `ctx.config` 的 `featureLab.E040.archive`。基础 a80e115 的 `src/main/main.js:2524` config:set 直接调用 Store；`src/main/feature-host.js` 65536 字节限制属于 hostCall，E040 不调用该接口。实际配置没有 64KiB 硬限制，本功能使用明确自限的 2MiB。保存失败标明临时保留，并提供备份/重试；公共 Config/Store 可能已更新内存缓存，不把缓存等同于落盘成功。无效自动档不会静默覆盖，必须确认应用有效备份或勾选确认替换为空档案；不会将空预览导出冒充无效档的备份。

格式依据：[W3C PNG](https://www.w3.org/TR/png-3/)、[ITU-T T.81 JPEG](https://www.w3.org/Graphics/JPEG/itu-t81.pdf)、[MDN createImageBitmap](https://developer.mozilla.org/en-US/docs/Web/API/Window/createImageBitmap)。支持上述有限子集，拒绝消息会说明边界。

## 4. 使用步骤与具体例子

1. 打开“娱乐 → 陪伴与放松体验 → 时光胶囊”，输入 `下一次春天见🌱`，选择本机今天之后的日期，可添加不超过 256KiB、1024×1024 的 PNG/JPEG。看完整原图预览后点击“封存给未来的内容”。
2. 自动档出现“已保存”后，文字输入框换成新空节点，列表不含全文或图片。未到期直接点“提前开启 C001”会要求确认；勾选该胶囊确认，再点才出现全文和图片。
3. 到期重开或刷新日期，仅显示“手动揭晓 C001”，不自动揭晓。点击后才显示内容；重新遮挡或离开使正文/图片退出 DOM。
4. “另存完整JSON备份”需选择新文件名。恢复选择 JSON 后只预览数量和日期，勾选“确认用备份替换全部胶囊”，再点“应用已校验备份”；恢复全部正文/日期/图片，界面仍遮挡。
5. 删除须勾选删除确认，只影响当前模块档案，不删除原图和已经保存的备份。尚未封存草稿离开会清空，应先封存或自行保留。

独立模型日期例：创建 `2024-02-28`、开启 `2024-02-29`、正文 `下一次春天见🌱`。2月28日未勾确认拒绝提前开启，确认后允许；2月29日允许手动揭晓。`2023-02-29` 无效，创建日当天开启也拒绝。界面采用真实本机当前日期，不必修改系统日期复现。

## 5. 使用后的产出

自动档与完整 JSON 备份含所有胶囊正文、创建/开启日期、编号及内嵌图片原始 Base64、SHA-256、MIME、编码尺寸、字节数。默认备份 `time-capsule-full-backup-copy.json`。先检查 `saveTextSupportsCopyOnly===true`，调用生产 `files.saveText({content,extension:'json',defaultName,copyOnly:true})`，严格 `ok===true` 才成功；取消/失败如实报告，已有目标拒绝且保持原文件，读取或恢复不覆盖原始图片/来源备份。

备份包含未到期内容的明文，这是界面明确说明的完整备份动作；展示遮挡不表示文件不可读。不声称 JavaScript 字符串、浏览器缓存或源文件已安全擦除。
