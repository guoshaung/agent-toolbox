# E013 随手弹琴

## 1. 功能内容与必要性

用电脑键或鼠标/多指琴键即兴演奏，支持三种程序合成音色、两八度窗口、延音、和弦、多音录制及回放，保存旋律工程和MIDI。对应 `entertainment.json` E013：同时按三个不同琴键发三音，录制/回放保留顺序与时值，MIDI包含对应音符。现有鼓点编排是步进节奏，本功能按住/松开演奏连续旋律，不再复制鼓机。

全部离线，WebAudio原生振荡器，不下载音色、不运行用户脚本、不调用AI/摄像头/麦克风/硬件MIDI或网络。三音色是正弦、三角、方波合成音，不声称钢琴录音或物理乐器模拟。额外提供完整Markdown与琴卷PNG，便于看时值和分享。

## 2. 实现与规则

`model.mjs` 管理严格源工程、单调录制时钟、延音语义、MIDI编码和琴卷；`audio.mjs` 只建WebAudio振荡器/包络及排程；`index.js` 原生DOM控件、输入和生命周期。用户明确点击“启用音频”或“回放完整旋律”才创建/恢复AudioContext，不在create/activate/重载时启动音频。

24个半音按低到高分两行，每行一八度。起始八度2–6，对应窗口C2–B3至C6–B7，总可演奏MIDI36–107。12平均律 `440×2^((MIDI−69)/12)`，A4=440Hz；最多24同时音。默认音色正弦、音量65%。按键力度固定100，导入工程可包含1–127力度；不读取触摸压力。每音最大增益 `0.8/24×力度/127×总音量/100`，5ms攻击、40ms释放；音量0合法静音。为保证24复音余量，单音较柔和。

keydown重复忽略，相同音高的多个输入共享一音，最后一个输入释放才结束。延音开启时松键继续持续，关闭时只释放已松开的音；同音重击先结束旧音再开始新音，不留下同通道同音高重叠的MIDI歧义。录制延音直接合并到音符结束时刻，不另录CC64踏板。鼠标Pointer capture覆盖按下/抬起/取消/捕获丢失，多触点用各自pointerId。键盘keydown只在琴键区处理，拥有的keyup在window处理，即使焦点移到其他控件也不会卡音；失焦/隐藏/离开收尾录制并停止所有声音。

录制以 `performance.now()` 相对开始时刻、四舍五入为整数毫秒；倒拨注入时钟取之前最大值，不倒退。零时差按下/松开为最短1ms，同音零间隔重击顺延1ms，保证可配对。上限五分钟/512音符，前者50ms检查自动停止并完整保留，后者在下一次新按键时停止并保留已有512音，不截断源内容。记录每音 `[pitch,startMs,endMs,tone,velocity]`，按开始顺序保存；24声并发及同音色同音高重叠导入检查独立于数组顺序。

回放按音符毫秒值一次性调度到WebAudio时间线，开始预留30ms，源note-off后有40ms包络释放，最后停止。JS 50ms定时器只更新状态/检查结束或录制上限，不用它逐音触发。实时最多48节点（包含24个释放尾音），快速重击时先关最旧释放尾音，不偷走仍按住的音；回放最多512节点一次排程、实际并发音数≤24。离开/失焦/隐藏/销毁停节点、断连接、清输入/捕获、关闭上下文、清定时器，返回不自动续播；pending resume不能复活旧演奏。

MIDI为SMF type0、单轨、500 PPQ、tempo500000微秒/四分音符，即1tick=1ms，不量化成节拍格。3音色使用channel0/1/2、GM program80/81/80的近似映射与CC7总音量，明确不能保证外部MIDI播放音色等同正弦/三角/方波。相同tick先note-off后note-on，保留全音符/力度和末尾静默区间，EOT在durationMs。实现依据：[W3C WebAudio OscillatorNode与AudioParam规范](https://www.w3.org/TR/2021/REC-webaudio-20210617/#OscillatorNode)；[MIDI协会SMF官方介绍](https://midi.org/standard-midi-files)说明时间戳音符交换。MIDI字节布局及VLQ/配对由独立解码器验收；未用DAW作外部互操作验证。

## 3. 使用与工程恢复

1. 打开娱乐 / 创作与音乐玩具 / 随手弹琴，选择八度、音色和音量，点击“启用音频”。自动聚焦琴键区，不需要设备授权。可点击琴键按住发音，抬起结束；单鼠标无法同时按三处，多触点或电脑键可弹和弦。
2. 低八度按键 `Z S X D C V G B H N J M`，高八度 `Q 2 W 3 E R 5 T 6 Y 7 U`；对应各八度12个半音。Tab逐键聚焦，Enter按住/释放焦点琴键。空格为临时延音踏板，也可点“延音开关”保持，Escape停止当前演奏/录制/回放。键盘快捷键不抢占参数输入框。
3. 点“开始新录制”，琴键区自动聚焦。已有录制先勾“确认替换上一段录制”，否则旧作品保留。演奏后“结束并保存录制”，保存成功状态明确显示；可回放，或停止全部声音关闭音频。录制/回放或持音期间锁定音色/八度/音量，先停止松键再改。
4. 完成的旋律及参数自动保存 `featureLab.E013.project`。新录制进行时旧完整工程保持到收尾，琴卷暂时显示上一份完整录制；此时导出禁用。必须结束/离开收尾后再重载；直接强制刷新/崩溃可能丢未收尾录制，不能称实时事务存档。正常模块切走/隐藏/失焦会收尾并请求保存，成功再离开有保证；磁盘失败显示临时保留，提供重试或副本。
5. File API选择严格UTF-8、≤64KiB工程，先显示音符数/时长预览，勾确认才替换全部内容。不执行HTML、不访问工程链接。不完整/未知字段、重复JSON键、未来schema、非安全整数、超范围/超512、非开始顺序/同通道重叠/超过24并发整体拒绝。坏旧档不默默覆盖，可以确认清空或导入。
6. 重载后恢复全部音符/当前音色/八度/音量，音频关闭，踏板与按键状态清空。schema1只有 `schema,octave,tone,volume,durationMs,notes`，没有音频节点/缓存/定时器/SVG/PNG。最大512音的完整pretty JSON低于64KiB，无静默截断；不导入MIDI、不连接硬件MIDI。

## 4. 产出与副本规则

- JSON：完整恢复工程，512音以内每音精确毫秒/音色/力度及总区间、参数。
- Markdown：所有音符的序号/音名/MIDI音高/起止毫秒/音色/力度表，附完整源JSON。表格不会截断。
- MIDI：全音符、三通道、整数毫秒时值和末尾静默；保存延音后的note-off，不附本机音色波形或踏板操作历史。
- PNG：Canvas原生1000×540完整琴卷，纵轴C2–B7全部72个音高位置，横轴0–durationMs，颜色正弦绿/三角紫/方波红，标题含音符数/音量/时长。长段短音可能很窄，图只是概览，精确值以JSON/MD/MIDI为准。没有AI位图或外链素材。

先检查 `saveTextSupportsCopyOnly===true` / `saveBinarySupportsCopyOnly===true`，缺能力禁用并说明。文本copyOnly，MIDI/PNG计算规范Base64与SHA-256，PNG≤10MiB；生产writer独占wx新建，已有目标拒绝，包括导入原JSON文件。不把取消或 `ok:'true'` 当成功，只有 `ok===true` 成功；partialPath要求人工核对。

导出期间锁定版本，准备PNG/摘要时切走使旧任务失效且不调用writer；已进入原生保存不能撤回，切回后保持锁定直到回执完成，旧回调不把新工程标成功。原生保存对话框导致窗口失焦只停止声音，不把进行中的原生保存伪装成取消。毁掉模块时清界面、监听器、捕获和临时Canvas，不能终止浏览器底层编码或自动删除已保存副本。

## 5. 可复现例子

**真实和弦**：默认C4–B5、正弦65%，启用音频、开始新录制，按住 `Z/C/B` 发C4/E4/G4，状态显示当前3音。依次松开，结束保存后回放，三个音符重叠及原顺序/持续时值保留。另存JSON/MIDI，MIDI独立解码得到音高60/64/67及JSON里的全部起止时间。重载恢复三个音符，不自启。

**精确时钟oracle示例**：录制起点1000ms，1100ms同时按60/64/67，1500/1650/1800ms分别释放，2000ms结束。源记录 `[60,100,500,0,100]`、`[64,100,650,0,100]`、`[67,100,800,0,100]`，duration1000ms；MIDI tick同以上毫秒。这个例子由注入时钟测试得到，不能称真人能精确同时按下或精确毫秒释放。

**延音**：按C4后保持空格，松C4仍发音；再按E4、松开；释放空格两音一起释放。时钟测试C4在10ms开始/E4在120ms开始，分别100/140ms松键，200ms释放踏板：两个note-off均200ms。同音在延音期间重击，会结束前一音并开启新音，不串成长驻音。

**原生实际记录**：本次真实Z/C/B顺次keydown且同时持有，录得C4 `[60,28,156,0,100]`、E4 `[64,41,172,0,100]`、G4 `[67,54,187,0,100]`，总260ms；顺次发事件并非时间oracle的同时100ms，MIDI/JSON/MD/琴卷都反映这份真实记录。复跑真人事件时间可能不同，不固定其SHA或毫秒为通用输出。
