# L054 前置约束学习排程

## 1. 功能内容

接受目标前置关系、人工预计分钟/优先级、日预算，生成满足输入依赖与预算的整块分日计划；完整列出未知估时、超全天预算目标及受阻后继，保留全部阻塞根因。`A→B`表示A是B前置，同日也先做A。全图循环/未知/重复/自身前置拒绝，不展示部分计划。不依赖AI/网络，不核实真实知识依赖、不保证实际完成时间。

完整实现catalog MVP：拓扑排序加确定贪心日预算，整块任务不可拆分；未知或超过全天预算不可安排，其后继受阻，独立目标仍可安排。不假定所有输入有解、不宣称最优日数。每页10目标真实编辑，完整产出不截断。

## 2. 为什么需要

目标很多时容易先安排后继、忽略日预算，或把超预算的前置放进某天并让后继继续推进。本工具把人工估计和图约束变成可核对的目标顺序、日内分钟区间、预算余量与无法安排原因，让用户明确应该修正哪些输入。

算法满足输入约束只证明本次有限模型内部一致；依赖是否是真实知识前置、估时是否准确、优先级是否合理及计划是否完成由用户判断。空估时不猜值、空来源仍未知，没有自动学习效果/能力评分，也不优化个人学习策略。

## 3. 实现方式

`model.mjs`提供严格输入验证、前置解析、Kahn拓扑顺序、根因传递、顺序整块装日及完整报告；`index.js`提供真实目标/分钟/优先级/前置/来源编辑、分页与分日时间条/任务表、无法安排解释、取消/预览/副本导出。生产catalog发现`meta.json`，CSS使用实际项目变量。

前置在后继行填写：B的前置ID写A，即A→B。目标ID唯一、1–12 ASCII字母起始字符，可含字母数字下划线/连字符，保留名拒绝；名字可Unicode且空项未知。前置用英文逗号分隔，空整栏表示无前置，逗号空项非法。修改或删除ID不会静默改写后继引用，用户需手动修正。

先校验全图（包括已超预算/未知估时部分）：未知前置、重复边、自身前置、循环均整份拒绝。循环错误列未处理的受循环牵连目标，不能把所有牵连目标都宣称为环上的节点。输入草稿允许保存结构合法但关系不成立的图，以便后续修正；每次生成计划都会全图校验，旧计划早已清除。

Kahn算法就绪队列只含全部前置已处理节点，优先级5高0低，相同优先级按输入顺序稳定选择；得到包括无法安排节点的完整拓扑顺序。沿该顺序传递所有未知/超预算根因，目标自身也有根因时保留自身及上游全部根因。自身用时未知/超预算优先标自身状态，其他后继标受阻，不以一个原因替代多根因。

把可安排目标按完整拓扑顺序顺次装日：当前日剩余预算不足，就开下一日；不拆任务、不回填早日空隙，不从后面挑小任务填缝。日从1编号、日内分钟0起算，任务区间半开 `[start,end)`；前置在较早日完成，或同日结束≤后继开始。每日日预算/已用/余量及所有任务都列明；这不是实际日期/时钟时刻，不模拟休息、周末、并行或中断。

限制≤80目标/160前置边；预计用时1–10080整数分钟或null未知，日预算1–1440整数、优先级0–5整数必须明确。空日预算/优先级拒绝，不猜。目标名200码点、来源名120/位置240/人工说明300。来源是用户声明，空项未知。完整输入JSON≤256KiB，JSON/MD报告各≤2MiB，超限整份拒绝不截断；日数≤目标数、分钟有限，空目标可得到完整0目标/0天报告。

schemaVersion1草稿仅存人工输入，UTF8≤64KiB才排队写配置，不存派生计划；恢复验证版本/字段/体积。大合法输入仍可生成/导出，但明确草稿不存，关闭只恢复较早合法输入。保存队列串行最新值，旧回执不掩盖新输入错误。异步冻结输入并每20目标检查点让出；编辑/取消/隐藏/离开/销毁票据隔离迟到结果，不自动重跑。文本安全渲染，Markdown转义HTML并动态围栏。saveText防覆盖能力严格true、copyOnly:true、ok===true，新副本不改来源。

## 4. 使用步骤

打开L054，填日预算、目标ID/名称、人工预计分钟与优先级，在每个后继填前置ID；展开来源说明，填写人工估计及依赖依据，未知可留空。新增目标默认预计分钟未知，不能因空值安排0分钟。

直接点击“生成完整分日计划”，无需额外许可；查看完整拓扑顺序、按日预算比例的时间条、实际任务区间/前置/优先级，核对全天预算。无法安排项列自身状态和所有上游根因，独立可安排目标继续列入计划。关系不合法时整份报错，没有部分计划；按提示修正前置再生成。

修改任一人工输入会清旧结果；正在分析可取消，隐藏/离开丢弃迟到任务，回来需主动生成。编辑每页10不影响完整产出。删除目标与替换示例需明确保留/确认；删除后不自动去掉前置引用，已有来源不会写回。展开完整逐目标/原始来源、JSON/MD预览后导出完整副本；保存取消保留计划、失败不声称成功。

## 5. 产出与可复现例子

完整JSON含模型/schema版本、所有人工目标/来源/预算、完整拓扑顺序、按输入顺序逐目标状态/日内区间、全部分日预算/余量/任务、完整无法安排项及全部根因、未知来源/名称和统计/规则。Markdown含摘要及同一完整报告；可能包含全部用户目标和来源说明，保存前自行预览。

默认A/B均60分钟、优先级3，B前置A、日预算60。生成：第1天A `[0,60)`、第2天B `[0,60)`，每日日预算全用，2目标都安排。改A前置B形成B→A循环时整份拒绝；A同时改90也不能绕过全图循环。清除A前置、保持A90，则A超全天60预算无法安排，B受阻根因为A，0天/0已安排/2无法安排，完整记录仍保留。A分钟清空时A未知估时、B同样受阻，不当作0分钟。

日预算改120、A/B都60，B优先级升5仍不能早于A：同日A `[0,60)`、B `[60,120)`，时间条各50%。对独立目标P/Q/R/S分别40/40/20/20、优先级5/4/3/2、日预算60，确定贪心结果是第1P、第2Q+R、第3S；用户如果忽略优先次序改成P+R/Q+S可两天，这说明本工具不保证最少日数，也不会悄悄优化掉高优先级先后的约定。

A未知、B90、C依赖A/B、D依赖C、E70依赖D且预算60：C/D根因均A未知与B超预算，E自身超预算并保留A/B/E三根因。独立F5可安排，不把受阻后继自动纳入计划。80目标/160边各1分钟预算10的例得到8天、80目标完整报告；30目标大来源输入可完整导出但超过配置64KiB不保存。未知/循环图不能声称可执行学习计划。

自编默认目标JSON源夹具UTF8 SHA256 `e6de265ccf92b54737d0ff606a845fde8c28cc35225744689087c2bff82e6baa`，默认报告input完全相同，真实验收前后源字节未改；工具仅编辑人工输入，没有自动导入或写回源文件。
