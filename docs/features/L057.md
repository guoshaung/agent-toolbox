# L057 时间估计回测

## 1. 功能内容

把用户事前估时、实际用时及任务类型整理为离线记录，计算实际／估计比率、分钟偏差、相对偏差、固定桶的偏差分布，以及每种类型的历史均值校正系数。提供真实任务／类型／时长编辑表、CSV 粘贴、任务增删、原始来源、分页、纳入／排除筛选及完整 JSON／Markdown 预览与副本导出。

不运行计时器，不读取番茄钟或专注历史。估时为 0 的记录完整保留，并从所有偏差和比率统计排除；界面和报告明确排除原因。空白时长不是 0，不能用于回测；空类型单列未知组，不推断任务类别。

## 2. 为什么需要

计划反复低估用时，可以先核对历史人工记录的偏差方向及同类任务的比率，而不只看总时间。每项比率的算术均值与总实际／总估计是不同口径，本功能同时列出，两种结果不混用。逐条原始记录、计数、排除项和类型组完整保留，让系数可复核。

「事前估时」是用户声明；本工具没有时间戳证据证明估时在任务之前记录，也不能认证实际用时或来源真实性。历史均值只是当前输入的描述统计，不保证下一项任务用它会更准确，不判断学习效果、能力、效率等级或医学问题，不自动给学习改进建议。

## 3. 实现方式、公式及边界

`model.mjs` 严格校验 schemaVersion 1 草稿，解析有限无引号逗号 CSV，冻结快照后回测。表头固定为 `id,task,type,estimateMinutes,actualMinutes`，ID 唯一且非空，任务名最多 100、类型与 ID 最多 40 Unicode 码点。CSV 字段首尾空白修剪，允许 CRLF／CR 行分隔及一次末尾换行；拒绝空行、引号、BOM、字段内逗号／换行／制表符、缺列和重复 ID。任务名或类型可空并保留未知。编辑表允许暂时留空时长，但回测会拒绝整份，不猜缺值。

统一单位为分钟。时长范围 0–100,000，最多 3 位小数，只接受非负十进制；拒绝指数、负号、NaN、Infinity、前置加号、无整数部分小数、四位小数和越界值。时长解析为整数千分分钟，例如 0.1→100、0.3→300，因此差值为精确的整数 200，再显示为 0.2 分钟。最大 500 记录的整数时长和差值求和保持在安全整数域；比率和均值使用有限 Number，不声称任意精度实数。

有效记录要求估计时长 e>0。每项比率 r=a/e，偏差=a−e，相对偏差=(a−e)/e。历史校正系数为有效记录 r 的算术均值，各项同权；另外单独展示 Σa/Σe，不能把它当逐项均值。类型按用户修剪后的字面标签分组、顺序为首次出现；空类型和字面名称「未知」是不同组。统计还给出比率中位数／极值、平均有符号及绝对偏差、低估／相等／高估数量。估时0记录不进入这些统计，只有排除计数及原始记录；全排除或没有任务时系数、偏差均值、中位数等为 null／不可估。实际0而估时正是有效记录，比率0，不能误排除。

固定分布桶是 r<1、r=1、1<r≤1.5、1.5<r≤2、2<r≤3、r>3；使用整数倍数比较划界，不依据浮点舍入值。桶仅描述本次分布，不代表质量或能力阈值。界面一般最多6位小数，非零且绝对值<0.000001时用科学记数避免伪显示0；完整副本保留 Number 和每项比率的整数分子／分母。

最多500任务，来源名最多160、来源位置最多320码点；原CSV≤192KiB、完整输入≤256KiB，完整JSON／Markdown各≤2MiB，超限整份拒绝而不截断。输入、结果和类型组每页10行，导出保留全部。每25任务异步让出并可取消，原CSV以 UTF-8 做 SHA-256；哈希只核字节不证明来源真实。所有文本经文本节点显示，Markdown转义HTML并调整代码围栏；不执行输入代码、不联网、不调用AI。

## 4. 使用步骤与恢复

1. 填写人工来源和出处，粘贴上述表头的CSV，或直接编辑任务表中的任务名、类型、估时、实际时长。ID可在CSV中修改。
2. 添加任务会产生新的唯一ID，时长为空，需要主动填写。删除某任务或整体替换示例需明确确认；需要保留旧记录先回测导出。表格编辑规范化为LF CSV，未编辑时原CSV保持原样。
3. 点击「回测估时偏差」，查看逐项比率、分钟偏差、排除项、分布及类型系数；错误时长会整份拒绝，不展示部分系数。
4. 翻页及纳入／排除筛选只改变显示。展开完整JSON／Markdown预览核对所有任务和人工来源。
5. 导出JSON或Markdown新副本。生产桥必须声明 `saveTextSupportsCopyOnly===true`，始终传 `copyOnly:true`，只有 `ok===true` 宣告成功；取消和已有目标拒绝都不算成功。

只保存schema1原CSV与人工来源，不把派生系数回填。完整JSON草稿的 UTF-8 体积必须≤64KiB；超过时不写全局配置，界面提醒导出完整报告，关闭后只能恢复较早合法输入。保存队列合并待写输入并隔离旧回执，错误版本及超容量草稿拒绝恢复；未完成的时长编辑可以保存为输入，恢复后仍须主动回测。编辑来源或记录、取消、隐藏、离开及销毁都隔离迟到结果，返回及重载不自动执行。没有计时／媒体采集资源。

## 5. 产出与可复现例子

默认例子可直接点击「回测估时偏差」：

```csv
id,task,type,estimateMinutes,actualMinutes
T001,阅读任务一,阅读,30,60
T002,阅读任务二,阅读,30,90
```

两项比率分别 **2、3**，类型「阅读」及总体均值校正系数都是 **2.5**；偏差分别30、60分钟，平均45分钟，分布的1.5<r≤2和2<r≤3各1条。

把T001估时改0后，T001完整保留但偏差／比率为null并标「估时0：整条排除」。仅T002纳入，系数变3，分布仅1条；T001类型改空时出现未知组，其系数不可估。再把T002估时改0，总体和两组系数均不可估，不显示0。把实际改0但估计保持30则比率0、偏差−30分钟，属于高估。

不同分母例：30→60、60→90，逐项比率2和1.5的均值 **1.75**，总实际／总估计为150/90=5/3，两种口径明确不同。极端有效例100000→0.001的比率为1e−8，界面用科学记数，不将其显示为0。

完整JSON包含原CSV、人工来源、来源字节哈希、全部任务原字符串及整数时长、每项比率分子／分母、偏差、排除原因、总体统计、类型组、桶边界和每桶记录ID、规则定义。Markdown包含同一完整安全JSON。副本可能含所有任务和人工记录，不是脱敏摘要；筛选排除项也仍导出全部记录。没有来源文件改写或自动套用系数功能。
