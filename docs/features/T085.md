# T085 用电成本情景计算

## 功能内容

输入设备运行/待机功率、每天在各电价时段的运行小时、天数和手填电价，输出每设备每时段耗电量、运行与待机电量、费用及多个情景的成本差异。每天所有时段需依次完整划分24小时。支持最多6情景、每情景20设备、每天6时段。

## 为什么需要

功率相同的设备，运行时长、待机功率或用电时段不同会产生不同费用。把这些输入明确列出，可以在同一口径下比较例如将5小时运行移到低价时段的估计成本；待机耗电也列为单独部分，避免以为运行外所有时间都断电。结果是固定功率假设下的估计，不能替代测量或实际账单。

## 实现方式

独立纯模型以整数缩放保存输入：W及小时各1000倍、电价10000倍。BigInt计算电量分子(功率缩放值×小时缩放值×天数)，分母1,000,000,000；费用分子再乘电价缩放值，分母10,000,000,000,000。运行与待机分别计算，所有设备时段精确相加后才舍入：电量6位小数、费用2位小数、半入。报告包含原始输入、精确总计分数、时段分数和估计假设。

每设备每时段待机小时=时段长度−运行小时；断电时间以待机0W表达。功率、电价、时长全部由使用者填入，不从网络读取。支持CNY/USD/EUR/HKD；只比较同币种、同天数情景相对第一个情景的费用变化，不转换汇率。没有阶梯、税费、固定服务费、损耗或自动测量模型。

天数1–3660整数，功率非负≤1,000,000W/3小数，小时≤24/3小数，电价非负≤1000/4小数。时段长度必须>0且合计正好24；设备运行小时不得超所属时段。缺少输入或非法字段整批拒绝，不默补0。名称1–80字符、情景名唯一。最多1440条设备时段明细，不保存大型输入到全局配置。

## 如何使用

1. 在功能工作台打开T085，点击基础示例或分时示例，也可修改控件。
2. 设置情景名、天数、币种；设置按日依次划分的电价时段长度与每度电价，合计24小时。
3. 输入各设备运行W、待机W及每时段运行小时。若其余时间断电，待机填0W。可添加/删除设备或时段。
4. 点击“复制首个情景进行比较”后修改复制的输入。点击“计算并预览用电估计”，核对估计总计及每时段明细。
5. 展开审计预览核对完整输入和假设；点击“导出用电估计 JSON”，选择新的路径。副本写入禁止覆盖已有文件，取消保存不提示成功。旧版缺安全接口时阻止导出。

输入更改会废弃旧结果；切换功能丢失当前未导出的输入。费用分项先舍入后的和可能不同于精确总计再舍入，这是显示规则，不是漏算。

## 使用后产出

情景汇总表、每设备每时段运行/待机小时、电量和费用明细，以及可比情景相对第一情景的费用差。完整JSON包含inputs、assumptions、scenarios、comparisons；不可比情景写明原因，费用差只在相同币种/天数时产生。导出为新的UTF-8文件，可追溯填入的价格和估计假设。

## 具体例子

点击“载入100W基础示例”并计算：运行功率100W，待机0W，每日运行5小时、30天，全天电价1 CNY/kWh。得到15.000000度、15.00元，待机0度。

点击“载入分时与待机比较”：每天高价8小时/1.5元每度、低价16小时/0.5元每度，设备运行100W、待机5W、30天。原情景高价运行5小时，其余19小时待机；估计总电量17.850000度、费用24.38元。将5小时运行移到低价时段的第二情景，同电量、费用10.13元，精确费用差−14.25元。显示两项费用之差与精确差在此例一致，其他小额例可能因显示舍入不同。

## 验证与边界

7项模型测试覆盖100W验收、分时与待机、分项/总计不同舍入、不可比币种/天数、24小时完整性与非法输入、超过安全整数范围的BigInt精确总计及JSON序列化、数量上限与输入副本。报价及功率仅由使用者提供，不保证设备按额定功率恒定运行。
