# T036 透明素材边界修复

## 1. 功能内容

批量选择1–20张静态PNG，按原始Alpha达到阈值的像素计算最小外接矩形，再加源图内的保留边距。显示全部原图和实际裁切PNG对照，失败来源逐项列出；核对后另存完整新目录。框内RGBA逐字节复制，包括半透明像素和Alpha为0的隐藏RGB，不经过Canvas重编码。

支持8bit、非交错、非动画PNG：灰度、RGB、8bit索引、灰度Alpha及RGBA，包含适用的tRNS透明信息。每源≤2MiB/全部≤20MiB，边≤4096、单图≤4194304/全部≤16777216像素；完整选择超限拒绝，不悄悄截断。Alpha阈值1–255（含等于），边距0–128整数。边距只保留原图现有像素，夹到源边缘，不添加新的透明边框。

## 2. 为什么需要

素材外围透明空白会影响图标布局、精灵尺寸和对齐。此工具把裁切条件变成可核对的数值，保存原主体的颜色与透明度，提供尺寸和偏移清单，让批量结果可以复现。阈值只影响外接框；不自动抠图、不清除框内杂点、不推断哪些细节应该删除。

## 3. 实现方式

功能私有`png.mjs`验证PNG签名、块长度/CRC、关键块、连续IDAT及有限IHDR；用平台DecompressionStream解压，逆算None/Sub/Up/Average/Paeth五类过滤器，展开为原始RGBA。解压扫描线容量按实际几何精确限制，超量立即拒绝。`model.mjs`逐像素扫描Alpha、计算矩形并逐行拷贝完整RGBA；CompressionStream生成新RGBA PNG，再完整解码产物，核对每个字节及几何。

保存原gAMA/cHRM/sRGB/iCCP/pHYs色彩与密度块，其余元数据不迁移；这不是隐私清理器。颜色块不重新解释，实际视觉预览交给浏览器ImageBitmap。预览Canvas可以用于显示，但不用于生成导出字节，避免半透明预乘/反预乘的舍入影响。输出颜色类型固定RGBA8，压缩字节与原PNG不相同，框内原始RGBA相同。

独立固定module Worker最长30秒，完成整批后每个成功来源及输出分别真实ImageBitmap解码（各5秒），全部预览完成才给结果。坏PNG、空主体和不支持的格式只列失败，不产生1像素替代文件。整批容量超限、线程或预览失败则没有可导出的部分结果。取消/离开终止自己的线程并废弃迟到结果，清除File引用、缓冲和画布；返回不自动处理。未使用外部库、在线服务、系统文件读取、配置持久化或网络。

目录保存走公共生产`exportBundle`，固定`copyOnly:true`，新目录独占创建、每文件wx、完整SHA核验；每PNG/报告≤2MiB、总包≤10MiB。报告另存走生产文本副本桥；已有来源/文件/目录不覆盖，只有`ok===true`确认保存成功。取消保存保留预览；打包SHA等待期间离开不会继续发出写入IPC。已开始的磁盘写入不声称可以物理撤销。

## 4. 如何使用

1. 打开功能工作台中的T036，选择完整PNG集合，核对名称和字节数。
2. 设置Alpha主体阈值、源内边距；默认1与0。明确点击“处理并预览全部透明PNG裁切”。
3. 查看每张完整原图/裁切图、源内偏移、尺寸以及全部失败原因。改变规则会废弃旧结果，需要重新处理。
4. 勾选已核对全部对照和失败项，再点击“另存全部裁切PNG和完整清单新目录”，在保存对话框选择全新目录名称。也可单独另存完整JSON清单。

全失败集合可以导出只有失败清单的目录，成功数为0，明确没有裁切PNG。选择新文件不会自动解码或写盘。离开工具后重新选择，未导出内容不保留。

## 5. 使用后产出

完整新目录含`cropped-01.png`等成功文件和`crop-report.json`。数字对应原选择顺序，失败项不会把后面的编号前移。清单包含原名称/字节/SHA、成功失败状态、原图几何/颜色类型/块清单、符合阈值像素数、主体框和源内裁切框、产物几何/字节/PNG SHA/RGBA SHA及保留色彩密度块数量。报告不含源像素正文，名称仍可能涉及隐私。

## 6. 具体例子、验证与限制
