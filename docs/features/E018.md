# E018 四格漫画

## 1. 功能与必要性

把一次小经历排成静态四格漫画。固定2×2、1280×1340整页，四格各600×600；默认每格都有一个可编辑对白气泡和项目自绘简笔人物。可添加猫、盆栽、杯子、更多气泡或自己的PNG/JPEG图片，调整格内位置、尺寸、颜色及图层顺序，也可移动整个分镜顺序。整页PNG用于分享，完整JSON用于重新打开继续编辑。区别于E016上下配字和E017逐帧动画，本功能编辑的是四个独立叙事画面。

所有人物和道具由本项目Canvas路径、椭圆、折线程序绘制，未使用网络素材、AI生成或图片模型。没有网络、账户、音视频、设备授权和计时评分。

## 2. 实现方式与范围

`model.mjs`管理schema1源工程：片名、当前格/选中图层、稳定ID、完整四格图层、内嵌图片与来源记录。Canvas原生绘制完整页面；图层数组从下到上绘制，点击命中从上向下查矩形边界框（不是仅不透明像素命中）。位置以当前格左上为原点，整数像素；图形完整保留在8px格内边距，越界编辑拒绝，拖动越界整次撤回，没有静默夹紧。每格最多16图层，总64；支持图层上下排序与整个分镜前后排序。拖动使用真实Pointer Capture，并有同指针文档move/up兜底；坐标由当前画布显示矩形换算。拖动结束作为一个撤销事务，Escape、pointercancel、失去捕获、隐藏、离开均撤回整次操作。方向键1px、Shift方向键10px作为替代。

对白最多600 Unicode码点，允许换行，拒绝控制符/无效Unicode。按Intl.Segmenter字素换行，结合Canvas实际字形边界，不拆emoji组合；字号14–48，可勾选完整自动缩小至14px。全文无法装入气泡时拒绝应用并禁止导出旧报告，不截断或省略。气泡文字保留20px左右内边距及尾巴区域；审计列出全部实际行、字号、字形边界。更高图层与对白字形矩形相交时显示“可能遮挡”提示，检查保守，仍尊重用户图层顺序；应移动图形或将气泡上移，确认整页预览可见后保存。它不自动把所有文字强制放到最上层。

源图片支持静态PNG或8bit灰度/RGB JPEG，1字节–5MiB、单边≤8192、总≤2400万像素。PNG检查签名、块长度、CRC、IHDR/IEND及非动画；JPEG检查有限标记、SOF、扫描/结束及单图结构，先核对大小/维度再调用浏览器解码。SVG/HTML/GIF/WebP/APNG及不支持的PNG高位深/JPEG CMYK等明确拒绝。Raster预检片段改写自本团队E016，JSON解析片段改写自E017；本功能不依赖其他feature运行时或新package。

图片不会把原文件直接塞进配置。选图前选择最大边128–1024（默认768，不放大）与转换格式：JPEG白底有损，固定质量85；PNG保留透明、无损编码，但浏览器解码/缩放可改变像素和色彩信息，不保证与原图字节等同。转换结果完整预览，必须明确勾选采用转换图才添加。单图≤512KiB，最多8张，合计≤3MiB；转换后超限拒绝，用户可重新选较小边/格式再读图，不暗改尺寸或质量。工程保留转换图片完整字节、SHA256、尺寸与原图文件名/尺寸/字节数/SHA记录，不能从工程恢复原始照片。SHA核对保证工程内图片字节与所附摘要一致，不提供签名认证；原图来源记录在导入时计算，原图不在工程内，恢复时无法独立重验该来源记录。

完整JSON≤8MiB，严格校验重复键、未知/缺失字段、schema、整数词法/精度、唯一ID、路径无外链、规范Base64、图片头/尺寸、素材引用；恢复全部图片SHA并成功解码后才预览。大工程不写config。撤销最多20条源快照且源JSON总≤16MiB，超过滚动移除最旧条；不承诺无限历史，撤销历史不写工程。“移除未使用嵌入图片”只移除没有图层引用的素材，释放对应Bitmap，操作可撤销。没有RAF/定时器，静态交互才重绘。

## 3. 使用方法

1. 点四格顺序按钮选格，点该格speech图层选择默认气泡，输入对白，点击“应用对白与位置”。输入变化会标记未应用，并禁导出；可用“撤回未应用输入”回到已应用工程。
2. 在种类中选人物/猫/盆栽/杯子/气泡，点添加。拖动图形或编辑X/Y/宽/高后应用；画布得到焦点后用方向键移动。数值越界明确拒绝。拖出允许区域或按Escape撤回整次拖动。
3. 图层列表从下到上，选择图层后“向上/向下”改变遮挡关系；分镜排序移动该格全部图层和对白，稳定分镜ID保留。删图层可撤销，删除图片图层后可移除未使用素材释放容量。
4. 选本地PNG/JPEG前设转换格式/最大边，查看转换预览与原/转换字节数、尺寸，明确勾选后应用。图片在图层框内等比留白，留白色是图层填色；不强行拉伸或裁切。原文件不改。
5. 展开全文排版审计，核对四格全部对白及可能遮挡提示。另存完整JSON，再另存整页PNG。重载后选JSON，核对完整工程身份、勾选替换全部四格再应用；恢复后可继续改对白或位置。建立新四格必须勾选清空确认，不会删除已经保存的文件。

## 4. 使用后产出与副本保护

- `四格漫画-完整页.png`：1280×1340、四格边框、整页标题、全部当前图层与按照源顺序排版的对白；纸张为不透明底色。不是截屏顶端、单格缩图或动画。
- `四格漫画-完整工程.json`：所有格/图层输入、顺序、对白、选择、颜色、尺寸，以及所有转换素材完整字节；恢复不靠外部图片路径。未保存输入、撤销历史和原图字节不属于工程。

两个导出都检查桥能力、传`copyOnly:true`并仅接受`ok===true`。PNG走生产`files.saveBinary`，完整编码PNG≤10MiB，主进程核验规范Base64与SHA后WX写新文件；JSON走`files.saveText`≤8MiB。已有目标拒绝，不覆盖原图、工程或已保存页。取消/错误/partialPath分别报告，没有成功回执不称已保存。原生保存未返回时锁编辑，隐藏/离开后迟到回执不复活旧结果。文件读取/解码取消是废弃返回结果，不能终止底层原生操作。销毁释放监听、Capture、全部Bitmap/临时画布、工程和历史引用。切换具体功能会销毁面板，因此离开前须主动保存。

## 5. 具体可复现例子

四格默认speech气泡依次输入并应用：

1. “今天，我想晒太阳。”
2. “猫说：先给我让个位😀”
3. “于是我把盆栽搬过去。”
4. “最后我们一起喝杯茶。”

第2/3/4格添加猫/盆栽/杯子，位置X410、Y350，默认宽160高220，应用。每格保留默认简笔人物。整页PNG应包含四格边框、全部四段完整对白、emoji、人物与不同道具。

第4格导入16×8 PNG，明确确认转换预览；设置X20/Y350/W160/H220，等比图像实际为160×80，垂直居中，其他位置留白。第3格可以导入4000×3000 JPEG，默认最大边768、JPEG85得到768×576转换图，明确确认后设X20/Y420/W160/H150。原文件SHA应不变；工程中的转换图SHA与原图SHA分别记录。

另存完整JSON和PNG，重载页面、导入JSON并勾确认，所有图层/对白/素材原样恢复。在同一Electron/字体环境再次导出PNG应字节SHA相同。第4格向前排序后分镜ID顺序为1/2/4/3，对白跟随分镜；撤销恢复原顺序。对白填600个“长”默认气泡装不下时拒绝且不能导出旧页；将气泡高度设560后可完整排版，仍需关注用户图层遮挡。
