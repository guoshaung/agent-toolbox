# L046 指代链消歧标注

## 1. 功能内容

学习工作台「语言与表达训练」中的离线人工篇章标注。用户填写完整原文、来源名和出处，选择原文片段标为实体或指代，再为每个指代人工勾选零个/一个/多个候选，并明确选择「未知」「多候选未定」或绑定某个人工实体。没有自动识别、AI候选建议或自动消歧；catalog的AI可选在本MVP中选择完整本地实现，无AI依赖。

实体/指代记录稳定ID、0起算UTF-16半开区间、当时原片段、文本修订号和人工说明。实体还保存人工名称；指代分别保存候选集合、明确状态和绑定ID。来源/依据为空显示「未说明」，不会自动补写出处、引文或实体。

用户可从真实文本框选区新增标注，也可编辑起止数字，核对当前原文该区间预览后按确认，或用原文选区重新标定已有记录。未确认数字不会保存配置、不会用于报告，链图会暂停显示，避免界面数字与导出旧位置混淆。删除被候选/绑定引用的实体要求先人工解除引用，不隐式删除链。

原文高亮只显示当前已确认位置，重叠片段标记全部ID。完整DOM实体链图使用实线明确绑定、虚线人工候选，并列出未绑定指代；候选可能出现在多个实体下，但未绑定列表按指代ID只计一次。下方报告显示全部失效标注、全部标注一致性冲突、完整JSON/Markdown预览与新副本导出。

## 2. 为什么需要

长段落中「它」「他」「这」可能有多个可解释的指向。若工具直接选一个，会掩盖真正的未知；若没有固定原文区间，修改前文后标注可能悄悄移到另一片段。本功能让用户保留多个候选及未知，并将人工决定、原文位置和待核问题分开。

新增能力是用户篇章实体跟踪与可复核人工消歧记录，与翻译、逐词解释或自动语言评分不同。绑定只是用户声明，不证明指向正确；候选多不等于错误，明确未知也不是认知失败。工具不核验语言能力、训练效果、作者意图、外部来源真实性或任何语法/指代理论标准。

## 3. 实现方式

### 原文区间与修订

`model.mjs`以Unicode字符串保存原文和人工记录。位置采用0起算UTF-16码元半开`[start,end)`；当前有效标注提供1起算逻辑行和UTF-16列，逻辑行结束符为CRLF/LF/CR。emoji等补充平面字符占两个码元，列不是UTF-8字节偏移或屏幕字形列；选择拆开代理对、空白片段、空区间、非整数或越界都会拒绝。

文本框选区使用[WHATWG HTML文本控制选区API](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#textFieldSelection)的`selectionStart`/`selectionEnd`和`setSelectionRange`，按码元偏移读取。真实textarea将CRLF/CR表示为LF时，`sourceSelectionRange`建立LF显示偏移到原文偏移的映射，新标注仍锚定完整原文的原始区间，不悄悄丢掉CRLF。配置恢复的全文和JSON保持原换行；用户在文本框重新编辑产生的值按浏览器LF值保存为新修订，全部旧标注会失效。

每次实际原文变化递增`source.revision`，已标注记录的区间、quote、textRevision、候选和绑定**原样保留**，不重新搜索相同字符串，也不按插入长度自动移动。即使只在末尾追加、原片段仍相同，旧修订的记录也须人工重新标定。旧位置越过缩短后的原文仍保留为失效记录，不能参与当前链。

重新标定是显式用户操作：先看当前片段预览/选区，再确认新的起止位置与原片段，更新该记录的修订。原候选/绑定保留，需要用户自行复核含义是否改变；工具不会因重标位置推断语义正确。保存的是当前全文及旧标注片段，不保存历次完整文本历史；若需要旧全文，应在编辑前导出报告。

### 未绑定及冲突口径

未绑定列表按每个指代恰一次生成，满足任一项就进入：用户选择未知；用户选择多候选未定；指代区间失效；或明确绑定的实体区间失效。`declaredBound`是原人工绑定数量，`effectiveBound`只计当前相关区间有效的绑定。失效不抹掉原绑定记录，也不把同一指代的多个失效原因重复计数。

三类标注一致性冲突明确限定如下：

1. `span-overlap`：任意两个当前有效标注的原文区间有非空交叠，包括实体/指代、同类或跨类；每对记录一项，相接不算重叠。提示人工核对，不断言语言学矛盾；失效区间不用于当前位置交叠判断。
2. `binding-outside-candidates`：明确绑定实体未列入该指代的用户候选表。保留绑定、仍计当前有效绑定，另标待核；不自动加入候选或改成未知。
3. `ambiguous-with-fewer-than-two-candidates`：用户声明多候选未定，但候选不足两个。只核对声明与字段的一致性，不判断真实文本歧义。

未知且候选为零或一个是合法人工状态，不自动推断应绑定。同名实体不自动合并。实体表示用户选择的一个介绍片段；指代只能绑定人工实体，不能绑定另一个指代，不做事件或跨文档实体解析。

### 容量、持久化与导出

- 实体0–20个，指代0–40个；没有标注不代表全文没有实体/指代。ID固定E1…E20/R1…R40；单片段非空≤240 Unicode码点，实体名非空≤80，人工依据≤320。
- 全文≤16000码点，来源名≤160、出处≤320。文本修订1–1000000，到达上限需导出后新开练习。拒绝重复/未知ID、重复/未知候选、非法状态、非法控制字符和孤立代理字符。
- 明确绑定须已知实体；未知/多候选未定的绑定ID必须null。旧修订区间允许超出当前短文本，但必须是非负整数、起点小于终点、终点≤32000，不接受来自未来修订的记录。
- 完整输入UTF-8 JSON≤128KiB，JSON/Markdown完整导出各≤1MiB；超过任一上限整份拒绝，不截断。最多60个标注的成对区间检查有限，最多1770对，不执行用户代码、联网或后台长任务。
- 配置只存`schemaVersion:1`完整确认输入/原片段/修订/候选/绑定，整体UTF-8 JSON≤64KiB；恢复再校验字段/版本/体积。未确认区间数字和派生链图/冲突/未绑定列表不保存。大型输入可完整检查/导出，但不写配置，关闭只能恢复较早合法输入，明确提示。
- 保存队列一个在途写、一个最新待写输入；旧回调不能遮盖新的非法草稿或未确认区间提示。离开忽略晚到控件操作，重新激活按当前模型同步控件；销毁释放草稿/报告/区间编辑和DOM，晚到导出响应不复活界面。没有音频、自播、网络或AI。

导出要求桥提供`saveTextSupportsCopyOnly===true`，发送`copyOnly:true`，仅`ok===true`提示成功；生产writer用`wx`拒绝已有目标，没有能力则不调用保存。报告含完整原文及人工说明，保存前先预览；只有新副本，无写回来源接口。

## 4. 使用步骤与可复现例子

1. 打开L046，点「重置三指代示例」。原文：`机器人见到研究员。它递给他报告，这让人意外。`。E1机器人区间`[0,3)`，E2研究员`[5,8)`；R1它`[9,10)`、R2他`[12,13)`、R3这`[16,17)`。
2. R1人工绑定E1，候选E1/E2；R2人工绑定E2，候选E2；R3明确未知，候选E1/E2。点「生成完整人工链报告」。恰3指代、2当前有效绑定、1未绑定；未绑定列表只含R3，冲突0。虚线候选有5条，但不能当作5个不同已绑定指代。
3. 把R3状态改为「多候选未定」，重新生成仍恰1未绑定。改成人工绑定E1后未绑定0；取消R3候选E1，会产生1项绑定在候选外冲突，原绑定仍保留。勾回候选并改回未知，恢复默认结果。
4. 在原文开头输入`前缀`。5条旧标注都失效，未绑定变为3；R1原记录仍为`[9,10)`和quote「它」，不会自动移成`[11,12)`，当前原文不高亮旧记录。
5. 逐条编辑起止数字、核对预览并确认：E1`[2,5)`、E2`[7,10)`、R1`[11,12)`、R2`[14,15)`、R3`[18,19)`；也可用当前原文选区重新标定每条。完成后失效0、未绑定1。含义是否仍相同由用户人工判断。
6. 在原文选择非空片段，点新增实体/指代；编辑人工名称、候选、状态和依据。若重复选择同一区间，会产生位置重叠待核，不自动去重。删除已被候选/绑定引用的实体时先解除相关引用。
7. 展开完整JSON/Markdown预览，分别导出到不存在的新文件。刷新恢复确认过的输入/人工状态，但报告需重新生成。正在编辑却未确认的区间数字会丢失，已保存的旧确认区间仍在；超64KiB输入不能承诺关闭恢复。

默认人工链：

```text
E1 机器人 ── 明确绑定 R1「它」
           ⋯ 候选 R1「它」、R3「这」
E2 研究员 ── 明确绑定 R2「他」
           ⋯ 候选 R1「它」、R2「他」、R3「这」
未绑定：R3「这」明确未知，候选E1/E2
```

图只呈现用户记录，不表明例句真实含义已经由工具证明。

## 5. 产出

JSON包含schema/model版本、当前完整原文/来源/出处/修订、全部实体与指代原区间/当时片段/人工说明、全部候选和原绑定、当前区间有效性及原因、全部实体链、全部未绑定指代、全部失效标注、全部冲突对/字段冲突及精确计数口径。旧记录不会因当前文本过短而被删掉；报告不漏掉位置失效/未知的合法人工状态。

Markdown嵌入同一完整JSON记录，HTML实体转义并按原文反引号长度增大围栏，避免原片段变成可执行HTML或截断围栏。复核嵌入记录时应还原实体。所有20实体、40指代和完整待核列表均进入导出，不因界面滚动、当前输入焦点或候选在多组出现而丢失。

报告不是自动消歧输出、语言学真值、作者意图证明、标准认证或认知评分。来源名和出处是人工记录，不能证明其与某个磁盘文件/外部文献绑定；没有读取/改写用户源文件或文本历史版本库。
