# L033 复现实验材料清单

## 功能内容

为一个复现实验项目记录固定五类材料：数据、代码、参数、环境、评估证据。每类填写证据文本、可选来源引用，并由使用者勾选“已经取得”。显示缺失、待确认、已确认三个状态，以及已确认类数/5的材料完成率。支持JSON/Markdown清单副本、本机小草稿与JSON恢复。

## 为什么需要

读完方法部分后，仍可能缺少数据划分、版本、参数或评估依据。固定类别帮助把“已经有材料”和“只是看见候选位置”分开；材料清单可用于下一轮收集和人工核对。完成率只反映此清单的材料确认情况，不承诺实验可运行或结果能复现。

## 实现方式

纯模型分别校验五类文本、来源与布尔确认。空白证据是missing，即便有来源或已勾选；非空证据但未确认是pending；非空且人工确认是ready。缺失及待确认ID单独保留，完成率=ready/5。来源仅文字引用，不自动读取文件或访问网址；工具不判断材料真假。

编辑证据或来源会取消该类旧确认，输入改变废弃旧报告，需重新检查与勾选。项目标题1–120字符，每类证据≤4000字符、来源≤400字符；草稿schemaVersion=1并按UTF-8≤64KiB校验，超限保留当前界面内容、阻止写配置并提示导出。只保存五类材料草稿，检查结果重新计算。恢复时忽略旧报告结论，验证input并重算；未知类别、版本或字段不会默默迁移。

界面采用文本节点，导出采用副本写入。没有AI自动确认、外部命令或实验执行。可选AI不是首版必需依赖，当前首版全部人工输入。

## 如何使用

1. 打开L033，填写项目名。各类别的提示列出建议记录内容，如数据版本、代码入口、参数种子、环境依赖和指标来源。
2. 填写材料证据，可附文件路径/页码/网址引用；确认已经取得时才勾选。空证据不会仅因勾选而完成。
3. 点击“检查材料准备情况”，按缺失和待确认分类继续补充。编辑证据或来源后旧确认取消，重新核对并检查。
4. 核对完整预览后导出JSON或Markdown，选择新路径。已有文件不能覆盖，取消不会报成功；老版本无copyOnly保护接口时禁用导出。
5. 可粘贴本工具JSON报告或版本1草稿并“恢复材料项目”。恢复失败保留当前项目，恢复成功重新计算状态。工作台关闭/切换时保存合规本机草稿，重要内容仍建议导出。

## 使用后产出

五类状态、缺失ID与待确认ID、已确认数量和材料完成率。完整JSON包含input、categories、missing、pending、ready、total、completion、scope，可恢复输入。Markdown列出五类证据与来源引用并保留未执行实验的范围说明。所有确认来自使用者，不生成虚构材料。

## 具体例子

点击“载入缺两类示例”：数据集版本与划分已取得，代码版本与入口已取得，评估表/指标已记录，三者经人工确认；参数和环境没有文本。结果ready=3、total=5、completion=0.6，missing恰好为parameters/environment，界面显示60%、缺失2类。

在参数证据中填写“学习率0.001，随机种子42”，暂不勾选，重查：缺失1类、待确认1类，完成率仍60%。确认已取得该参数后勾选，重查得到80%。以后修改证据文本，确认自动取消，回到待确认，避免把新材料沿用旧确认。

## 验证与边界

7项测试覆盖60%验收、来源/勾选不能替代证据、候选材料须人工确认、100%仍不宣称实验完成、版本/类别/长度校验、UTF-8实际64KiB边界及输入副本、Markdown表格与HTML转义。工具是材料准备清单，不能核实文件存在、实验可执行性或方法完整性；如需要真实复现实验须另行执行与验证。
