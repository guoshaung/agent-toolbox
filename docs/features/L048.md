# L048 受众版本对照

## 1. 功能内容

学习工作台「语言与表达训练」中的本地人工对照工具。用户填写共同事实清单，标明必保/可选与作者或用户来源，再分别编辑专家版、入门版的全文、来源名和出处。两版最多两份，固定专家/入门标识，空稿允许保留；两份稿件不会合并或自动生成改写。本MVP采用catalog的AI可选所允许的完整本地人工流程，没有AI必要依赖。

用户为每条共同事实分别绑定两版原文片段，指定每版各自的人工术语清单，再为各术语绑定解释片段。可以在真实稿件文本框中选择区间，或编辑起止数字并查看预览后明确确认。事实和术语可增删，术语名称、依据、来源原句均可编辑；术语出现字样不会自动被视为解释。

直接点击「分析两版人工覆盖」，得到两版独立的必保事实覆盖、全部事实证据表、绑定状态差异ID、每版全部人工术语及解释锚，以及仅该版未绑定/失效的术语待核项。共同事实来源名、位置、原句为空时按具体字段单列未知，不自动编造出处。完整JSON/Markdown预览与新副本导出包含两稿全文、共同事实、全部术语、旧quote/修订和所有待核项。

## 2. 为什么需要

同一内容写给专家和入门读者时，可能一版漏掉了必要事实，另一版保留术语却没有提供解释。只比较文字相似度无法确认作者是否保留了限定条件，也不能代替判断哪些概念需要解释。

本功能让用户先明确共同必保事实，再分开记录两版证据与各版术语解释位置，保留修改前的原句和真正未知项。新增能力是多受众版本的人工约束对账与可复查位置记录，避免把「文字里出现了术语」混同于「已经解释了术语」。

工具只对照人工声明及当前锚状态，不自动发现全部事实/术语，不评价入门难度、语言能力、解释正确性、语义一致性、真实读者理解效果或来源可靠性。相同事实覆盖比例可能对应不同文本；比例一致不等于内容相同，差异也不自动等于矛盾。

## 3. 实现方式

### 共同事实与独立覆盖

schema1草稿包含共同事实数组和固定`expert/beginner`两版。每条事实保存稳定F1–F20 ID、人工描述、必保布尔值、事实修订、来源名/位置/原句、两版人工锚以及说明。每版保存来源名、位置、完整文本、稿件修订和本版术语清单。专家术语ID为E1–E10，入门术语为B1–B10；删除后新记录可复用空ID，当前数组内必须唯一，不伪称不可更改的历史身份。

覆盖分母均为共同必保事实数，但分子分别是该版当前有效人工事实锚数，绝不复用另一版计数。0条必保时分数和比例为null，界面显示未定义。可选事实保留完整输出，只不计入覆盖分母。待核事实ID包含该版全部未绑定/失效事实（包括可选），界面与导出说明其口径。绑定差异仅当一个版本锚当前有效而另一个无效时列该事实，不判断两个有效片段的意义是否相同。

共同事实来源名/位置/原句各自为空就显示待补字段；此来源待补独立于两版覆盖比例。原句是人工提供的来源引用，不存在第三份自动扫描的文本版本，也不核验作者或网页。来源说明更改会废弃旧分析但不修改片段位置，事实描述更改则使两版该事实旧锚失效。

### 字面锚、解释位置与修订

锚记录0起算UTF-16码元半开`[start,end)`、当时quote、稿件修订和事实/术语修订。当前锚必须修订相同、位置合法且quote字面相同；有效锚显示1起算逻辑行和UTF-16列，逻辑换行识别CRLF/LF/CR。片段非空、非纯空白且≤240Unicode码点，禁止拆分代理对。UTF-16列不是UTF-8字节偏移或显示字形列。

选区使用[WHATWG HTML文本控制选区API](https://html.spec.whatwg.org/multipage/form-control-infrastructure.html#textFieldSelection)的selectionStart/selectionEnd。真实textarea把CRLF/CR显示为LF时，模型把显示偏移映射回原始稿件的UTF-16区间，报告仍保留原换行。用户重新编辑后的浏览器LF值成为新修订，旧锚失效。报告码点长度包含空白/标点/换行，🙂计1、组合字符可多码点、CRLF计2；这只是文本规模信息，不评价哪个版本更易读。

修改某版全文后只使该版所有事实/解释锚失效；另一版不受影响。修改共同事实描述使其两版锚失效；修改某术语名仅使该术语解释锚失效。即使只是末尾追加，也要人工重新确认当前修订，不搜索同词、不按插入长度漂移位置。旧区间越过缩短后全文仍作为失效记录保留，旧quote不丢。原文全文历史不保存，如需旧全文先导出。

术语清单仅由用户指定，本版解释锚未绑定或失效才列本版术语待核；不会因某术语在另一版已解释而认定本版解释完成。多个术语/事实允许共用片段，含义由人工复核。清空全部术语只能表示没有人工清单，不能证明没有难词；绑定解释锚只表示人工选了位置，不证明定义正确或适合目标读者。

### 有界执行与持久化

两稿各≤16000Unicode码点，最多20事实，每版最多10术语；事实描述/依据/来源原句≤320，术语名非空≤80、术语依据≤320，来源名≤160/位置≤320；稿件和记录修订为1–1000000。重复/未知ID、未来锚修订、非法控制/孤立代理字符、未知schema字段、超过事实/术语容量整份拒绝，不截断成成功报告。完整输入UTF-8 JSON≤256KiB，JSON/MD各≤2MiB，发布报告前验证两种产物完整体积。

全局配置只存schemaVersion=1确认输入，TextEncoder计算整份UTF-8 JSON≤64KiB；恢复重新验证版本/结构/体积。不存派生报告、未确认数字或历次全文。大输入明确提示未保存、关闭只能恢复较早合法草稿，仍可生成完整报告并导出。区间数字编辑但未确认时，仅保留内存且阻止分析/导出，避免数字界面与旧报告不一致；错误确认保留之前完整已确认记录。

分析先复制确认输入快照，开始、每版处理后及结束异步让出，取消检查在让出前后执行。编辑、取消、切走、destroy票据失效，迟到旧结果/部分结果不能发布。配置一个在途加一个最新待写快照串行保存，票据及实例所有权隔离迟到回调，旧成功不得盖掉未确认数字或容量警告。激活重建控件；离开忽略编辑并使当前分析失效，销毁清DOM/引用，不启动媒体/网络或执行用户代码。

导出冻结完整报告文本，要求saveTextSupportsCopyOnly严格为true，传`{content,extension,defaultName,copyOnly:true}`，响应严格`ok===true`才宣布保存成功；生产writer用wx拒绝已有目标。取消/失败保留报告，destroy后迟到保存响应不能恢复DOM。Markdown含完整JSON，用动态围栏和HTML转义保留资料，不写回来源文件。分析无需许可确认；整体示例替换会覆盖当前两稿及标注，因此有明确确认/保留当前输入操作。

## 4. 使用步骤

1. 打开L048，填共同事实，标必保或可选，记录来源名、作者证据位置和原句；不确定项保留空项/人工疑问。
2. 输入专家稿和入门稿的全文及来源说明。对每条事实分别选择两版对应片段并按绑定，或编辑起止数字、核对预览后确认。
3. 为各版添加自己认为需要解释的术语，选中该版解释段落绑定。尚未找到解释时保持未绑定，不借用另一版解释。
4. 直接按「分析两版人工覆盖」，核对独立分数、绑定差异、来源待补以及各版术语待核。输入变化废弃旧结果；按取消可停止当次分析，不显示半份报告。
5. 修改全文/事实/术语后查看旧锚失效原因，再明确绑定当前区间，重新分析。预览全部资料并导出JSON或Markdown新副本。
6. 如需改用示例，先保存所需资料，再点示例替换并明确确认；按「保留当前输入」不改变草稿。

## 5. 产出与可复现例子

专家稿（32码点）：`缓存存储副本，命中时复用。TTL=60秒。LRU按最近使用排序。`

入门稿（46码点）：`缓存是临时存储的副本。TTL是副本可用时长，设为60秒。命中时直接复用。LRU选择替换对象。`

| 共同必保事实 | 专家人工片段 | 入门人工片段 |
| --- | --- | --- |
| F1 缓存保存副本 | [0,6) 缓存存储副本 | [0,10) 缓存是临时存储的副本 |
| F2 TTL设为60秒 | [13,20) TTL=60秒 | [22,27) 设为60秒 |
| F3 命中时复用副本 | [7,12) 命中时复用 | 未绑定/待核 |

专家术语E1 LRU解释锚[24,31)「按最近使用排序」。入门B1缓存解释[3,10)「临时存储的副本」，B2 TTL解释[15,21)「副本可用时长」，B3 LRU解释未绑定。直接分析：专家3/3，入门2/3，差异ID仅F3；入门术语待核仅B3，不把B1/B2标错。示例片段仅演示人工标注，不用来核验缓存概念定义。

选择入门稿[28,35)「命中时直接复用」绑定F3；给B3输入[39,45)「选择替换对象」，明确确认后再分析：入门3/3，术语待核空。这里人工绑定并不证明这段充分/正确解释LRU。清除F1专家锚，专家变2/3，入门仍3/3。再把F1来源原句清空，来源待补恰F1/quote，覆盖比例不变。

在入门稿前端连续输入「前」「缀」，原稿r1→r3；入门所有旧锚保留quote和原位置但失效，覆盖0/3，术语B1/B2/B3均待核；专家仍3/3且E1当前有效。分别重新确认入门F1[2,12)、F2[24,29)、F3[30,37)、B1[5,12)、B2[17,23)、B3[41,47)，恢复入门3/3和无术语待核。更改F1事实描述会使两版F1锚同时失效，更改B1名称只使B1解释失效。

JSON/Markdown包含全部当前两稿和来源、共同事实、人工原句、原旧quote/修订、两版覆盖和所有事实/术语状态、差异与待补列表，最大20事实和10+10术语仍完整。导出不是只保存当前可见行或单版资料。
