# T084 订阅续费成本比较

## 1. 功能内容

在本地配置 1–10 个订阅方案，比较共同币种下的区间内收费总额，查看按公历月的当月费用/累计费用、逐次首付/续费金额及下一次区间外收费日期。每个方案可选择每月、每季（3个月）、每年（12个月）自动续费，明确首次付费日、每周期原价和可选限时优惠金额/到期日。所有输入是可直接编辑的金额、周期、日期和优惠控件。

输入改变时旧结果废弃；结果分页展示，但副本保留完整数据。可导出版本1方案草稿、完整 JSON 结果、完整 CSV 结果和 Markdown 阅读报告。草稿或完整 JSON 结果可重新导入，仅恢复配置并要求重新计算，不采用文件里的旧统计。数据不上传，不调用付款或取消服务，不自动查询价格，不写全局配置。

## 2. 为什么需要

年付和月付不能仅按标签价格比较，优惠到期也不一定落在续费日。把全年费用摊销到某个月、把结束当天的续费算入区间，或从二月缩短的日期继续滚动，都可能得出不同结论。该工具把这些计算假设显式展示，用户可以核对每一次实际收费日期和优惠是否生效，并保存方案以供以后重新计算。

## 3. 实现方式与计算口径

- `model.mjs` 只处理纯公历年月日与整数分，不依赖 Date 的本地时间戳、地区日期解析或时区；不会因 UTC、系统时区或夏令时漂移一天。输入日期必须是 `YYYY-MM-DD`，范围 1900–2199 年，逐项校验月份天数和公历闰年规则。
- 比较区间是 **左闭右开 `[start,end)`**。开始当天收费计入，结束当天收费不计入，并可显示为下一次区间外收费。月份模式 1–120 整数个月，结束日按比较开始日的原始日号/月末锚点推算；日期模式指定结束日，最多到开始日的10年周年（2月29日周年夹至2月末），结束必须晚于开始。比如 `2022-02-28` 起120个月的月份模式终点为月末 `2032-02-29`，而日期模式的10年上限为 `2032-02-28`，两种规则在界面假设中明确区分。
- 每次自动续费都从原始首次付费锚点加 `周期数×1/3/12` 个月。若首次付费是该月最后一天，则以后收费取目标月最后一天；否则保留原日号，短月暂夹到该月末，但下一周期仍用原日号。`2027-01-30` 的月付日期为1月30日、2月28日、3月30日；`2024-01-31` 的月付为1月31日、2月29日、3月31日。4月30日是月末，季付下一次是7月31日；2月29日年付跨非闰年取2月28日，到闰年又回到2月29日。
- 每次完整收取当周期费用，**不摊销、不退款**。开始前已经支付的费用不进入区间，即使服务仍覆盖区间；首次付费晚于区间时没有虚构收费。无收费的方案明确提示“区间内无收费不代表服务未使用或永久免费”。各方案是互斥选项，分别比较，不把所有方案成本相加或判断服务质量相等。
- 限时优惠按 **收费日期 `< 优惠到期日`** 判断；到期当天恢复原价。年费在优惠期内收费时整个年费按优惠金额收取，不在到期日拆分。优惠金额可为0，不能高于原价；优惠已在首次付费前到期时没有优惠收费。相同优惠金额和原价仍按日期标记优惠适用。
- 金额只接受非负十进制字符串，最多两位小数，不接受空白、正负符号、指数、逗号、`NaN` 或数值类型的导入。用 BigInt 分解十进制文本得到整数分，按安全整数分精确累计，展示时再按100分/主单位格式化；不会用浮点金额 `0.1+0.2` 累加。当前仅支持共同的 CNY/USD/EUR/GBP，每币种均按100分/主单位，不换汇、不支持零位或三位最小单位货币。导入中的单方案额外币种字段会拒绝，不能夹带混币种方案。
- 每次收费输出 `cycleIndex`（首付0，后续递增）、`kind`、`date`、实际金额/原价整数分、优惠布尔值及该方案区间累计分。`nextCharge` 是收费日期不早于区间结束的首个事件，可能是首付或续费；不计入区间总额。若输入靠近2199年末，数学推算的下一次区间外日期可以超过2199年，输入日期和比较区间仍受1900–2199约束。
- 月表按公历月份分桶，首尾部分月只计有效区间内收费，保留0成本月份。跨12个收费周期可能出现13个公历月桶，不能把桶数当收费次数。逐月累计与逐次收费总额执行一致性校验，失败不提供导出。

`json.mjs` 是从 T010（70ad3087）的独立纯 tokenizer 复制并收紧限额，没有运行时跨功能导入。版本、结构和输入配置校验严格；重复键、非法 JSON、不安全整数/精度丢失数值和未知草稿配置字段拒绝。输入名/金额/日期只当数据，不运行脚本。解析、计算和导出定期让出事件循环并检查 AbortSignal，取消不留下可保存半成品。

## 4. 如何使用

1. 打开工具工作台 **T084 订阅续费成本比较**。选共同币种，设置包含的开始日期，选月份数或不包含的结束日期。
2. 逐方案输入名称、每周期原价、月/季/年周期和原始首次付费日期。点 **添加订阅方案** 最多加到10个；可移除方案，但至少保留一个。
3. 如有优惠，勾选该方案 **限时优惠**，填写优惠期每次金额与优惠结束日期。默认未勾选的金额/到期控件禁用；勾选后需要用户核对到期日，程序不猜优惠期限。
4. 点击 **比较订阅成本**，核对总额、收费/优惠次数、下一次区间外收费。按月表每页12个月；收费清单选择一个方案，每页25次。界面修改任何有效输入立即废弃旧结果。
5. 保存完整 JSON、CSV 或 Markdown 结果；也可在未计算时保存合法的版本1方案草稿。全部要求 `saveTextSupportsCopyOnly===true`，调用 `files.saveText({content,extension,defaultName,copyOnly:true})`；旧基础层能力缺失时按钮禁用。基础层独占创建副本，已有目标（包括原草稿）拒绝覆盖。生成副本阶段可取消；进入原生另存对话框后通过该对话框核对目标或取消，面板取消暂时禁用。对话框取消不报告保存成功。
6. 在 **恢复草稿 / 完整JSON结果** 中导入 UTF-8 `.json` 文件或粘贴版本1 JSON，点击导入。成功后恢复可视控件，旧结果清空，重新比较。非法 UTF-8、版本、结构或超限文件原子拒绝，当前方案/结果保持。仅编辑候选导入文本不会改变正在使用的可视方案。

切换具体功能会销毁未保存内容，离开整个工具会取消操作；没有隐式自动保存或服务账号同步。请显式保存草稿以便恢复。

## 5. 产出与具体例子

核心验收可直接点 **载入月10与年100示例 → 比较订阅成本**，输入为共同 CNY，开始 `2027-01-01`、12个月，两个方案首次付费均为 `2027-01-01`，无优惠：

| 方案 | 每周期金额 | 周期 | 区间内收费 | 累计总成本 | 下一次区间外收费 |
| --- | ---: | --- | ---: | ---: | --- |
| S1 月付 | 10.00 | 每月 | 12次 | 120.00 CNY | 2028-01-01，10.00 |
| S2 年付 | 100.00 | 每年 | 1次 | 100.00 CNY | 2028-01-01，100.00 |

区间为 `[2027-01-01,2028-01-01)`。S1 的收费日期从1月1日到12月1日，S2仅1月1日收费。1月累计为10/100，12月累计为120/100；结束日下一次费用均不计入。

优惠边界复现：载入示例后勾选 S1 限时优惠，优惠期金额 `5.00`，到期日 `2027-04-01`，点击比较。S1 1/2/3月1日各5.00，4月1日起恢复10.00，共 **3次优惠、12次收费、105.00 CNY**。将比较模式改为日期，结束填 `2027-04-01`，总额变为15.00，4月1日10.00只显示为下一次区间外收费。

月末复现：只保留一个方案，首付/开始 `2024-01-31`，月份数3，原价10.00，月付、无优惠。终点为 `2024-04-30`，收费1月31日、2月29日、3月31日，共30.00；月表包含1月31日至2月1日的首个部分月和4月1日至4月30日的最后部分月（末月费用0），不会多计4月30日。

草稿结构为 `{feature:"T084",version:1,kind:"draft",config:{currency,interval,plans}}`。完整 JSON 结果为版本1 `kind:"report"`，含 `draft`、`assumptions`、`interval`、每方案全部 `events`/`nextCharge`、全月表及最低区间成本的方案 ID（相同费用全部列出）。金额以整数分存储，如120.00为12000。导入完整结果只恢复 `draft.config`，即使文件中的旧总额被修改也会重新计算。

CSV 有 BOM、CRLF，列为 `section,plan_id,detail_json`；`metadata` 保留全部假设与草稿，`summary` 保留总额及下一次收费，`charge` 是逐次事件，`month` 是完整逐月数据。明细使用完整 JSON，避免名称、字符串/数字及边界标记混淆。Markdown 是易读完整报告，含方案成本表、所有按月累计行、每次收费/优惠/累计及可恢复 JSON 草稿；方案名称经过 Markdown/HTML 转义。
