# L013 页表地址翻译

## 1. 功能内容

在“学习 → 计算机原理交互实验”中提供一个完全本地的单级页表教学模型。用户选择页大小，编辑虚页号、物理页号、是否驻留、可读/可写，再按顺序登记虚拟字节地址和读/写请求。运行后得到页号与偏移、物理地址或明确的异常；每次访问都有解释路径和TLB之前/之后的可视表格，可以上一步、下一步、选择或点击指定访问。

TLB固定为4项全相联缓存，采用LRU；不需要AI、登录、外部软件或新增依赖。内置公式、异常、LRU三套可编辑示例；JSON与Markdown均可导出完整输入及当前结果。编辑任何页表字段、页大小或访问会立即清空旧结果与TLB显示，每次运行从冷TLB重新开始，避免旧映射继续生效。

## 2. 为什么需要

只看到地址翻译公式，容易把“没有映射”“页表有条目但页面不在内存”“页面驻留但访问无权限”混成一种缺页，也容易认为TLB命中就能绕过权限。本功能把三个检查和地址范围错误分别展示，并给出缓存改变的具体原因，帮助学习者用可验证数字核对理解。

新增能力是实际输入和可复现的地址/TLB演算，区别于知识网页、AI讲解以及其他缓存实验；它不处理数据缓存的组映射或写策略。

## 3. 实现方式与确定规则

- `model.mjs`纯模型校验输入，执行顺序访问，返回独立的前后快照；`index.js`使用现有`h`建立真实表格、输入、复选框与步骤控件；`style.css`只作用于本功能。元数据由功能工作台发现，不修改公共注册表。
- 地址是32位无符号字节地址，合法范围0～4294967295。页大小可选256～65536之间的2的幂。虚页/物理页必须在0～`floor(4294967295 / 页大小)`之间，禁止重复虚页。
- `虚页 = floor(地址 / 页大小)`；`偏移 = 地址 % 页大小`；`物理地址 = 物理页 × 页大小 + 偏移`。全部使用安全整数除法、取余、乘加，不使用会产生有符号溢出的JavaScript位运算。
- 页表至多64条，访问至多128条。地址和页号接受十进制或`0x`十六进制整数文本；拒绝小数、科学计数、Infinity、布尔/数组和脚本。输入栏最多24字符。负数和超出32位域但仍属于安全整数的访问地址会产生逐条“地址越界”；超过安全整数域或格式非法则整轮拒绝，不生成半份轨迹。
- 检查顺序为：地址范围 → TLB/页表 → 是否映射 → 是否驻留 → 本次读写权限 → 地址计算。未映射：没有页表行；不驻留缺页：有行但`present=false`；权限错误：驻留但请求的`read`/`write=false`。异常的物理地址为“无”，不会伪造为0。非驻留条目也需给出合法物理页号，该字段只作教学草稿，不用来翻译。
- TLB缓存已成功翻译页的物理页和权限，最多4项，展示从最旧到最新。每次命中都检查缓存权限；命中（包括权限拒绝）将该页移到最新。只有成功的未命中访问才填入；满4项时淘汰最旧项。未映射、缺页、权限拒绝的未命中不填入，也不淘汰。拒绝权限的命中更新LRU是本模型明确规定的策略，不声称所有处理器均如此。
- TLB命中率分母为合法32位地址的TLB查询次数，包括权限拒绝访问；越界不会查询TLB，不进分母。空访问或全越界时命中率未生成；异常总数只是被拒绝访问数，不等于缺页数。
- 配置只保存`schemaVersion:1`的输入草稿，不保存TLB、轨迹。写入前按`TextEncoder`测JSON UTF-8大小，超过64KiB拒绝写入并提示导出完整JSON；恢复校验整个存储对象的体积、版本、结构及容量。未完成输入允许恢复为草稿，运行时再做数值校验。关闭超限草稿后只能恢复较早草稿，不能声称自动恢复当前输入。
- 保存延迟250ms，切走/销毁清除定时器并尝试保存；运行有界且同步，不留后台模拟。异步导出或保存结束后若组件已销毁，不再更新界面。
- 导出检查`files.saveTextSupportsCopyOnly`并传递`copyOnly:true`、`content`和扩展名，基础层排他创建新文件，拒绝覆盖已有目标。全部用户输入用表单值或文本节点呈现，不执行任意代码、不插入HTML；Markdown草稿也转义HTML字符。

## 4. 使用步骤与可复现例子

打开功能，先使用默认“公式示例”，点击“运行地址翻译”。页大小4096，页表虚页2→物理页5，驻留、读、写均选中。第一条访问8199/read显示：`8199 = 2 × 4096 + 7`，`5 × 4096 + 7 = 20487`，TLB未命中并填入虚页2。点击“下一步”，8200/read产生20488，命中同一虚页；总命中率1/2=50%。

点击“载入异常示例”再运行：页表虚页2→物理页5只读，虚页3→物理页6不驻留。按以下顺序观察：

|步骤|地址/操作|预期结果|TLB|
|---|---|---|---|
|1|8199/read|成功，物理20487|未命中，填入虚页2|
|2|8199/write|写权限错误，无物理地址|命中，仍校验权限|
|3|12288/read|不驻留缺页|未命中，不填入|
|4|16384/read|未映射|未命中，不填入|
|5|-1/read|地址越界|未查询|
|6|4294967296/read|地址越界|未查询|

此例命中1/4=25%，成功1次、异常5次，TLB仅虚页2。选中“页表1可写”后立即显示旧轨迹已清空；再运行第二步转为成功。取消该页“驻留”后再运行则为缺页，TLB不填入；不会沿用旧权限或旧物理页。

点击“载入 LRU 示例”再运行。虚页0、1、2、3、4分别映射物理页5、6、7、8、9，访问地址依次0、4096、8192、12288、0、16384（虚页序列0、1、2、3、0、4）。第4次访问后LRU为`[0,1,2,3]`；第5次命中0变成`[1,2,3,0]`；第6次填入4，替换虚页1/物理页6，变为`[2,3,0,4]`。通过“查看第6次”或步骤选择器核对前后表。

要自定义，可添加/删除映射、逐项编辑页号与三个复选框，再添加/删除读写访问。运行遇到非法字段时按提示修正；参数编辑后必须重新运行。点击JSON或Markdown导出，选择一个不存在的新文件名；取消导出保留当前输入与结果。

## 5. 产出

界面输出顺序结果表、每条异常/成功解释、页号偏移和物理地址、TLB查询与LRU操作、前后完整TLB、命中率及异常计数。

JSON包含feature、schemaVersion、modelVersion、导出时间、原始字符串草稿、规范化输入及完整结果；每个步骤含状态、查询、替换对象、解释路径、前后TLB，可供后续复核。Markdown包含完整输入表、访问表、统计、逐步公式和前后TLB。未运行或编辑后导出则只有当前草稿，明确没有有效结果。当前不提供报告导入，已保存配置草稿可自动恢复后重新运行。
