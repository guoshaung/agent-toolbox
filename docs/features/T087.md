# T087 采购规格单价比较

## 功能内容

录入1–50项商品的名称、同类比较组、币种、每包装净含量、单位、包装数量、商品合计价及本笔运费，将总净含量统一为kg/L/件，计算每标准单位价格并按精确值排序。所有不符合条件的记录都保留原因，不能用错误输入取得有意义的名次。

## 为什么需要

购物时500克、1千克、两包装和不同运费容易使标签价格失去可比性。明确总价与总净含量后，使用者可以核对付出的钱对应多少商品；按同类、币种和量纲分组避免将一瓶水和一袋米或人民币与美元直接排名。排名只是价格比较，不判断品牌、品质、退货政策或值得购买与否。

## 实现方式

独立model.mjs解析金额为整数分，净含量为十进制精确分数；BigInt进行分数交叉乘积排序。每标准单位价格=(商品合计价+本笔运费)/(每包装净含量×包装数量×单位换算因子)。g→kg及ml→L除以1000，件无需换算。运费只加一次，商品总价已包含所填全部包装，不再乘包装数。

比较键为人工同类组名+明确币种+量纲；只对同键至少两项排名，单项显示无法比较。相等精确价格并列，采用竞赛名次1、1、3；同价保留来源顺序。显示单价半入到四位小数、净含量六位，排名使用未舍入分数；完整报告保留分子、分母字符串供审计。不同显示舍入下可能看起来同价却名次不同。

金额非负、最多两位小数且每个≤50,000,000；净含量>0、≤1,000,000,000、最多六位小数；包装1–10000整数；数字字段最多32字符。币种CNY/USD/EUR/HKD；不做汇率或密度换算。不解析指数、负数、未知单位。某行有误时不会阻止其余有效商品比较，但明确保留输入与错误。所有输入只在当前面板内存，不写全局配置。

## 如何使用

1. 在功能工作台打开T087。给可以相互比较的商品填相同“同类比较组”。
2. 选择币种，输入每包装净含量、单位和包装数量。填写全部包装合计商品价，以及这一笔的总运费。
3. 点击“计算并预览单价”，核对各组的排序、来源行、总量与名次。对无法比较项阅读原因并修正，再计算。
4. 展开完整审计预览可见精确分数和无效原始行。点击“导出采购比较 JSON”并选择新路径，已有目标不能覆盖；取消保存不会报成功。旧版缺副本保护接口时禁用导出。

输入改变会立即废弃旧报告，避免导出之前的价格。切换功能会丢失未导出的输入和结果。

## 使用后产出

按同组同币种同量纲排列的单价表，及所有无法比较的明细。JSON包含formula、rounding、grouping、rows、comparisons、comparableCount、uncomparableCount；有效行有原始序号、费用整数分、总量与单价精确分数、是否可比、名次；无效行保留raw与issue。导出为新的UTF-8文本文件。

## 具体例子

点击“载入500克与1千克示例”后计算：A的总价20元、500g、一包、运费0；B的总价35元、1kg、一包、运费0。两者同组大米/CNY，结果A=40.0000 CNY/kg，B=35.0000 CNY/kg，B第1名、A第2名。JSON rows 保留输入顺序，comparisons.sourceRows=[2,1]表示价格排序后的来源行。

若A改为两包各500g、合计价30元、运费5元，总量1kg、合计35元，和B精确同价，均第1名。若将A币种改USD，其与B无法互比，两行均没有名次，不擅自换汇。

## 验证与边界

7项模型测试覆盖40/35验收、运费和包装数、精确并列、币种/量纲/组隔离、显示同价但精确排序不同、无效输入留存、最大值序列化、件价格与半入边界。输入上限和32字符校验约束计算量。仅做可核对的单位价格计算，商家折扣须先由使用者计算进合计价，不自动获取商家信息。
