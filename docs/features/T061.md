# T061 域名解析路径诊断

## 1. 功能内容

用户输入域名、一个自选 DNS 的 IP[:端口]（IPv6 使用 `[地址]:端口`）和 A 或 AAAA。先检查输入、展示规范化域名、系统名称服务与指定 DNS 两个目标、API 调用次数及等待期限，用户另行点击确认才发起查询。结果分别列出来源、完整地址、耗时、状态、错误代码和分类，缓存命中标 `unknown`，明确 **未测 HTTP/TLS/连接**。可预览并导出完整 JSON/Markdown 新副本。

系统 `dns.lookup({all:true,family,verbatim:true})` 最多调用一次；独立 `Resolver({timeout:5000,tries:1})` 设置一个用户 DNS，`resolve4/resolve6` 最多调用一次。每个发送窗口同时一个任务、每次最多等待 5 秒，不自动换 DNS、不重试 API、不修改系统/全局 DNS 设置。**两次是 API 调用数，不是实际网络报文数**：系统名称服务可能使用 hosts/缓存/系统 DNS；底层 CNAME、TCP 回退或网络报文不可观测，不保证一个 API 仅一包。

## 2. 为什么需要

“域名打不开”可能发生在名称服务、DNS、连接、TLS 或 HTTP 不同层。把系统 ENOTFOUND 当成确定 NXDOMAIN，或把地址返回当作网站可用，都会误导排障。本功能把可测范围限制在名称解析，并保留两种来源的不同语义；相同地址、地址差异及不完整解析分别报告，不推测劫持、缓存命中或 HTTP 故障。

## 3. 实现方式、协议和边界

渲染界面通过生产 `features.callHostSupported / callHost('T061',operation,payload) / cancelHost('T061',jobId)` 调用固定可信 `host.cjs`。公共 Host 桥只加载安装目录里有有效 meta 的固定文件，只接受本地 file: 顶层 live sender、有界 JSON，操作不会动态执行用户代码或命令。后端 allowlist 为 `plan`、`run`；plan 只校验/规范化，不构造解析器或查询。run 需要 `confirmed:true` 和 12–64 字符唯一任务 ID，按 `context.senderId` 隔离；另一个 sender 不能取消本窗口任务。`disposeSender` 在窗口销毁时取消其解析器、停止等待并释放状态。不是远程公共 DNS 服务。

输入采用 Node `domainToASCII` IDNA 转换并小写。源域名最多 512 字符，规范化域名去掉可选末尾根点后最多 253 字符，每标签 1–63 字符，仅 ASCII 字母数字/点/连字符，首尾不为连字符；至少两个标签，例外是明确支持本机 `localhost`。保留输入的末尾根点；没有根点的域名仍由系统名称服务按系统策略处理，工具没有修改搜索后缀。拒绝 IP 字面量、URL、端口、路径、空白、控制字符、通配符、百分号编码、命令语法和非法 IDNA。只支持主机名形式，不支持任意 DNS owner（如 `_service`）。DNS 必须是合法 IP，不先解析 DNS 服务器的域名；端口 1–65535，默认 53；不接收 IPv6 zone ID、广播/多播/未指定地址。界面示例只填 `localhost / 127.0.0.1:5353 / A`，不查询，也不会自行启动 DNS 服务。

来源与错误分类：

| 来源与代码 | 分类 | 能得到的结论 |
| --- | --- | --- |
| system_lookup / ENOTFOUND | system_name_failure | 系统名称查询失败，原因不一定是 DNS NXDOMAIN |
| specified_dns / ENOTFOUND | dns_nxdomain | 指定 DNS 返回域名不存在的错误；保留 Node code，不是 HTTP 失败 |
| ENODATA | no_data | 没有请求类型的记录，区别于 NXDOMAIN |
| ETIMEOUT 或本应用 T061_TIMEOUT | timeout | DNS/名称查询等待超时，未测 HTTP |
| ECANCELLED | canceled | 已取消该来源的等待 |
| ECONNREFUSED/ECONNRESET/EHOSTUNREACH/ENETUNREACH/ESERVFAIL/EREFUSED | dns_connection_or_server_error | 名称服务连接或服务器错误，不当作 HTTP 连接检测 |
| 其他错误 | resolution_error | 保留有限错误 code，不回显堆栈、系统路径或内部异常 |

每来源完整保留至多 1024 条合法 IPv4/IPv6 地址；超过上限或格式错误整份来源标失败，不悄悄截断。地址对照按去重后的集合比较；不同来源成功地址可能不同，这不是劫持证据。每份导出最多 2 MiB，超过上限拒绝。窗口状态最多 32 sender，各保留最多 128 个已使用任务 ID，达到诊断次数上限需关闭并重新打开窗口；不长期保留域名、结果或源正文到配置。暂停/隐藏/清除/销毁调用取消并通过任务票据忽略晚结果，恢复不自动查询。指定 Resolver 可以 `cancel()`；**系统 lookup 无取消句柄，五秒期限及取消只停止本应用等待，无法终止已在操作系统中的查询**，故不能宣称所有底层网络活动立即停止。

产品只依赖 Node 内置 DNS/URL/net 能力和公共 Host 桥，不新增 DNS npm 包。API 依据：[Node DNS 与 lookup](https://nodejs.org/api/dns.html#dnslookuphostname-options-callback)、[独立 Resolver / cancel / timeout / tries](https://nodejs.org/api/dns.html#class-dnsresolver)、[DNS 错误代码](https://nodejs.org/api/dns.html#error-codes)、[domainToASCII](https://nodejs.org/api/url.html#urldomaintoasciidomain)。文档中的 `tries` 自 Node 16.7.0 支持；实际运行时与验收范围另列，不声称协议报文抓包、DoH/DoT、代理解析、缓存来源或操作系统具体 DNS 路径均已测量。

## 4. 如何使用

1. 打开 **T061 域名解析路径诊断**，填写域名、自己希望查询的 DNS IP/可选端口与 A/AAAA。
2. 点击 **检查输入并显示请求计划**。该步骤不发 DNS 查询；核对显示的 IDNA 后域名、系统目标、指定 DNS 目标、每来源最多一次 API 调用和 5 秒期限。
3. 明确点击 **确认以上目标并运行最多两次查询**。不自动跟随输入变化或切换服务器；运行中输入禁用，重复点击不重复发起。
4. 查看两种来源、完整地址及分类。可点击 **取消当前任务**，宿主返回后报告记录 canceled 和各来源当前状态，已完成来源不会伪装未执行。隐藏/暂停则丢弃晚回调，回来后手动重新准备目标。
5. 分别 **预览完整 JSON 报告 / MD 报告**，核对全部内容、拟创建文件名和共享信息，再 **保存已预览报告新副本**，在宿主保存对话框选全新目标。

输入变化立即废弃旧确认计划、报告及导出预览；清除和切换功能不会自动草稿。取消保存无法撤回已实际写完的文件；取消/失败不会显示成功，预览保留。报告含域名、用户 DNS、地址、任务 ID 和耗时，分享前核对。

## 6. 具体例子、验证结果与限制

有本机可控 DNS 夹具监听 `127.0.0.1:5353` 时，输入 `localhost`、该 DNS、A，点击检查计划：此刻无 DNS 包。确认运行后，系统来源应得到本机地址，夹具为 `localhost` 的 A 请求返回 DNS RCODE=3。指定来源应为 `failed / dns_nxdomain / ENOTFOUND`，空地址，`httpMeasured:false`；系统来源独立列出它实际返回的地址，不改写成指定服务器来源。报告对照 `incomplete_resolution`，JSON/MD 都保留两项，不能写成 HTTP 失败或断言系统 DNS 劫持。切换夹具回复 A=`192.0.2.7` 或 AAAA=`2001:db8::7` 可重放完整地址展示；夹具无回答时最多等待五秒，手动取消则当前来源记 canceled。填示例按钮本身没有启动夹具或网络查询。

专项 `node --test test/feature-T061.test.js`：23 项（15 模型/Host，8 真实模块 DOM 事件），另有公共 Host 桥 6 项，本树合计 29 项通过。真实 Node UDP 在临时 **127.0.0.1** 端口服务开发者夹具、查询域名仅 **localhost**；覆盖真实 NXDOMAIN、A、AAAA、ENODATA、取消和五秒静默超时，实际系统 lookup(localhost) 分开成功，`dns.getServers()` 前后不变。记录实际夹具收到的类型/数量；不是通过注入 DNS 结果冒称真实 DNS。系统 ENOTFOUND、堆栈遮蔽、不可取消晚回调与精确任务/计时边界使用受控注入单测，因为不向外网失败域名发查询；这部分不是生产系统失败探针。UI 单测用轻量 DOM 适配器运行真实计划/确认/取消/预览/保存事件，涵盖旧目标废弃、重复点击、保存 false/undefined/canceled/throw、暂停/隐藏/销毁，不当作原生窗口证据。
