# T091 分享包敏感内容预检

## 功能内容

读取用户通过 HTML 文件选择器明确选择的文本文件或目录，执行本地固定规则，给出已遮蔽风险位置、文件覆盖状态和人工审阅报告。不会上传、修改或删除源文件，不读取密码本，不通过任意系统路径打开文件，不依赖 AI、网络或账号。

三组可切换规则：高信号 api_key/access_token/secret_key/client_secret 赋值；典型 sk-、ghp_、github_pat_、AKIA/ASIA 标识形态；中国大陆手机号格式 `1[3-9]` 加九位数字。规则重叠时合并一个位置并保留全部规则标签。未发现、完成扫描或人工标记误报都不证明文件安全。

## 为什么需要

分享代码、笔记、日志和资料前，人可能忘记某个文件夹里夹带了测试密钥、手机号或访问标识。此功能把有限范围的本地规则定位与人工核对放在一起，减少在分享报告里二次泄漏原值的机会。它保留“哪些文件实际检查过、哪些未检查”而不会把读取失败当作零风险。

## 实现方式

`model.mjs` 的 `Scan` 用固定规则扫描用户交给它的 File 对象，使用 `slice().arrayBuffer()`，不使用 main/preload 新接口或 File.path。每次最多 50 文件，单文件 256 KiB、总读取 2 MiB、最多 500 个合并位置；限额在读取前检查，50 文件超限会拒绝整次选择而不静默截取。结果上限使本文件显示“部分扫描”，后续文件显示“未扫描”。每文件建立行起点表，二分计算行列，不为每个发现项重扫全部前文。

严格 `TextDecoder('utf-8',{fatal:true})`，支持 UTF-8 BOM 并在位置计算中除去 BOM；UTF-16 BOM、无效 UTF-8、NUL 或明显控制字节，以及明确二进制扩展/MIME 都显示未扫描。未知编码不尝试猜测、转换或假装已经检查。空文本可执行规则，但结果只说明没有匹配，不表示安全；二进制检测是有限启发式，不能辨认所有格式。

检测表达式只来自代码内的三组规则，不接受任意正则。密钥赋值只识别约定关键词、最多八个空白字符、可选引号和 8–256 个指定 ASCII 字符；典型令牌采用限定前缀与有限字符范围。非常长值可能只定位前 256 字符；不承诺穷尽所有供应商格式。手机号仅做格式提示，不验证真实持有人。GitHub 前缀参考 [GitHub 官方说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/about-authentication-to-github)，AWS 标识前缀参考 [AWS IAM 官方说明](https://docs.aws.amazon.com/IAM/latest/UserGuide/securing_access-keys.html)，并未把标识格式当作有效凭证校验。

原文、原始风险值和整行上下文均不进入 UI 报告或导出。位置保留文件编号、遮蔽文件名/相对路径、1 起算行列、0 起算 offset、命中长度，位置单位明确为 JavaScript UTF-16 代码单位，不是原始 UTF-8 字节偏移。整行原文只显示长度说明，避免同一行未选中规则的另一风险随上下文泄漏。文件名/相对路径、审阅原因和导出错误也执行规则及保守 ASCII 串遮蔽，已发现原值再次出现时完整替换。长 ASCII 名称可能全部隐藏，按 F001 起的选择顺序对应原文件；保留路径层次及常见安全扩展名，不把秘密前后几字符作为预览。

原文只在单文件读取/检测期间的局部内存出现；为了遮蔽路径及原因，当前实例私下保留最多 500 个已发现片段，不序列化它们、不写全局配置。报告只保存限额、覆盖、位置、标签、长度与人工标记。文件名处理最多 512 字符，标记原因最多 180 字，风险 UI 每页 25 项；没有无界结果或草稿存储。

## 如何使用

1. 在“文本文件，可多选”或“目录”选择要分享的内容，两种选择都会替换本次源选择和未导出结果。文件选择器值随后清空，实际 File 引用只由当前面板持有；不会展示未遮蔽的选择路径列表。
2. 选择检查规则，至少一项，点击“开始本地扫描”。观察文件覆盖状态；按“取消扫描”会保留已有发现，并将未处理文件列为取消。暂停或隐藏整个工作台也请求取消，回到面板保留结果，需要主动重扫才能继续。
3. 查看每项的文件编号/遮蔽路径、行列/偏移、规则和遮蔽说明。在自己的原文件中核对位置；面板不提供显示原值按钮，也不会自动打开任意本地路径。
4. 为每项选择“待审阅”“确认风险”或“人工标记误报”。误报须有简短原因，例如“这是练习占位符”；保存后原因遮蔽并保留，发现项不会被删除。修改审阅使旧导出预览失效，需重新预览。
5. 选择 JSON 或 Markdown 报告预览，先检查遮蔽报告和拟新文件名，再点击“导出当前预览副本”；实际目标路径在原生保存对话框中由用户确认。保存失败或取消均保留当前结果和预览。

目录选择使用 `webkitdirectory` 和 [File.webkitRelativePath](https://developer.mozilla.org/en-US/docs/Web/API/File/webkitRelativePath)，在 Electron 中依赖 Chromium/平台文件选择器；此处没有增加原生目录遍历接口。若所在版本或系统不支持目录按钮，使用多选文件，或先把待分享文本整理到可选择范围。不会递归读取符号链接或未经选择的磁盘位置；只检查 FileList 实际返回的文件。

## 使用后产出

本地结果列出 scanned、partial、unscanned、canceled，以及大小/总读取/结果限额、未知编码、疑似二进制、读取失败等原因；取消报告保留取消来源（用户、页面隐藏、工作台停用）。风险列表和 JSON/Markdown 包含同样的遮蔽位置与人工状态/原因，不包含原文行、原始完整值或未遮蔽路径。MD 对标记里的特殊符号转义。

只有扫描结束或取消完成后能生成完整报告预览。导出检查 `files.saveTextSupportsCopyOnly === true`，调用 `saveText({copyOnly:true})` 创建新副本、不覆盖已有文件。仅 `ok === true` 显示成功；`canceled`、已解决 Promise 的 `ok:false/error`、缺失成功标记或抛错分别处理，错误文字也遮蔽。旧文件接口会阻止导出并提示升级。保存对话框是最终路径确认步骤，不会假称渲染层提前获得了系统目标路径。

此模块不导出自动删除后的分享包，也不修改任何原文件。用户可依据报告在自己的文件中处理后，重新选择、重扫。结果不持久化到全局配置；切换具体功能、关闭应用、选择另一批文件或开始新扫描会丢失旧未导出结果。destroy 取消异步扫描、解绑可见性事件、清空选择和预览，并忽略迟到回调；File API 无法强制中断已经发出的单次 arrayBuffer 读取，因此取消在读取返回后生效，不再检测该内容。重新选择时也会等待此前取消的读取结束，避免叠加多个读取任务，旧进度不会覆盖新选择。

## 具体可重现例子、验证与限制

创建一个 UTF-8 `notes.txt`，内容如下（全是测试占位值）：

```text
intro
api_key = "DEMO_A1B2C3D4E5F6G7H"; phone=13800138000; harmless-context-text
```

选中该文件、启用三条规则、开始扫描，恰好发现两项：密钥在第 2 行第 12 列、offset 17；手机号在第 2 行第 41 列，offset 46、长度 11。这里 offset 是 UTF-16 代码单位。每项显示遮蔽值和“本行原文已全部隐藏”；JSON/MD 中找不到测试密钥、完整手机号或 `harmless-context-text`。将文件名或相对路径包含这两个占位值再扫描，导出仍不会包含完整值。

把 R001 标为误报但不填原因，会提示补充原因；填写“这是练习占位符”后保存，仍有两项发现，R001 保留 falsePositive 和原因。生成 JSON 或 Markdown 预览，取消保存后预览与结果保留。将第二个文件改为无效 UTF-8、UTF-16 BOM 或 `.bin`，覆盖表会列未扫描而不是“无风险”。扫描时取消，已有发现保留，未处理文件显示取消；读取中的文件返回后也不再产生发现。

专项验证：`node --test test/feature-T091.test.js`，覆盖两项定位、合并、规则开关、严格 UTF-8/BOM/Unicode位置、二进制/未知编码、文件/字节/结果限额、读取失败、File API 不支持、大小异常、文件间/读取中取消、路径含风险值、关闭密钥规则仍遮蔽路径及原因、误报原因与标记、MD 转义，以及实际选择/目录/规则/审阅/预览/导出/生命周期事件。另做模块导入、语法、暂存差异和提交后自有引用检查；不重复已知其他模块依赖缺失的全库检查。

事件测试使用 File/DOM/文件桥适配器，不能算作原生 Electron 文件/目录选择、平台兼容或系统副本落盘验证；这些由集成窗口验收补充。规则只覆盖明确描述的形态，不检查跨行秘密、经过编码/加密的值、证件信息、所有密码或压缩包内部；保守名称遮蔽也可能隐藏普通英文文件名。报告和人工标记是预检证据，不能证明最终资料安全。


主代理在实际Electron33.4.11中构造File/DataTransfer选择事件，扫描一个UTF-8样例、一个二进制PNG、一个坏UTF-8文件：发现2项、扫描1、未扫描2；位置分别[行2,列12,offset17,长度20]和[行2,列41,offset46,长度11]。手机号改为有原因的人工误报后预览并保存，JSON2207字节实际落盘且不含完整测试密钥、手机号和harmless-context-text。样例的webkitRelativePath是夹具元数据，包含两种敏感值的路径已遮蔽；未操作系统文件/目录选择器。隐藏测试窗口关闭后台节流以让Page Visibility呈可见状态，验证实际活动页流程。
