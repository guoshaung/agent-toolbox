# T079 摄像头麦克风权限说明台

## 1. 功能内容

选择摄像头或麦克风，只读查看系统公开权限状态、浏览器Permissions状态和当前可枚举设备条目，三个来源分别保留。给出对应系统设置位置但不打开设置。默认省略设备名称，用户可明确勾选披露可读取标签；始终省略deviceId/groupId。支持完整JSON/Markdown新副本，不申请授权、不创建音视频采集流。

## 2. 为什么需要

权限拒绝、设备不在可枚举范围以及正在被其他应用占用是不同问题。只读状态可以先说明哪些信息确实可读，避免为排查而主动开启摄像头或麦克风。API不支持、失败、超时一律未知；空列表不证明没有设备，空标签不证明拒绝，也不根据granted或条目数承诺可采集。

## 3. 实现方式

公共Host桥固定加载本功能host，仅支持read_status及camera/microphone字段，不接受requestPermission、screen或任意操作。Windows/macOS使用Electron `systemPreferences.getMediaAccessStatus`，保留not-determined/granted/denied/restricted/unknown。其他平台明确platform_api_unsupported/unknown，异常或非法返回也为unknown，不回显内部异常。没有调用askForMediaAccess、shell打开设置或系统改权限操作。

renderer使用 `navigator.permissions.query({name})` 只读状态，保留granted/denied/prompt；prompt表示查询状态，不是已经弹授权。支持性不同或失败时unknown。再调用 `navigator.mediaDevices.enumerateDevices`，仅筛选当前类型videoinput/audioinput，排除其他类型展示，不启动getUserMedia/getDisplayMedia。隐藏document不调用枚举，明确document_not_visible；每接口3秒，三来源最多9秒等待，取消或离开废弃结果，底层公开Promise没有取消句柄，晚返回被忽略。

枚举最多100返回条目，每标签≤512 UTF-8字节/合法Unicode；非法kind/标签或超限将整个枚举来源标未知、空entries，不截断成成功。保留其他可用来源，不把局部未知变成拒绝总判定。default/communications可能是同一设备别名，matchingReturnedEntries是条目数，不是物理硬件数。标签默认省略，labelAvailable仅表示浏览器返回标签非空；明确勾选后才把可用label加入报告，HTML经文本节点/JSON编码展示。deviceId/groupId不进入报告、DOM、配置或文件。

观察标记为system_api_reports_blocked、browser_query_reports_denied、prompt、空枚举或全空标签，但没有“总许可/总可用”状态。deviceBusy和deviceUsable始终unknown_not_tested，captureStarted和permissionRequested为false。系统路径只供阅读：Windows `ms-settings:privacy-webcam` / `ms-settings:privacy-microphone`，macOS System Settings→Privacy & Security→Camera/Microphone；Linux无统一入口。

依据 [Electron getMediaAccessStatus](https://www.electronjs.org/docs/latest/api/system-preferences#systempreferencesgetmediaaccessstatusmediatype-windows-macos)、[Permissions.query](https://developer.mozilla.org/en-US/docs/Web/API/Permissions/query)、[enumerateDevices](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/enumerateDevices)、[Microsoft设置URI](https://learn.microsoft.com/en-us/windows/apps/develop/launch/launch-settings)、[Apple摄像头设置](https://support.apple.com/en-gb/guide/mac-help/-mchlf6d108da/mac) 与 [麦克风设置](https://support.apple.com/en-gb/guide/mac-help/mchla1b1e1fe/mac)。浏览器枚举受当前权限/策略、文档活跃和可见状态影响；本工具不绕过这些规则。

输入类型、披露选项、权限结果和设备名称没有自动持久化。类型/选项改变清空旧报告；隐藏/切走/销毁取消等待并清空结果，返回不自动查询。原生另存期间锁定操作，仅ok===true成功；取消/失败保留完整预览。系统状态接口缺失仍可查询浏览器来源，但平台/设置路径未知，不猜测Windows。

## 4. 如何使用

1. 工具工作台打开 T079，选择摄像头或麦克风。页面不会自动查询。
2. 如确实要在共享报告中包含可用名称，明确勾选“在报告显示可读取的设备标签”；默认名称隐藏。
3. 点击“只读查询权限和可枚举设备”，分别查看systemPermission、browserPermission、enumeration和observations。没有授权弹窗或采集画面；不要把未知当拒绝、granted当可用或空条目当没硬件。
4. 按报告settings.path/uri自行查看系统设置，本功能不会打开或改变它。设备占用、真实声音/画面需要在另一个明确授权的应用中检查。
5. 预览完整JSON或Markdown，再“保存已预览报告新副本”。须公共saveTextSupportsCopyOnly=true，copyOnly:true独占新文件，已有目标拒绝，取消/失败/partialPath明确反馈。

## 5. 产出与具体例子

`media-permission-report-copy.json/.md` 完整包含设备类型、标签披露选择、平台、系统/浏览器状态、枚举条目、观察标签、系统设置路径、未测占用/采集说明。无设备ID/groupId，没有音频、照片或视频。Markdown含同一完整结构化JSON，路径/标签的反引号不会破坏围栏。

拒绝夹具：camera系统公开状态denied、浏览器query=prompt，同时enumerate返回一个label空的videoinput。预期systemPermission.state=denied、settings.uri=ms-settings:privacy-webcam；browserPermission.state=prompt，enumeration有一条labelAvailable=false但无label；observations包含系统blocked、浏览器prompt、空标签解释。不能推断没有摄像头或已经发出授权，captureStarted/permissionRequested均false。该拒绝例通过受控单测，不修改用户系统权限。

实际验收机器上，系统和浏览器camera/microphone均granted，摄像头返回1条、麦克风3条；报告照实保留来源和条目数，deviceUsable/deviceBusy仍未知。三个麦克风条目可能包含别名，不宣称安装了三套硬件。切换类型后旧结果立即消失，需手动重新查询。
