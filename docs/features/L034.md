# L034 图表证据辨识

## 1. 功能内容

用同一份两列 CSV 生成并排的用户纵轴图与包含零的参考图，支持单系列柱图和折线图、线性纵轴、自选比较基准与目标行。显示有符号差值、差值绝对值和百分变化，列出全部原始标签、原始数值文本及实际 Number，提示柱图非零基线造成的柱长截断。切换图形不会改变数据；改变输入会清空旧图表，需重新生成。

这是一项图表阅读训练：用户可以观察轴范围如何改变视觉差异，再回到真实数值。它不识别图片、不推断单位、不自动判定论文或作者误导，也不代替研究语境和原始证据核查。

## 2. 为什么需要

100 和 110 的实际差值是 10，百分变化为 10%。当柱图显示范围为 95–115 时，可见柱长对应 5 和 15，视觉柱高比为 3；包含零的参考图柱高比为 1.1。数据点都在图内，却可以形成明显不同的视觉印象。

柱长需要明确基线。折线主要表达数据点及变化，非零起点可能适合研究目的，因此折线的零轴视图只作参考，界面不会据此自动认定误导。负值基准还会影响百分公式的符号；本功能明确公式而不暗自改变分母。

## 3. 实现方式与模型

`model.mjs` 提供严格 CSV 解析、轴校验、比较公式、几何坐标、SVG 和报告生成；`index.js` 负责实际输入、事件、提示与生产文件桥接，不执行用户代码。`meta.json` 由功能工作台发现，样式采用项目实际主题变量。没有网络、摄像头、定时器、后台动画或图像分析。

- CSV 表头必须恰为 `label,value`，支持 LF/CRLF、首字节 BOM、双引号字段与 `""` 转义，包括标签内逗号；拒绝引号内换行、空行、多列、闭引号后的空格和未引号字段内的引号。允许一个末尾换行，不自动 trim 字段。1–100 条数据，CSV ≤16384 UTF-8 字节；空白标签、控制符和孤立代理项不允许。标签长度为 1–40 Unicode 码点，重复标签按行索引区分。
- 数值及轴端点是最多 32 字符的普通十进制或科学计数法，指数最多三位，须为有限 JS Number 且绝对值 ≤10亿；拒绝 NaN、Infinity 以及非零输入下溢为零。小数采用 IEEE754 双精度，并非精确十进制。摘要和刻度最多八位有效数字，完整报告保留 CSV 原文、原始 value 文本和实际 Number。
- 用户轴必须最小值小于最大值并包含全部数据；生成五个严格递增的 Number 刻度，过窄范围拒绝。不会裁切数据或静默截断。参考轴范围为 `[min(0,数据最小值), max(0,数据最大值)]`，全零时使用 0–1。
- 柱图实际基线为零。零在用户轴外时，可见柱基线夹到最近的边界：正值轴取 min，负值轴取 max，明确提示柱长截断但数据点未裁切；零在轴内则显示零线。折线连接原始行顺序，零基线只供参考；横轴等间距且不自动将标签解释为时间或数值。
- 选择任意两个 0 起行索引，计算 `Δ=b-a`、`|Δ|=abs(b-a)`、百分变化 `(b-a)/a*100`。基准零时百分未定义；计算无法以有限 Number 表示时也明确未定义，不保存数值 Infinity。负基准保留分母符号，例如 −100→−90 得 Δ=10、百分=−10%，不会自动解释成增长率；同一行比较为零。
- 单个 SVG 为 640×420，两图完整对照 SVG 为 1280×480，无脚本和外部资源。所有数据点保留；超过12行不逐点标值，横轴抽样标签截为10码点，完整数据仍在表格及导出中。标签、单位和 metadata 做 XML 转义；单位由用户声明，长度最多40码点。
- 配置 `features.L034.state` 使用 `schemaVersion:1`，仅保存七个输入字符串，不保存图表或统计。写入及恢复先验证整个 JSON 的 UTF-8 体积 ≤64KiB，再校验字段限额；失败提示当前草稿未保存、关闭只能恢复较早草稿并建议导出。切走保存草稿；销毁清除图像与 DOM，异步导出完成后不更新已销毁界面。

## 4. 使用步骤与可复现例子

1. 在功能工作台打开“图表证据辨识”，或点“载入95轴示例”。输入如下，用户轴 min=95、max=115，选择柱图，比较基准索引0、目标索引1，点击“生成轴对照”。

   ```csv
   label,value
   基期,100
   本期,110
   ```

   预期 Δ=10、|Δ|=10、百分变化=10%；提示“柱图非零基线”，用户图可见柱从95起，参考图从0起且范围0–110。图高255像素：用户柱高63.75/191.25，比值3；参考柱高约231.81818/255，比值1.1。

2. 切换“图表类型”为折线图，旧结果清空，CSV保持相同；重新生成后看到相同两组数据点，提示零基线仅参考、折线并非必须从零开始。
3. 点“载入负值示例”并生成：−100/−90，用户轴−115至−80，可见柱从−80起，参考轴−100至0；Δ=10，百分=−10%，提示负基准公式语义。点“载入零基准示例”得到0/10，百分显示未定义。
4. 可自行编辑 CSV、单位和任意比较行。例如 `"项目,甲",100` 是合法带逗号标签，单位填写“人”；将 min 改为105后生成会拒绝，因为100不在用户轴内，并清空旧图，不裁切。包含引号内换行的标签会明确拒绝。
5. 生成后导出 JSON、Markdown 或对照 SVG；未生成时仍可导出草稿 JSON/Markdown，SVG需有效结果。修改输入后必须重新生成，恢复草稿也需重新生成。

## 5. 产出与保存

JSON 包含 feature、schemaVersion、modelVersion、导出时间、完整草稿和完整结果；结果含全部 series、用户轴和参考轴及刻度、图形类型、单位、比较行、差值、百分有效性和全部提示。Markdown 使用安全动态代码围栏承载完整草稿与结果，不依赖页面当前显示条数。

对照 SVG 可作为独立图片查看，含两张带坐标、网格、标签和基线说明的图以及差值/百分摘要；XML `<metadata>` 保存完整结果，包含全部100行时也不截断。图片视图横轴标签抽样，原值保留在元素 title 与完整 metadata；需要完整 CSV 草稿和导出时间时使用 JSON/Markdown。

所有导出先检查 `saveTextSupportsCopyOnly===true`，请求 `copyOnly:true`，仅返回 `ok===true` 才显示成功；取消保留当前内容。生产写入器使用 `wx`，已存在目标拒绝覆盖。文件对话框和写入错误有明确提示，不把未确认写入当成功。自动配置仅输入草稿，结果需重算；文件报告是完整新副本。
