# T008 数据字段字典生成

## 1. 功能与交付内容

读取CSV表格或JSON对象数组，对每个顶层字段统计样本数、实际类型分布、缺失/null/空字符串计数、合并空值率、混合类型提示、非空示例及数值/字符串/布尔值域。用户可逐字段填写业务含义、单位、来源等人工说明，并保存JSON或Markdown字典副本。

页面支持UTF-8文件导入、粘贴/编辑数据、明确格式、分页字段表、真实说明文本框和完整字段详情。全部统计使用本地完整已加载样本；不上传、不依赖API、不推断数据库约束、不把样本结果当作总体分布。首版不展开嵌套对象/数组，不计算日期域、分位数或自定义类型转换；结构化值作为object/array单元格统计并提供示例。

## 2. 为什么需要及已有能力关系

共享导出表格时，列名往往缺少业务解释，接收者无法判断单位、空值比例和允许取值。单靠观察前几行容易遗漏稀少类型及缺失值。本功能把可验证的样本统计和用户人工说明放在同一份字典中，既展示观察结果，也保留解释来源。

现有webtools主要提供网页入口；本功能为断网也可用的原生本地统计与副本导出。它与T003对账不同：不比较两批数据或建立业务身份。catalog中待选的表格依赖由本功能独立严格解析器完成，没有添加npm包或依赖其他功能的运行时代码。

## 3. 实现方式及边界

`meta.json`沿用工具/文本与结构化数据分组。`index.js`使用现有h()创建界面，create同步返回activate/deactivate/destroy。`parser.mjs`复制自本代理T003严格解析实现（提交`980d2df9`），在本功能独立保存并增加数值精度验证，不import未合并的T003；`model.mjs`负责字段统计、编辑说明和有界导出。

CSV使用严格引号状态机，保留引号内逗号、换行、转义引号、空格及起始物理行；第一行是唯一非空标题，不自动改名或修剪。JSON使用有界异步递归解析，顶层必须是对象记录数组，保留记录起始物理行，拒绝重复属性、尾逗号、注释、非JSON值、非有限数字及不安全整数。

额外比较输入数字和`String(Number(...))`的规范化十进制含义，例如1.2300和1.23相同、1e2和100相同；`1.00000000000000001`、`0.100000000000000005`或`1e-999`转成Number后含义改变，会明确拒绝。允许0.1等最短十进制可往返值；这不承诺二进制浮点能精确表示0.1，也不做浮点加减运算。-0与0按相同十进制值处理，大编号/高精度小数需用字符串保存，不偷偷舍入后再统计。

对字段使用类型计数、数值Set、字符串频次Map及最多3个非空示例。值域和频次使用全量输入，输出字符串频次前10个并标明是否省略其余值；去重数仍准确。对象/数组不枚举内部取值域。JSON字段按名称排序，CSV字段沿用标题顺序。只统计输入中观察到的顶层字段并集，不虚构完全未出现的schema字段。

解析、字段扫描及逐字段导出定期让出事件循环并检查AbortSignal。切走/销毁会取消当前操作；输入或来源/格式变化废弃旧统计和说明；说明编辑更新当前字典，统计无需重新解析。每页10字段，分页前后保留当前说明。切换到另一个功能会销毁面板并丢失未保存内容，不写入全局配置。没有后台常驻、任意JS执行或新增公共IPC。

读取采用可取消FileReader及fatal UTF-8解码，非法编码或大小错误不替换当前输入。独立保留文件原始文本，避免textarea显示时规范化CRLF影响长度/示例；用户手动编辑后使用文本框值。导出通过实际`window.toolbox.files.saveText({content,extension,defaultName,copyOnly:true})`，先确认`saveTextSupportsCopyOnly===true`；缺能力时禁用导出。基础排他写入拒绝已有目标，包括原文件，用户在原生对话框核对新路径。系统保存对话框打开后用其取消按钮关闭；面板取消负责生成阶段。

## 4. 如何使用与透明统计口径

1. 点击内置10行示例，或导入UTF-8文件/粘贴CSV或JSON对象数组，核对来源名称及明确格式。
2. 点击“生成字段字典”，查看样本分母、每类空值、类型分布、值域及混合提示。
3. 在每行“人工字段说明”文本框填写业务含义，使用翻页继续编辑其他字段。点击“完整值域与统计”查看未截断统计与当前说明。
4. 核对样本口径及说明后保存JSON或Markdown副本，并在保存对话框确认新文件名。取消另存不会报成功，已有文件不会被覆盖。

| 统计项 | 明确口径 |
|---|---|
| 分母 | 解析成功的全部数据记录；CSV不含标题，实际空物理行计入，末尾换行不生成虚构记录 |
| 缺失 | JSON该记录没有该字段；CSV列齐全，字段不存在通常为0 |
| null | JSON字段存在且值为null；CSV文本`null`是字符串 |
| 空字符串 | 字段存在且值严格等于`""`，CSV引号空值和空单元格属于此类 |
| 空值率 | `(missing + null + emptyString) / sampleCount`，三类互斥；10行2空为20%；0行时rate=null，显示不适用 |
| 非空 | 纯空白字符串、0、false、空对象和空数组均不算空；不自动trim或规范化 |
| 类型分布 | missing、null、string、number、boolean、object、array分别计数，合计等于每字段样本数 |
| 混合提示 | 排除missing/null后实际类型超过1种；空字符串仍是string，数字加空字符串会提示混合。提示不是自动判定业务数据错误 |
| CSV类型 | 所有单元格均为字符串，不推断数字、日期或布尔值；CSV`01`保持`"01"` |
| 数值域 | 仅number观测值的最小、最大、数量、去重数；null不会被当作0；没有数值时min/max为null |
| 字符串域 | 含空字符串的数量、去重数、UTF-16长度范围及UTF-16编码单元字典序边界；非地区排序；频次前10个，同频按字典序 |
| 示例 | 源记录顺序最多3个不同非空值，保留类型和来源名称/记录序号/物理起始行；不表示完整枚举 |

文件开头一个UTF-8 BOM作为格式标记去除；其他字符不隐式清洗。标题名称大小写和空格保持原样。字段路径以顶层JSON Pointer表示，名称中的`/`→`~1`、`~`→`~0`。字段说明不参与统计值域。

## 5. 使用后产出与可执行例子

点击“载入10行20%空值示例”得到10条JSON记录：id为1至10，前8条score依次10、20、…、80，后2条score为null。点击“生成字段字典”，定位score字段：

- 样本分母10；number=8、null=2，其余类型0。
- missing=0、null=2、emptyString=0，合计2，rate=0.2，界面显示20%。
- 无混合类型；数值域min=10、max=80、distinctCount=8。
- 示例10/20/30，均有scores.json的记录序号及物理行。

在score的说明框填写“测试成绩，单位：分”，保存JSON及Markdown副本，两者均包含这句人工说明和上述统计口径。

另一份可直接粘贴的JSON：

```json
[{}, {"x":null}, {"x":""}, {"x":" "}, {"x":0}, {"x":false}, {"x":{}}, {"x":[]}]
```

x的分母8，missing/null/emptyString各1，合并空值率37.5%。string=2，number/boolean/object/array各1，混合提示为是。空白字符串的长度为1，0和false属于非空值。

CSV例：标题value，8条数字文本、1条`""`和1条实际空行，得到10条string、2条空字符串、空值率20%，数值数量仍为0。JSON对象换属性顺序不会改变类型/值域统计，但示例来源始终沿用记录顺序。

JSON导出包含feature=T008、version=1、来源、样本数、字段数、basis口径及字段统计/人工说明。Markdown为可阅读字典，保留相同统计、值域、来源示例和口径。用户内容作文本转义，HTML、Markdown链接/标题等不会被当作输入指令执行；界面使用文本节点。长预览会截断，完整详情及导出不截断值；超出导出上限时明确失败，不生成部分文档。
