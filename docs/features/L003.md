# L003 反例边界工坊

## 1. 功能内容

手填1–10个布尔条件、2–64个正/反样本和全部真/假标注。工具展示每条件在两类样本中的真/假覆盖人数，从少到多枚举条件子集，输出该最小层的全部区分组合及条件向量对应样本；完全相同却标签相反的样本单独列冲突。

## 2. 为什么需要

背会定义仍可能不知道哪些条件真正区分正例和反例。手动对比样本可发现冗余条件、互相冲突的标签和缺少区分力的描述；全部最小方案比只挑一个条件更便于判断。工具帮助检查人工归纳，不能把有限样本结果当作一般概念定义。

## 3. 实现方式

“区分”定义为所选布尔条件的值向量不会同时对应正例和反例，允许正例具有多种向量；不是要求所选条件全部为真。每一正/反样本对记录其不同条件的位掩码，子集必须命中每一对的差异位。按组合基数从1递增，同层全部枚举，发现最小层后停止更大子集；最多10条件，有限搜索空间最多1023非空子集。输出同层全部最小组合，而非贪心取第一个。

若任一相反标签样本在全部条件上相同，则任意子集都无法区分，直接列出这些冲突对，不伪造最小组合。至少各有一个正/反例，所有值必须明确为boolean；新增未填项不默认false，阻止枚举并指出样本。ID唯一且有限，样本及列增删保持矩阵对齐，任何修改清除旧结论。

纯模型不执行用户代码，UI动态矩阵支持编辑/增删。完整有效标注可显式保存版本1草稿；恢复输入后重新计算，旧报告的最小数与组合不受信任。暂停阻止操作，销毁清理面板；不上传、不使用AI、不自动造题。

## 4. 如何使用与具体例子

1. 搜索L003并载入“四样本 C2 示例”：P1=[真,真,假]、P2=[假,真,假]为正例，N1=[真,假,假]、N2=[假,假,假]为反例。
2. 点击枚举，最小条件数1、仅组合C2。向量1对应P1/P2正例、向量0对应N1/N2反例；C1混在两类中，C3全假，不能单独区分。
3. 把N1的C2改为真再枚举：P1/N1所有条件相同但标签相反，报告无法区分。需核对人工标签或增加真正不同的条件，而不是继续拿旧C2结论。
4. 添加条件时全部新值显示未填，补齐每个样本后才能再算；增加正/反样本可能改变此前的最小组合。
5. 保存版本草稿或另存JSON/Markdown新副本；恢复面板可粘贴草稿/报告，重新枚举。

另一例四向量00/11为正、01/10为反，两条件一起才能区分；这说明组合不是“条件全部为真”的合取定义。

## 5. 使用产出

JSON含版本、完整条件/样本矩阵、两类样本数、条件覆盖表、冲突对、最小条件数、全部最小组合、每组合的向量/标签/样本分组、实际检查子集数和范围声明。Markdown含最小组合、分组、冲突和完整输入，可依据原矩阵复核覆盖表。

草稿仅存完整有效标注，保存/恢复限64KiB UTF-8，超限不截断。JSON/Markdown导出只用copyOnly=true，明确ok=true才报成功，已有目标拒绝覆盖，取消保留结果，最终路径由原生另存选择。全局配置不自动保存结果，关闭前需自行保存或导出。
