# T005 清单集合运算

## 功能内容

本地读取两份逐行清单，按用户选定的比较规则生成交集、并集、A−B、B−A、对称差集及数量。集合结果去重，但独立保留每个重复值的原始行、原文和来源。支持显式粘贴与 UTF-8 文本文件导入、分页预览、当前集合 TXT 副本和完整 JSON 对账副本。

## 为什么需要

核对名单、已处理编号、文件清单或权限列表时，手工比较容易漏掉重复和空白差异。一个“交集结果”也无法解释大小写或全角字符为什么合并。本功能同时提供规则、结果和来源证据，便于确认真正新增、移除或重复的内容。

## 实现方式

`model.mjs` 使用 Map 以字符串为键，记录每次出现的物理行号和原文，避免将 `__proto__` 等值误作对象属性。规则顺序固定为 NFKC、首尾空白、连续空白、小写；每项都可单独选择，默认只去首尾空白及忽略空白行。比较采用 Unicode 字符串相等及标准小写转换，不做模糊匹配、地区语言排序或拼音合并。

五类运算保持 A 首次出现顺序，需要追加的 B 值保持 B 首次出现顺序。默认集合有序只是为了结果稳定，不代表数值排序。空文件是零行；最后的换行是终止符，多出来的空白行仍有物理行号。关掉“忽略空白行”可保留空字符串这个真实集合元素。JSON 原文中的控制字符以 JSON 转义保存。

UI 使用项目现有 `h()` 和 textContent 安全展示，结果每页最多 100 项，重复值每份预览前 20 个。文件使用 UTF-8 严格解码，读取完成有版本令牌防止旧导入覆盖新编辑或切换后的界面；不修改源文件或配置。

## 如何使用

1. 打开“功能工作台”，搜索 T005 或“清单集合运算”。
2. 将每个完整值单独一行粘贴到清单 A、B，或分别导入文本文件。CSV/TSV 文件也按整行处理，不会解析字段列。
3. 核对五项比较规则；需要区分首尾空白时取消默认修剪。
4. 点击“计算五种集合”，查看总数量和重复来源。
5. 选择结果集合，分页查看；输入或规则改变后重新计算。
6. 导出当前集合 TXT 或包含全部运算与来源的 JSON，选择新的文件路径。防覆盖接口拒绝写入已有目标。

## 使用后产出

当前集合 TXT：每个规范化值一行，空集导出空文件。JSON：格式版本、功能 ID、具体规则、A/B 输入统计、忽略行号、重复值原始出现、五类结果和计数、全部值的 A/B 原文及行号、当前选中运算。JSON 可用于审计，但首版不提供报告重新导入。

## 具体例子

点击“载入甲乙丙示例”，A 为“甲、乙、乙”三行，B 为“乙、丙”两行。交集仅乙；并集甲、乙、丙；仅 A 有甲；仅 B 有丙；对称差集甲、丙。A 有 2 个不同值和 1 个重复行，乙的来源准确列出 A 第 2、3 行与 B 第 1 行。

另一个例子：A 为“ Ａ  B ”和“A b”，B 为“a b”。默认交集为空；勾选 NFKC、连续空白合并和忽略大小写后，交集为“a b”，A 的两个原文仍完整保留，不会把两个来源静默删除。

## 验证和限制

`node --test test/feature-T005.test.js` 覆盖精确样例、五类集合、默认与可选规范化、重复原文与行号、BOM/混合换行、空值与终止符、稳定顺序、特殊键名、UTF-8/行数/字符上限及非法规则。

每份最多 2 MiB UTF-8、20000 行，每行最多 2000 UTF-16 字符。没有跨会话草稿、模糊去重、CSV 列解析、排序或后台剪贴板读取。规范化会改变结果值，必须核对规则；JSON 包含输入原文，导出前请自行决定是否可以分享。宿主渲染、实际 IPC 和文件写入验证记录另行补充。
