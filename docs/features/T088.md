# T088 行李重量预算

## 功能内容

手动录入包限重、空包自重、物品单件重量与数量，将同一物品的数量分配到不同包。逐包显示物品重、总重、超重/余量、装包清单，并单独保留未分配物品。可导出完整预算JSON、从本工具版本1报告恢复草案。

## 为什么需要

旅行前常需要把一部分东西从一个包挪到另一个包，直接加减容易忘记空包重量或某件物品已被移走却没有最终归属。透明数量分配与未分配清单帮助使用者核对草案是否完整，不因为某个包降到限重以内就把全部物品误称为安排完毕。

## 实现方式

独立纯模型统一为整数克：g只允许整数，kg最多3位小数，按十进制直接转克，不用浮点相加。逐物品计算单件克×分配数量，计入指定包，空包自重只算一次。超过所拥有数量、未知包、重复包/物品ID或非法重量都整批拒绝；未分配数=拥有数−各包分配之和。

限制1–10包、0–100种物品，每种数量1–10000，重量/限重/自重≤100,000,000克；最坏总和仍在安全整数范围。包限重与单件重须>0，自重可0。包名和物品名1–80字符，ID最多40字符。表格名称用文本节点，无HTML插入。所有输入只在面板内存，JSON保存输入与计算规则。

超重=max(0,总重−限重)，余量=max(0,限重−总重)。只有所有物品已分配且所有包未超重才标记完整满足手填重量规则。没有自动装箱优化，不读取实时航空限制、不订票，不判断尺寸或其他运输规则。删除包的分配回到未分配；删除物品表示使用者从清单移除这类物品。

## 如何使用

1. 打开T088，为每个包填写名称、限重及空包自重，选择g或kg。可添加最多10包。
2. 为物品填名称、单件重量、拥有数量，分别填分到各包的数量。数量可分到多个包，但合计不超过拥有数。
3. 点击“核对重量预算”，检查逐包超重/余量与装包草案，阅读未分配清单。
4. 改动分配后重新核对；输入改变立即废弃旧结果与导出能力。点击“导出行李预算 JSON”保存到新路径，已有文件不能覆盖，取消不报成功。
5. 下次打开可展开恢复区，粘贴本工具的JSON报告并“恢复预算草案”；只恢复经过完整模型校验的inputs并重算，不信任旧计算结果。恢复失败保留原草案。

旧版无copyOnly保护接口时禁用导出。切换功能会丢失当前未导出的内容。

## 使用后产出

逐包整数克预算、kg显示、超重/余量、按数量的装包清单与未分配明细。JSON包含inputs、rules、bags、items、unassignedGrams、overweightBags、complete；未分配并非丢弃，仍有原始来源行与重量。此输出是手动分包草案与用户输入的重量约束核对。

## 具体例子

点击“载入7kg限重示例”：随身包限重7kg、自重0，装6kg主物品与2kg可移走物品各1件，总重8kg，超重1kg。

点击“示例移走2kg”：可移走物品分到此包的数量改0，包总重6kg、余量1kg；报告仍列未分配物品1件/2kg，complete=false。给它另建限重够用的包、分配1件后，再核对，才可成为完整未超重草案。

## 验证与边界

7项测试覆盖7/8kg验收与移走后保留未分配、空包自重与跨包数量拆分、超额/未知包/负数/非法单位拒绝、0.001kg=1g、空物品时空包超重、恰好限重与输入副本、重复ID与数量上限。手填或测量重量可能有误；工具仅按给定数据确定性计算。
