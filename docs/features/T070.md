# T070 局域网访问地址自检

## 1. 功能内容

输入一个本地 TCP 端口和可选手机 IPv4/CIDR 网段，读取本机网卡、地址、路由及该端口监听快照，列出所有非回环单播 IPv4 候选 HTTP/HTTPS 文字地址、监听范围、子网关系、路由表区间关系和人工排查建议。没有连接手机、扫网、抓包、HTTP探针或进程管理，也不修改系统网络、服务绑定和防火墙。远端实际可达性始终是“待手机实际验证”。

支持 Windows 的固定系统 PowerShell 查询；非 Windows 或系统不在支持的固定路径时，分组明确 unknown，不能把未知当作未监听。未实现离线快照 JSON 导入，不把模拟数据或用户填写网卡伪装成 live 证据。

## 2. 为什么需要

电脑服务可能仅绑定 127.0.0.1，也可能存在 Wi-Fi、虚拟交换机、隧道等多地址，手机填错候选地址或不同网段容易造成误判。本工具提供本机可观察证据和准确限制：127.0.0.1 仅监听说明“未直接监听局域网地址”，不能推断手机一定不可达，因为未检查其他转发/代理/服务。IPv4通配监听也不能保证防火墙、Wi-Fi隔离、手机返程路由和服务协议正确。

## 3. 实现方式与支持范围

生产 `features.callHost` 加载固定 `host.cjs`，只允许 plan/inspect；用户端口在 Node 中严格校验为整数 1–65535、网段为有限 IPv4/CIDR。用户输入不会插入脚本、命令行或环境变量。plan 仅返回范围，零 OS 查询；inspect 才启动一个固定只读子进程。窗口同一 sender 同时一任务，首 await 前登记；早到的取消意图也会保留，随后同 ID 零子进程输出 canceled/unknown。窗口最多128个任务编号/取消意图、最多32sender；达到限额明确拒绝，关闭窗口释放。取消、隐藏、切走和销毁停止本查询子进程并隔离晚结果，期限最多15秒；不结束用户服务或其他进程。

固定执行 `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`，`shell:false`、`-NoProfile/-NonInteractive/-NoLogo/-EncodedCommand`、隐藏窗口。脚本内容固定；子进程 PSModulePath 仅 `C:\Windows\System32\WindowsPowerShell\v1.0\Modules`，禁自动加载，显式导入该绝对目录下系统 Microsoft.PowerShell.Utility/CimCmdlets/NetTCPIP/NetAdapter 模块，未使用用户 profile 或第三方模块目录。只运行 `Get-NetAdapter -IncludeHidden`、`Get-NetIPAddress`、`Get-NetRoute`、`Get-NetTCPConnection -State Listen`；只读取当前本机 session，没有远程 CimSession。Node 离线过滤目标端口，不传手机地址给任何网络查询。

输出 UTF-8 严格解码、256KiB（stdout+stderr）总预算，网卡128、地址256、路由1024、监听1024；固定管道读取上限+1 检查超限，整组 unknown，不输出部分列表冒充完整。组失败/权限/模块缺失及容量均有组状态，不能精准确认失败权限原因时保留 `QUERY_FAILED_OR_LIMIT`；进程超时、启动失败、异常编码等保留明确固定错误码，不回显错误上下文、内部路径、进程名、MAC或用户名。不自动提权或重试。OS原始查询内部枚举开销不承诺被行预算提前终止；15秒进程与输出预算限制用户等待和IPC产物。快照跨数个读取操作，非原子，有起止 UTC/单调耗时，查询结束后系统状态可能变化。

Wi-Fi 仅依据 `InterfaceType=71` 或 `NdisPhysicalMedium=1/9`；证据字段随记录输出。名称含 Wi-Fi/VPN、不在这些字段支持域，不能确定类别；虚拟、PPP、隧道字段仅列线索，VPN用途状态一律未知，需要用户核对实际连接。已有 VPN 可能也是普通以太网字段，工具不会根据品牌名排除其地址。网卡名和本机IP会进入报告，分享前核对；输入/结果不写config，无自动草稿。

IPv4 用无符号整数区间与 2^(32-prefix) 掩码计算，不使用字符串前缀。支持 /0–/32、/31、/32、负号/前导零/越界拒绝；手机 CIDR 主机位归一为网络地址，显示规范网段。分别报告电脑地址是否在手机范围、两个网段是否有交集、范围是否完全相同；不同掩码不能当相同子网。路由只列与手机范围相交及覆盖完整范围/部分交集，不计算最佳选路（未合并接口 metric/策略路由）、不证明手机返程。IPv6地址/路由和监听只保留证据；手机IPv6网段、作用域候选 URL、双栈不可推断。`::` 通配监听明确 IPv4 支持 unknown，不能当 `0.0.0.0`；具体 IPv6 监听的作用域不进一步推断，也不能推出 IPv4 监听。

## 4. 如何使用

打开工作台 T070，输入服务本地 TCP 端口，例如3000。在手机网络设置手工核对 IPv4/CIDR（例192.168.1.0/24）后填写，或留空仅查看本机范围。点击“校验输入与只读范围”：这一步零系统查询、零网络。核对固定查询与限制，点击“读取本机信息并自检”。本机只读操作不另加网络授权勾选。查看实际监听记录及组状态，优先核对 Wi-Fi 字段证据与手机网段；候选 URL 只是文字，实际 HTTP/HTTPS 协议未测试，需手机自己打开服务协议对应的地址。

同一功能重复检查需再次校验范围，输入编辑会废弃旧计划、报告和预览；清除释放源和结果内存。隐藏或切走取消当前查询且不自动恢复，已保存副本无法撤回。分组 unknown 时核对系统模块/权限/时间，不能据此说服务未监听。候选网卡状态不是 Up 或地址不是 Preferred 会附提示；所有已取得地址仍在源快照中，IPv4链路本地地址单独提示作用域限制。

## 5. 使用后产出

界面显示完整组状态与源快照、所有候选和路由关系，没有只留首几条的截断。JSON/MD 保存完整报告（≤2MiB），超过预算阻止且不导出部分文本。先点“预览完整 JSON/MD 报告”，再“保存已预览报告新副本”。生产文本写入器强制 `copyOnly:true`、独占新建，已有目标拒绝而原件不变。仅 `ok===true` 报成功；canceled/false/undefined/throw 保留预览并分别提示取消/失败。宿主缺能力时拒绝保存。产物是本机证据和建议，不是手机可达性、防火墙允许、最佳路由或服务协议测试证书。

## 6. 具体例子、验证与限制

开发夹具启动一个仅 `127.0.0.1` 绑定的 TCP 服务，例如端口3000。填写3000和192.168.1.0/24，自检后 listenerAnalysis.scope=`loopback_only_not_direct_lan`，说明未直接监听LAN；仍列本机非回环候选及其 `no_direct_ipv4_listener_observed`，手机实际可达待验证。换成夹具绑定0.0.0.0，会报告IPv4通配监听，但不声称手机能访问。绑定`::`（即使夹具自身启用双栈），产品只报`ipv6_wildcard_ipv4_unknown`，因为本工具没有测或读取该socket的双栈选项。

离线可重放数值例：电脑192.168.1.200/25，手机192.168.1.0/24，电脑地址在手机范围、网段有交集、范围不相同，电脑网段规范为192.168.1.128/25。手机改192.168.10.0/24时不相交，不能因“192.168.1”字符串前缀把二者判同网段。默认路由0.0.0.0/0覆盖手机范围、192.168.1.128/25仅部分交集，二者均只是路由表证据。手机::/64明确拒绝，源输入编辑后旧报告不存在。
