# E026 真心话大冒险

## 功能内容

内置 50 道原创日常问题和 50 个原创轻松小挑战。问题围绕食物、周末、爱好、旅行、小物件与创意；挑战主要是说一句话、编一个小故事、坐着比划或在空中画图，不要求摄像头、麦克风、联网、付费、接触他人或实际进食。任何人可以直接跳过，不需要解释，完成、跳过、移除和未处理均为零惩罚，没有分数或排名。

支持 2–12 位玩家，按名单顺序或按局号随机循环轮换；每个随机循环让每人轮到一次，循环交界避免同一人连续出场。可选择真心话、小挑战或两类混合。一局 1–100 轮，卡片不重复，达到轮数、卡片耗尽或主动结束均产出完整记录。完成、跳过、移除当前卡都会单步进入下一张，不需要反复点“下一题”。

## 为什么需要

聚会临时想话题容易重复，也容易忘记哪些题不适合当前参与者。此功能提供可直接使用的轻松内容、随手跳过、即时移除和清晰轮流顺序，既可完成一场短聚会，也可以只用几轮话题让大家休息。记录只说明发生过哪些行动，不把参与程度变成比赛。

## 实现方式

`cards.mjs` 保存原创文本；`model.mjs` 验证题库与设置并实现纯状态机。卡片先按种子洗牌，抽到后即从候选队列取走；完成、跳过和移除分别记录。已删除卡号集合在当前局一直有效，恢复下一局内置题库不会恢复当前局已删除或消耗的卡。真心话、小挑战筛选在创建局时完成，不能跨类抽取。随机卡片和随机玩家使用独立种子流，保证同样题库、选项、局号重放一致。

状态为 ready → active → finished，暂停是保留底层状态的开关。当前卡操作校验局代号、轮次、卡号和状态，双击及旧按钮不会消费新卡；主动结束当前卡会记录为“结束时未处理”，不会暗算作完成或跳过。UI 使用已有 `h()` 作为文本渲染，样式仅作用本模块；不执行导入文本，也不运行用户代码。

当前题库、下一局设置和当前局有明确边界：建立新局时拍摄题库及设置快照；新增、整库导入、恢复内置题库仅改变下一局。删除某卡号会立即从当前局未抽候选池排除，同时从下一局题库删除。编辑区禁止删除当前卡，需回到局内用“移除此卡，下一张”，这样归属和操作会写入当前局。题库编辑自动暂停，关闭编辑后需手动继续；工作台停用、窗口失焦和页面隐藏也会暂停。无定时器或媒体资源，destroy 解绑事件并清空局、卡片、草稿和本地引用。

## 如何使用

1. 玩家框每行一位，2–12 人，每个名字 1–20 字且规范化后不同。选择类别、顺序/随机、轮数和局号，再点“建立新局”。只有点击“开始抽卡”才显示第一张。
2. 轮到的玩家可回应话题、完成轻松动作，或直接跳过。点击“完成，下一张”“跳过，下一张”或“移除此卡，下一张”自动记录并轮换。跳过不用输入理由；任何参与者都可操作这些按钮。
3. 可随时暂停；恢复要手动点击“继续”。若想提前结算，点“结束本局”，当前卡标为未处理。
4. “编辑题库”可添加一张自定义卡（自动生成不与现有或最近删除卡冲突的 C 编号），或逐张删除。当前卡删除按钮禁用，返回局内处理即可。“恢复内置 100 张卡”只影响下一局。
5. JSON 导入替换下一局整个题库；通过校验后清空草稿，当前局继续使用旧快照。关闭编辑也会清空草稿。编辑区和结算区均提供题库副本导出，结算区提供完整报告副本导出。

题库 JSON 必须为 version 数字 1、cards 数组，仅接受这两个字段。每张卡只含 id/kind/prompt；1–200 张卡，id 1–32 位字母、数字、_ 或 - 且唯一；kind 为 truth/dare；prompt 1–240 字的非空单行文本，规范化去空白后不可重复。草稿最多 65536 字符；错误会给出明确提示，保留草稿和当前局，方便修正。自定义内容由使用者确定，结构校验不判断它是否适合参与者。

```json
{"version":1,"cards":[{"id":"MY001","kind":"truth","prompt":"你喜欢哪一种水果？"},{"id":"MY002","kind":"dare","prompt":"用手在空中画一个圆。"}]}
```

只真心话筛选在上述题库中只会抽 MY001；若指定 3 轮，它处理一次后会以“可用卡片已抽完”结束。全选类别没有可用卡片时禁止新建局并说明原因。题库删空后需添加卡片或恢复内置题库，不能导出一个无法重新导入的空题库。

## 使用后产出

结算屏提供每位玩家的完成、跳过、移除、未处理数量，全部惩罚为 0；逐轮记录包含轮次、玩家、卡号、类别、原文和行动。本局移除列表区分“当前卡移除”与“题库编辑删除”。完整 JSON 还包含局号、筛选、轮换设置、结束原因及建立本局前最近最多 200 张题库删除记录；当前局移除记录不会漏掉当前局快照内的卡片。

题库导出为可再次导入的 `{version:1,cards:[...]}`。两类导出均先检查 `files.saveTextSupportsCopyOnly === true`，再使用 `saveText({copyOnly:true})` 创建新 JSON 副本；老接口会阻止保存并说明需要升级，取消保存明确显示取消，既有文件不会被覆盖。

全局配置仅保存最近 10 局小摘要（选项、日期、结束原因、完成/跳过/移除总数），不保存大题库、逐轮原文或草稿。保存失败不妨碍当前内存报告导出。题库、未导出局和报告只在本功能内存存在；切换具体功能、退出应用或新建一局会丢失，离开前可导出。

## 具体可重现例子、验证与限制

从完整内置题库开始；若之前删过卡，先在编辑区恢复内置 100 张卡。玩家为小明、小红，选择“真心话”“按名单顺序”、3 轮、局号 `demo`，建立新局后开始抽卡：

1. 第 1 轮，小明，T013：“如果只能带一本书去度假，你想带哪本？”点“完成，下一张”。
2. 第 2 轮，小红，T002：“如果今天多出一小时空闲，你想做什么？”点“跳过，下一张”，不需要解释，也不扣分。
3. 第 3 轮，小明，T023：“你会选择窗边、靠墙还是中间的座位？”点“移除此卡，下一张”。本局达到设定轮数后结算；小明完成 1、移除 1，小红跳过 1，所有惩罚 0；报告保留三种行动，题库副本剩 99 张，没有 T023。

删除验收：恢复内置题库并按同样设置建立新局，在点击“开始抽卡”前编辑删除 T013，关闭编辑、点击继续、再开始，首张变为 T002；T013 记入本局“题库编辑删除”列表，后续不会抽中。仅真心话验收先恢复内置题库，再将轮数改为 100，处理全部卡后只有 50 条 truth 记录，以耗尽结束，没有 dare 卡。随机玩家可设置三人、随机循环、至少六轮；每三轮各出现一次，跨循环不连续轮到同一人。

验证：`node --test test/feature-E026.test.js` 覆盖 100 卡唯一性、导入字段/大小/类别/非空限制、设置边界、三类筛选、不重复与耗尽、种子复现、随机玩家循环、零惩罚、当前/未抽删除、暂停、旧按钮、主动结束、有限历史；DOM 事件测试覆盖实际按钮处理函数、题库编辑边界、文本安全、隐藏/失焦/工作台生命周期、草稿上限、copyOnly、取消和保存失败。另做语法、暂存差异及提交后的自有模块/样式引用检查。
