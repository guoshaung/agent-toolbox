# L055 迁移距离证据表

## 1. 功能内容

以一个原任务和一个新任务为单位，记录人工拟观察的能力维度，分别填写表面、结构、情境变化的「改变／相同／未知」及说明，再把成果原文的精确片段绑定到三个维度。结果显示三维变化矩阵、当前绑定覆盖、待补维度、来源空项及旧锚失效原因。

三维的分母固定为 3。覆盖只计算当前版本中有效的字面绑定，既不衡量迁移距离，也不判断成果质量、语义匹配、学习效果或能力已经迁移。变化标记为未知时仍可人工绑定成果：这种绑定增加字面覆盖，但未知标记独立保留，并不证明该变化存在。没有自动生成题目、AI 判分或来源核真；离线人工操作即可完成 MVP。

## 2. 为什么需要

会做原任务并不能单凭一个比例证明会处理新任务。这个表把用户声称的变化、拟观察能力、原／新任务来源及成果证据放在同一处，帮助发现「说到了结构变化，却没有绑定成果」这样的记录缺口。来源没有填写时明确标未知，旧证据失效时保留原句和来源，避免输入改动后仍显示先前覆盖。

这些记录供人工复核，不能替代真实迁移研究、独立评估或证据真实性核查。即使覆盖为 3/3，也不会输出「迁移已证实」。

## 3. 实现方式与边界

`model.mjs` 提供严格 schemaVersion 1 输入校验、三个固定维度、纯绑定规则及完整报告。`index.js` 提供真实任务表单、成果编辑、选区／数字位置确认、结果矩阵、报告预览和副本导出。文本均经文本节点渲染，Markdown 中 HTML 字符转义，围栏随内容调整；不执行用户代码，不联网。

成果最多 8 份，每份原文最多 6,000 Unicode 码点；名称最多 160 码点，来源位置最多 320，任务描述最多 2,000，能力维度最多 400，变化说明最多 600。修订号为 1–1,000,000。完整输入最多 256 KiB，超限整份拒绝，不截取后继续分析。每个完整 JSON／Markdown 报告最多 2 MiB，超限不导出。成果引用 ID 不与仍由旧锚引用的已删除 ID 重用。

位置使用原文 UTF-16 半开区间 `[start,end)`，不是码点或字节下标。绑定需非空、不能只有空白，片段最多 240 Unicode 码点，不允许拆开 emoji 的代理对。实际文本框选区会把 CRLF／CR 规范化后的换行位置映射回原文；原文仍完整保留。数字区间必须由用户明确确认，编辑区间或选成果并不会自动建立证据。

每个锚保存任务对修订号、变化行修订号、成果修订号、精确原句、原位置、成果名称和来源快照。任务、能力或任务来源修改使所有旧锚失效；某变化行修改只使该行失效；成果文字、名称或来源修改使引用它的旧锚失效。删除成果后旧锚仍显示旧原句及来源。版本、字面原句或来源快照不符均视为待补，不自动漂移位置或重绑定。

全局配置只保存经校验的输入草稿及已确认锚，不保存派生报告或未确认数字区间。完整 UTF-8 草稿超过 64 KiB 时不写配置，界面明确提示导出完整报告；关闭后只能恢复较早的合法草稿，不能承诺恢复这次大型输入。恢复检查版本和容量。保存队列隔离旧票据；编辑、取消、隐藏、离开及销毁都废弃迟到结果，返回页面不自动分析。没有音频、相机或网络资源。

## 4. 使用步骤

1. 打开功能，填写原任务、新任务及各自人工来源，填写拟观察能力。
2. 为三个维度选改变／相同／未知，写出自己的变化说明；空项保留未知。
3. 编辑成果名称、人工来源及原文。可添加至最多 8 份；删除或整体换示例前需确认。
4. 在成果文本框实际选中片段，点击对应维度的选区绑定按钮；也可选成果并填写 UTF-16 起点、终点，再明确确认区间。未确认区间会阻止分析，不会写入恢复草稿。
5. 点击「分析三维绑定覆盖」，查看矩阵、待补及来源未知。输入或标注变化后旧结果清除，需要重新分析。
6. 在完整预览中核对来源与旧锚，导出 JSON 或 Markdown 新副本。使用生产保存桥的 `copyOnly:true`，仅 `ok===true` 才提示成功；已有目标拒绝覆盖，取消不算成功。

对失效证据需要人工重新阅读并选择当前片段；重新绑定只确认当前字面关联，不确认它能支持能力迁移。

## 5. 产出与可复现例子

默认原任务为单页缓存，新任务为跨页缓存并含网络中断情境。E001 原文「页面样式不同，复用前仍检查缓存期限。」的 `[0,6)` 绑定表面，原句是「页面样式不同」；E002 原文「网络中断时标记缓存状态，恢复后再次核验。」的 `[0,6)` 绑定情境，原句是「网络中断时标」。结构没有绑定。点击分析后覆盖恰为 **2/3**，待补恰为 **结构**。片段文字由用户选取，工具不推断它是不是充分论据。

在 E001 实际选取 `[7,12)`，原句「复用前仍检」，点击「用成果选区绑定结构维度」，再分析变为 **3/3**。随后在 E001 开头插入「前」，表面与结构旧锚均失效，情境仍当前，因此是 **1/3**；结构旧锚仍保留 `[7,12)` 和「复用前仍检」，不会自动移至 `[8,13)`。只有明确重新选择并绑定当前 `[8,13)` 才恢复该行。

将情境标记改为未知后重新人工绑定，可以出现绑定覆盖已包含情境且未知变化列表仍有情境；两项含义独立。清空原任务来源时来源字段显示未知，不伪造文献。删除 E001 后旧锚及旧来源完整保留，新成果使用新 ID，不能冒充被删除的成果。

完整 JSON 包含全部任务、能力、成果原文、人工来源、标记、版本化锚、三行状态、待补维度、未知项和计数定义。完整 Markdown 包含同一报告的安全 JSON 内容。报告可能包含用户输入的全部作品和来源，不是脱敏或只摘要版本。没有派生结论自动回填草稿，也没有导入报告自动认证来源的功能。
