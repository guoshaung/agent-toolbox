# E011 像素画编辑器

## 1. 功能与必要性

16×16或32×32逐格画头像、小图标和色块。提供铅笔、橡皮、正交连通填充、取色、左右/上下/双轴镜像、整笔撤销、调色板、颜色控件与自定义HEX、键盘及坐标输入替代，自动保存可恢复的完整像素工程。原尺寸透明PNG用于其他软件，JSON工程用于继续修改，Markdown用于核对每格数据。无需大型绘图软件或图片模型，全部由本项目Canvas代码绘制，没有imagegen、外部素材、网络或设备授权。

颜色范围明确为完全不透明RGB（`#RRGGBB`）及完全透明（`null`），不支持半透明笔刷。这样每格RGB和alpha可在PNG中字节准确核对，也避免把Canvas半透明通道量化说成无损还原。两种尺寸就是设计要求，没有人为缩小输入到少量可用格子；32盘全部1024格均可画、保存、恢复和导出。

## 2. 工具规则与事务

左上坐标(0,0)，x向右、y向下，范围0至15或31。铅笔写当前色，橡皮写null，取色读当前单格：非透明色设为当前色并转铅笔，透明转橡皮但保留当前色。调色板可点，也可用原生颜色控件或输入合法`#RRGGBB`；大写输入归一为小写，颜色名、短HEX和带alpha的8位HEX拒绝。

拖笔用PointerEvent单个primary指针和pointer capture，按经过的格子画线；采样间用整数Bresenham连接，避免快速拖动留下间隙。同一笔重复经过格子只记录第一次旧色，松开后整笔作为一次撤销事务提交。第二触点/另一pointer ID不能混入；移出画布、外部落点、按钮松开、pointercancel、失去捕获、Escape、隐藏/离开/销毁均回滚未提交整笔，不夹到边缘假装成功。释放捕获并清除旧节点监听后，旧pointerup不会修改下一模块。

左右镜像沿竖直中线：`x→n−1−x`；上下镜像沿水平中线：`y→n−1−y`；双轴同时取四个组合。目标格集合去重，即使一笔经过某格及其反射格也只存一份旧色/写一次相同色，不翻转颜色。16/32都是偶数尺寸，中线在两格之间；任意反射重合和重复触点仍由集合/事务Map去重。例16盘(0,0)双轴对应索引0、15、240、255；(7,7)对应(7,7)/(8,7)/(7,8)/(8,8)。

填充先复制**原始像素**，找种子原颜色的四正交连通区域，再对这个区域的结果施加镜像；不沿新填颜色继续找区域，不含对角、不绕行。镜像后的目标允许原色不同，这是“把已找到的区域反射作画”，不是再次对反射种子串填。一次填充为一事务，最多1024格，可一次撤销。没有改变的动作不占撤销记录。会话最多最近100个实际改变事务，超出时最旧滚动移出并提示；最大100×1024=102400个旧值差分，有界内存。撤销只恢复像素，不撤销工具/颜色切换。

## 3. 实现与严格工程恢复

`meta/index/model`独立目录，分类娱乐/创作与音乐玩具，符合create/activate/deactivate/destroy契约。屏幕Canvas显示棋盘透明底、格线、焦点框和放大像素，属于预览，不进入作品PNG；PNG使用全像素RGBA的ImageData直接写16/32原尺寸Canvas，不缩放、不插值、不带文字/网格。没有RAF、刷新interval或自动绘画；仅用户事件触发有限重绘，返回不会接续旧笔画。

自动保存键 `featureLab.E011.project`。schema1只包含 `schema,size,pixels,tool,ink,mirror`，pixels完整256或1024项，行优先，值是规范小写6位HEX或null。源档≤64KiB UTF-8，完整1024色格远低于限额，不保存生成SVG、预览缓存或外部图像。调色、工具和镜像也保存。撤销历史与焦点只属当前会话；**重载、导入和新建后撤销栈为空**，作品全部像素/工具设置保留。这一规则在UI和Markdown明确说明，没有把保存当前画面说成保存全部编辑历史。

严格恢复拒绝未知版本/字段/尺寸、数量不足或超出、稀疏/非法像素、非规范HEX/8位alpha、无效工具/镜像/当前色、重复JSON键、非安全整数词法和深度超过8。文件声明和实际大小都检查≤64KiB，严格UTF-8。导入先完整验证并显示尺寸/已画数量，额外勾选确认才替换；错误或未来版本不自动覆盖旧配置，需明确清空或合法导入。

第一次activate保存空工程，创建不启动资源。整笔/填充/撤销和设置改动自动保存；未松开笔画不写配置。保存待回时锁画布和设置，失败显示临时状态、允许重试/副本另存。离开时取消笔画后保存已提交作品，待保存情况下会再次保存当前冻结源档。强关、崩溃或断电不能保证尚未完成IPC，可使用已确认另存的工程备份恢复。销毁移除所有监听、释放capture、清空DOM和临时/当前Canvas像素；不会删除用户已另存的副本。

## 4. 使用与可复现例子

工作台→娱乐→创作与音乐玩具→像素画编辑器。默认16盘全透明，当前色`#e4583f`、铅笔、无镜像。坐标都从0起：在(1,1)按下，横拖到(3,1)松开，得到第二行第2至4列三格红色；统计已画3/256、透明253、撤销1/100。一按撤销即撤掉整笔三格，不是一格一格撤。重画并另存透明PNG，应是16×16，仅这三格RGBA为(228,88,63,255)，其他253格为(0,0,0,0)。自动保存后实际重载每格一致，撤销显示0/100。

Canvas可Tab聚焦，方向键移动单格且边界不绕行，空格/Enter执行当前工具，repeat不连画，Escape取消未提交笔画。也可在x/y输入框填0起整数后点“在坐标格执行工具”；越界/空值拒绝，不改变作品或焦点。画完(3,1)后按Down/Space会在(3,2)画当前色，撤销能只退这一键盘事务。橡皮点(2,1)变透明，撤销恢复；取色点红格转红铅笔，取透明转橡皮。

镜像例：16盘选双轴，点(0,0)，四角各写一格；撤销一次全部恢复。填充例：画一道封闭边框，选连通填充并点内部，只填内部同色连通区域，外部透明不动；撤销一次恢复整次填充。要新建32盘/清空当前盘，选择尺寸、勾“确认放弃当前作品”，点新建；未确认不会丢画。

原生32盘实际作品例：红铅笔从(4,4)→(27,4)→(27,27)→(4,27)→(4,4)画闭框，92格；用`#2b8a78`填(16,16)，填内部484格。取红边后选`#f5c557`、左右镜像，在(10,10)点一格，再Down/Space补一格，得到两侧各2格黄眼。橡皮仍左右镜像点(15,20)，擦出两格透明口。最终574不透明/450透明，JSON记录工具eraser、mirror horizontal、当前黄颜色；原PNG32×32，屏幕预览只是放大显示。

## 5. 产出与安全副本

JSON保存完整当前作品与工具设置，可再次导入修改。Markdown列出全部256/1024格0起坐标、颜色或透明，并内嵌完整源JSON；不是只输出非透明格的摘要。PNG只包含原尺寸像素，不含屏幕棋盘底、焦点、网格或UI文字；完全透明像素RGB为0/alpha0，不透明alpha255。普通查看器可能把透明背景显示黑色/白色，但文件RGBA已核验。无放大PNG/图片导入/图层/半透明模式。

导出检查文本或二进制安全副本能力；旧应用缺能力按钮禁用并显示升级提示，当前编辑/本地保存仍可用。所有请求 `copyOnly:true`，PNG≤10MiB、规范Base64与SHA-256，生产写入器独占wx创建，已有文件不覆盖；成功仅接受`ok===true`。取消不报成功，错误和partialPath需人工核对明确提示。拖笔过程中导出控件锁定，先松开提交或取消再另存。保存待回也锁改动；离开/新源状态使generation变化，迟来的旧保存/导出回调不能恢复旧UI或替换当前作品。编码完成或销毁清除临时Canvas像素及引用。
