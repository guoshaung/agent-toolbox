# T045 录音静音片段裁剪

## 1. 功能与支持范围

读取一份本机录音，完整波形标出候选静音，用户逐段取消不想剪掉的候选，再生成真实的保留区间拼接 WAV。成品可手动试听，核对实际时长和采用区间后保存到新目录；目录包含成片与完整 JSON 报告。另可保存分析阶段或结果阶段的 JSON 新副本。没有联网、录制、麦克风权限、自动上传或自动播放。

首版是 Windows 本地可信 FFmpeg/FFprobe **6.x 外部安装**的有限处理域。一份文件≤128MiB，实际 PCM 时长1毫秒至600秒；16bit 有符号小端 PCM WAV，单/双声道，采样率为8000、11025、12000、16000、22050、24000、32000、44100、48000、88200、96000Hz。支持严格的16/18字节fmt和有限40字节PCM16 extensible头（有效位等于容器位、规范PCM GUID、mono mask0/4或stereo mask0/3）。RIFF声明大小须等于实际文件，恰好一个fmt/data、整帧数据、至多1024chunk；RF64、多data、压缩/MP3/M4A、8/24/32bit整数、float、非标准结构明确拒绝，**不会替用户偷偷转换**。有此需求可自行产生符合上述范围的PCM16 WAV再选择。界面和报告列明本域。

静音阈值−90至−6dBFS，最短停顿100至30000整毫秒。候选最多100段，超过即拒绝完整分析，不截掉其余候选。波形覆盖全部录音，最多1000等时段峰值列；横轴从0到实际结束。每段勾选拟删除为红色，取消勾选保留为蓝色。无候选时可输出全部录音；全部删除导致空成片时禁止生成。更改阈值/最短时长废弃旧分析和成品，更改候选废弃旧成品而保留分析。

## 2. 为什么需要

会议录音、旁白练习、口述笔记常有长停顿。自动阈值裁剪会把弱声、尾音或环境音误认为静音，直接输出难以追查。因此本功能让用户先看整份波形和逐段精确范围、试听源，再主动决定采用哪些候选。报告同时保留删除与排除候选、所有保留区间、实际输出帧数和源/成品哈希，可以复核8秒成片是如何从10秒源得到的。

阈值仅是逐采样**绝对幅度**，不是LUFS、语义语音检测或噪声判断；用户需根据素材选择，不承诺自动识别每个有意义的声音。拼接不隐式增加淡入淡出或修饰，也不承诺消除接缝点击声。

## 3. 实现方式与安全边界

`model.mjs` 包含本ID私有RIFF解析、PCM候选扫描、选择映射和固定FFmpeg参数生成。RIFF/有限Host基础从T044私有复制后适配；没有跨feature运行时引用或新依赖。按照 Microsoft [RIFF chunk说明](https://learn.microsoft.com/en-us/windows/win32/xaudio2/resource-interchange-file-format--riff-) 计算chunk大小/偶数字节填充，并按 [WAVEFORMATEX](https://learn.microsoft.com/en-us/windows/win32/api/mmreg/ns-mmreg-waveformatex) 核验整帧对齐、声道/位深与字节率。本域更严格的限制属于本功能选择，不声称所有合法WAV都支持。

扫描每个交错PCM帧，取所有声道绝对采样值最大值；只有每个声道同时低于阈值才连续计数。阈值对应 `floor(10^(dBFS/20)*32768+1e-9)` 最大允许整数样本；1e-9样本只是浮点指数边界数值容差，不是音频时长容差。默认−50dBFS对应103/32768，超过即有声。最短帧数为 `ceil(毫秒*采样率/1000)`；有声单帧会中断，不跨越它合并低幅段。候选和采用区间均为**左闭右开采样帧** `[startFrame,endFrame)`，帧包括所有声道；毫秒/六位小数秒仅为展示，不拿显示舍入值剪辑。波形每列是该时段全帧/全部声道的最大绝对值，不能用于辨认每一采样的细节。

`host.cjs` 才持有原生对话框选中的路径/源SHA/身份、可信运行时和结果令牌。renderer不能提供任意路径、命令或filter文本。固定查询版本/atrim/asetpts/concat/asplit/pcm_s16le能力。真正剪辑采用数字帧生成的 `asplit→atrim=start_sample/end_sample→asetpts→concat`，单区间不需concat；采样率、声道、PCM16保持原值，没有gain/fade/resample。官方 [atrim文档](https://ffmpeg.org/ffmpeg-filters.html#atrim) 区分按采样计数和按时间戳裁剪；[concat文档](https://ffmpeg.org/ffmpeg-filters.html#concat) 要求各片段时间戳从0开始。这里使用帧计数、重置时间戳、只有一条音频流。输出后重新核验RIFF/FFprobe一致与精确期望帧数，**逐块比较成片全部PCM字节与源所有保留区间**；任何字节不一致整体失败，不发布可保存结果。

所有源/结果读取与复制前后检查文件身份及SHA-256。拒绝链接、junction、UNC、URL、NFC/保留名字/遍历等不支持路径，仅规范Windows本地盘符。源不写入；元数据不复制到成品，报告不声称全面照片/音频隐私清理。可信本机程序仍由用户自己选择并确认，不是下载或鉴定第三方exe的沙箱。

每个扫描/哈希/PCM核对最多262144字节一块，异步I/O与扫描块后让出事件循环；不在renderer持有大型源。分析/生成单作业180秒总截止，查询/FFprobe5秒、剪辑60秒；输出轮询与FFmpeg `-fs` 限制128MiB，日志128KiB，报告256KiB。16 sender、每sender512唯一job、最多4个子进程；超过需重新开窗口。shell=false、windowsHide、系统路径有限env、stdin忽略、强制WAV/file协议，线程2/filter线程1，没有用户代码或网络入口。

取消请求杀子进程，但**观察close前仍忙**，5秒关闭宽限不声称已立即退出；若未关闭明确pending。取消扫描/哈希在下一块守卫生效。临时结果仅自己创建的`T045-*`目录/`trimmed-01.wav`，15分钟过期；陌生条目/身份改变保守拒绝删除，给`TEMP_CLEANUP_FAILED/partialPath`人工核对。离开、隐藏、销毁停止播放器、移除src、取消作业和清空本批，回来不续播、不续处理；不把音频、波形、项目写配置。不提供跨模块草稿恢复。

保存走本ID**可信Host原生新目录**：mkdir独占、WAV `COPYFILE_EXCL`、报告`wx`并核对副本哈希。已有目录拒绝；正常失败只清理本次拥有的目录，身份/陌生文件改变时保留并返回partialPath，不伪称断电事务。此路线与FFmpeg暂存路径同属可信Host，能保存超过公共bundle单文件2MiB/总10MiB的有限WAV；不把大音频塞公共bundle/binary或配置。独立报告另存检查公共`saveTextSupportsCopyOnly===true`并传`copyOnly:true`，只有`ok===true`成功，取消/字符串true/失败不成功。

## 4. 如何使用

1. 查看默认运行时查询计划，或选择自己信任的FFmpeg 6.x目录。默认是`C:\ruanjian\ffmpeg\bin`，目录须有固定`ffmpeg.exe`和`ffprobe.exe`；核对路径后确认查询。
2. 选择一份本机PCM16 WAV。来源区显示原名、字节数、SHA；可先用原录音播放器试听，没有自动播放。
3. 选择幅度阈值和最短停顿，例如−50dBFS/500ms，点击“确认分析完整波形与静音候选”。完整波形和每段起止秒/时长/帧显示后，核对候选。
4. 默认所有候选勾选拟删除。逐段取消勾选可完整保留该候选；查看预计采用的帧区间与预计时长。取消只是**排除该候选**，不会删除它，更改候选后旧成品立即失效。
5. 点击“按当前选择生成实际裁剪预览”。只有实际生成且全部保留字节校验通过才有成品播放器。源与成片可分别手动试听；HTML媒体元数据时长与实际时长相符后，勾选手动核对并确认。
6. 点击保存，原生对话框输入一个**不存在的新目录名**。核对目标再保存，目录内含WAV/报告。不要选回原目录或已有目录。另存JSON仅保存报告，不包含音频。按“取消当前作业”会清空本批并等关闭；按清空或离开也清掉本批，想继续须重新选择。

## 5. 使用后的产出

`trimmed-01.wav`：当前所有保留区间按源顺序实际拼接的PCM16成片。没勾选任何候选时完整保留声音；如果源只有规范44字节头无其他元数据，本例完整保留的WAV甚至与源SHA完全一致，但不保证所有含元数据源的整个文件逐字节一致，只强制保留PCM一致。

`trim-report.json`：version1、源原名/字节/SHA/结构、运行时版本、阈值整数口径/最短帧数、**完整候选和完整波形峰值列**、removeIds、删除/排除候选、所有保留区间、期望/实际输出帧数/时长/字节/SHA、全PCM比对数量、源未变、无淡入淡出说明，以及目标目录/副本确认与非崩溃事务边界。报告总≤256KiB，超限整体拒绝，不静默删行。另存报告是同内容JSON副本，可在分析阶段保存候选计划；它不是可导入的音频工程，不含源或成片样本。
