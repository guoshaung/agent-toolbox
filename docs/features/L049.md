# L049 口头陈述彩排

## 1. 功能内容

学习工作台「语言与表达训练」中的本地页级彩排。用户编辑1–20页标题/提纲、各页整数秒预算、来源名/出处和人工备注，总预算从所有页面求和。用户可以直接开始仅计时，也可以主动点击「开始计时并请求麦克风录音」，通过浏览器getUserMedia请求仅音频、创建MediaRecorder。无后台请求麦克风、无转写/识别、无内容评分。

计时中手动切页，逐次记录页面访问、活动计时起止和该时段采集起止；同页点击不添加虚假访问，回访同页按完整访问列表累加。暂停或结束封存时段，完整报告显示总实际/超时、各页实际/超时/是否访问、全部访问和播放标记。页按钮定位该页第一次可验证采集时段，定位后暂停，另按手动播放；没有有效录音的页明确未知。

录音实际编码格式检测WebM/Opus与OGG/Opus能力，按MediaRecorder真实mimeType命名导出。整份录音通过AudioContext实际解码验证后才可回放/导出；原始WebM/OGG字节和完整JSON/Markdown分别保存防覆盖新副本，音频不是报告内塞入的Base64大段。报告预览包含全部提纲/来源/时段/媒体元数据，不存录音字节到全局配置。

## 2. 为什么需要

演讲超时往往发生在部分页面，而总时长不能说明哪些页需要调整。页级预算、手动切页时段和录音回放标记让用户复查自己在哪些页花了时间，按当时实际采集段听回自己的表达。

本功能新增的是彩排行为测量和页级录音定位，区别于PPT编辑、讲稿备注、语音转写或自动表达评分。计时、采集事件时间、真实解码音频长度各自独立；不会把计时150秒但实际采集约2秒的录音标为150秒，也不把暂停后的无录音时段拼接成假连续音频。软件成功事件不证明设备/人耳正常或陈述准确。

## 3. 实现方式

### 权限、CSP与主动录音

先读取生产`src/main/main.js`既有media许可处理：主窗口自身请求允许，外部窗口默认拒绝；仍可能受到系统权限、设备缺失或浏览器运行时限制。功能只在用户直接点录音按钮后调用`navigator.mediaDevices.getUserMedia({audio:{channelCount:1},video:false})`，不增加额外应用确认步骤。浏览器或OS可能提示许可；生产Electron自己的主窗口media handler可能直接允许应用请求，不能承诺一定出现OS对话框。

标准依据是[W3C Media Capture and Streams](https://www.w3.org/TR/mediacapture-streams/)的getUserMedia/MediaStreamTrack和[MediaStream Recording工作草案](https://www.w3.org/TR/mediastream-recording/)的能力检测、录音事件、完整数据收集及stop。`isTypeSupported`选择候选格式，目标码率64000bit/s，实际容器以recorder.mimeType为准；能力声明不保证编码成功。权限拒绝、无音频轨、构造/启动失败自动降为仅计时，录音状态明确失败/未知，不声称已听过或设备正常。

生产renderer CSP为`media-src 'self' data:`，没有blob许可。因此播放使用data音频；不修改共享CSP。原录音完整字节保留用于binary导出，回放另使用实际解码样本生成的完整PCM16 WAV，以提供有限可验证HTMLAudioElement时长（MediaRecorder WebM元数据可能没有有限duration）。回放转码只在内存，导出的原始录音不转码/裁剪/拼接。

### 两个时钟与页时段

计时默认使用performance.now单调毫秒，暂停间隙不计入累计；ctx.clockNow只是独立测试钟注入点，普通UI不能设置/加速时钟。每次切页封存旧访问，打开新访问。页实际秒数为该页全部访问时长之和，总预算为各页预算之和，总超时`max(0,实际−预算)`，每页超时单独同式计算；未访问页实际0并标未访问，不推断讲述过。

采集start事件之后才开始同步计时。采集偏移另用真实performance.now从录音start事件起算，与活动计时累计分开。页切换记录当时采集经过秒数；没有活跃采集时为null。原始采集偏移不按计时总长或解码总长缩放。报告首次播放标记必须非负且小于实际解码长度，否则未知；时段末播放边界最多到真实音频结束，并保留原始事件偏移供核对，不制造不存在的声音。

播放依据[W3C Web Audio的decodeAudioData](https://www.w3.org/TR/webaudio/#dom-baseaudiocontext-decodeaudiodata)实际解码，采样率16000Hz、1–2声道。PCM16回放样本逐帧量化（幅值按[-1,1]饱和，是回放转换而非无损音频处理），播放duration=完整解码帧数/采样率，与解码轴一致；播放时刻由HTMLAudioElement.currentTime定位。编码器启动/封装延迟未独立测量，标记是浏览器事件对应的近似位置，不保证声学或样本级同步。定位只暂停定位，不自播；播放成功/playing是软件证据，不证明人实际听到。

### 暂停、离开、取消与容量

暂停会停止计时interval、MediaRecorder并停止所有tracks，收齐最终dataavailable/stop后验证完整录音，期间禁止导出部分报告/音频。继续必须手动点击，仅继续计时，不重新请求设备；新访问音频位置null，先前封存音频可保留。要连续录音需明确新开一轮；不会把多次采集自动合并。

隐藏/切走停止计时/所有tracks/MediaRecorder，取消请求/解码/回放准备并关闭context，未完成媒体释放为未知，已经封存音频可在当前实例保留。页面可见/功能激活只重建控件，不自动采集、计时或播放。取消getUserMedia不能撤回OS提示，但迟到返回的每条track立即停止，不启动录音/计时。旧start/error/stop/解码结果按捕获票据及对象所有权隔离，不能停止或盖掉新一轮；销毁移除visibility监听、清interval/watchdog/seek等待、播放器及引用。

每页预算0–300整数秒，总预算1–300；页标题非空≤120码点、提纲≤2000、来源名≤160/出处≤320、备注≤500。最多100次访问，下一访问整项拒绝，可结束保留前100次。计时/采集达到300秒发停止请求；事件排队可能产生延迟，记录观察值，不静默截为恰300秒。原始计时>600秒安全域整轮报告拒绝，实际解码>301秒、录音>8MiB、非法格式/声道/非有限样本均整份音频拒绝，不用截断音频假成功。大于8MiB的数据块会立即停止真实设备轨，保留计时并标录音失败。

解码最多9,632,000个跨声道样本（301秒×16000Hz×2），回放PCM16字节≤19,264,044。WAV生成每16384帧让出检查取消，Base64每262144字节让出；SHA-256和解码异步。临时context最终关闭，原始录音、回放data及有限报告驻留当前实例内存，不能无限录制。

### 草稿和安全产出

schemaVersion=1输入草稿整体UTF-8 JSON≤64KiB，恢复也校验版本/结构/容量。配置仅来源、页提纲/预算和备注，不保存录音字节、媒体元数据、计时、结果。写入一个在途加最新待写快照串行排队，过期成功不盖掉非法预算/容量警告；大提纲保持界面但不能开始或写配置，只能恢复较早合法提纲，不自动丢页面。

本轮开始后提纲锁定，避免一份录音被静默归到改过的页面；新一轮会丢旧媒体/时段，需明确确认或保留本轮，提纲保留供编辑。重载只恢复提纲，已丢的本轮和音频不会伪称恢复，必须关闭前结束并导出。

JSON/MD各≤512KiB，完整预览含所有页面/访问、原始时段和录音hash/MIME/解码时间。文本saveText与二进制saveBinary分别严格检查桥接copyOnly能力=true、传copyOnly:true、仅ok===true声称成功。音频binary含规范base64+SHA256、实际WebM/OGG文件名，由生产feature-binary writer校验并wx写新目标；桥上限10MiB，本功能8MiB更小。失败/取消保留报告/音频；不覆盖既有文件，不改来源。

## 4. 使用步骤

1. 打开L049，编辑各页标题/提纲和整数秒预算，填写来源与备注；核对总预算≤300秒。
2. 选择仅计时，或直接主动点请求麦克风录音。许可/能力失败会显示仅计时与录音未知；录音start事件前等待期间可取消请求。
3. 按页面按钮手动切页。需要暂停时按暂停计时并停止录音，等待完整封存/解码；若继续，仅计时且后续时段无录音。
4. 结束本轮后查看总/页级预算、实际、超时及全部访问。点击某页首次录音按钮只定位并暂停，再按手动播放/暂停；未知页不能定位。
5. 预览JSON/Markdown，分别导出完整报告与完整原始录音新副本。二者分开管理，可凭报告SHA256/MIME匹配音频。
6. 如需改提纲或再录一轮，先导出，点新一轮并明确确认清除媒体/时段；提纲保留，下一轮仍需手动开始。窗口重载不会恢复录音。

## 5. 产出与可复现例子

默认P1「问题与背景」预算60秒，P2「方法与结论」预算60秒，总120。计时开始后60秒切到P2，150秒结束：P1实际60/超0，P2实际90/超30，总实际150/超30。完整连续录音时第2页起点是对应采集事件经过秒数（约60秒，受编码/事件延迟影响），点击定位P2在实际解码轴对应位置暂停。

独立模型oracle从1000ms开始、61000ms切P2、151000ms结束，采集起点0/60/150秒，得预算120、实际150、超30，P2首次播放60秒。另一个时钟分离oracle保持计时同样150秒，但采集切P2=.75秒、结束2秒、实际解码2.1秒，P2播放标记为.75，不缩成60或放大成150。实际解码只有.5秒时该页标记未知，不越界定位。

暂停算例：开始后10秒暂停、90秒时手动继续、95秒切P2、100秒结束，活动实际20秒，P1累计15、P2为5，80秒暂停间隙不算。初段已封存10秒音频，后续两访问captureStart=null；P2音频未知，不指向旧录音末尾。未访问页仍列0并标未访问。

原始音频新副本使用实际MIME扩展名；JSON/MD包含两页或全部20页完整提纲、所有100次以内访问、来源、计时/采集/播放起止、报告状态/停止原因和媒体SHA/原始字节数/解码时长。报告不含录音Base64，不伪造转写或评分。
