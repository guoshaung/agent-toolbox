# T039 SVG 交付安全检查

## 1. 功能内容

离线读取1–8份本地UTF-8 SVG，或一份粘贴SVG，解析并逐项报告脚本、事件属性、图片/引用、CSS、外来命名空间及未支持元素/属性。按固定静态几何规则和可选“允许静态文本”规则生成全新副本；提供完整风险记录、净化源码和实际图片预览，确认预览后导出新目录。

首版固定规则保留svg根、g/path/rect/circle/ellipse/line/polyline/polygon，用户可明确选择保留text/tspan/title/desc。移除所有script、事件、href/src、CSS、image、use、渐变、滤镜、动画、foreignObject及其他元素；被移除子树的后代不会重新插入输出。复杂SVG可能显著改变视觉，所有改动进入完整记录；不是所有SVG的通用安全认证或无损转换。

## 2. 为什么需要

SVG不仅是绘图路径，也能包含脚本、事件与外部资源。用户交付第三方素材前需要知道这些内容在哪里，并得到不带上述主动内容的限定静态副本。检查只作文字/XML处理，源SVG从不被插入活动DOM；用户看的是重新建立的限定副本，避免为了检查先加载原始主动内容。

保留完整来源名、原字节摘要和输出摘要，使交付副本与输入能对应；净化后必须人工复核视觉，不能把删除复杂效果后的文件称为绘制完全等价。

## 3. 实现方式与规则边界

`model.mjs`先拒绝DTD/ENTITY与非XML声明处理指令，再用生产 `DOMParser(...,'image/svg+xml')` 解析独立XML文档。仅接受SVG命名空间根；检查Mozilla与Chromium/XHTML parsererror，异常或非法XML整组失败，不导出部分结果。创建全新SVG Document及全部新节点，逐节点按允许规则复制；不将原文树mount、import或innerHTML装入活动页面。

属性为具体有限规则：几何数值有限且绝对值≤1,000,000；长度相关r/rx/ry/width/height/stroke-width/font-size非负，透明度0–1；颜色为有限常用名称或#RGB/#RGBA/#RRGGBB/#RRGGBBAA；fill-rule、线端/线连接、text-anchor为有限枚举。d/points只保留有界几何数字/命令词元，最多1000词元；transform仅translate/scale/rotate/matrix/skewX/skewY、指定参数个数、最多16个变换。不是完整SVG路径语法验收或外观保证；几何无效值可能不能绘制，应检查预览。

所有URI引用、CSS/style、font-family和未列出的属性删除，namespaced属性不当作同名普通属性。源xmlns声明除正确默认SVG声明外记录移除，输出命名空间由XMLSerializer生成；普通文本以Text节点转义，`<script>`字样不变成元素。事件属性按on开头识别并记录，引用仅保留定位、属性名称及原值长度，不请求或回显完整私密URL。

viewport须成对正数width/height（支持px）各≤8192、面积≤16MP，或有限合法viewBox。只有viewBox的来源明确使用800×600预览尺寸，viewBox数值保留，不称原始显示尺寸不变。百分比/单侧尺寸/缺失viewport/超大或非有限尺寸拒绝，避免无界预览资源。

输入预算：每文件256KiB、最多8文件且总1MiB，来源名≤120码点；UTF-8严格解码，不猜GBK/UTF-16；BOM可由解码器移除，但原字节hash保留。每文档2000元素、12000属性、32层；节点/属性名80字符、定位路径1200字符；风险记录≤15000项且累计JSON≤1MiB，净化源码≤1MiB；完整批次报告≤2MiB。任何超限或坏文件使整组无可导出结果，未截断冒充完整报告。

`index.js`用File/arrayBuffer读取，WebCrypto SHA-256计算原字节和输出UTF-8字节；显示PNG化前的静态SVG data图片，符合项目img data CSP，不加载原SVG。输出名固定为sanitized-F1.svg等，粘贴为sanitized-P1.svg，避免源文件名带路径进入导出。完整风险报告含原文件名及hash，报告分享前仍须核对。

一次最多一个读取/检查流程。取消或离开使票据失效，底层File/hash不能强制中断；释放前禁用再次检查，防止积累未结束流程。同步XML解析与序列化在上述有限输入内执行，不声称可逐字节中止。窗口隐藏/离开/销毁清空文件输入、粘贴、图像和结果，返回不自动检查；没有草稿、后台监控或网络。JavaScript字符串不作安全擦除承诺。

报告另存使用生产 `files.saveText(copyOnly:true)`；SVG集合与完整risk-report.json使用生产 `files.exportBundle(copyOnly:true)`，基于基础PR #14验证规范Base64/SHA后独占新目录创建。二者严格ok===true才显示成功，已有目标拒绝，普通失败/partialPath如实提示。完整模板预览不是相同源名覆盖操作，导出不写原File。

依据：[MDN DOMParser.parseFromString](https://developer.mozilla.org/en-US/docs/Web/API/DOMParser/parseFromString)说明XML独立文档及插入活动DOM风险；[W3C SVG脚本/事件](https://www.w3.org/TR/SVG/interact.html)和[SVG处理模式/外部引用](https://www.w3.org/TR/SVG/conform.html)。本工具使用上述明确有限规则，未声称遵循完整SVG兼容性或达到第三方安全认证。

## 4. 如何使用

1. 打开“工具 → 图片与视觉素材 → T039”。选择本地SVG集合或粘贴一份SVG，两种来源不能同时非空。
2. 可先“载入脚本与外链样例”。选择是否允许静态文本；几何规则固定，不能允许脚本、外链或CSS。
3. 点击“检查并预览静态新副本”，查看每条风险/改动的节点定位，核对实际图像及完整净化源码。复杂效果删除后可能不同，需人工确认适合交付。
4. 完整JSON风险报告先预览再另存新文件，或点击“确认预览后创建静态副本新目录”，选择尚不存在的新目录名。目录包含全部成功副本及完整risk-report.json。
5. 来源或规则改动使旧结果失效，须手动重检。任一输入不合法整组失败；取消后不输出部分副本。已有目标写入拒绝，可另选新目录。

## 6. 具体使用例子

点击样例后，源SVG含onload事件、script和远程image，同时有背景rect、蓝circle及中文text。检查后风险报告定位根onload、/svg/script[4]、/svg/image[5]的href；输出副本不含这些主动元素/属性，静态预览仍显示蓝圆和中文。

预览完整报告另存svg-static-policy-report-copy.json，再创建一个全新目录；其中sanitized-P1.svg是已核对静态副本，risk-report.json含原/输出hash和7项记录。再次导出到同一目录拒绝，既有SVG保持相同。取消“允许静态文本”再检查，文字子树被移除且记录，蓝圆/背景保留；由用户判断无文字版本是否适合。

把来源改成未闭合的`<rect>`会整组拒绝并禁用导出；带DOCTYPE外部实体或xml-stylesheet的SVG在调用解析器前拒绝，不请求其资源。普通渐变、图片或CSS素材也会被有限规则删除，必须观察预览，不能依据“检查完成”推断视觉等价。
