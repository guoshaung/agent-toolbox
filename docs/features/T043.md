# T043 视频关键画面提取

## 1. 功能内容

本机选择一个 MP4，通过指定时间列表或固定间隔，提取1–32张真实 PNG 画面，逐张保存请求时间、实际源帧整数PTS、时基、实际时间、正偏差和联系表行列。先显示完整请求/固定执行计划，确认后提取所有图片并拼接真实联系表；所有PNG及联系表完成预览之后，创建全新目录副本。不是视频总结，也不是只取编码关键帧。

有限支持 Windows 本地固定盘普通 MP4：≤64MiB/120秒，唯一H.264/yuv420p视频、≤1920×1080/60fps、方形像素、零起始时间；可有唯一AAC单/双声道音轨（8–48kHz，仅忽略其声音，不转换/导出音频）。多视频/多音轨、字幕/数据流、封面/章节、旋转、HDR/10bit、外部轨道引用、UNC/链接等整份拒绝。指定时间为不重复整数毫秒，`0≤时间<格式时长`；按列表顺序输出，不隐式排序。固定间隔≥100ms，从0开始，不包含终点，总帧数超过32先拒绝。

## 2. 为什么需要

演示录像、操作记录需要可复现截图。输入相同时间点，记录真实PTS与偏差，可以解释帧边界导致的时间差，区分用户请求与实际提取画面。联系表方便快速总览，完整索引让每个画面都有可核查的来源，而无需手工逐次暂停猜时间。

## 3. 实现方式与必要依赖

私有 `model.mjs` 建立有限计划、生成纯数值固定参数、解析showinfo实际整数PTS、校验输出PNG结构/CRC/尺寸预算。私有 `host.cjs` 经生产 `features.callHost` 固定加载；原生目录/源对话框把本次允许的可信安装与文件绑定到sender不透明令牌，不收renderer系统路径/命令、不跨其它功能import。

依赖用户自己可信安装的 Windows **FFmpeg/FFprobe6.x**，需PNG编码器；本次验证6.1-full_build。默认目录候选 `C:\ruanjian\ffmpeg\bin`，也可原生选择含固定 `ffmpeg.exe`/`ffprobe.exe` 的普通目录，逐个realpath/身份确认。缺文件、缺PNG编码器、其它主版本清楚拒绝。可从 [官方FFmpeg下载入口](https://ffmpeg.org/download.html) 获取合适Windows发行版并解压到可信本机目录，本工具不安装/下载、修改PATH或系统设置。选择/预览候选仅查文件，用户确认后才固定3次版本/编码器查询；它不证明二进制可信，不是程序沙箱/签名校验器。Python/PIL等仅为开发验证，产品不依赖它们。

每请求独立解码源视频，固定 `-copyts` 和 `select=gte(t,requested_seconds),showinfo`，取首个输出帧；showinfo在缩放之前，未用seek、fps重采样或setpts。按 [官方select](https://ffmpeg.org/ffmpeg-filters.html#select_002c-aselect) 的时间筛选与 [showinfo](https://ffmpeg.org/ffmpeg-filters.html#showinfo) 的源PTS单位计算 `实际ms=pts×numerator×1000/denominator`，同时交叉检查日志pts_time。源格式时长内的请求也可能晚于最后视频帧；没有合格帧、日志缺失/歧义/不一致都整份失败，不返回部分成功。不是“最近帧”或“时刻完全相同”的保证。不同请求可能落在同一真实帧，保留其各自请求，不擅自去重。

PNG RGB8保持比例且不放大，最多640×360；联系表使用实际生成的PNG序列，经固定scale/pad/tile拼接，3列，每格320×200，间隔/边距8px。其行列从1开始、先行后列，索引明确对应图片；黑色剩余格不是额外帧，PNG联系表不自带文字标签，需与索引共同看。图像缩小会损失细节。每帧<1MiB、联系表<8MiB、全部图像+预留完整索引<20MiB；任何触限/损坏/截断整体拒绝。

固定MOV解复用、file协议白名单，禁外部/绝对轨道引用，额外有界ISO-BMFF自包含dref检查；[官方MOV选项](https://ffmpeg.org/ffmpeg-formats.html#Options-5)。无shell/任意表达式、网络/登录态、隐式重试或源文件写入。run前后核对源SHA/大小/身份并重新FFprobe；所有PNG签名、IHDR、整文件CRC、IEND与预期尺寸校验。完整结果还必须在Chromium全部加载并核对naturalWidth/Height，人工确认后才能保存，加载信息不是观看每个像素的证明。

单sender一job，串行每帧进程，全局最多4个实际子进程，sender最多16；每版本/FFprobe/提帧/联系表过程最长5秒，提取批次deadline60秒并逐操作/读块复核，stdout+stderr≤128KiB。文件系统读取和同步PNG解析是有限容量协作取消，不保证OS I/O硬中止。源/结果各一个，每窗口最多512次Host调用，需要重开窗口；取消意图有限32条且60秒失效。invoke首个await前预留job；取消/销毁终止自己的子进程，close后才释放槽，不确认终止则保留槽并报pending。自己的生成图片才有file预览URL；清除/切换/隐藏会停止任务并清除源、全部图像/计划/临时目录，返回不自动恢复，不写全局配置。空闲结果约15分钟清理，崩溃可能留临时目录，需人工核对。

本ID Host原生保存对话框预览新的目录名称，所有结果验证完成才写。普通本地祖先拒链接；独占mkdir、每PNG `COPYFILE_EXCL`、完整JSON索引`wx`，核对每个落盘SHA。已有源文件/目录均拒绝；取消/失败保留已有完整预览，普通中途失败清理自己新建目录，身份不明/清理失败给partialPath。只 `ok===true` 成功，不承诺跨文件/断电事务或抵御同权限恶意竞态。

## 4. 如何使用

1. 点默认引擎计划或选择可信引擎目录，阅读固定三次查询后确认。原生选择单个本机MP4，核对源名/大小/SHA，再确认一次只读媒体检查。
2. 选择“指定时间点”，填整数毫秒，例如 `0,5000,9000`；或固定间隔 `5000`。空输入、非法范围/重复时间/超量明确报错，不执行提帧。
3. 点“预览全部请求与固定执行计划”，核对来源、顺序、数值/图片尺寸、实际调用数和预算；点确认才执行。
4. 阅读每帧真实PTS/时基/时间/偏差及联系表行列，查看全部图片和实际联系表。任何图片加载失败禁止导出。勾选已核对确认。
5. 点创建新目录副本，在原生保存对话框预览全新目录名称并确认。保存取消可保留完整预览重试，已有目标绝不覆盖。编辑参数废弃旧计划/图像；切换或隐藏清除内容，返回要重新选择源。

## 5. 使用后产出

目录含完整 `frame-01.png`…`frame-NN.png`、`contact-sheet.png`、`frame-index.json`。PNG是真实提取画面，索引含每请求/实际PTS/时基/实际毫秒/偏差、位置、图片大小尺寸与SHA、源信息/SHA未变核对、完整选择规则/固定argv摘要、联系表规则与hash、目标目录/副本语义。PNG包含实际画面内容；目录不另输出音频文件、整段视频或AI摘要。源名及本机目标路径可能是隐私，分享前自行决定范围。原视频不写、不移动，不生成关联账号工程。
