# E035 平衡石头

## 1. 功能内容

十种原创程序石块：扁青石、圆灰石、长砂石、高岩石、小卵石、斜纹石、宽河石、细页岩、暖砾石、厚玄石。用户加入石块后明确继续，石块缓慢下落；可拖放、数值编辑、键盘移动和旋转。模型根据面积重心、上方依赖的合成重心和支撑区间判断稳定或倾倒，提供冻结、撤销、版本存档和完整 PNG 新副本。

没有随机晃动、游戏时钟、计分、排行或关卡，没有网络、音频或摄像头。动画只用于观察下落与失衡，首次打开和恢复后保持冻结。

## 2. 为什么需要

让用户用少量动作专注于摆放，观察“重心是否仍在支撑区间内”的明确关系。具体位置、角度、支撑段和失衡原因可查看；撤销保留操作前的几何坐标，冻结后不用担心场景继续移动。场景可用独立 JSON 保存恢复，图像可作为本地作品留影。

## 3. 实现方式与模型边界

`model.mjs` 定义十种有限凸多边形，形状、长宽和颜色不同；面积与局部重心使用多边形鞋带公式，密度统一，质量为面积。角度应用真实二维旋转矩阵，因此实际轮廓、水平投影、重心坐标均改变。X/Y为多边形局部底部锚点坐标，不是面积重心；向右为X正方向，向下为Y正方向。

本首版是**二维准静态模型，非通用刚体物理引擎**。每个稳定石块的上表面用其水平包围投影区间近似，支撑高度为多边形最高点Y；下降石块最低点跨越这个高度且两者水平投影有重叠时落在该高度，按最高可接触面优先、同高度按编号稳定选择。接触段为两块水平投影的交集，地面是Y=540、X=[0,800]。它不声称倾斜石块的实际接触面也是水平，也不计算摩擦、弹性、转动惯量、冲量或精确边缘碰撞。

石块及沿支撑依赖树在其上方的所有石块，按面积质量加权计算合成重心X：`sum(mass×centerX)/sum(mass)`。落在接触段含两端点的区间内为稳定，严格超出为失衡。界面橙点是自身面积重心，金色横线是接触段，上方小竖线是合成重心投影。移动某支撑石会把依赖它的整棵上方子树解除支撑，重新下降；下层因上方载荷失衡会让依赖子树一起进入倾倒，而非只判断最上面一块。

下落步长1/60秒，每步下降2.5坐标单位。倾倒方向由合成重心相对接触段的位置确定，先至多45步每步旋转1.2°并横移1.2单位，每步向下5单位；触地后校正最低点到地面，至少30步才稳定，最多180步强制有限落地。普通下降最多360步落地。倾倒组直接落向地面，途中不重新堆叠，石块可能相互重叠；侧向插入已占据位置也不做一般穿透解算。模型提供明确支撑碰撞与有限结局，不将上述近似称为连续多体物理。

RAF使用固定步长累积器，每帧最多4步、长帧仅接收最多4步的时长，丢弃长暂停积压；1e-9毫秒容差只处理固定步长浮点除法，不改变支撑端点判据。稳定场景自动停止RAF。首次create/activate不自动启动；冻结取消RAF、清帧时间/积累量，禁止对已有石块拖放/旋转/数值修改；加入新石块是明确用户修改，新石块在冻结状态保留出生坐标。隐藏、离开、销毁释放Pointer Capture并停止RAF；返回和恢复保持冻结，不补算离开时间。

最多20块，最近20个完整操作前快照用于撤销；动画帧不逐帧进撤销栈。撤销后还原真实坐标/角度/阶段/支撑引用并冻结。X范围80–720、Y范围-200–800、角度-180–180；拖放/方向键在坐标边界限幅，数值越界或空值拒绝。预览是固定800×600场地；允许Y暂时位于画外，使用数值控件找回。PNG导出会在不改坐标的情况下扩展SVG viewBox以包住全部石块加12单位余白，并缩放到800×600；正常场内场景保持原比例。

存档 `schema:1` 保存源几何、阶段、有限步数、倾倒方向、支撑引用、编号与冻结标志；不保存SVG、重心、判定结果或用户脚本，恢复后全部派生内容重算。限64KiB UTF-8，精确根字段与每石块字段、枚举、有限数值、整数编号/步数、唯一编号、阶段对应引用、已落地高度、接触几何、支撑存在性/稳定阶段和无环关系严格校验；拒绝未来schema、重复键、未知字段、损坏UTF-8/JSON、过深和超限内容。结构合法但已失衡的静止石堆可恢复冻结；明确继续会重新判定并倾倒。导入先校验放进草稿，点击恢复才替换当前场景，恢复强制冻结且可撤销。

PNG经本地SVG Blob→原生Image→800×600 Canvas编码，限10MiB；规范Base64与原字节SHA-256交生产二进制桥核验。JSON用 `saveText({content,extension:'json',defaultName,copyOnly:true})`，PNG用 `saveBinary({copyOnly:true,defaultName,base64,sha256})`，先检查对应 `SupportsCopyOnly===true`，依赖公共二进制基础 `c0c93aa`（PR #14）。已有目标独占创建失败，只有 `ok===true` 才显示成功；取消/失败/partialPath明确报告。本地读取/解码可取消或随生命周期失效，未提交结果不写文件；原生另存已经提交时需在对话框取消。销毁清理UI/景观/document监听、Blob URL、撤销栈和草稿。

## 4. 如何使用

1. 选择石块种类，点击“加入所选石块（中央上方）”，出生X400/Y75。初始保持冻结；点击“继续下落 / 启用摆放”。
2. 点击石块拖动。Pointer Capture保持拖动，屏幕坐标通过SVG CTM换算；拖动中暂不推进模型，松手后重新下落。也可用“选择石块”、X/Y/角度控件后点“应用位置 / 角度”。
3. 景观获焦点时，方向键每次移动8单位，R旋转15°；此方式与拖放一样改变实际模型。冻结时这些修改禁用，选择查看仍可用。
4. 点击“冻结坐标与下落”停止RAF和坐标推进。“撤销上次摆放（保持冻结）”恢复操作前场景；随后需明确继续。
5. 用“保存场景JSON副本（冻结）”另存。用文件输入导入或粘贴草稿，再点“恢复草稿（替换并冻结）”。切换具体功能会销毁未保存状态，恢复需用户导入自己保存的档。
6. 用“保存完整石堆PNG副本（冻结）”另存完整场景。保存后仍冻结，选择新文件名；原名已有时拒绝。清空需勾选确认并点击“建立空场景”，可撤销。

## 5. 产出与可复现例子

确定性失衡例：默认扁青石加入第一块并继续，等待落地（X400、Y540、角度0）。加入第二块，在其尚处于上方时拖右约90单位，或直接设置第二块X490、Y75、角度25，再点应用。第二块下落接触第一块，合成重心约495.44，支撑段约[439.25,456]，严格超出右端，显示包含编号、重心和支撑段的失衡原因，进入倾倒后有限落地。该设置最终第二块X约526、角度约61°，最低点Y540。把第二块改为X400/角度0从上方下降，则稳定堆在第一块上方。

独立边界判据例：支撑[0,10]，重心0、5、10均稳定；-0.000001或10.000001失衡。真实多边形面积重心使用数学计算；上方重石可使原本自身重心仍在段内的下层石头失衡，测试覆盖整棵依赖倾倒。

冻结例：石块在Y75时冻结，向帧驱动注入一天时间后仍保持相同X/Y/角度/阶段，没有后台追赶。撤销例：加入后连续21次向右键移动，X568；撤销20次后X408且冻结，最早的那次操作已超出最近20记录范围，撤销按钮禁用。

输出 `balance-stones-archive-copy.json` 可独立查看每块几何与阶段，导入后保持冻结。`balance-stones-copy.png` 为800×600完整场景，包含背景、地面、石块及重心/支撑辅助标记；画外块通过导出viewBox缩放也进入图片，不修改源坐标。两种文件都只另存新副本。
