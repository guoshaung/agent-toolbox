# T089 尺寸摆放试算

## 1. 功能内容

以统一厘米配置一个矩形房间和1–30个矩形物件，查看等比例 SVG 平面图，选择物件拖放、以左上角为锚点切换0°/90°，或直接编辑x/y坐标。每次合法编辑、拖动、旋转后立即重算二维重叠和出界，显示超出左/上/右/下的长度及正面积交集；非法或未完成的输入会废弃旧检查并禁用导出，修正后恢复。

所有位置保留，包括负坐标和出界坐标，不自动夹到房间内。平面图视野包含房间及全部物件轮廓；拖动中固定视野，释放后重新包含出界部分。支持完整 JSON 布局（含恢复草稿、位置、检查和视图）、静态安全 SVG、完整 Markdown 副本。版本1草稿或完整JSON可重新导入，只采用配置重新计算，不沿用旧检查。数据不上传、不改原文件、不写全局配置。

## 2. 为什么需要

只比较宽高不足以理解旋转后的实际占地，多个物件也可能同时重叠或部分伸到边界外。若拖动时自动把物件夹到房间里，会把真实超界问题隐藏；若使用浮点尺寸和误差容忍，贴边与1毫米重叠也可能混淆。该工具按整数毫米精确检查、展示全部出界轮廓，并提供拖放、数值与键盘三种操作方式，让布局和错误可审查、保存及复现。

## 3. 实现方式与输入规则

- `model.mjs` 为纯本地几何模型。输入统一 `unit:"cm"`，宽高/坐标是十进制文本，最多一位小数，`0.1cm=1mm`。BigInt 分解文本并转成有界整数毫米，不进行浮点尺寸累加。宽高允许 `0.1–10000.0cm`；坐标允许 `−20000.0–20000.0cm`。宽高须正数，仅坐标允许负数；`1e2`、`0.01`、空白、逗号、正号、数值类型的导入不接受。规范输出统一一位小数，`-0.0`规范为`0.0`。
- 原点是房间左上角，x向右、y向下；物件x/y是当前占地矩形左上角。90°仅交换原始宽高，左上角不变，不绕中心、不自动移动或适配。每物件有明确允许旋转开关；当前90°时关闭开关会拒绝并提示先恢复0°，不会静默改变形状。
- 出界判断为 `x<0`、`y<0`、`x+w>房间宽`、`y+h>房间高`，等号允许；逐侧记录正的超出毫米长度。重叠要求两个矩形在x/y方向都有**严格正长度交集**，贴边/角接触不算重叠。物件出界部分同样参与物件间重叠，检查不会先把形状裁切到房间内。每一对只报告一次，最多30物件/435对，交集面积是精确整数平方毫米。
- 图形通过 `document.createElementNS('http://www.w3.org/2000/svg', ...)` 生成，视图使用同一整数毫米坐标和 `preserveAspectRatio="xMidYMid meet"`，长宽不拉伸。视野取房间与所有物件的完整边界加4%余量（至少20mm）；远处物件会使整体缩小，仍可用数值编辑精确摆放。蓝色物件无出界/重叠问题，橙色表示有问题，选中边框更深；文字和报告提供同样的信息。
- Pointer 拖动在 SVG 根元素捕获指针。`createSVGPoint` 经 `getScreenCTM().inverse()` 把屏幕像素变为毫米，正确考虑缩放、偏移和留白；保存起始抓取偏移，不把物件左上角强行贴到指针。仅响应对应的主指针；移动四舍五入到最近1mm（`Math.round`，恰好半毫米时向正方向取整）。拖动期间固定viewBox，避免自动缩放造成坐标反馈；释放后重新适配视野。pointerup的最后坐标也纳入计算。
- 出界保留，超过**坐标硬上限**的拖动/键盘更新会拒绝，保留最后一次合法位置，不夹紧到房间内。取消、Esc、pointercancel、lostpointercapture或离开工具，恢复拖动前坐标并释放capture。重绘后保持所选图形焦点；键盘事件阻止向SVG根冒泡重复移动。暂停和destroy移除根Pointer/键盘监听，activate重新附加且不重复；旧图形事件有active/alive检查，避免误改后续模块。capture/坐标变换不可用时提示使用数值或键盘替代。
- 图形或SVG聚焦后，方向键每步1cm，Shift+方向键10cm，Alt+方向键0.1cm，R旋转，Esc取消拖动；Enter/Space选择物件。直接编辑x/y是同等能力的替代交互。Ctrl/Meta组合不被该模块接管。
- 版本/JSON输入由本功能独立 `json.mjs` 严格解析（复制自T084 0df64b9，源自T010/T008，没有运行时跨功能依赖），拒绝重复键、非法语法、精度丢失数字、超限结构和未知草稿配置字段。物件ID为唯一I1–I30，名称1–80 UTF-16单位，无首尾空白、控制/非法XML字符。旧报告里的伪造位置、重叠、出界和视图都不采用；只读取 `draft.config` 重算。

SVG副本不含脚本、事件属性、外部图片/链接/字体、DTD或嵌入网页；用户名称用XML文本转义，所有几何属性来自有界整数模型，`metadata`中的完整JSON同样XML转义。Markdown名称经过转义，恢复草稿放在JSON代码块。绘图不是把用户输入当HTML执行。

## 4. 如何使用

1. 打开工具工作台 **T089 尺寸摆放试算**。输入房间宽/高厘米。初始为400×300cm房间、一个100×50cm物件。
2. 用 **添加矩形物件** 添加，选择下拉框切换物件，编辑名称、原始宽高、左上角x/y。添加默认50×50cm且放在原点，因此可能重叠；用户需要自行摆放。可删除所选物件，但至少保留一个。
3. 在图上拖动某个物件，拖动会同时选中它；按 **旋转所选物件90°** 或角度下拉框旋转。也可Tab聚焦图形后用方向键/R操作，或者直接编辑x/y。关闭允许旋转前先恢复0°。
4. 查看状态、出界各侧长度、重叠对象与交集面积。编辑自动检查，**重新检查全部物件** 可主动复查。问题布局也可导出，程序不把“存在问题”当输入错误或自动修正。
5. 保存完整JSON、比例SVG或完整Markdown。调用 `files.saveText({content,extension,defaultName,copyOnly:true})`，并要求 `saveTextSupportsCopyOnly===true`；能力缺失时按钮禁用。基础层独占创建，新文件以外的已有目标（包括原JSON）拒绝覆盖；在原生另存对话框核对目标或取消，取消不报告成功。生成副本阶段可用面板取消，进入对话框后面板取消暂时禁用。
6. 在 **恢复草稿/完整JSON布局** 中导入UTF-8文件或粘贴版本1 JSON。成功恢复可视控件并重算；非法UTF-8、JSON、版本或超限导入原子拒绝，当前布局/检查保留。仅改候选导入文本不改变当前有效布局。SVG/Markdown不能直接作为导入文件，使用JSON或其中的版本1草稿。

切换具体功能会销毁未保存内容；离开整个工具会取消处理/拖动。没有自动保存，请先保存JSON。

## 5. 产出与可复现例子

核心验收点击 **载入100×50放入80×60示例**：房间80×60cm，物件100×50cm，x=0/y=0，允许旋转。

| 方向 | 当前占地 | 出界判定 | 图形/位置 |
| --- | --- | --- | --- |
| 0° | 100×50cm | 右超20.0cm，出界1物件 | 左上角仍(0,0)，完整宽100cm轮廓可见 |
| 点击旋转后90° | 50×100cm | 下超40.0cm，仍出界1物件 | 左上角仍(0,0)，完整高100cm轮廓可见 |

贴边与1mm重叠例：房间20×20cm，物件I1/I2均10×10cm，I1坐标(0,0)、I2坐标(10,0)，无出界、无重叠。把I2.x改成9.9cm：出现I1/I2一对重叠，交集宽1mm、高100mm、面积100mm²。把I2.y改成−0.1cm：上超0.1cm保留，出界部分不被裁掉；模型仍按完整矩形检查重叠。

拖动/键盘例：初始400×300cm房间。Tab聚焦I1图形，右箭头一次x=1.0cm，Shift+下箭头y=10.0cm，Alt+左箭头x=0.9cm，R变90°且坐标不变。拖动I1到负y位置后释放，图形与报告显示上侧出界且视野包含轮廓；拖动过程中按Esc则回到拖动前的坐标。数值输入与这些操作得到同样的毫米检查结果。

最小版本1草稿：

```json
{"feature":"T089","version":1,"kind":"draft","config":{"unit":"cm","room":{"width":"80.0","height":"60.0"},"items":[{"id":"I1","name":"矩形","width":"100.0","height":"50.0","x":"0.0","y":"0.0","allowRotate":true,"rotation":0}]}}
```

完整JSON为版本1 `kind:"layout"`，包含上面 `draft`、`assumptions`、整数毫米房间/每物件原始与当前尺寸、x/y、旋转、各侧超界毫米、重叠对象、全部交集对、`isValidPlacement`和view。将其中`outOfBounds`/`overlaps`伪造为空再导入，仍从草稿重算真实出界/重叠。

SVG为1200×800展示画布、等比例viewBox（内部单位毫米），包含房间、每个物件、来源名称、安全完整JSON元数据和二维限制说明，不含交互代码。Markdown包含厘米尺寸/位置/方向、四侧超界、重叠对象和所有毫米交集，再附可恢复草稿；三个副本都保留问题布局。

DOM为最小fixture，模拟完整SVG CTM与捕获事件，属于渲染契约验证，不能称为真实浏览器鼠标、Electron原生IPC、文件对话框或打包验收；主代理在集成环境验证这些部分。本worktree没有node_modules，按协调约定不重复全库缺依赖检查；ESM/model/parser/test语法及staged diff另检查。

限额：1–30物件、435重叠对、宽高0.1–10000cm、坐标±20000cm、名称80单位、JSON导入256KiB/深度12/节点20000/每对象50字段/字符串2000单位、每副本512KiB。最大交集面积10000000000mm²仍为安全整数。超限拒绝，不截断物件，不自动夹紧到房间，不给“放得下”的错误成功提示。

本功能只检查二维静态矩形占地，不涵盖门口搬运、三维高度、非矩形真实轮廓、通道安全/承重或最佳布局；图上检查通过仅表示当前矩形无出界和正面积重叠。屏幕像素有限，毫米级细调请用数值或Alt方向键，不把边框像素粗细当几何重叠。
