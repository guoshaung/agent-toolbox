# E010 熄灯谜题

## 1. 功能与必要性

本地3×3、4×4、5×5联动熄灯小游戏。每按一格翻转自己与四个正交邻格，尝试把灯全灭；有鼠标、键盘、撤销、暂停、确认重开、可查看的生成记录/初始局解例、完整续玩和副本导出。显示亮灯数量、当前有效按数、完整用户操作数、主动用时及三种尺寸首次通关。适合短时尝试，相比只随机摆灯，可解构造能避免把用户困在不可解的输入局。

无网络、AI、排名、计分、自动代按或设备授权；生成逆操作是已知解例，不声称最短、唯一解或每种尺寸所有任意局面都有解。尺寸只改变棋盘，不把解例长度或短时间真人试玩当作难度/最优性证明。

## 2. 规则、随机生成与独立证明

坐标左上为A1，列A至E、行1至5，按实际尺寸显示。中心格翻自身及上/右/下/左四格；边缘只翻存在的邻格，角落翻3格，不包括对角、不从右边绕到下一行。亮变灭、灭变亮。一次按键只影响这些格；全部灯灭即通关，冻结本局、停止计时。通关不能撤销/再按，要确认重开；未通关可撤销最近有效按键，用时不倒退。每种尺寸第一次通关保存一条记录，共3条；重载、再次通关或新谜题不会重复累计。

生产生成器使用 `crypto.getRandomValues(new Uint8Array(n*n))`，每格一个字节，取最低位1决定从全灭按该格一次，按行顺序记录。这是等概率二选一映射：256种字节中128个最低位为1；没有 `%任意非二幂` 的余数偏差。API用途、整数TypedArray及原位填充核对了[MDN getRandomValues 主文档](https://developer.mozilla.org/en-US/docs/Web/API/Crypto/getRandomValues)。只取最多25字节/次；没有可预测的Math.random或假随机种子。源档保留生成按键，恢复无需再次抽随机数。

空按键集可能全灭，非空按键也可能互相抵消。生成结果若全灭则重试，最多4次；仍全灭则使用确定的中部单按fallback（3×3 B2、4×4 C3、5×5 C3），界面明确标注。4×4没有唯一中心，固定选择右下中部C3。随机API本身异常会报错，不伪装成成功随机生成。重试/排除全灭/fallback意味着**不承诺所有可解局面均匀分布**。

每格翻转是自身的逆运算；将生成按键逆序再翻转，可把初始盘变回全灭。独立oracle扫描全部格，用二维曼哈顿距离≤1判定是否翻转，没有调用生产 `neighbors/flip/press/replay`。测试逐格覆盖全部50格（9+16+25）、300个真实crypto生成谜题以及全部256种字节映射，验证构造可解。若逆序某前缀已全灭，应立即停下；剩余后缀可能自身抵消，不必按完，UI和规则在首次全灭即冻结。一个独立4×4零空间反例覆盖了这条边界，不把完整逆序的长度当作最短按数。

## 3. 实现、计时与严格恢复

功能目录包含独立 `meta/index/model`，娱乐/独立休闲游戏分类，使用同步create/activate/deactivate/destroy契约。程序按钮网格和Canvas灯盘都是本项目绘制；无外部图片、用户代码、额外依赖或跨功能运行时依赖。纯模型保存完整生成序列和操作日志，界面只渲染≤25灯格、每页50操作和3条首次摘要；JSON/Markdown保留分页外的全部内容。

创建界面不启动计时；首次activate保存刚生成的新谜题，尚未按键也能重载同一局，不会重新随机。用户明确开始后建立250ms显示刷新，以注入单调clock或生产performance.now累计整数毫秒，不靠刷新次数计时。暂停、隐藏、离开、销毁和导出前停止计时；返回/恢复不自动继续。暂停期间不补算；倒拨时钟增量夹0，累计上限七天。撤销不倒退用时；重开同题或随机新局时当前用时归0。

自动配置键 `featureLab.E010.progress` 保存schema1源档：当前尺寸、升序唯一base36生成序列、生成方法`crypto/fallback`、用户完整操作、准确整数毫秒，以及3种尺寸各首次完整记录。原始格索引`行×尺寸+列`从0计，0至24编码单字符`0..o`；用户按键为格子字符，撤销为`-`。当前有效按键栈由完整日志重放产生，不另存派生棋盘/胜负。例3×3生成`048`表示A1、B2、C3；用户`45-`表示按B2、C2、撤销C2。

每份当前/首次记录的生成+用户轨迹合计≤10000次，总源档≤64KiB UTF-8。最大当前与三条完整10000源迹一起仍符合64KiB，测试已核对，没有偷偷压缩成最后N步或只保存终盘。达到操作上限不能继续按/撤销，可另存完整记录后确认重开。完成记录保留包括撤销的完整首局日志；当前只保存一局，随机新局会替换当前局但保留首次记录，旧局需要事先另存。

恢复逐条重放生成和全部按键/撤销，再判亮灯、胜负和有效按数。拒绝未知版本/尺寸/字段/方法、重复JSON键、非安全整数词法、负数或超七天时间、空/乱序/重复/越界生成、生成全灭、不规范按键、无有效按键时撤销、通关后操作、重复尺寸完成记录及未达全灭的假记录。当前通关必须有该尺寸首次记录。源方法是档案内的声明，不提供随机来源/作者身份认证；允许导入合法可解源档，不承诺篡改检测签名。

输入文件声明和实际大小均≤64KiB、严格UTF-8、结构深度≤8；输入错误不会覆盖旧档。导入预览只验证，应用还需勾选替换全部进度。坏配置保持禁用，明确勾清空或导入后才替换。每次按键、撤销、暂停/导出、重开和正常离开保存；待保存锁操作，若离开时仍待返回，则完成后再次保存冻结用时。失败显示临时状态，可重试/另存。销毁释放监听、DOM、定时器和临时Canvas，尝试最后保存；强关进程/断电仍可能丢尚未完成IPC，已确认写出的JSON副本可恢复。

## 4. 使用与具体例子

工作台→娱乐→独立休闲游戏→熄灯谜题。初始随机3×3局保持暂停；开始后鼠标按灯格。方向键移动焦点但不跨行绕边，空格/Enter按格，按键repeat不连按。未通关时撤销退最近有效按键并暂停，点击继续再尝试。要换尺寸，选择新局灯盘尺寸，勾“确认放弃当前局”，点击“确认生成所选尺寸新局”；“确认重开当前谜题”保持生成序列，回到同题初始盘。未勾确认不会改变棋盘。

中央翻转例：3×3按B2，只翻B2、B1、C2、B3、A2，四角A1/C1/A3/C3保持原状态。原生验收真实鼠标中央按键按独立oracle逐格核对；全部尺寸边界另有独立测试。暂停时灯格不可按，不把无人操作的计时结束当成通关。

生成/逆trace具体例：验收的3×3生成序列`245678`（C1→B2→C2→A3→B3→C3），初始仅B2/C3两灯亮。展开“查看生成记录与初始局解例”，确认重开同题，然后开始，依次按C3→B3→A3→C2→B2→C1，实际6按后全灭，首次3×3通关记一条。每次新局随机不同，使用**本局显示的**序列，不直接套此固定例；不提供自动执行解例入口。若已做其他按键，先确认重开同题再用初始局解例；提前全灭立即停止。

另一个可手工创建的测试源档为下方JSON，将其保存为UTF-8 `.json`，选“熄灯续玩JSON”，预览通过后勾确认替换并应用；这是可解例子档，不是随机来源认证。初始A1/B2/C3三灯亮，逆生成C3→B2→A1（用户编码`840`）在3按后全灭：

```json
{"schema":1,"current":{"size":3,"generation":"048","method":"crypto","actions":"","elapsed":0},"completed":[]}
```

暂停后重载恢复同一棋盘、完整生成/日志、准确用时和首次进度，保持暂停；完成后重载也不会重复计完成。操作预览50行/页，导出完整所有日志，不因翻页丢数据。

## 5. 产出与副本保护

JSON完整保存当前和三尺寸首次源档，可通过真实文件输入恢复。Markdown含生成坐标、只适用于初始局的逆序解例、全部按键/撤销/每步亮灯数、完整二维0/1盘、首次尺寸和完整源JSON代码块；显示秒保留一位，代码块准确毫秒。PNG为完整820×820当前盘、行列坐标、数量/有效按/日志数/用时/状态和规则说明；亮格金色、灭格深蓝。它不是完整历史备份，生成和所有首次/撤销记录应另存JSON或Markdown。

全部另存检查 `saveTextSupportsCopyOnly===true` 或 `saveBinarySupportsCopyOnly===true`，请求 `copyOnly:true`。PNG≤10MiB、规范Base64、SHA-256，生产写入器核验后独占wx创建；文本同样不覆盖已有副本。成功只接受`ok===true`，取消不报成功，错误和partialPath明确提示。缺桥能力按钮禁用，用户可以看到依赖信息。编码后或销毁时释放Canvas像素/引用；导出先保存暂停时的准确源档，晚回调且已离开不会更新旧界面。保存副本不会删除源文件或旧副本。
