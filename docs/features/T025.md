# T025 PDF 可用性预检

## 1. 功能内容

选择一份本地PDF，设定预期纸型、容差、是否要求字体程序嵌入和是否允许附件，主动执行只读结构检查及全部页实际渲染。完整报告列每页MediaBox/CropBox、旋转、UserUnit、纸型、页和FormXObject中的字体资源与程序流状态、文档EmbeddedFiles名称树及页附件标记。支持A4/A3/Letter/任意纸型、1–16页，全部页预览和JSON/Markdown报告新副本；不需要AI、网络、Python或Acrobat。

结构与渲染状态明确分开：加密文件为encrypted-uninspected，页/字体/附件均未知、不渲染；普通文件全部渲染成功仍为inspected-rendered-manual-review-required，须人工核对字形/内容。渲染失败、超预算页完整列出，状态inspected-render-incomplete，不能把成功前缀当全部通过。问题0也不自动声称内容可读、印刷合格或PDF/A合规。

## 2. 为什么需要

分享或打印前可能漏掉混合纸型、意外旋转、未嵌入字体资源和附带文件。逐页结构与实际预览能让用户在发送前发现这些问题，而不是只看首页。默认检查字体程序嵌入并禁止附件；纸型默认任意，用户指定A4后才按该约束标出A3。

这是有限预检，不能代替人工阅读或专业印前检查。字体程序存在不证明字形有效；标准字体未嵌入可能仍被阅读器替代而正常显示。报告检查当前资源字典，包含未实际用于绘制的字体，不推断全部字体使用情况。附件只列有限名字和标记，不打开或扫描内容，也不保证已穷举所有身份、安全或附件风险。

## 3. 实现方式

本ID私有pdf-lib1.17.1固定原始ESM负责只读解析；没有修改共享package/lock，也没有跨功能运行时import。原始文件523417字节、SHA256 `72c052d97b4d5d9fa6cdbdcb7ad709f03d4ddb1122390cb3afeba4d88651d969`，vendor/NOTICE、完整许可及manifest标出版本与上游来源；私有.gitattributes保留原始vendor字节。库的文档/低层上下文和加密标记见[PDF-LIB PDFDocument](https://pdf-lib.js.org/docs/api/classes/pdfdocument)。运行从完整Uint8Array副本加载，ignoreEncryption=false、updateMetadata=false，不调用save或修改原PDF。

`model.mjs`实现精确约束、纸型分类、字体/附件有限遍历及完整报告。纸型按MediaBox宽高乘UserUnit，宽高中较小/较大值对照A4(595.275590551×841.88976378pt)、A3(841.88976378×1190.551181102pt)、Letter(612×792pt)，两边差均≤用户容差才匹配；方向无关，不自动缩放/旋转/修正页面。容差普通十进制0–10pt，默认2pt。CropBox单独报告；旋转须有限90度整倍数，UserUnit须大于0且≤100。

字体遍历页继承Resources和Form XObject的Resources，避免重复对象递归；FontDescriptor的FontFile/FontFile2/FontFile3非空流为程序存在证据，仅记录引用与压缩字节数，不导出流正文。Type0检查1–8个子字体描述，区分embedded/partially-embedded/not-embedded/unknown；Type3仅当1–256个CharProcs项都是非空流时标embedded-type3-glyph-programs，不解码或认证字形。直接字典/流仅标direct-object，不用toString序列化隐藏字体/附件字节。页面资源最多256、遍历512节点/深度8，超限整份结构拒绝，无部分正常报告。

附件列文档Names/EmbeddedFiles NameTree完整有限列表，每个名字对应文件规格与EF流引用/压缩长度；最多50项、树128节点/深度8，循环/错误引用整份拒绝。页FileAttachment注释最多100项及页/目录AF存在另标，不承诺已展开这些关联附件的全部名字或正文。不打开附件、不解密、不执行PDF脚本，也不使用ignoreEncryption=true。固定发行库的Error子类在ES5产物中可能失去instanceof关系，加密拒绝同时匹配库自身EncryptedPDFError工厂的完整精确消息；没有模糊匹配任意“encrypted”字样。真实独立加密夹具覆盖该路径，结果不判合格。

`worker.mjs`只接受固定inspect操作/精确字段，结构解析最多15秒，renderer实际terminate线程；源PDF≤2MiB/1–16页。主线程通过项目已有pdfjs-dist4.10.38逐页白底72DPI实际渲染，isEvalSupported=false、disableFontFace=true，worker、标准字体和cmap均为本地固定路径。相关加载/渲染API见[PDF.js官方文档](https://mozilla.github.io/pdf.js/api/draft/module-pdfjsLib.html)。每页边≤4096、≤4194304像素、全页累计≤16777216像素，全部渲染30秒协作期限。超限/失败页完整列原因；任务成功不等于文本语义可读。线程期限与声明字节/像素容量不是浏览器/解压内存沙箱或系统I/O硬期限。

编辑约束使旧预检失效；取消、隐藏、deactivate、destroy废弃票据并停线程/渲染、释放来源字节和画布引用，返回需重新选择并主动执行。文件只经Chromium FileAPI读取，源/位图/派生报告不写config；工作台可记最近功能ID。JSON/Markdown各≤2MiB，完整报告超限整体拒绝，不截断页/资源/问题；文字用textContent，Markdown内完整JSON围栏转义反引号。

## 4. 如何使用

1. 功能工作台→工具→PDF可用性预检，选择一份完整PDF≤2MiB。
2. 如打印要求所有页A4，选A4；设置容差（通常默认2pt），确认字体嵌入/附件约束。改变约束须重新执行，不沿用旧结果。
3. 点击“执行结构检查并渲染全部页”。查看完整逐页摘要和全部实际位图，检查旋转、字形及内容。字体检查是资源存在性；不把标准字体替代显示当嵌入证据。
4. 查看完整JSON或Markdown，其中所有页、字体资源、附件标记、问题、未渲染原因及人工可读性未确认状态均保留。
5. 点击“另存完整预检报告新副本”，选择不存在的新文件名。已有目标被WX拒绝，不能覆盖原PDF或已有报告。取消/失败时完整预览保留。
6. 加密文件只导出明确未检查报告，本工具不询问密码或解除权限。超出渲染预算的文件需在适合的软件人工核对，报告不称其合格。

## 5. 使用后产出

`pdf-preflight.json`或`pdf-preflight.md`为全量报告：源文件名、字节数、SHA256、用户约束、状态、每页尺寸/纸型/旋转/资源字体流状态、附件列表/标记、全部问题、逐页实际渲染状态及范围。没有改写PDF、抽取附件正文、复制字体流或自动修复产物；不持久保存页面PNG。分享报告前核对文件名、字体/附件名等可能属于文档元信息。

只使用基础files.saveTextSupportsCopyOnly===true和saveText(copyOnly:true)；主进程writeText以wx新建，成功严格要求ok===true。false/undefined/canceled/throw不假称成功，报告仍在内存；保存已开始不能撤销落盘，离开后的迟到回执不恢复旧状态。JSON/MD切换只改变报告预览，不丢其他页。
