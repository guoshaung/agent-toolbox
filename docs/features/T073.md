# T073 项目环境前置检查

## 1. 功能内容

按用户有限 JSON 项目声明逐项输出 pass / fail / unsupported / unknown：允许目录内现存文件/目录的类型及 fs.access 读写条件、目录所在卷 statfs 可用字节、当前主进程环境变量名称存在性，以及经 T071 明确选择/确认后的可信 Node/Python 自报版本。未知、不支持或未查询不能判通过；全部声明条件 pass 也不证明项目能启动。不安装、运行项目、执行清单命令、读取项目正文或创建写探针。

版本条件依赖 [T071 独立 PR #138](https://github.com/guoshaung/agent-toolbox/pull/138)，通过公共生产 Host 调用，不跨功能 import、不复制其查询源码。不安装T071时其它检查仍可用，版本项明确unsupported。T071能力未确认、未执行或失败为unknown，无PATH扫描/任意命令回退。

## 2. 为什么需要

项目首次启动可能因目录不存在、磁盘空间不足、变量未设置或所选解释器过旧失败。把声明和观察分开，能在启动之前保留时点条件证据，又不会把一次权限条件或版本自报冒充实际读写、依赖完备或应用启动证明。空变量只检查存在，不声称密钥正确或值非空。

## 3. 实现方式与有限域

清单 `T073-project-checklist` v1，严格UTF-8、64KiB、8层、1000节点、1–20项，每项id唯一；未知/缺失字段、重复JSON键、不安全整数、未配对Unicode整份拒绝。有限四种类型，不是JSON Schema执行器：

- `path`: id/type/path/kind/access；path是≤256字节、最多8段的NFC相对路径或`.`，kind为file/directory，access是read/write的非空不同值列表。只检查现存路径，不替用户创建输出目录。
- `space`: id/type/path/minimumBytes；路径须现存目录，阈值是0–10^15字节规范十进制字符串，禁止用JS Number传大数。
- `env`: id/type/name/required；名称匹配 `[A-Za-z_][A-Za-z0-9_]{0,63}`，required布尔；空字符串也算存在。不读取/导出变量值、长度、原始异常、环境正文。Windows名称忽略大小写，歧义重复名称为unknown，其它平台大小写敏感。检查Electron主进程继承的环境，不代表另一个终端或项目将来的环境。
- `runtime`: id/type/runtime/minimum/bits；runtime只node/python、每类最多一条件，minimum是0–999的完整无前导零major.minor.patch，bits为any/32/64。稳定final且三元组逐数字>=minimum、位数满足才pass；预发布失败、无有效观察未知。

OS目录选择只选一个允许根，本窗口绑定随机opaque token；renderer不能提交绝对路径用于查询。拒UNC/设备前缀/根最终链接，canonical父路径可规范化，不声称祖先完全无链接。相对路径拒穿越、绝对/反斜杠、ADS、Windows保留名、尾点空格及超限；逐段lstat拒链接，realpath须落在允许根，根/路径身份前后检查。不抵御恶意TOCTOU、不锁目录；映射盘的底层介质/传输未知，不承诺都为物理本地盘。根/路径变化unknown/unsupported，不擅自跟随路径逃逸。缺失/类型不符fail，支持域外unsupported，权限/系统失败未知或明确access条件失败。

只用lstat/realpath/access/statfs元数据，不open/readdir项目、读取正文或写新文件探针。fs.access通过只证明API条件；Windows完整ACL不由该函数验证，不能说实际写入成功。空间用statfs({bigint:true})，`bavail*bsize`，不使用bfree代替普通用户可用块；原始块数/块尺寸/可用Bytes/阈值/不足Bytes都按十进制字符串保存，1GB=10^9 bytes、1GiB=2^30 bytes。无statfs为unsupported，坏单位/负数/非BigInt为unknown。时点空间不分配/预留，也不证明配额与后续写入。

同sender一个任务、最多128编号/取消意图、最多32sender，元数据10秒协作期限。inspect在首await之前登记，取消先到可记录意图；开始/每次await之后检查取消/过期/目录代次。文件系统API没有硬取消，取消/10秒到期等待已发起API收尾，槽仍占用，晚结果无效，不谎称硬实时10秒终止。未创建Dir/FileHandle，无目录句柄泄漏；clear随时撤销token并取消本功能任务，窗口销毁释放sender。不会终止用户程序，T071取消只交回其已启动查询任务。

版本复用 T071 choose/clear/plan/run 固定操作：先用户显式重置本窗口T071共享候选，最多每类1个（共2个）明确选择可信可执行文件；T071生成包含全部路径/固定代码/参数/期限的计划；用户确认后才调用run(planId,jobId,confirmed:true)。T073按各声明独立比对观测，不自行spawn版本程序，metadata不触发版本查询。T071原有隔离、字节/期限/终止范围与可信安装限制照常适用：用户文件名不认证安全，隔离不是系统沙箱，版本为程序自报。选择/计划不执行，版本确认是唯一程序执行许可；目录只读条件无需额外勾选。

## 4. 如何使用

在工作台 T073 编辑/导入UTF-8清单（浏览器File API，仅用户选择此JSON文件），选择OS允许目录，点“检查目录空间与变量”。结果完整列每项状态、实际数字、原因和支持范围。目录与环境元数据无需版本确认；缺目录先人工建立/选择正确目录，本工具不代建。

需要版本项时，点“重置本窗口T071候选”（会清除同窗口原T071候选），经T071选择可信Node/Python；点“预演T071完整固定版本查询”，核对文件与全部固定参数，勾选确认后执行。若先查版本，再查目录可合成完整报告；若先查目录，版本回来刷新对应行。两者不自动启动项目。编辑/导入声明清除旧报告、版本证据及计划；取消/隐藏/切走忽略晚结果，不自动重查。清除释放本功能源、结果、根授权；T071共享候选通过单独显式重置。根与报告仅内存，不写配置。

## 5. 使用后产出

`T073-project-report` v1完整保留原声明、源时点/所选目录、每项期望/实际/错误码、四类数量、T071依赖与完整观察来源。env实际仅present，无值或长度；无token或项目文件正文。声明中项目名/相对路径、所选根/T071运行时绝对路径进入报告，分享前查看。报告不是启动、ACL、配额或磁盘保留承诺。

JSON/MD均先完整预览，再保存新副本，最多2MiB、超限拒绝而不截断。生产saveText `copyOnly:true` 独占新建，已有目标/原清单不能覆盖。只有ok===true显示成功，canceled/false/undefined/throw分别提示取消/失败并保留完整预览。宿主缺副本能力时阻止保存。

## 6. 具体例子与验证

示例要求20GB：`{"format":"T073-project-checklist","version":1,"project":"空间示例","checks":[{"id":"space","type":"space","path":".","minimumBytes":"20000000000"}]}`。受控statfs返回bsize=4096、bavail=1000、bfree=9999999、blocks=10000000，本项实际可用4096000 bytes，要求20000000000 bytes，准确fail/INSUFFICIENT_AVAILABLE_SPACE、不足19995904000 bytes；不能拿更大的bfree判通过。阈值改4096000时等值pass。本测试是元数据夹具，不会实际填满磁盘。

路径例：根内data/output目录存在，则对应read/read+write仅条件pass；缺missing目录fail/ENOENT；文件误要求directory则fail/PATH_KIND_MISMATCH。TOKEN设置但值为空也present/pass，未设置且required=true为fail；不评估值正确性。Node声明20.0.0，T071观察19.99.99则fail，20.0.0稳定则版本条件pass，prerelease或声明64实际32则失败；T071未安装版本unsupported而其它检查继续。source编辑后旧报告不可导出。

定向：`node --test test/feature-T073.test.js test/feature-host.test.js`，覆盖严格清单/重复键/边界、数值空间独立期望、真实目录与同步statfs独立空间oracle、变量getter完全不读、root sender token/链接/相对路径限制、早期与等待取消、未支持条件、组件可信确认、File API、保存失败分支。28项全部通过（本功能22项、公共Host6项），包含真实本机目录与空间；其余注入的20GB不足、取消期限和组件版本结果是明确夹具，不把它们称原生OS不足或实际版本执行。
