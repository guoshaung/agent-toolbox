# L052 评分一致性校准

## 1. 功能内容

本地记录匿名编号作品、固定人工量规和两位评审的完整0–5整数评分，逐作品/维度计算差异，列出超过用户阈值的人工重评候选。1–12作品、1–8维，先冻结作品/量规再评分；两份分别提交后锁定，未提交分数明确未知、不能作为0或生成对照。评分视图不显示来源标题/映射及对方已提交分数。

这是catalog L052的完整MVP：本地匿名化编号、分开人工评分、逐维度差异、用户阈值及重评候选，无在线协作/AI依赖。匿名仅指界面编号隐藏来源映射；正文不自动去身份，本地配置也不防窥读。完整JSON/Markdown包含所有人工来源与原文，不是匿名分享文件。

## 2. 为什么需要

同一作品的分数可能受评审对量规的理解影响。先固定作品及标准、分别登记两套评分、再定位分歧，可以帮助用户带着具体分数与原句证据讨论重评，而不会把分歧直接视作作品差或某评审不可靠。界面分开填写不能保证现实中的不同人员身份或真正独立评审；用户应自行安排独立评分与说明证据。

工具只给差异与候选，不自动评分、不核实证据、不计算ICC/kappa，也不以计数代表量规效度、评审可信度、作品质量或学习效果。差异不超阈不证明两评审都正确；超阈也不能判谁正确。

## 3. 实现方式

`model.mjs`实现纯数据验证、编号分配、冻结/丢弃评分、单元评分、提交锁定、差异报告；`index.js`提供真实作品/量规编辑、两套评分选择器及证据文本、锁定状态、完整预览与副本导出；`meta.json`供生产catalog发现，样式使用实际主题变量。

编号为W001…/D001…，在当前集合唯一；删除后可复用最小空编号，只允许设置阶段增删。标题/来源由用户填写，评分时只展示编号和正文。冻结要求正文、维度名及说明非空；0–5评分锚点由用户在说明中定义。冻结之后这些内容只读；修改作品/量规须明确确认丢弃当前两份评分，保留作品/量规进入编辑阶段，再次冻结生成全未知矩阵。没有隐式保留旧评分或历史版本功能。

每份矩阵恰为作品×维度完整笛卡尔积，拒绝未知/重复坐标。空分为null未知，0是明确人工0分。只有全部分数合法才能提交；已提交不可修改/重复提交。A/B可任意先后单独填写，提交后自动转到尚未提交评审；没有自动评分。两份完整提交后才能主动计算。证据为人工原句或位置说明，空项显示未知，不排除该评分对，不伪造引文。

每单元 `signedDifferenceBMinusA=B−A`、`absoluteDifference=abs(B−A)`；严格 `absoluteDifference>threshold` 才标候选，相等不标。每维度保留全部作品对、差异及候选作品ID；没有以平均数掩盖逐项。阈值可在评分前后修改，旧报告立即失效，已提交分数保持锁定，重新计算使用新阈。作品/来源/人工分/证据修改也清派生结果。

边界：1–12作品，每篇正文≤4000Unicode码点，标题120/来源320；1–8维，维度名80/说明600；每单元证据400码点；评分/阈值均0–5整数。非法控制、孤立代理字符、额外schema字段/坐标/阶段状态拒绝。完整输入JSON≤256KiB，完整JSON/MD输出各≤2MiB，超限整份拒绝不截断。派生差异矩阵至多96对，输入最多192评分单元；大矩阵全部显示并可滚动查看。

schemaVersion1配置仅存作品/量规/阈值、两份人工评分与提交状态，不存派生报告；完整UTF8草稿≤64KiB才排队保存，恢复同样校验。较大合法输入可分析/导出，但明确提示配置未保存，关闭只恢复较早合法草稿。保存队列串行保留最新合法值，过时回执不能掩盖新输入错误。分析三个异步检查点，编辑/取消/隐藏/离开/销毁通过票据隔离迟到结果，不自动重跑。用户来源文本通过文本节点输出，Markdown转义HTML及动态围栏；生产saveText要求防覆盖能力严格为true、copyOnly:true、ok===true，不写回来源。

## 4. 使用步骤

功能工作台打开L052，输入作品正文及自用来源说明；正文身份信息需先自行移除。添加或删除作品/维度，在量规说明写明0–5分解释，设置差异阈值，点击“冻结作品与量规”。

评审A按固定量规逐单元选分，可填原句/位置证据；未评分显示未知。点击“提交并锁定评审A”会验证全矩阵并锁定，随后评审B独立填写/提交。两份均提交前不会展示已提交分值或来源映射。要更换填写顺序，可用“当前评审”切换；这是本地界面隔离，不是在线账号权限。

点击“计算两份评分差异”直接本地执行，无额外确认；查看完整差异表、逐维度候选和证据未知项，展开来源/原文映射与完整JSON/MD预览后导出新副本。取消保存保留报告，防覆盖失败不会声称成功。改阈值需重新计算。改量规或替换示例会丢弃评分，因此必须先保留/确认；需要旧记录时先完成并导出。隐藏/离开取消迟到分析，恢复控件不会自动重新对照。

## 5. 产出与可复现例子

完整JSON含模型/schema版本、所有原始输入/人工评分/提交状态、作品匿名编号与来源/正文映射、固定量规、阈值、全部有符号与绝对差异、逐评审证据/未知状态、逐维度所有作品对/候选列表、候选坐标和规则定义。Markdown含简洁摘要及同一完整JSON。来源/正文/全部评分都会保存，适合自用对账，分享前自行检查身份内容；工具不生成去身份分享报告。

默认一作品W001、D001“论证依据”、D002“表达明确”、阈值2。点击冻结，评审A给D001=2、D002=2，可填“人工依据：正文第1句”，提交锁定。评审B给D001=5、D002=2，证据可空，提交后点击对照。结果D001：B−A=3、abs=3，W001/D001恰一个重评候选；D002：差异0、不标。A的原句意见如实保存，B空证据显示未知；不因此假定A正确。阈值改3并重新计算，差异3等于阈值，不再标候选，但评分保持2/5不可覆盖。

默认正文“缓存可以减少重复请求；缓存副本过期后应核验。”来源是用户自编练习。原生验收同内容TXT夹具UTF8 SHA256 `56f0f85652f9bfb9d4fec591c50b3a2a8d58daafee258da71dba6c368e87f260`，输出原文完全一致，夹具字节未变。此hash只用于源夹具一致性证据，没有伪装为作者真实性认证。

添加第二作品和第三维后，两评审都评分得到6完整评分对；若D001两篇分别2/5，其余相同，则2候选、各维度保留全部2作品对。12作品×8维最大例保留96对/192人工单元。5篇各4000emoji仍可完整对照与导出，但草稿超64KiB拒存；再加大量证据若整体超256KiB，整份拒绝而不截掉评分或正文。
