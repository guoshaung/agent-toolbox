# L030 表达式等价挑战

## 1. 功能内容

“学习 → 编程验证与调试训练”的受限表达式差分穷举工具。输入两个纯整数/布尔表达式及1–3个有限变量域，完整检查Cartesian积（≤10000输入），列出同类型/同值结果、全部反例与运行域错误，并明确实际检查域。

默认 `x*x` 与 `x`、x域{-1,0,1,2}，四行中恰有-1和2两反例。另有三变量德摩根真值表、运算优先级示例。界面支持输入编辑、变量增删、类型AST、进度/取消、分类筛选与20行分页、完整JSON/Markdown副本。纯本地，无AI、新依赖、用户JavaScript或外部代码运行。

## 2. 为什么需要

重构时常凭直觉认为两个表达式一样，单个例子通过也容易被误当等价证明。本工具让学员亲自选择有限域、找反例、看到运算类型与优先级，把结论限制到实际完整检查的域。

整数用BigInt精确计算，可区分Number安全整数范围外的相邻值。运行失败与结果不等是不同问题，两个表达式同样超界也不能算一致；取消后的部分一致同样不能宣称整个域等价。本工具只是有限表达式教学，不做一般程序验证、源码重构分析或域外证明。

## 3. 实现方式与精确语义

`meta.json` 供工作台发现；`index.js` 提供同步create与生命周期；`model.mjs` 提供lexer、precedence parser、有类型AST、解释器、域枚举/取消和报告；`style.css` 使用现有主题变量。无eval、Function、动态用户JS、属性/函数访问。用户文本通过h/textContent/value显示。

### 输入域与容量

变量1–3个，名称仅x/y/z、不得重复。每域1–100唯一值，以空白或逗号分隔，只能整数或true/false；同变量不得混整数/布尔。整数输入绝对值≤1000000，-0规范为0，因此-0与0会视为重复。不接受小数、指数、字符串、对象、null。不同变量可以有不同类型。

Cartesian积≤10000，超过拒绝整个分析，不抽样或截断。所有配置变量均参与枚举，包括表达式未使用的变量；按照变量行顺序，最后一行变化最快。表达式及每域文本各≤2048 UTF-8字节，token≤128，AST深度≤32，括号嵌套另限32。AST深度按叶1、父节点加1计算；连续一元/左结合链也计入深度。

### 操作与优先级

| 操作 | 类型语义 |
| --- | --- |
| 整数字面量/true/false/变量 | 字面整数0–1000000，负数由一元负号表达；变量类型由完整域确定 |
| 一元+/- | 仅整数，禁止布尔转数值 |
| 一元! | 仅布尔，禁止数字truthiness |
| + - * | 两侧均整数，BigInt精确加减乘 |
| < <= > >= | 两侧均整数，输出bool |
| == != | 两侧须同类型，严格比较，不隐式转换 |
| && \|\| | 两侧均bool，按布尔短路执行 |
| 括号 | 只改变组合/优先级，不执行代码 |

优先级从高到低：一元!/+/-，*，+/-，关系比较，==/!=，&&，||；二元同级左结合。`1+2*3`为7，`10-3-2`为5。比较不能链式表达数学含义；`x<2<3`前一个结果为bool，后续与整数比较会拒绝。

浮点、除法、取模、幂、调用、属性、数组、赋值、三元表达式、JS严格相等语法等均不支持，明确拒绝。两表达式的最终类型可以不同，按全域反例比较，而不是强行把bool与整数互转；例如false与0不一致。

### 静态类型与运行错误

先完成两个AST的全部分支类型检查，再开始枚举。即使`false && ...`的右侧不会执行，也不能写`true+1`。合法类型的&&/||按短路执行；例如`false && (x*x*...>0)`右侧不执行，因此其潜在数值超界不报运行错误。这不是忽略类型问题，而是类型检查和实际运行分开。

每个算术/一元整数中间结果的绝对值最多128十进制位，符号不计；超过返回该侧`{ok:false,error}`。中间乘法最多临时形成256位整数后立即校验，不能继续无限增长。输入和字面量本来已有±1000000限制。零的位数按1位。

分类规则：任一侧运行错误→runtimeError；两侧都ok且type/value完全一致→match；其余→counterexample。错误不等同于任何结果，两侧相同错误也不当match。静态语法/类型失败阻止整局，旧结果清空，不产生“正常穷举完成”统计。

### 让出、取消、展示与结论

每50个输入汇报进度并让出事件循环；每行检查取消信号。最多10000行，全部穷举不抽样。取消保留实际检查行、完整声明域、checked/total，status=cancelled/complete=false，结论“未完成，不作域内等价结论”。完成有运行错误时不能判等价；完成无错误且全部match也只说明指定域内一致，绝不证明域外。

分类筛选/20行分页只影响UI，完整报告仍保留全部已检查行。结果表逐行展示变量类型/值、左右准确结果或错误、分类。AST显示运算/字面量/变量与节点类型。运行中输入禁用；输入编辑/示例切换清掉旧AST和反例，重新分析。

### 保存、生命周期与副本

配置键`features.L030.state`、schemaVersion=1，只存两表达式和变量域草稿，不保存AST、进度或结果。保存前TextEncoder测整个JSON≤64KiB UTF-8，再查字段限额；恢复先检查完整原始体积和版本，未知大字段不会被提前剥离后绕过上限。草稿允许暂时语法未完成，但须满足结构/容量。

输入编辑250ms合并保存；切走会abort并释放等待计时器，保留部分报告而不继续后台运行；销毁同样终止、释放、清DOM，异步完成不回写已关闭DOM。取消后重新开始会重算，不续跑旧局。超限不写配置并提示导出，关闭只能恢复较早草稿；重开结果必须重新检查。

导出检查saveTextSupportsCopyOnly===true，发送copyOnly:true，生产writer采用wx拒绝已有目标。仅响应ok===true算成功，取消/未知成功/错误分别提示。JSON完整包含域、类型AST、所有已检查行与状态；Markdown完整记录同等数据，转义HTML并动态选择代码围栏。部分/运行中报告不会把未检查行补造为通过。

## 4. 使用步骤与具体例子

### 核心反例

1. 打开“功能工作台 → L030 表达式等价挑战”，默认x*x与x，域`-1 0 1 2`。
2. 点击“开始完整穷举”：完整4/4，一致2、反例2、运行错误0。默认仅反例显示x=-1时1/-1，x=2时4/2。
3. 结果筛选改“全部已检查”，显示四行；再改“仅反例”，导出仍含全部四行、完整域与AST，不只导出可见行。
4. 右式改x*x，旧结果清空；重新检查全部一致，但结论仍限定这四个输入。

### 布尔与优先级

点击“载入德摩根真值表”：`!(x && (y || z))`与`!x || (!y && !z)`，x/y/z均false true。8行全一致；改筛选全部可读完整真值表，左右输出依次true,true,true,true,true,false,false,false。不能从这条有限真值枚举扩展到未支持的其他语言或对象运算。

“载入优先级示例”比较`x + 1 * 2`与`(x + 1) * 2`，原四值域中只x=0一致，其他三反例。类型AST展示各自括号组合。

### 精确数值、错误与短路

将x域设1000000、左x*x*x、右x*x*x+1：结果1000000000000000000/1000000000000000001是反例，BigInt不会丢掉+1。若左右均为22个x连乘，133位中间结果超界，显示运行错误1、一致0，不当等价。

`false && (true+1==2)`静态拒绝类型不匹配。22个x连乘后比较>0属于合法bool AST，在false &&右侧会短路不执行，和false比较可一致；改true &&就实际计算并报超界。

### 大域与取消

增加y，x/y各输入0至99的100个整数，左x+y、右y+x，共10000行。开始后完成10000/10000，筛选全部可分页至500页，导出仍含全部10000行。运行中点击取消保留实际完成的前缀，状态明确部分；切走同样停止，不宣传未完成域已等价。

## 5. 产出

界面包含完整声明域与类型、checked/total、match/counterexample/runtimeError计数、有限域结论、有类型AST、分页分类结果表。每反例保留完整变量赋值和左右类型/值；运行错误分别保留两侧ok/error。

JSON为`{feature,schemaVersion,modelVersion,exportedAt,draft,result}`；result有input、compiled（域/AST/token数）、status/complete、total/checked、分类计数、rows与conclusion。整数值按十进制字符串输出并标type=int，避免JSON数值精度丢失；bool保持真实布尔值。无有效分析时result=null，未完成只包含实际已检查行。首版没有导入、自动创造输入域、任意程序对比或证明域外等价。
