# E019 分形画廊

## 1. 功能内容与必要性

按照 `docs/feature-planning/entertainment.json` 的 E019，实现 Mandelbrot / Julia 的离线探索、框选缩放、拖动平移、迭代和配色控制，以及固定 1920×1080 PNG、完整参数 JSON 和可复现参数链接。它适合用一个明确区域反复调色，保留喜欢的画面并再次计算。无需账户、网络、AI、摄像头或麦克风。

预览固定640×360，完整图固定1920×1080。两者使用同一数学与颜色规则，但采样点不同，因此预览不是完整图的逐像素缩小副本。必须先生成完整图才能保存PNG；不会悄悄把目标尺寸改小。没有随机参数、自启动计算或后台播放。

## 2. 实现方式与明确规则

`model.mjs` 提供纯参数验证、复平面映射、整数逃逸配色和固定可信Worker源码；`worker.mjs` 在真正的模块Worker中逐行计算；`index.js` 使用本功能的控件、Canvas和生产文件桥。create/activate不计算，用户点击才创建Worker。取消、隐藏、离开、销毁、超时终止Worker并废弃未完成图像，没有主线程计算回退。每16行报告进度，默认60秒超时；降迭代或改范围后可重新计算。内存只存一张完整RGBA与暂时导出画布，有界到2,073,600像素，不保留历史图像；最近30份参数可撤回，超过后丢弃最早参数历史。

采用JavaScript Float64：Mandelbrot从z=0开始、c取采样点；Julia从采样点开始、c为用户固定实部/虚部。每步按固定顺序计算z²+c，更新后平方模严格大于4才记录第1至N次逃逸；迭代上限内未逃逸用“未逃逸色”。这只是有限迭代图像，不是无限集合归属证明。像素(x,y)采样中心：实部 `xMin+(x+0.5)*(xMax-xMin)/width`，虚部 `yMax-(y+0.5)*(yMax-yMin)/height`，图上方虚部较大。

三个RGB颜色节点在256项色表的0/85/170处，255回到第一个颜色；各段85步线性插值并Math.round。逃逸颜色索引为 `(逃逸次数*11+配色相位)&255`。所有像素alpha=255。相同规范参数、尺寸、算法与同一数值环境可得到同RGBA；PNG字节受编码环境影响，不承诺跨引擎极限边界、任意深度缩放或跨OS字节一致。

所有坐标和Julia常量限制−4至4，两个轴跨度至少1e−9；迭代32–2000整数，配色相位0–255整数，颜色为小写 `#rrggbb`。框选四边对应新复平面范围，支持反向框选，两个边都至少4个图像像素，不强制16:9范围，因此固定16:9图像可能非等比显示。平移按实际位移改变范围；整体越过坐标限制拒绝，拖出图面取消整次操作，不自动夹紧。没有宣称无限精度、实时无延迟、平滑逃逸或数学最优选区。

## 3. 如何使用与恢复

进入娱乐工作台的“分形画廊”，点击“生成640预览”。选择Mandelbrot或Julia，填写实/虚轴范围、Julia常量、迭代次数，选择三种渐变色、未逃逸色和相位，然后点击“应用参数并生成预览”。输入改变立即废弃旧图与旧链接，导出暂时禁用；“撤回未应用输入”返回已应用参数，需要重新生成图。

在“画布交互模式”选择框选放大或拖动平移，用主鼠标按钮拖动；按Esc、丢失capture或移出图面撤销本次拖动。也可使用中心放大/缩小2倍、手工坐标或聚焦画布后的方向键：按方向移动观察中心10%范围，Shift为20%。这些键操作与鼠标操作均先验证完整范围。鼠标指针坐标根据Canvas实际显示矩形换算，而不是假定CSS尺寸等于图像尺寸。

点击“生成1920完整图”，等进度全部完成后查看完整画布并保存PNG。计算期间其它来源和导出控件锁定，“取消分形计算”仍可用。隐藏/离开会终止计算，回来不会自动续算；已完成的图可在面板仍存在时保留，具体功能被销毁或窗口重载后不保留。**参数不会自动写入config**，需要显式另存JSON以继续上次探索。

恢复时用“分形参数JSON”选择已保存的UTF8文件（1字节至64KiB），核对“待应用参数”，点击“应用导入参数并预览”。拒绝未知schema/字段、缺字段、重复键、非法范围、非UTF8、超限和非规范数值词法；例如`1e0`、`-0`、`0.10`与超精度十进制拒绝，保存器输出的 `JSON.stringify` 数值词法可直接恢复。界面数字输入按Number解释后会显示实际规范Float64值，导入不会宽松吞掉超精度数字。

可将参数片段或包含片段的完整链接粘贴到“粘贴参数链接”后应用。只解析`#E019=`之后的有界JSON，**不会访问所粘贴地址**。如果先另存离线查看器HTML，界面显示当前本机文件路径加参数片段；没有获得保存路径时提供片段。选中后由用户手动复制，无剪贴板授权调用。

## 4. 使用后产出与安全副本

完整JSON含schema、两种分形模式、四个范围边界、Julia常量、迭代次数、配色相位、三个颜色和未逃逸色，不含大图像、网络地址或缓存。JSON≤64KiB，HTML≤64KiB，PNG≤10MiB；超限整体拒绝，不截断或降低尺寸。完整PNG是1920×1080不透明画面，无界面按钮、选择框或进度层。

离线HTML是一个单文件查看器，内嵌完整参数、固定算法和可信BlobWorker源码；没有外部脚本、字体、图片、imports、fetch或用户JavaScript。CSP只允许正文脚本的SHA-256与BlobWorker，禁止网络连接。双击打开时只加载参数，手动点击“生成/重新绘制”再绘图；可选择640或1920尺寸。链接片段可贴到查看器的“应用链接并重画”，也可用该文件路径加片段打开。隐藏或pagehide终止计算，返回手动重画。

此链接依赖本机HTML路径，不能当成公开网页或已注册的工具箱深链接。分享时同时提供HTML和参数片段，接收方在其本地查看器粘贴片段即可复现；文件移动后旧路径需更新。查看器允许选择链接供手动复制，没有绕过原生副本保存的浏览器下载入口。

原生JSON/HTML使用 `files.saveText({copyOnly:true,...})`，PNG先对完整原字节计算SHA-256，再使用 `files.saveBinary({copyOnly:true,...})`。必须具备对应 `SupportsCopyOnly===true` 能力，成功只认 `ok===true`；取消、失败、字符串“true”或partialPath均不报成功，后者提示人工核对。原生保存期间锁定来源变更，生命周期token阻止晚到结果重画或再发写入。已有目标由生产WX写入器拒绝，源参数与已有产物不会覆盖。依赖公共二进制安全桥（已在本功能基线a80中），未更改共享接口或package。

## 5. 具体可重现例子

默认Mandelbrot范围是实轴−2.6至1.4、虚轴−1.125至1.125。将最大迭代次数改为64并应用，生成1920图，另存完整JSON和PNG。重载窗口，选择该JSON并应用，再生成1920图，RGBA应逐像素一致；本机验收PNG的SHA也一致。然后将模式改为Julia，常量保留−0.8+0.156i、相位设85并应用，生成和保存完整Julia图。

在640×360图像逻辑坐标从(160,90)框到(480,270)，得到实轴−1.6至0.3999999999999999、虚轴−0.5625至0.5625；从反方向框选相同。CSS缩放和实际鼠标整数坐标会带来少量选区差异，应以界面显示/导出参数的完整范围为准。点击“撤回上一参数”恢复旧范围。平移逻辑64×36像素后，实轴最小变−3、虚轴最小变−0.9；不要把平移方向与观察中心键盘方向混淆。

另存离线HTML后复制本机参数链接，用浏览器打开会显示“离线参数已载入，手动点击生成”。选择1920完整图并点击生成，可得到同参数相同RGBA；将另一组Julia片段贴到“应用参数链接”，点击应用会切为对应Julia图。取消一次2000迭代的密集区域计算，仍可选择默认范围并重新生成；离开再返回不会偷偷重新计算。
