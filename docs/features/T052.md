# T052 环境变量契约验收

## 1. 功能内容

本机接收 .env 文本/严格 UTF-8 文件、有限契约 JSON 和应用引用名称列表，检查必需缺项、未知环境项、类型/范围/枚举失败、重复定义和引用关系。契约支持 string/int/number/bool/enum 五种有限类型；结果只含合法变量名称、状态、错误码和 .env 行号。JSON/Markdown 完整报告先预览，再保存新副本。

环境与契约正文默认只在当前面板内存，未显露时 textarea.value 为空，通过显露按钮才能编辑源文本；验收、读文件、隐藏和暂停会遮蔽。结果、预览和导出不含实际值、实际长度、枚举选项、契约正文、源行或错误上下文。不执行 shell、变量插值或命令替换，不读取 process.env，不上传、不访问网络、不写配置、不新增依赖。

## 2. 为什么需要

部署缺变量、数字范围错误或误拼变量名可能在运行后才暴露。契约能提前明确必须有哪些变量及值的形态；应用引用列表补充实际使用的名称，帮助发现引用无契约和引用缺值。

必需约束和应用引用各自检查：必需 TOKEN 即使没有出现在完整引用列表中也仍需存在；未引用提示分必需与可选，不把“未引用”当成可以忽略 required 的理由。重复定义不采取后者覆盖，否则不同 dotenv 解析器可能读取不同值。敏感值和枚举选项留在手动源编辑边界，报告只携带定位与错误码，可交给同事核对而不附原值。

## 3. 实现方式

- 元数据“工具 / 开发转换与生成”。`index.js` 同步 create 返回 activate/deactivate/destroy，真实界面使用公共 h() 文本节点，样式局限 `.feature-t052`。独立 model.mjs 解析与验收，不引用其他功能或 Node 执行接口，不改 main/preload/shared。没有全局 config 写入、保存秘密的草稿或任务历史。
- 每种输入最多 1 MiB UTF-8；环境最多 1000 个定义（重复也计数），契约 1–200 变量，引用最多 1000 个名称行（重复也计数）。环境/引用最多 5000 物理行、单行 65536 字符。超限整体拒绝，无截断。JSON 最大 8 层、20000 值；报告完整输出最多 4 MiB。所有值留当前内存，不把输入大小或值长度写入产品报告。
- 名称固定为大小写敏感 `[A-Za-z_][A-Za-z0-9_]{0,99}`，无需推测宿主大小写规则。.env 接受 LF/CRLF，拒绝单独 CR、非法控制和未配对 Unicode；只逐物理行解析，不支持物理多行值、BOM、连接续行或完整 shell 语法。空行/注释行忽略；可选前导空格和 `export `；KEY 前后空格可用，赋值必须有 `=`。
- 未引号值去除首尾空格/制表符；`#` 在值开头或前面有空格/制表符时启动注释，所以 `A=a#b` 保持 a#b，`A=a #注释` 是 a。单引号保留内部字面字符与反斜杠；双引号只解释 `\\`、`\"`、`\n`、`\r`、`\t` 五种转义。关闭引号后只能空格/可选注释；不支持的转义、未闭合、引号后垃圾、未引号中引号分别给错误码。引号内 # 是内容。物理换行不跨行配对，双引号的 `\n` 可表示逻辑换行。
- 解析值后拒绝 `${...}`、`$(...)`、`$NAME` 及反引号，所有引号模式一致，不求值、不替换、不执行。`$5` 等未识别为插值的字面值保留。注释不作为值解析。合法 KEY 的错误定义保留名称/行号并阻止验收；不合法行只报告行号/错误码，不显示原行或非法名称。重复 KEY 保留全部物理行号，不能选择其中任一值做类型检查，报 duplicate_definition。
- 契约格式固定 `{format:'T052-contract',version:1,variables:[...]}`，每项 name/type/required 必填，required 必须布尔；变量名唯一。string 仅允许 nonEmpty（布尔）、minLength/maxLength（0–65536 整数），nonEmpty 按 trim 后非空，长度按 Unicode 码点；int/number 仅允许 min/max（必须有效、范围顺序正确；int 边界安全整数）；bool 无附加参数；enum 必须 values 数组 1–50 个唯一字符串，每项最多 1024 字符，选项可以敏感。未知/缺失关键字、不支持版本、类型错误和重复 JSON 字段（含转义后同名）拒绝，错误不携带字段值。这不是 JSON Schema，不支持 pattern/default/oneOf 等。
- int 值仅有可选正负号和十进制数字，须 Number.isSafeInteger；可有十进制前导零，不接受科学计数、十六进制或小数。number 允许十进制小数及科学计数，必须有限，不接受空串、NaN、Infinity 或十六进制。bool 只允许小写 true/false；enum 精确字符串匹配。类型、数值/长度范围或枚举失败只导出错误码，不含实际值、实际长度或选项。可选未提供给 optional_absent，必需空字符串在 nonEmpty 约束下失败。
- 引用列表仅每行一个名称，可有空行和 # 注释行；不是应用源码扫描。显式勾选“启用完整引用列表核对”才检查使用关系，未启用不从未提供/空列表推断全部未使用。启用且空列表代表用户声明完整应用没有引用；仍检查 required。重复/非法引用给行号与安全错误码；读取引用文件时若存在非法行或重复，拒绝放进显示控件，避免误把源值文件当名称列表。手动输入引用原文则是用户可见的源输入，报告仍不含非法行内容。
- 合并契约名、识别到的环境名和启用的引用名生成一条名称记录：unknown_env、referenced_not_contract、referenced_missing_env、unreferenced_required_contract/unreferenced_optional_contract 分开计数。必需缺项 missing_required 与使用关系独立；语法无效和重复定义不参与值检查，给 env_syntax_invalid/duplicate_definition。解析问题完整单独列出，不伪装全部输入成功解析。
- 报告 format 为 T052-report v1，records 每条仅 `{name,status,codes,lines}`；issues 仅 source/line/code 和可选合法 name；其余为不含值的固定 notice、是否启用引用、总体计数和 accepted。accepted 表示无错误记录/解析问题；unknown 与未引用等警告不会解除必需约束，也不使输出等同“全部部署条件满足”。界面明确显示警告数，不隐藏警告。变量和问题每页 50，JSON/Markdown 导出完整，Markdown 对名称中的下划线转义。
- source editor 私有内存保存字符串，默认空 value/readOnly。手动显露会把正文放进 DOM，用户可编辑；遮蔽时从控件 value 移除，验收/读文件/隐藏/暂停均再遮蔽。浏览器输入和调试器可能曾留存原值，遮蔽不是加密、进程隔离或安全擦除；清除/销毁仅释放引用。枚举值可能敏感，所以契约正文同样默认遮蔽。引用列表本身是用户提供的名称源输入，不声称手动输入框里从无原文。
- File API 每 64 KiB 读取 UTF-8，核对实际字节数，fatal 解码；清除旧的对应源数据后读新文件，失败不会默默验收旧源。编辑、清除、取消、隐藏/暂停/销毁使旧票据失效；每 50 名称让出事件循环并检查取消，读取返回后也检查。JSON 与文本解析内部是有界同步阶段，不能中途抢占，不承诺大包性能。已完成安全报告同面板暂停恢复保留，切换功能清除私有源/报告和监听，不自动验收或导出。
- 报告必须先完整预览，再用生产 `files.saveText({content,extension,defaultName,copyOnly:true})`，检查 saveTextSupportsCopyOnly。生产 writer 独占创建，已有目标拒绝；实际路径由保存对话框确认。仅 ok===true 成功，canceled/false/undefined/异常保留预览且不显示内部错误上下文或秘密。原生保存确认后的副本写入无法由 UI 取消票据撤回。

## 4. 如何使用

1. 默认示例契约已在内存：PORT 为必需 int 1..65535，TOKEN 为必需非空 string。可点“显露并编辑契约”查看/修改有限 JSON，再遮蔽；或读契约文件。
2. 读取 .env 文件，或“显露并编辑 .env”粘贴内容。文件读入后值不会自动出现在控件，手动显露编辑需自己确认本机分享/录屏范围。
3. 若要核对应用使用，逐行填名称、勾选完整引用列表；没有列表不勾选。引用文件必须仅合法名称，不能粘贴环境值或代码文件。
4. 点击“离线验收（遮蔽所有源值）”，查看必需、引用缺项、未知项、未引用和具体错误码及行号。重复定义修改源文件后重新验收；解析问题没有上下文回显，手动显露源可定位该行。
5. “预览完整 JSON/Markdown 报告”，核对合法名称是否适合分享，再保存新副本；已有源/目标文件不能覆盖。取消/失败预览保留，不算成功。
6. 编辑/引用范围变化废弃报告；读新文件失败不会使用旧对应源。清除/切换前保存需要的安全报告，源文件自行保存，本工具不导出环境或契约正文。

## 5. 使用后产出

遮蔽 JSON/Markdown 报告包含每个名称的状态、错误码、定义行号；解析问题只携带安全位置/代码；总体计数区分必需缺项、引用缺项、未知环境、引用无契约、未引用必需/可选。没有实际值、值长度、枚举选项、原契约正文、原行上下文或错误堆栈。

报告创建新副本，原 .env/契约/引用文件不改动。不会应用变量到 shell、生成进程环境、连接服务、认证令牌、检验实际运行部署或证明秘密来源。变量名称和状态本身仍可能敏感，分享前用户核对范围。

## 6. 具体例子、验证和限制

“演示：只有 PORT”使用 `PORT=8080` 与默认契约。结果 PORT 为 pass / ok / 行 1，TOKEN 为 error / missing_required / 无定义行，必需缺项 1，accepted false。报告不包含 8080，读取 TOKEN 值不为补缺项自动访问 process.env。

“演示：重复与引用”环境两行 PORT，再有 EXTRA；完整引用 PORT 和 NEW_NAME。PORT 报 duplicate_definition 并列行 1,2，不选后者；TOKEN 同时 missing_required 与 unreferenced_required_contract；EXTRA unknown_env；NEW_NAME referenced_not_contract + referenced_missing_env。不因为 TOKEN 未引用就忽略 required。禁用引用核对后使用相关提示不再推断，环境与契约问题仍在。

引号例 `A=a#b` 与 `A="a#b" #外部注释` 都解析为含 # 的字符串；`A=a #注释` 为 a；`A='one\nline'` 是反斜杠字面值，`A="one\nline"` 有逻辑换行。`TOKEN=$(cmd)`、反引号、`${TOKEN}` 和 `$TOKEN` 在单/双/无引号都报 interpolation_not_supported，不执行。TOKEN 未闭合引号只报告行号和 unterminated_quote，不输出那行的秘密内容。

枚举契约 values 放入人工敏感哨兵并给 MODE 不允许的另一个哨兵，结果只有 enum_not_allowed，没有实际值或允许选项；允许枚举值成功也不导出该选项。File API 读入这两个源后默认 DOM/input.value 不出现哨兵；手动显露时会出现，遮蔽/验收/暂停后移除。测试核对这一区别，不把源编辑框描述成永远无正文。

29 项专项：`node --test test/feature-T052.test.js`，17 模型 +12 UI，覆盖样例、注释与引号/转义/插值、重复名称与物理行、类型/安全整数/数字范围/非空/Unicode 长度/枚举、独立 required 与引用、引用非法/重复、严格 JSON/未知关键词/范围/容量/编码、1000 定义完整输出、取消，真实 h() UI 事件、默认私有与手动显露边界、值及枚举哨兵不进入 DOM 结果或报告、copyOnly 与 ok:false/undefined/canceled/throw、文件失败废弃旧源、分页和生命周期。DOM 适配器不是原生证据；生产 preload/IPC/writer 的隔离 Electron 验收另行追加。未新增依赖或反复执行无关缺依赖全库失败项。

限制：有限 dotenv 和有限契约，不支持 shell 求值、完整 dotenv 方言、多行/续行、JSON Schema、任意用户正则、进程/容器环境、实际应用扫描、网络服务验证或秘密加密保护。相同字符串在变量名称位置可被合法名称报告；本功能只能分辨数据角色，不能自动判断名称是否秘密。输入/输出有界不代表总进程内存或解析瞬间性能承诺，清除不承诺物理擦除。
