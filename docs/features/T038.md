# T038：文字配色对比度检查

## 功能内容

在功能工作台“工具 → 图片与视觉素材”中，输入一组或多组文字前景／背景颜色、最终字号 pt 和粗体状态，计算文本对比度、判定 AA 文本阈值、预览文字，并为未通过的配色提供可应用的前景调整候选。结果可导出为 JSON 报告副本。一次最多 40 组，无需联网、AI 或新依赖。

## 为什么需要

好看的配色可能让正文难以阅读。已有科研图板用于绘图编排，在线工具入口需要选择外部网站；这个功能为本机交付素材提供直接的文本配色检查和可保存报告。它不把“配色通过”当作整张图或整个应用的无障碍合规结论。

## 实现方式

纯 `model.mjs` 校验不透明 sRGB 十六进制颜色，线性化三个颜色通道，计算相对亮度及 `(较亮值 + 0.05)/(较暗值 + 0.05)`。判定使用完整数值，展示值保留三位小数。字号至少 18pt，或至少 14pt 且粗体，使用大文本阈值 3；其余使用普通文本阈值 4.5。

未通过时，沿前景到黑色及白色的两条插值路径做有限搜索，选取验证通过的候选；不修改背景，不承诺全色域最小改动。应用候选后重新检查。各行独立报告错误，报告保留未经四舍五入的对比度、阈值、输入和候选。

计算与字号阈值依据 [W3C WCAG 2.2 对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)。用户输入只以文本显示，颜色预览只使用校验通过的标准化颜色。副本输出依赖公共工作台的 `copyOnly:true` 安全保存接口，已有目标不会被覆盖。

## 如何使用

1. 打开“功能工作台”，搜索 T038 或文字配色，选择该功能。
2. 直接编辑前景、背景或使用取色控件。填写最终呈现字号，勾选粗体；界面单位是 pt，不是 px。
3. 点击“添加配色”检查更多组，或点击“载入示例”。
4. 点击“检查配色”，查看结论、阈值和预览。点击调整候选旁的“应用到前景”会替换该行并重新计算。
5. 点击“导出 JSON 报告副本”，选择不存在的新文件名。取消保存不会报告成功；旧后端缺少安全保存能力时明确阻止导出。
6. 切换功能会关闭面板，先导出需要保留的报告。

## 使用后产出

结构化 JSON 报告包含格式版本、功能编号、标准来源、范围限制、每组输入、完整精度对比度、大小文本分类、阈值、通过与否、候选或输入错误。输入改变后旧结果清空，避免导出与当前输入不一致的报告。

## 具体例子

点击“载入示例”：

| 名称 | 前景 | 背景 | 字号 | 预期 |
|---|---|---|---|---|
| 黑对白 | #000000 | #FFFFFF | 12pt 普通 | 21:1，通过 4.5 阈值 |
| 普通灰字 | #777777 | #FFFFFF | 12pt 普通 | 约 4.478:1，未通过，提供前景候选 |
| 大号灰字 | #777777 | #FFFFFF | 18pt 普通 | 相同对比度，通过 3 阈值 |

把第二组改为 14pt 粗体后也通过大文本阈值；输入 `#7777` 会报告透明颜色不支持。导出 `文字配色对比度报告.json` 包含三组详细结果。模型验收另外验证 4.499 的普通文本不会因显示精度而误判通过。

## 验证与限制

定向模型测试覆盖黑白 21:1、相同颜色 1:1、阈值不舍入、字号边界、同色不同文本分类、透明与注入输入拒绝、候选实测达标、批次错误隔离和报告序列化。浏览器交互及集成结果由 PR 验收记录补充。

首版仅支持 #RGB／#RRGGBB 不透明 sRGB。透明、渐变、图片背景、特殊字体和抗锯齿效果不在算法检查范围内；pt 需要是最终呈现字号。没有扫描整个页面或 PDF，也不评价完整无障碍合规。没有原地改写素材或自动发布。
