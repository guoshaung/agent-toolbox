# T028 办公文档元数据清理

## 1. 功能内容

选择本地DOCX或PPTX，完整检查有限ZIP/OPC/XML结构，列出核心/扩展属性及支持状态。逐项选择需要移除的属性，在内存生成完整改动报告和输出文档，核对相对路径/字节/SHA后明确保存到全新的副本目录。默认不选任何属性、默认遮蔽原值，可主动勾选“显示原属性值”核对；预演后再次隐藏原值。无需AI、网络、Python或安装Word/PowerPoint。

支持15个核心属性：creator作者、lastModifiedBy最后修改者、title标题、subject主题、description属性说明、keywords关键词、category分类、contentStatus内容状态、identifier标识、language语言、revision修订号、version版本、created创建时间、modified修改时间、lastPrinted打印时间。另支持app.xml中的4个标量扩展属性Company、Manager、Template、HyperlinkBase。只列实际存在的属性，空属性元素也可移除。未知属性、HeadingPairs等复合属性或不支持属性结构明确列为unsupported并原样保留，不提供不可执行的选择框；其他docProps部件也完整列为unsupported_kept。

## 2. 为什么需要

文档核心属性可能包含作者/修改者姓名、公司或模板路径，直接发出副本会一并携带。逐项选择能只移除本次不需要携带的属性，保留未选择的信息，并提供可核对的完整改动范围。这里的description是文档属性说明，不是正文批注；不会通过删正文、演讲备注、批注或整段部件来假称“清理成功”。作者也可能出现在正文、批注作者、修订、关系、缩略图、自定义属性等，本工具没有全文个人信息清除保证。

## 3. 实现方式、依赖及限制

本ID私有`zip.mjs`/`xml.mjs`/`write-zip.mjs`来自同作者T027/T016已验证算法的源码副本，独立固定模块，无跨功能import，不改共享package/lock，不使用第三方发行包或Python运行时库。ZIP先检中央/本地头和路径、声明尺寸/压缩比，再在浏览器解包并检查RFC1951边界、实际字节、CRC和SHA；XML有限token解析不执行DTD/实体/代码或发网络请求。定位按namespace URI和localName，支持前缀别名，重复属性/重复元数据元素整体拒绝，不能以“后者覆盖”清理。

DOCX/PPTX使用过渡版OOXML。必须有完整Content Types、唯一officeDocument关系及匹配word/document.xml或ppt/presentation.xml主根；核心/扩展属性关系必须绑定标准docProps/core.xml及docProps/app.xml，声明类型匹配。关系源、内部目标和XML中r:id/embed/link引用须存在；正常外部超链接关系原样保留、不访问，根主/核心/扩展部件外部关系拒绝。宏、ActiveX、嵌入对象、数字签名、附加模板、altChunk及相关类型明确拒绝，避免清理后错误声称仍保留签名或完整功能。未知普通部件内容原字节保留，不对全文身份风险作自动清理。

核心/扩展部件必须匹配正确根，支持字段须为叶元素，仅允许普通namespace声明/xml:space/xml:lang及日期的xsi:type；复合或其他属性结构标unsupported_kept。实际清理按原XML元素起止偏移删除选中元素，不重新序列化未选属性；未选属性元素、其余原XML区域保持原字符串。再解析并确认选中expanded name不存在。没有对正文、备注或未改部件的编辑操作；每个ZIP部件的前后尺寸和SHA进入完整审计。输出ZIP容器重新创建为Store和固定时间信息，保留每个非修改部件的数据字节，不承诺原ZIP压缩、时间、权限、注释或显式目录记录逐字节不变。

边界：输入ZIP≤2MiB、实际展开≤2MiB/100文件；一般XML≤1MiB/30,000节点/深度60，docProps XML≤64KiB；核心+扩展属性≤100项、单标量值≤4096字符。输出完整办公文件≤2MiB，报告≤2MiB，包内任意不支持项或容量溢出整体拒绝，无截断。普通单卷Store/Deflate、ASCII/UTF-8路径；加密、ZIP64、数据描述符、extra字段、特殊文件/链接、危险路径、NFC/大小写/文件目录冲突和空目录记录整体拒绝。Deflate需浏览器支持DecompressionStream('deflate-raw')，缺少时明确拒绝。XML限UTF-8/XML1.0、ASCII QName、普通元素/属性/注释、合法预定义/数字实体；DTD、自定义实体、CDATA、其他处理指令、保留命名空间误绑定、重复expanded属性、未闭合/非法Unicode整体拒绝。这是有限解析器，不是完整OOXML XSD/排版/身份审计工具。

15秒是协作期限，并非同步解析/系统I/O硬中止；读文件/解码/SHA后检查取消票据。修改输入清空旧检查/选择/输出，修改选择废弃旧预演；隐藏/deactivate/destroy取消内存处理，隐藏属性值并清除源模型/DOM/结果，不存大字节config。已经交给主进程的保存不能中途撤销或自动回滚，可在保存对话框取消；切走不会发起额外保存。

生产依赖a80e115公共基础的`files.exportBundleSupportsCopyOnly`/`exportBundle(copyOnly:true)`及`saveTextSupportsCopyOnly`/`saveText(copyOnly:true)`。固定输出metadata-cleaned.docx或metadata-cleaned.pptx加report.json，不继承源文件名；renderer不能指定任意目标路径，保存对话框返回新目录后由实际writer独占创建。已有目录、选回源文件或已有报告拒绝；`ok===true`才成功，false/undefined/throw/canceled不能显示成功，正常失败保留预演。清理失败partialPath显示人工核对位置，正常writer失败只清理本次目录；不保证断电/崩溃事务。

官方格式依据：[ECMA-376与OPC](https://ecma-international.org/publications-and-standards/standards/ecma-376/)、[Microsoft核心属性接口和OPC来源](https://learn.microsoft.com/en-us/windows/win32/api/xpsobjectmodel/nn-xpsobjectmodel-ixpsomcoreproperties)、[PKWARE APPNOTE](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT)、[RFC1951](https://www.rfc-editor.org/rfc/rfc1951)、[XML1.0](https://www.w3.org/TR/xml/)。开发oracle依据[python-docx文档和core_properties](https://python-docx.readthedocs.io/en/latest/api/document.html)、[python-pptx备注接口](https://python-pptx.readthedocs.io/en/latest/user/notes.html)，这两者不进入产品运行时。

## 4. 如何使用

1. 功能工作台→工具→办公文档元数据清理，选择一个.docx/.pptx，点击“检查文件和属性（只读）”。
2. 核对所有字段支持状态。需要看原值时勾选“显示原属性值”；未知/复合字段不可选择，仍保留在文档。
3. 只勾选实际需要移除的字段，如“移除 core.creator”。不勾选的lastModifiedBy、标题和其他属性保持；不做隐式“全选”。
4. 点击“预演移除选定属性（仅内存）”，检查完整报告中的removed/kept_unselected/unsupported_kept和每部件SHA、两个输出路径。没有正文或备注排版预览，也不需要通过删内容清理。
5. 点击“确认创建清理副本新目录”，在保存对话框输入尚不存在的目录名。也可单独保存已预览完整报告新副本。任何编辑选择后必须重新预演。
6. 隐藏或切换后重新选择输入，内存不保留秘密；已生成副本不会因切换而删除。后续办公软件另存文件可能再次加入作者属性，需按新的实际文件重新检查。

## 6. 具体可重放例子

制作普通DOCX，正文“培训正文保持”；文档属性作者为“张三”，标题“培训说明”，最后修改者“李四”。检查→主动显示原值核对→只选core.creator→内存预演：creator为removed，title和lastModifiedBy为kept_unselected，其余部件全部unchanged_content_bytes。确认保存新目录后creator元素缺失，原标题/修改者存在，Word正文、表格和批注等部件原字节不变，报告不复制“张三”。如果正文或批注本身写了张三，它仍然存在，这不表示清理失败或全文匿名成功。

PPTX同样：一页写“演示正文保持”，演讲备注写“讲者备注必须保留”；作者“张三”、标题“演示说明”。只选core.creator后输出完整PPTX，幻灯片/notesSlides/notesMasters等未修改部件前后SHA相同，备注文本仍在。再勾选另一个属性会废弃旧报告；不重新预演不能保存。将目标选回源DOCX/PPTX或已有目录保存失败，源SHA不变。
