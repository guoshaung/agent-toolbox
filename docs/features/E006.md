# E006 汉诺塔

## 功能和验收

这是可离线完整游玩的三柱汉诺塔，支持 3–6 层。玩家把 A 柱上的全部盘移到 C 柱，每次只移动源柱顶盘，且大盘不能放在小盘上。支持点击、顶盘拖拽、键盘、撤销、单步提示、暂停、重置和完成成绩。

四层模式的理论最少步数为 15。只有 C 柱包含全部四个盘才通关；未完成、中途重开或退出都不产生完成记录。三至六层的理论最少分别为 7、15、31、63 步。

## 必要性和边界

汉诺塔提供规则简单、需要提前规划的短时休息挑战。它直接呈现可操作的搬盘谜题，与已有编程学习题、舒尔特、记忆游戏和桌宠的玩法不同。无需账号、AI、摄像头、音频、网络或新增运行时。

本模块遵循独立功能工作台的 `meta.json` 和同步 `create(root, ctx)` 契约，由工作台发现并加载；无需修改共享注册表、主进程或预加载接口。

## 实现

- `model.mjs` 保存三根柱子（每柱数组从下到上）、阶段、累计合法移动、撤销数、提示数和有效游玩时间。盘数必须是 3–6 的整数；非法移动不改变棋盘、步数或首次计时状态。
- 理论最少使用 `2 ** n - 1`，它只表示初始局面的最少步数。当前最短剩余通过从目标状态反向广度优先搜索得出，单步提示选择距离减少 1 的合法移动。六层最多 729 个合法状态，缓存仅有四种盘数；走错后也能提供正确最短续走提示。
- 撤销最多保留最近 256 次合法移动。撤销不扣已走步数，避免反复试探后把成绩写成理论最少；撤销次数另记。完成后固定成绩并停止移动和撤销，每局只记录一次。
- `index.js` 使用现有 `h` 创建三柱 UI。只允许顶盘开始拖拽，内部拖拽标记包含本局代号，外部内容或重开前的拖拽无法移动盘。点击和键盘同样经过模型校验。
- 首次合法移动启动计时。暂停隐藏棋盘、停止计时；切换功能、工作台退出或页面隐藏会自动暂停，重新进入后须点击“继续”。计时器只在运行中存在，销毁清理监听器、计时器、下载 URL 和节点。
- `style.css` 全部限定于 `.feature-e006`；功能通过自己的样式链接加载，不修改共享样式。

## 使用

1. 在盘数框选择 3–6 层，再点“新局”。“重置本局”重开当前盘数，放弃未完成局。
2. 点有盘的源柱，再点目标柱。再次点源柱或点“取消选柱”取消选择。也可以拖动顶盘到另一柱；触屏可用两次点击。
3. 大盘压小盘会出现说明，棋盘保持原状。源柱仍被选中，可改选目标。
4. 点“单步提示”查看下一步：源柱被选中，目标柱有标记；玩家仍须执行移动。每次请求都会记录提示次数，不自动移动。
5. 点“撤销”撤回最近移动；点“暂停”停止棋盘和计时，再点“继续”恢复。完成后可点记录旁的“重玩”从相同盘数的新局开始。

键盘先 Tab 到棋盘：方向键、Home、End 在三柱间移动焦点，Enter 或空格选柱；数字 1、2、3 对应 A、B、C；U 撤销，H 提示，Esc 暂停。暂停后使用 Tab 到“继续”按钮恢复。

## 产出和记录

每个完整通关产生 `disks`、`moves`、`minimum`、`undos`、`hints`、`elapsedMs` 与 `finishedAt`。最近完成最多 20 条，最佳按四种盘数各保留一条（最多 4 条）；同层先比较合法移动数，步数相同再比较有效用时。使用提示或撤销不禁止记录，次数会明确展示。

记录保存在配置键 `features.E006.scores`；独立打开且没有配置接口时使用本机 localStorage。存储失败仍可继续游玩，当前打开期间的记录可导出。“导出成绩”输出 JSON，包含最近和最佳记录。原生成绩保存接口仅在支持 `copyOnly` 时调用，并请求副本保存；其他环境使用浏览器下载。取消保存不会声称导出成功。

例如四层无提示、无撤销的通关记录可以是：

```json
{
  "disks": 4,
  "moves": 15,
  "minimum": 15,
  "undos": 0,
  "hints": 0,
  "elapsedMs": 14000,
  "finishedAt": "2026-10-02T00:00:00.000Z"
}
```

其中时间和日期仅作示例；自动测试使用可控时钟验证 14 秒，真实手动游玩按实际有效时间记录。未完成局不持久化，关闭功能后不恢复中间棋盘。

## 可重放的操作例子

选择“四层”并点“新局”，初始 A 从下到上为 4、3、2、1，B/C 为空。依次点击每行的源柱再点击目标柱，不使用撤销或提示：

| 步 | 源 → 目标 | 移动盘 |
| --- | --- | --- |
| 1 | A → B | 1 |
| 2 | A → C | 2 |
| 3 | B → C | 1 |
| 4 | A → B | 3 |
| 5 | C → A | 1 |
| 6 | C → B | 2 |
| 7 | A → B | 1 |
| 8 | A → C | 4 |
| 9 | B → C | 1 |
| 10 | B → A | 2 |
| 11 | C → A | 1 |
| 12 | B → C | 3 |
| 13 | A → B | 1 |
| 14 | A → C | 2 |
| 15 | B → C | 1 |

最后 A/B 为空，C 从下到上为 4、3、2、1；显示“15 步完成”、初始理论最少 15、当前最短剩余 0，并新增一条四层记录。这套序列也可用数字键输入源目标，例如前两步为 `1,2,1,3`。

非法移动例子：四层新局先 A → C，再尝试 A → C；第二次要把盘 2 压在盘 1 上，必须拒绝，此时仍为 1 步，A 为 4、3、2，C 为 1。

提示准确性例子：三层新局第一步 A → B，此时已走 1 步、初始理论最少 7，但当前最短剩余仍为 7。继续按提示需再移动 7 步，总成绩为 8 步；剩余不是用初始最少减去已走步数得出。
