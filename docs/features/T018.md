# T018 大目录索引与定位

## 1. 功能内容

为明确选择的一个本地目录建立只读文件元数据索引：普通文件的相对路径、逻辑字节大小及修改时间。按名称／相对路径包含文本、大小上下界和UTC修改时间上下界筛选，每页40条；复制完整文件路径供用户定位。支持两次完整相同范围的增量对比，列出新增、变化、移除及未变文件；显式保存本地索引、窗口重载恢复快照，以及确认删除本工具索引。

完整JSON／Markdown报告包含全部索引、当前扫描、目录／排除／链接／失败记录、全部增量以及筛选命中路径。分页和筛选不截断完整索引。只读元数据，不读文件正文，不跟随链接，不移动、清理或删除来源。

## 2. 为什么需要

在大量文件中反复定位名称或大小、时间范围时，一份可重载的本地索引能供之后筛选使用。刷新后明确列出新增文件，也便于用户发现交付集合变化。将不完整扫描与完整索引分开，取消或权限不足不会把未观察文件误判为删除。

索引是过去观察，文件可能已经改名或变化。复制路径不是再次确认文件存在，也不自动打开或执行文件。大小／mtime相同的内容变化不能识别；本功能不是内容检索、全文索引、实时监视或文件历史。

## 3. 实现方式与范围

自有可信host.cjs通过归属当前窗口的目录对话框选择根，生成窗口绑定rootId。只接受扫描／选择操作，无renderer任意路径入口。根的普通目录身份和规范路径核验后，用lstat／opendir逐层读取；最终文件／目录链接跳过，特殊项跳过，排除相对路径及整个子树在元数据读取前跳过。目录前后dev／ino／mtime和realpath检测普通变化；目录句柄finally关闭。不是抵御恶意路径竞态的锁或原子文件系统快照，普通挂载／驱动器映射的实际存储本地性未知。Windows最终根链接及UNC／设备路径不接受。

最多10000已读取项（文件与目录都计）、1000目录、24层、1MiB累计相对路径、30秒协作期限。取消只能等待当前OS元数据调用返回，窗口busy保持到读取与句柄收尾。容量／取消／权限错误／目录变化提供明确部分报告；部分报告不能替换上一完整索引或断言移除。排除、已跳过链接／特殊项属于明确支持域之外，不伪称这些项也被索引。

model.mjs验证完整索引、做路径键对比、筛选和报告。增量刷新仍遍历当前范围的元数据，然后以Map与上次完整索引比较；没有watcher、目录mtime快捷复用或承诺减少系统扫描。根、平台和有序排除规则必须相同才可对比；不同范围返回不可比，不把全部文件当新增／移除。Windows路径比较不区分大小写，但仅大小写变动作为relative字段变化保留。变化只检查relative／size／mtimeMs。

排除规则每行一个根内精确相对路径，以/分隔，最多32条／4096字节；匹配该项与子树，无glob或正则。名称筛选是相对路径中不区分大小写的字面包含。大小是非负安全整数，UTC边界须规范ISO毫秒且上下界含端点；空字段不限制，错误界限整体拒绝。

完整本地索引紧凑JSON≤2MiB、最多10000普通文件，由用户点击后通过既有Config／Store保存至应用userData/config.json中的feature.T018.index.v1，不新增数据库或依赖。Store使用已有临时文件+rename写入；配置含路径，未加密。重载只恢复经过严格验证的快照，不自动选择根或扫描。删除操作确认后将自己的索引值清为null，不操作来源或已导出的副本。完整报告≤8MiB且不截断，只通过copyOnly:true及wx另存新文件，只有ok===true宣告成功。

## 4. 如何使用

打开T018，点击“选择索引根目录”，每行填可选排除项，例如cache或node_modules。点击“扫描或增量刷新索引”，核对完整支持域／部分状态、文件列表和观察时间。输入名称、大小或规范UTC时间筛选；点击行内“复制完整路径”后可在用户自己的文件管理器回源核对，工具不调用shell打开路径。

同一根和排除规则下再次点击刷新，查看全部新增／变化／移除计数；报告保留对应完整元数据。改变范围后两份观察不可比。想下次继续筛选，点击“保存本地索引到配置”，否则新索引仅在当前模块内存。重载后先查看旧观察日期，再重新明确选择根才能刷新。

点击完整JSON或Markdown报告预览，核对全部本地路径，再保存新副本。已有目标拒绝且保留预览。点击“删除本地索引”并确认，只清本工具索引。隐藏／离开取消当前扫描、清根选择与报告；返回不自动运行。切换具体功能销毁内存，只有显式保存的索引可恢复。

## 5. 使用后的产出与具体例子

根下有a.txt（3字节）、b.txt（6字节）、remove.txt及45个其它文件，共48普通文件。排除cache子树；一个指向根外的link目录跳过。第一次得到48条完整索引，没有可比较上一范围，不能冒称新增48个。

在外部人为修改a.txt为4字节并改变mtime、删除remove.txt、新建new.txt，再点刷新。结果是 **新增1（new.txt）、变化1（a.txt的size与mtimeMs）、移除1（remove.txt）、未变46**，索引仍48条。名称包含new得到1个显示命中，但完整JSON／Markdown仍包含全部48条与全部差异。这个例子中的改变由使用者或开发夹具完成，不是工具修改来源。

取消第三次扫描时，本次scan.complete=false／reason=canceled，旧完整48条保留且delta=null，不给出移除结论。保存本地索引再重载恢复过去48条；重新选择根之前刷新禁用。删除索引不删除b.txt或既有报告。完整报告的index／scan／delta／filters／matchingRelativePaths区分当前快照、本次观察和显示筛选，JSON机器可读，Markdown包含同一完整JSON。
