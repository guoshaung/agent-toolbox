# T035 界面截图差异定位

## 功能内容

选择旧版和新版两张同尺寸截图，设置RGB容差、最少连通区域像素和最多20个忽略矩形。工具实际比较像素，输出完整差异热图、变化面积、编号区域标注图与完整JSON报告。支持屏蔽时钟等动态区域；必须核对全部源图/输出并确认后才能另存新目录。依赖基础工作台、目录和文本副本接口 PR #14；本 PR 只包含 T035 自有文件，不导入其他新增功能，没有改共享依赖或CSP。

## 为什么需要

界面调整后，截图中细小位移或颜色改变容易漏看，而时钟、动态计数会造成大量干扰。先明确屏蔽这些区域，再对同一像素坐标进行比较，可以定位改动位置并留存可复查的图像与面积数据。像素变化不等于缺陷或真实UI元素，结果需要结合界面语境判断。

## 实现方式

- 两张来源各1字节–2MiB，静态PNG或8bit灰度/RGB JPEG；有界结构检查后用实际File API、ImageBitmap、Canvas完整解码，透明内容明确合成白底。实际显示尺寸必须完全相同，边≤4096、像素≤4194304；不自动缩放、配准或猜测位移。Canvas解释源显示方向/色彩，不承诺跨引擎颜色相同。
- 固定本地模块Worker复制两份完整RGBA计算，运行15秒到期实际terminate。RGB最大通道绝对差严格大于整数容差0–255才为变化；最大差指标包含全图，面积统计另按屏蔽区划分。忽略矩形必须是图内整数半开范围，按并集统计，重叠不重复计数；完整JSON最多16KiB、20矩形。
- 四连通区域按上到下、左到右首次发现顺序编号。小于最少区域像素1–5000的块不标暖色，但完整原始/排除统计保留。超过5000个原始块时整份拒绝，在小区域过滤前检查，没有悄悄取前5000。变化比例分母是未屏蔽像素；全图屏蔽时比例null，不能报成100%相同。
- 热图的非计入变化像素显示淡灰新版，计入的像素按真实最大通道差显示暖色；标注图再绘制全部区域框/编号及忽略区灰虚框。区域是像素连通块，不代表UI元素，不提供OCR、语义结论或自动原因推断。临近编号可能重叠，精确坐标始终保留在完整报告。
- 两个PNG均完整编码并再次实际解码/检查尺寸，再展示全部预览。每PNG和完整报告≤2MiB，完整目录≤10MiB；任何失败整体拒绝，不保存部分图或截断区域。来源及结果不入配置，未上传，依赖私有结构检查代码和既有浏览器API，无运行时下载。
- 用户确认后通过生产copyOnly/WX接口保存。已有目录、文件或源PNG拒绝覆盖；只有 `ok===true` 报成功，取消/false/unknown/throw保留完整预览且明确反馈。设置修改废弃旧结果；取消、隐藏、离开、销毁终止线程/使票据失效、释放画布/来源RGBA，返回不自启。每次实际图片解码有5秒限制，异步收尾期间锁控件；目录哈希准备期间离开，不再提交迟到写入。

## 如何使用

1. 打开“界面截图差异定位”，一次选择两张截图；第一张旧版、第二张新版，检查完整源图及显示尺寸。
2. 设置RGB容差与最少区域像素。需要屏蔽区域时，在JSON填写如 `[{"x":0,"y":0,"width":110,"height":40}]`，坐标为实际图像像素。
3. 点击“比较并预览完整截图差异”，核对完整热图、编号标注、变化面积及全部区域报告。修改规则后须手动重算。
4. 勾选已核对全部预览，选择不存在的新目录保存两图和报告；也可独立另存完整JSON报告新文件。

## 使用后产出

新目录中的 `diff-heatmap.png`、`diff-annotated.png`、`screenshot-diff.json`。报告包含两份来源名称/字节/SHA/帧头与实际显示尺寸、完整规则/忽略矩形、原始变化/计入变化/被屏蔽变化/小区域计数、面积分母及比例、所有区域索引/边界/像素数、两图完整字节/SHA及计算定义。报告和图可能暴露界面内容/文件名，这不是脱敏工具。

## 具体使用例子

两张360×220截图中，“Save”按钮由(60,80)移动到(200,80)，按钮外框均60×30；左上时钟也更新。设置容差8、最少区域1、忽略矩形(0,0,110,40)：输出标出按钮新旧两处位置，排除4400个动态区域像素，比较分母74800，实际计入3572像素，每处1786。按钮文字有抗锯齿，部分像素与背景差≤8，所以不将外框3600像素误称为实际变化数。

改忽略规则为空数组再计算，时钟新增1553个变化像素，合计5125、三个区域。把容差改为255则计入变化0、完整区域数组为空；把整张图设为忽略矩形则分母0、比例null，保留全图忽略的明确状态。
