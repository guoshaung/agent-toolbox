# 科研优先路线图

这份路线图服务于 Agent Toolbox 的持续迭代。优先保证科研主链路稳定，再扩展语音、演示和数字人能力。

## P0 · 科研主链路

### 文献检索与入库

- 多来源检索结果统一去重，保留来源、匹配依据和开放全文状态。
- PDF 直链、DOI、arXiv 编号和普通标题分别走明确的识别路径。
- 下载任务支持失败原因、重试、暂停后继续和批量结果导出。
- 登录后的学校图书馆流程只执行用户有权限的正常下载，不绕过验证码、付费墙或权限控制。
- 搜索方向、筛选条件和最近检索保存在本机，便于复现实验性文献清单。

### 阅读与理解

- PDF、TXT、Markdown 统一记录阅读进度；重新打开文献时恢复上次位置。
- 打开文献自动标记为“阅读中”，读完可一键标记“已读”。
- 单词速查、划词翻译、圈译、双语对照、批注和问答都要明确显示结果位置。
- 翻译默认本地优先，模型调用必须显式触发并保留原文、译文和 provider 信息。
- 后续增加页面目录、阅读历史、批注检索和从批注回跳原文。

### 科研画图

- 继续优先修复连接线端点、曲线弯曲、箭头粗细、层级和导出一致性。
- 模板按论文结构扩展：方法流程、模型架构、实验管线、消融对比、系统总览。
- 画板数据与多页 PPT 数据保持可迁移，SVG 作为投稿级导出，PNG/JPG 作为分享导出。
- 素材库优先收录可追溯许可的原创或明确授权素材，并保存署名信息。

## P1 · 练习项目库（第二优化目标）

- 维持“项目挑战”入口，优先增加真实工作中会遇到的 mock 项目，而不是继续堆单行语法题。
- 项目按科研数据、AI 工程、后端、自动化、测试、Shell、Git 协作分类；每个项目包含目标、步骤、技能、多个可运行单元格。
- 项目运行必须继续使用临时沙箱；Python、Shell、Git 单元格可以复用前置上下文，但不能触碰用户真实项目。
- 后续增加项目评分、失败复盘、提交记录和“从失败状态重新开始”，不把答案直接塞给用户。

## P2 · 研究生产力扩展

### Voice Box

- 将现有本地语音输入容器接入工具箱，提供录音、转写、朗读和设备状态面板。
- 支持本地模型优先、可切换兼容 API，明确显示音频是否离开本机。
- 语音输入可直接进入文献问答、想法、任务和 PPT 大纲。

### PPT 生成

- 从文献摘要、批注或画板模板生成可编辑的多页大纲，而不是只生成一张图片。
- 每页保留标题、要点、图形对象、引用和讲稿字段。
- 先支持 PPTX/图片/Markdown 三种导出，生成前显示大纲供用户确认。

## P3 · 数字人与趣味工具

### 数字人

- 先做可替换的角色、头像、字幕和语音驱动层，不绑定单一厂商或模型。
- 数字人用于论文讲解、术语复述和 PPT 演示；默认不自动上传文献全文。

### 趣味工具

- 保留专注、火柴人战斗等低打扰模块，统一使用任务和学习数据作为可选输入。
- 趣味模块不能阻塞科研下载、PDF 阅读或画板编辑，也不能默认占用网络和麦克风。

## 质量门槛

- 每个科研功能至少有一条纯逻辑测试和一条失败路径验证。
- macOS、Windows 的路径、进程、快捷键和内嵌网页行为分别检查。
- 任何 AI、语音或外部网页能力都显示配置状态、数据去向和可恢复的错误信息。
