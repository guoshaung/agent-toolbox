# Agent 工具箱 0.47.5

这次把 0.46.16 之后的本地功能汇总为一个版本，包含额度中枢的跨设备配置向导、DSH 文本会话历史保留、上游模型显示，以及独立的快速翻译工具。此前尚未发布的 iPad 画板、系统美化、科研和学习工具改动也随同发布。

DSH 新安装使用的种子包内，DS Bot 更新到 0.2.1。该版本修复 Chief 换新会话时沿用上一段会话模型线路的问题。已经安装的 DSH profile 不会被种子包覆盖；其插件需要在原 profile 中单独更新。

`config-presets/personal-preferences.json` 保存当前侧栏布局、外观和少量工具偏好，可作为迁移参考。运行时的 `config.json` 含个人资料和加密凭证，不作为发布资源。密码箱使用系统安全存储加密；复制密文到另一台电脑不能直接恢复密码。安装更新时，应用继续使用原有 `userData`，不会覆盖本机密码箱和布局。

额度中枢的文本桥使用 OpenAI Chat Completions，只适合普通文本对话。Chief 等需要工具调用和较大上下文的 DS Bot，请在 Bot 设置中选择相应的完整模型服务。

经典 DSH 页面若选中 Chief / Dev 的原始 Session，会自动转到 DS Bot 对话页，避免把内部交接确认当成回复显示。

快问新增右侧阅读锁：开启后冻结自动追到底部的位置，J 下翻、K 上翻；⌘J（Windows 为 Ctrl+J）随时切换。锁旁可调每次翻页幅度，输入框内打字不受影响。
