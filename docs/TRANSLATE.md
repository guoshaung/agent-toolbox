# 独立翻译

入口：更多 → 学习科研 → 翻译；也可以用 ⌘K 搜「翻译」。

中英互译默认自动判断目标语言，支持显式选择中文或英文。短文本在输入停顿后翻译；超过 1,000 字时按「立即翻译」或 ⌘ Enter。可从剪贴板粘贴、复制译文、交换方向。状态栏显示这次翻译的实际耗时。

首版采用工具箱已接入的有道在线快译，单段最多 450 字，长文本最多 20,000 字，最多同时请求两段；成功路径没有人为等待。原文会发送给有道服务，界面明确提示；工具箱不保存独立翻译的原文或译文，也不使用 DSH 或额度中枢的模型额度。免费演示服务可能限流，限流或失败时如实显示错误。

2026-10-24 在本机短句实测约 47–177 毫秒、约 900 字双段约 178 毫秒；这是当前网络与服务状态的观察值，不保证所有文本或时间都一样。研究阅读的本地优先翻译保持原样。Chrome 内置 Translator API 要求 Chrome 138，而工具箱现用 Electron 33 内含 Chromium 130；本机 Apple Translation 中英语言包尚未安装，Argos Python 包也未安装，因此独立工具选用当前实际可用且响应最快的现有通道。
